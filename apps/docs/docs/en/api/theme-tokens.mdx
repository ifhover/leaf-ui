# Theme tokens

Prefer ConfigProvider's `theme.primaryColor`, `theme.borderRadius` and `theme.controlHeight` for everyday customization. Related styles derive automatically; see [theming](/en/guide/theming).

## LeafThemeTokens

Pass advanced overrides through `theme.tokens` only when a derived value needs to change independently. Every field is optional, and nested providers inherit unspecified fields. Numeric lengths use pixels; numeric durations use milliseconds.

## Type import

```tsx
import type { LeafThemeTokens } from '@ifhover/leaf-ui';

const tokens = {
  controlHeightSm: 28,
  borderRadiusLg: 14,
} satisfies LeafThemeTokens;
```

Pass this object to `<ConfigProvider theme={{ tokens }}>`.

## LeafComponentTokens

Style fields for `theme.components` overrides by component name. Check each component's documentation for the fields it supports.

| Property | Type | Description |
| --- | --- | --- |
| `borderRadius` | `string \| number` | Corner radius; numbers are pixels. |
| `controlHeight` | `string \| number` | Control height; numbers are pixels. |
| `padding` | `string \| number` | Content padding. |
| `gap` | `string \| number` | Space between children. |
| `fontSize` | `string \| number` | Font size; numbers are pixels. |
| `color` | `string` | Color or semantic color. |
| `background` | `string` | Component surface background. |
| `borderColor` | `string` | Outer borders and section dividers. |
| `headerBackground` | `string` | Header background. |
| `footerBackground` | `string` | Footer background. |
| `shadow` | `string` | CSS box-shadow value. |

## LeafThemeStyle

A React style type with `--leaf-*` custom properties. See [Theming](/en/guide/theming#use-the-theme-in-application-css) for consuming variables in application CSS.

| Property | Type | Description |
| --- | --- | --- |
| `` [key: `--leaf-${string}`] `` | `string \| number \| undefined` | Reusable CSS custom property. |
