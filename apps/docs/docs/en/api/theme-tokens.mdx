# Theme tokens

Prefer ConfigProvider's `theme.primaryColor`, `theme.borderRadius` and `theme.controlHeight` for everyday customization. Related styles derive automatically; see [theming](/en/guide/theming).

Default light base colors come from `colors.ts`: primary and success use `#1e964f`, danger uses `#dd3f2e`, warning uses `#d38b11`, and info uses `#1677ff`. Component styles and static palettes consume the same `--leaf-color-*` variables instead of redeclaring semantic colors.

## LeafThemeTokens

Pass advanced overrides through `theme.tokens` only when a derived value needs to change independently. Every field is optional, and nested providers inherit unspecified fields. Numeric lengths use pixels; numeric durations use milliseconds. For `lineHeight`, numbers greater than 0 and up to 4 keep the legacy multiplier meaning.

## Type import

```tsx
import type { LeafThemeTokens } from '@ifhover/leaf-ui';

const tokens = {
  controlHeightSm: 28,
  borderRadiusLg: 14,
} satisfies LeafThemeTokens;
```

Pass this object to `<ConfigProvider theme={{ tokens }}>`.

## LeafComponentStateTokens

States override only explicitly supplied appearance fields. Nested themes inherit each field without mutating the parent; `undefined` does not replace existing values. Disabled appearance takes precedence over hover, active and focus states. Native disabled behavior and visible keyboard focus feedback remains available.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | — | Text color in this state. |
| `background` | `string` | — | Background in this state. |
| `borderColor` | `string` | Border color in this state. | Border color in this state. |
| `shadow` | `string` | — | CSS box-shadow in this state. |
