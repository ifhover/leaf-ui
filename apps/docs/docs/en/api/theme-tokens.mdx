# Theme tokens

Prefer ConfigProvider's `theme.primaryColor`, `theme.borderRadius` and `theme.controlHeight` for everyday customization. Related styles derive automatically; see [theming](/en/guide/theming).

Default light base colors come from `colors.ts`: primary uses `#1e964f`, success uses `#52c41a`, danger uses `#ff4d4f`, warning uses `#faad14`, and info uses `#1677ff`. Component styles and static palettes consume the same `--leaf-color-*` variables instead of redeclaring semantic colors.

## Type import

```tsx
import type { LeafThemeTokens } from '@ifhover/leaf-ui';

const tokens = {
  controlHeightSm: 28,
  borderRadiusLg: 14,
} satisfies LeafThemeTokens;
```

Pass this object to `<ConfigProvider theme={{ tokens }}>`.

| `disabled` | [`LeafComponentStateTokens`](#leafcomponentstatetokens) | — | Disabled appearance overrides; disabled behavior is unchanged. |

Date, time and range pickers share the `DatePicker` field shell states. This includes `picker="time"`: use `DatePicker.focus` for the focused field and `DatePicker` for panel paint. `InputOTP` does not support all four state overrides. States affect the control regions listed here, without recursively restyling all child nodes.
