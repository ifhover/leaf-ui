# Component defaults

Use `components` on ConfigProvider to set shared default props. See [component defaults](/en/components/config-provider#component-defaults) for examples, naming rules and inheritance.

## Type import

```tsx
import type { LeafComponentDefaults } from '@ifhover/leaf-ui';

const components = {
  Button: { variant: 'outline' },
  Confirm: { confirmText: 'Continue', cancelText: 'Back' },
} satisfies LeafComponentDefaults;
```

Pass this object to `<ConfigProvider components={components}>`. Instance props and individual service calls still take precedence.
