# API reference

Complete configuration fields for applications that need more control. For everyday setup and runnable examples, start with [ConfigProvider](/en/components/config-provider).

## Configuration

| Reference | Purpose |
| --- | --- |
| [LeafComponentDefaults](./component-defaults#leafcomponentdefaults) | Supported component names and default props. |
| [LeafThemeTokens](./theme-tokens#leafthemetokens) | Advanced overrides for derived theme styles. |
| [PopupOptions](./popup-options#popupoptions) | Shared popup containers, placement and content customization. |
| [Translation resources](./translations) | Add languages, choose fallbacks and validate JSON. |

Each component page documents its own props, defaults and examples. The references here describe shared configuration.
