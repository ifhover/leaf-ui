# Tailwind CSS

Reuse Leaf UI colors, radii and spacing in Tailwind.

## Quick setup

For a project with Tailwind installed, choose the configuration for your version. Versions 3.x and 4.x are supported; upgrade first if you use 2.x or earlier.

### Tailwind CSS 4

Add one import to your CSS entry:

```css title="app.css"
@import 'tailwindcss';
@import '@ifhover/leaf-ui/tailwind.css';
```

<DocsCollapse title="Keep your existing base styles">

To omit Tailwind's Preflight reset, use this entry instead:

```css title="app.css"
@layer theme, base, components, utilities;
@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/utilities.css' layer(utilities);
@import '@ifhover/leaf-ui/tailwind.css';
```

</DocsCollapse>

### Tailwind CSS 3

Add the preset and adjust `content` to match your source directories:

```js title="tailwind.config.cjs"
const leafPreset = require('@ifhover/leaf-ui/tailwind').default;

module.exports = {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  presets: [leafPreset],
};
```

Keep the Tailwind 3 directives in your CSS entry:

```css title="app.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

For an existing configuration, append the preset and keep your source paths and plugins.

<DocsCollapse title="Use a TypeScript configuration (3.3+)">

```ts title="tailwind.config.ts"
import type { Config } from 'tailwindcss';
import leafPreset from '@ifhover/leaf-ui/tailwind';

export default {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  presets: [leafPreset],
} satisfies Config;
```

To disable Preflight, add `corePlugins: { preflight: false }` to the configuration.

</DocsCollapse>

## Usage tips

- **Opacity**: Tailwind 4 supports `bg-leaf-primary/50`. In Tailwind 3, these colors do not support `/50`, `bg-opacity-*` or `text-opacity-*`; define translucent colors in application CSS.
- **Source scanning**: Write complete class names such as `bg-leaf-primary` instead of constructing `bg-leaf-${color}`.
- **Base styles**: A CSS-only page with no Leaf UI component imports also needs `@ifhover/leaf-ui/styles.css`.
- **Breakpoints**: `sm:` and `md:` use your Tailwind configuration, independently of ConfigProvider breakpoints. Follow Tailwind 4's official browser support requirements.
- **Regions and overlays**: Custom Portal content needs the intended theme scope too. Leaf UI overlays synchronize themes automatically. Configure component-specific variables through [ConfigProvider](/en/guide/theming).
