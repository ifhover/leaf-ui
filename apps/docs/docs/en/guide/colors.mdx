# Colors

Each of the five semantic colors generates seven derived shades, while neutral keeps its nine-step scale. Light and dark modes share both.

## Global Color Variables

Each row shows an independently preserved base color and its derived band. The five semantic colors provide 35 derived swatches and neutral provides nine, for 44 in total. Select a swatch to see its value and CSS variable.

<ColorPalette />

## Change Base Colors

Configure the primary base with `theme.primaryColor`, and the other five with `theme.tokens`. Update these JS values through ConfigProvider to regenerate the scales; changing DOM styles does not trigger JS theme recalculation.

The example uses the light appearance and sets `tokens.mutedSurfaceColor` to `rgb(244,243,239)`. The Tabs track and the outer canvas of a layered Card share this surface, while inner Card content keeps the content surface. Explicit component overrides take precedence.

All `on*Color` values default to white. Set the corresponding value to `#000000` for black text and choose suitable foreground/background pairs for your application.
