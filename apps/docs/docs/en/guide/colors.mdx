# Colors

Each of the five semantic colors derives seven shade steps (`light-N` / `dark-N`) in JS, while neutral derives a nine-step OKLCH lightness scale. Global CSS exports only the active semantic and neutral usage roles computed from these bands, while light and dark modes switch the role mappings automatically. You can also set `theme.primaryColor` to `'neutral'` for adaptive high-contrast black/white primary styling.

## Color Scales & Shades

Each row shows an independently preserved base color and its derived band. The five semantic colors provide 35 derived swatches and neutral provides nine, for 44 in total. Select a swatch to see its step name and computed hex value (generated via `generateColorShades` and `generateColorScale`).

## Change Base Colors

Configure the primary base with `theme.primaryColor` (supporting hex strings or `'neutral'`), and the other five with `theme.tokens`. Update these JS values through ConfigProvider to regenerate colors; changing DOM styles does not trigger JS theme recalculation.

The example uses the light appearance and sets `tokens.mutedSurfaceColor` to `rgb(244,243,239)`. The outer canvas of a layered Card uses this surface, while inner Card content and clean controls keep the content surface. Explicit component overrides take precedence.

All `on*Color` values default to white. Set the corresponding value to `#000000` for black text and choose suitable foreground/background pairs for your application.
