# Introduction

Leaf UI is a lightweight React component library with a natural visual style. Start with its green theme, then adapt it to your product.

## Your own theme

Customize colors, radii, fonts and motion with CSS variables. Use [ConfigProvider](/en/components/config-provider) to give individual regions their own primary color, radius and language. Nested regions inherit omitted settings.

## Familiar React patterns

Components support React 18 and 19, controlled and uncontrolled values, standard HTML attributes and DOM refs. TypeScript declarations are included. [Form](/en/components/form) organizes labels and feedback while preserving normal form submission and FormData.

## Everyday components

Leaf UI includes buttons, text fields, selection controls, date and time pickers, forms, menus, dialogs and feedback. Explore the [component overview](/en/components/).

Keyboard interaction, visible focus, disabled states and reduced-motion preferences are supported. Built-in text supports Chinese and English; application labels remain under your control.

Start with [installation](/en/guide/installation) and [quick start](/en/guide/getting-started), or try the [theme playground](/en/guide/theming).
