# Introduction

<IntroductionHero>

A UI component library for React applications. Start with a natural green theme, then make room for your own brand and ideas.

</IntroductionHero>

## Why Leaf UI

<IntroductionFeatures>
  <IntroductionFeature icon="leaf" title="A natural starting point">

Quiet colors, comfortable corners, and clear interaction states keep the focus on your content. Ready to use, with room for your own design.

  </IntroductionFeature>
  <IntroductionFeature icon="palette" title="Your theme, your style">

Configure colors, radii, control heights, typography, and light or dark appearance with ConfigProvider. Nested themes, popups, and messages share the settings of their region.

  </IntroductionFeature>
  <IntroductionFeature icon="types" title="Familiar React patterns">

TypeScript declarations, native HTML attributes, and DOM refs are included. Use controlled or uncontrolled values, native form submission, and FormData.

  </IntroductionFeature>
  <IntroductionFeature icon="components" title="Everyday components, in sync">

Buttons, inputs, date pickers, tables, navigation, and feedback share consistent sizing and interaction rules. Use Lucide icons or pass your own icon nodes.

  </IntroductionFeature>
  <IntroductionFeature icon="languages" title="Ready for different languages">

Built-in locales, custom translations, language fallbacks, and RTL direction are supported. Configure component messages while keeping application titles and labels in your own translation system.

  </IntroductionFeature>
  <IntroductionFeature icon="keyboard" title="Thoughtful interactions">

Keyboard navigation, visible focus, disabled and loading states, and reduced-motion preferences are supported. Add an aria-label to icon-only buttons to give them an accessible name.

  </IntroductionFeature>
</IntroductionFeatures>

## Environment support

Supports **React 18 / 19**, **ESM / CommonJS**, and server-side rendering. We recommend the current or previous stable release of a modern browser.

<IntroductionBrowsers />

These are minimum support targets. See [browser compatibility](/en/guide/compatibility) for tested environments and fallbacks, or [server-side rendering](/en/guide/ssr) for Next.js, TanStack Start, and other frameworks.

## Start with one component

Install the library in an existing React project:

<PackageInstall>

```bash
npm install @ifhover/leaf-ui
```

```bash
yarn add @ifhover/leaf-ui
```

```bash
pnpm add @ifhover/leaf-ui
```

```bash
bun add @ifhover/leaf-ui
```

</PackageInstall>

Import a component and start using it. Browser builds load the required styles automatically; you do not need Sass. Try the button below:
