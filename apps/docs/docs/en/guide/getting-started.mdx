# Installation & quick start

Leaf UI supports React 18 and React 19. Install the package and import its styles to start using components in your application.

## Install the package

```bash
pnpm add @ifhover/leaf-ui
# or
npm install @ifhover/leaf-ui
# or
yarn add @ifhover/leaf-ui
```

React 18 or 19 and the matching React DOM version must be installed in your application. If needed, run `pnpm add react react-dom`. See the current release on [npm](https://www.npmjs.com/package/@ifhover/leaf-ui).

## Styles

Import the base stylesheet once in the application entry. It includes theme variables, shared popup styles and API services such as Confirm and Message:

```tsx
import '@ifhover/leaf-ui/styles.css';
```

Browser component entries load their styles automatically. No separate component CSS imports or Sass installation are needed. See [SSR usage](/en/guide/ssr) for Next.js and other frameworks.

The root entry is the recommended default. Vite and Rsbuild / Rspack production builds retain styles for named imports and their internal dependencies on demand; component subpaths are optional. Direct esbuild bundles retain CSS traversed through the root entry. In that case, use subpaths such as `@ifhover/leaf-ui/button` to reduce stylesheet size.
