# Installation & quick start

Leaf UI supports React 18 and React 19. Install the package to start using components; base and component styles load automatically.

## Install the package

Run this in your React project directory:

<PackageInstall>

```bash
npm install @ifhover/leaf-ui
```

```bash
yarn add @ifhover/leaf-ui
```

```bash
pnpm add @ifhover/leaf-ui
```

```bash
bun add @ifhover/leaf-ui
```

</PackageInstall>

React 18 or 19 and the matching React DOM version must be installed in your application. If needed, run `pnpm add react react-dom`. See the current release on [npm](https://www.npmjs.com/package/@ifhover/leaf-ui).

Browser component entries load theme variables, shared styles and the required component and service styles automatically. No manual CSS imports or Sass installation are needed. See [server-side rendering](/en/guide/ssr) for framework-specific setup in Next.js, TanStack Start and other frameworks.

Examples use Flex, Space, Grid and FormField for layout. Tailwind CSS is not required.

## Use a component

Import components directly from `@ifhover/leaf-ui` and add content and events:

<ComponentExample title="Your first button" preview={<GettingStartedExample />} fileName="getting-started.tsx">

```tsx lineNumbers file="../../../src/examples/en/guide/getting-started.tsx"
```

</ComponentExample>

The root entry is the recommended default. Vite and Rsbuild / Rspack production builds retain styles for named imports and their internal dependencies on demand; component subpaths are optional. Direct esbuild bundles retain CSS traversed through the root entry. In that case, use subpaths such as `@ifhover/leaf-ui/button` to reduce stylesheet size.
