# Browser compatibility

Use the current or previous stable release of Chrome, Edge, Firefox or Safari.

## Minimum versions

| Browser | Minimum version |
| --- | --- |

These versions are Leaf UI's minimum support targets, not a claim that every version has been tested. IE, legacy Edge (EdgeHTML) and older WebViews are outside the supported range.

## Features and fallbacks

| Capability | Implementation and fallback |
| --- | --- |
| Derived colors | JavaScript emits concrete color variables; static palettes support initial rendering and standalone CSS |
| Background blur | Standard and WebKit-prefixed filters; unsupported filters use a darker translucent mask; disable with `maskBlur={false}` |
| Entrance motion | Keyframes fade the mask; without `@starting-style`, some content appears immediately and remains usable |
| Web Animations | Layout updates immediately when `Element.animate` is unavailable |
| ResizeObserver | Optional observers are guarded; window resize continues to measure layouts. Third-party virtualization requires modern browsers |
| IntersectionObserver | Infinite scrolling offers a manual load button |
| Reduced motion | System preferences and `theme.motion={false}` are honored |
| Forced colors | Keyboard focus and native selection indicators remain visible; text and ARIA communicate status |

```tsx
<ConfigProvider maskBlur={false} theme={{ primaryColor: '#635bff', appearance: 'dark' }}>
  <App />
</ConfigProvider>
```

Configure colors through `theme` and `tokens`. Solid foregrounds default to white and can be set to black through `on*Color`. CSS expressions are preserved, not resolved after mounting or synchronized from class/style changes.

## Validation coverage

Compatibility targets and automated coverage do not guarantee every device. Automation uses Chromium, Firefox and WebKit and checks React 18/19, SSR and package exports. WebKit does not replace testing on physical Safari/iOS devices; validate your application on its target devices.
