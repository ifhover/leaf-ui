## Usage

items presents events with individual colors and icons. mode controls alignment, reverse flips the order, and pending indicates an event is still in progress.

## Types

Import these types for data, callbacks and refs.

```ts
import type { TimelineItem, TimelineProps } from '@ifhover/leaf-ui';
```

## TimelineItem API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique stable identifier |
| `label` | `ReactNode` | — | Display label |
| `children` | `ReactNode` | Required | Timeline content. |
| `dot` | `ReactNode` | — | Custom timeline dot |
| `color` | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| (string & {})` | — | Color; `error` is a compatibility alias |

## TimelineProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | [`readonly TimelineItem[]`](#timelineitem-api) | Required | Items; keep keys unique and stable |
| `mode` | `'left' \| 'right' \| 'alternate'` | `'left'` | Timeline layout: left, right or alternating. |
| `reverse` | `boolean` | `false` | Reverse order |
| `pending` | `ReactNode` | — | Pending content |
