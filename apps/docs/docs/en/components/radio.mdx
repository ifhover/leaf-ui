#### Forms and reset

Set `name` to submit the selected option's `value`. Unselected and disabled options are not submitted. When composing individual `Radio` controls, use the same `name` and unique values for each group.

Uncontrolled groups return to `defaultValue` on form reset. For controlled groups, reset application state as well.

## API

### Radio API

Configure selection, submission value and disabled state for an individual radio.

Individual `Radio` controls support native radio attributes. `className` and `style` apply to the label container.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `variant` | `'plain' \| 'card'` | `'plain'` | Plain choice or a card with a full clickable surface. |
| `description` | `ReactNode` | — | Supporting text below the option. |
| `icon` | `ReactNode` | — | Leading icon content for the option. |
| `extra` | `ReactNode` | — | Supplementary status or tags; avoid interactive controls. |
| `checked` | `boolean` | — | Controlled checked state. |
| `defaultChecked` | `boolean` | — | Initial checked state for uncontrolled usage. |
| `value` | `string \| number \| readonly string[]` | — | The value submitted by this radio, not its checked state; use checked for selection. |
| `name` | `string` | — | Field name in native FormData. |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Read the selected value from event.target.value. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `required` | `boolean` | `false` | Require a selection among radios with the same name. |
| `children` | `ReactNode` | — | Clickable choice label. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

### RadioGroup API

Manage the selected value and layout of a group of radio options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly `[`RadioOption`](#radiooption)`[]` | Required | Options |
| `value` | `string` | — | Controlled selected value; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `string` | — | Initial selected value for uncontrolled usage; native form reset is supported. |
| `name` | `string` | Generated | Shared field name; specify it for form submission |
| `label` | `ReactNode` | — | Group name |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `variant` | `'plain' \| 'card' \| 'list'` | `'plain'` | Plain choices, a card grid or a list with shared borders and dividers. |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Read event.target.value |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `ref` | `Ref<HTMLFieldSetElement>` | — | DOM reference |

### RadioOption

One group option containing its submission value and displayed content.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | Required | Visible option content. |
| `description` | `ReactNode` | — | Supporting text below the option. |
| `icon` | `ReactNode` | — | Leading icon content for the option. |
| `extra` | `ReactNode` | — | Supplementary status or tags; avoid interactive controls. |
| `value` | `string` | Required | Option value; unique within the group. |
| `disabled` | `boolean` | `false` | Disable the option. |
