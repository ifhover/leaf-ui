## API

### Select API

Select component props.

Use `name`, `required`, `form` and uncontrolled reset behavior for [forms](form). Other native input props and `aria-*` reach the input; `className` and `style` apply to the outer container. See [PopupOptions](../api/popup-options) for shared popup settings.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly (`[`SelectOption`](#selectoption)` \| `[`SelectOptionGroup`](#selectoptiongroup-api)`)[]` | Required | Options |
| `value` | `string \| readonly string[]` | — | Controlled value; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `string \| readonly string[]` | `multiple ? [] : ''` | Initial uncontrolled value; defaults to an empty string in single mode or an empty array in multiple mode, restored on form reset. |
| `onChange` | `((value: string, option?: `[`SelectOption`](#selectoption)`) => void) \| ((value: string[], options: `[`SelectOption`](#selectoption)`[]) => void)` | — | Single mode returns the value and option, or an empty string and undefined when cleared; multiple mode returns value and option arrays, both empty when cleared. |
| `multiple` | `false \| true` | `false` | Use arrays for multiple values; default [] |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `allowClear` | `boolean` | `false` | Show a clear button |
| `showSearch` | `boolean` | `false` | Allow typing to filter options |
| `filterOption` | `boolean \| ((query: string, option: `[`SelectOption`](#selectoption)`) => boolean)` | `true` | Custom filtering; false supports external filtering |
| `onSearch` | `(query: string) => void` | — | Search text changes |
| `loading` | `boolean` | `false` | Loading indicator |
| `notFoundContent` | `ReactNode` | — | Content when no options match |
| `maxCount` | `number` | — | Maximum selections; selected items remain removable |
| `maxTagCount` | `number \| 'responsive'` | — | Maximum visible tags; responsive collapses them to the available width. |
| `tagWrap` | `boolean` | `true` | Allow selected tags to wrap; false keeps one line and collapses overflow. |
| `allowCreate` | `boolean` | `false` | Allow selecting a new option unless the query exactly matches an existing value or search text; also enables search. |
| `onCreate` | `(option: `[`SelectOption`](#selectoption)`) => void` | — | Called with a newly selected option; it is kept internally, while the application updates options for persistence. |
| `labelRender` | `(option: `[`SelectOption`](#selectoption)`) => ReactNode` | — | Customize the selected value. |
| `optionRender` | `(option: `[`SelectOption`](#selectoption)`) => ReactNode` | — | Custom option content |
| `tagRender` | `(option: `[`SelectOption`](#selectoption)`, remove: () => void) => ReactNode` | — | Customize selected tags; use remove to request removal. |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Option panel open-state changes |
| `inputReadOnly` | `boolean` | — | Disable typing while retaining panel selection. |
| `virtual` | `boolean` | More than 100 options | Render visible items only |
| `listHeight` | `number` | `248` | List height |
| `optionHeight` | `number` | Theme and density dependent | Estimated virtual row height, calculated from the theme and density by default; actual rows are measured. |
| `popupWidth` | `number \| string` | `'trigger'` | Popup width; trigger matches the trigger, auto fits content (and may be narrower), numbers specify fixed pixels; CSS lengths are also supported. |
| `popupMaxWidth` | `number \| string` | — | Optional maximum popup width; no additional limit when unset, still bounded by the viewport. |
| `onPopupScroll` | `(event: React.UIEvent<HTMLDivElement>) => void` | — | Popup scroll event, useful for loading another page. |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Popup styling |
| `popupStyle` | `CSSProperties` | — | Popup styling |
| `popupRender` | `(content: ReactNode) => ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

### SelectOption

An option passed through options; value identifies the option.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Unique option value; empty strings are reserved. |
| `label` | `ReactNode` | Required | Option content, as text or a React node. |
| `disabled` | `boolean` | `false` | Disable the option. |
| `searchLabel` | `string` | — | Plain search text; defaults to a string or numeric label, otherwise value. |

### SelectOptionGroup API

A labeled group containing Select options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | Required | Visible label or content. |
| `options` | `readonly `[`SelectOption`](#selectoption)`[]` | Required | Available options. |
