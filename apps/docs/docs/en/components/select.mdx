# Select

Choose one or several options from a dropdown list. Opening the popup deepens the existing neutral border without a theme-colored outer ring. Selected options use a gray background, ordinary text and a checkmark.

## Basic selection

Use options with unique nonempty string values. onChange returns the value and option; clearing returns an empty string and undefined. Arrow keys highlight options, Enter selects, Escape closes and Tab moves on.

## Single-line selections

Set `tagWrap={false}` to keep selected values on one line. Long labels truncate; extra values collapse into `+N`. In very narrow controls, only the count is shown. Open the popup to review or change selections. `maxTagCount` can further limit the visible tags; `maxTagCount="responsive"` also enables automatic single-line collapsing.

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.

In multiple mode, clearing returns []. FormData submits repeated values under the same name; read them with `formData.getAll(name)`. Empty-query Backspace removes the last enabled tag. Leaving clears the query; searches never create values. For node labels, supply searchLabel. The ref and other input attributes target the input.

The field keeps its layout width. The popup matches it by default (`popupWidth="trigger"`). Set `popupWidth="auto"` to size the popup solely from its option content, which may be narrower than the field. Use `popupWidth={300}` for a fixed 300px width or pass a CSS length. `popupMaxWidth` is unset by default and can be supplied when needed. All width modes remain bounded by the available viewport width; content wraps when it exceeds the actual popup width.

Options have no extra vertical gaps. A normal row matches the Select height (34px comfortable, 30px compact), while long labels wrap and grow as needed. Changing the selected value updates the label immediately without an inside-text movement animation.
