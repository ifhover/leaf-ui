Show the current page within a navigation hierarchy.

## API

### Breadcrumb API

Configuration for path levels, separators and collapsing intermediate entries.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`BreadcrumbItem`](#breadcrumbitem)`[]` | Required | Path items |
| `separator` | `ReactNode` | ChevronRight | Separator |
| `maxItems` | `number` | `Infinity` | Collapse middle entries above this count; the minimum threshold is 3 and entries do not collapse by default. |
| `itemsBeforeCollapse` | `number` | `1` | Leading items retained after collapse. |
| `itemsAfterCollapse` | `number` | `1` | Trailing items retained after collapse. |
| `itemRender` | `(item: `[`BreadcrumbItem`](#breadcrumbitem)`, index: number) => ReactNode` | — | Customize item content. |
| `aria-label` | `string` | Locale default | Navigation label |

### BreadcrumbItem

A path level defined through `items`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable identifier |
| `title` | `ReactNode` | Required | Page title |
| `icon` | `ReactNode` | — | Leading icon |
| `menu` | `readonly `[`DropdownItem`](dropdown#dropdownitem)`[]` | — | Dropdown items for a breadcrumb. |
| `href` | `string` | — | Link destination. |
| `target` | `string` | — | Link target, following the native anchor target attribute. |
