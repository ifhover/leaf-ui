## Breadcrumb API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`BreadcrumbItem`](#breadcrumbitem)`[]` | Required | Required. Path items |
| `separator` | `ReactNode` | ChevronRight | Separator |
| `maxItems` | `number` | — | Maximum items before collapsing a path. |
| `itemsBeforeCollapse` | `number` | `1` | Leading items retained after collapse. |
| `itemsAfterCollapse` | `number` | `1` | Trailing items retained after collapse. |
| `itemRender` | `(item: `[`BreadcrumbItem`](#breadcrumbitem)`, index: number) => ReactNode` | — | Customize item content. |
| `aria-label` | `string` | Locale default | Navigation label |

## BreadcrumbItem

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable identifier |
| `title` | `ReactNode` | Required | Required. Page title |
| `icon` | `ReactNode` | — | Leading icon |
| `menu` | `readonly `[`DropdownItem`](../components/dropdown#dropdownitem)`[]` | — | Dropdown items for a breadcrumb. |
| `href` | `string` | — | Link destination. |
| `target` | `string` | — | Target selector or element getter; omit to center the step. |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { BreadcrumbProps, BreadcrumbItem } from '@sudden3/leaf-ui';
```

## Usage notes

The final item is marked as the current page. BreadcrumbItem accepts native anchor attributes. A router Link can be passed as title; omitting href avoids an additional anchor.
