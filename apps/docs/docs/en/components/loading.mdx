## Loading API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `spinning` | `boolean` | `true` | Whether loading |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Indicator size |
| `tip` | `ReactNode` | — | Hint text |
| `delay` | `number` | `0` | Display delay in milliseconds |
| `children` | `ReactNode` | — | Covered content |


## Types

Import these types to define props or prepare data.

```ts
import type { LoadingProps } from '@sudden3/leaf-ui';
```

## Usage notes

Used alone, Loading displays an indicator. With children it covers the area and prevents interaction while visible. A delay prevents flicker for brief requests.
