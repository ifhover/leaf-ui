## Loading API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `spinning` | `boolean` | `true` | Whether loading is active |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Spinner size |
| `tip` | `ReactNode` | — | Loading message |
| `delay` | `number` | `0` | Delay before displaying, in milliseconds |
| `children` | `ReactNode` | — | Content covered during loading |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { LoadingProps } from '@sudden3/leaf-ui';
```

## Usage notes

Use alone for a spinner, or pass children to cover a content region and block interaction while the overlay is visible. delay avoids flashes for short requests. The cursor keeps its normal appearance.
