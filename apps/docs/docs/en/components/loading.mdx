### Delayed display

The indicator appears only if `spinning` is still `true` after `delay` milliseconds. Ending loading before then leaves it hidden.

`delay` does not delay your request or block interaction during the wait. Disable actions separately if they must be unavailable immediately.

## API

### Loading API

Props for loading state, status content and delayed display.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `spinning` | `boolean` | `true` | Whether loading |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Indicator size |
| `tip` | `ReactNode` | — | Hint text |
| `delay` | `number` | `0` | Display delay in milliseconds |
| `children` | `ReactNode` | — | Content covered by the loading overlay. |
