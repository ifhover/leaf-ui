# Anchor

Use Anchor to navigate page sections and Affix to keep an action visible while scrolling.

{/* leaf:section basic */}

## Basic usage

Each item's `href` points to a section element's `id`. Set `container` to use a scroll area; omit it to use the window.

Same-page navigation updates the URL and history and moves focus to the destination. Modified clicks and external links retain native navigation.

## API

### Anchor API

Configuration for directory entries, scroll positioning and the active section.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`AnchorItem`](#anchoritem)`[]` | Required | Items to display. |
| `container` | `() => HTMLElement \| Window` | — | Return the scroll container; defaults to window. |
| `offset` | `number` | `12` | Scroll-target distance from the container top in pixels. |
| `activeKey` | `string` | — | Controlled active section. |
| `onActiveChange` | `(key: string) => void` | — | Called when the active section changes. |
| `smooth` | `boolean` | `true` | Enable smooth scrolling, respecting reduced motion. |

### AnchorItem

An entry supplied through `items`, defining its target anchor, title and children.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Stable, unique identifier. |
| `title` | `ReactNode` | Required | Title content. |
| `href` | `string` | Required | Link destination. |
| `children` | `readonly `[`AnchorItem`](#anchoritem)`[]` | — | Anchor entries. |

### Affix API

Props for fixing content within a specified scroll container.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `offsetTop` | `number` | `0` | Distance from the container top in pixels. |
| `offsetBottom` | `number` | — | Distance from the container bottom in pixels. |
| `container` | `() => HTMLElement \| Window` | — | Return the scroll container; defaults to window. |
| `onAffixChange` | `(affixed: boolean) => void` | — | Called when the affixed state changes. |
