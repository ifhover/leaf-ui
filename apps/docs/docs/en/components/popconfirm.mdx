## Usage

onConfirm can return a Promise. Pending operations display loading and prevent duplicate submissions. The popup closes on success and stays open on failure; use onError for feedback. The trigger must accept a ref and button interactions.

## Types

Import these types for data, callbacks and refs.

```ts
import type { PopconfirmProps, ButtonProps } from '@ifhover/leaf-ui';
```

## PopconfirmProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `children` | `ReactElement< HTMLAttributes<HTMLElement> & { ref?: Ref<HTMLElement>; disabled?: boolean } >` | Required | Required. Element that triggers the confirmation. |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | `'top'` | Placement |
| `open` | `boolean` | — | Controlled visibility |
| `defaultOpen` | `boolean` | `false` | Initial visibility |
| `onOpenChange` | `(open: boolean) => void` | — | Open state changes |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `enterDelay` | `number` | `100` | Pointer opening delay in milliseconds |
| `leaveDelay` | `number` | `100` | Pointer closing delay in milliseconds |
| `width` | `number \| string` | `'max-content'` | Width, numbers are in pixels |
| `maxWidth` | `number \| string` | `320` | Maximum popup width |
| `className` | `string` | — | Container class name |
| `style` | `CSSProperties` | — | Container inline styles |
| `aria-label` | `string` | — | Accessible name when no visible label is provided |
| `title` | `ReactNode` | Required | Required. Title content |
| `description` | `ReactNode` | — | Supporting description |
| `type` | `'success' \| 'info' \| 'warning' \| 'danger' \| 'default'` | `'warning'` | Confirmation status style; `error` is a compatibility alias. |
| `icon` | `ReactNode` | — | Custom icon |
| `confirmText` | `ReactNode` | — | Confirm button content |
| `cancelText` | `ReactNode` | — | Cancel button content |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | Confirm button props |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | Cancel button props |
| `showCancel` | `boolean` | `true` | Show cancel button |
| `onConfirm` | `() => void \| Promise<void>` | — | Confirm action; supports async completion |
| `onCancel` | `() => void` | — | Cancel action |
| `onError` | `(error: unknown) => void` | — | Error callback |
