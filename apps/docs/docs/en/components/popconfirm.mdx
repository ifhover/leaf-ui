# Popconfirm

Confirm a simple action beside its trigger. Use [Confirm](/en/components/confirm) for decisions requiring detail, or [Modal](/en/components/modal) for editing.

{/* leaf:section basic */}

## Basic usage

## Examples

### Asynchronous confirmation

`onConfirm` may return a Promise. While pending, loading is shown and cancel is disabled. Repeated confirmation, outside clicks and Escape do not interrupt the action; success closes the popup. In controlled mode, the application can still change `open`.

### Failure and retry

Failure keeps the popup open and shows a built-in error message. Confirm again to retry. Use `onError` for additional application feedback; this example fails on its first attempt and succeeds on retry.

## API

### PopconfirmProps API

Configure confirmation content, triggers and confirmation actions.

The trigger must support a ref and button interaction. See [Button](button#button-api) for confirmation and cancel button options, and [PopupOptions](/en/api/popup-options) for shared popup options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Title content |
| `description` | `ReactNode` | — | Supporting description |
| `children` | `ReactElement< HTMLAttributes<HTMLElement> & { ref?: Ref<HTMLElement>; disabled?: boolean } >` | Required | Element that triggers the confirmation. |
| `onConfirm` | `() => void \| Promise<void>` | — | Confirmation action, optionally returning a Promise; success closes the panel, failure keeps it open with built-in retry feedback. |
| `onCancel` | `() => void` | — | Cancel action |
| `onError` | `(error: unknown) => void` | — | Called after confirmation fails to provide additional application feedback; built-in error feedback remains visible. |
| `type` | `FeedbackType \| 'error' \| 'default'` | `'warning'` | Confirmation status style; `error` is a compatibility alias. |
| `icon` | `ReactNode` | — | Custom icon |
| `confirmText` | `ReactNode` | — | Confirm button content |
| `cancelText` | `ReactNode` | — | Cancel button content |
| `showCancel` | `boolean` | `true` | Show cancel button |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | Confirm button props |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | Cancel button props |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `open` | `boolean` | — | Controlled visibility |
| `defaultOpen` | `boolean` | `false` | Initial visibility |
| `onOpenChange` | `(open: boolean) => void` | — | Open state changes |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | `'top'` | Placement |
| `aria-label` | `string` | — | Accessible name of the confirmation panel; defaults to a string title or the localized confirmation label. |
| `width` | `number \| string` | `'max-content'` | Width, numbers are in pixels |
| `maxWidth` | `number \| string` | `320` | Maximum popup width |
| `enterDelay` | `number` | `100` | Pointer opening delay in milliseconds |
| `leaveDelay` | `number` | `100` | Pointer closing delay in milliseconds |
| `className` | `string` | — | Container class name |
| `style` | `CSSProperties` | — | Container inline styles |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |

### ButtonProps API

See [Button API](button#button-api) for button properties.
