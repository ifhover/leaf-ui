## Steps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`StepItem`](#stepitem)`[]` | Required | Required. Step items |
| `current` | `number` | `0` | Current step index, starting at 0 |
| `status` | `'process' \| 'finish' \| 'error'` | `'process'` | Current step status |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Step size |
| `loading` | `boolean` | `false` | Show a spinner for the current step |
| `onChange` | `(current: number) => void` | — | Makes steps selectable |
| `progressDot` | `boolean \| ((dot: ReactNode, info: { index: number; status: string }) => ReactNode)` | — | Use progress dots, optionally with custom content. |
| `percent` | `number` | — | Completion percentage. |

## StepItem

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable identifier |
| `title` | `ReactNode` | Required | Required. Step title |
| `description` | `ReactNode` | — | Supporting description |
| `icon` | `ReactNode` | — | Custom icon |
| `status` | `'wait' \| 'process' \| 'finish' \| 'error'` | — | Override the item status |
| `disabled` | `boolean` | `false` | Disable interaction. |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { StepsProps, StepItem } from '@sudden3/leaf-ui';
```

## Usage notes

Keep current in application state. onChange reports the selected index. Item statuses are derived from current unless explicitly supplied.
