# Icons

Add icons to actions and fields with the component's icon slots.

## Install and import

The examples use [Lucide](https://lucide.dev/icons/). Add the package as an application dependency when importing icons directly. Other React icon libraries can also be used: the slots accept `ReactNode`.

```bash
pnpm add lucide-react
```

## Button icons

Use `startIcon` or `endIcon` for an icon beside text. Icon-only buttons require an accessible name such as `aria-label="Add project"`.

## Input icons

Use `prefix` and `suffix` for input icons. Decorative icons do not replace a field label; use FormField to associate the name with the input.

Icons inherit the component's text color. Do not hardcode icon colors to reproduce button states.
