### Controlled value and completion

`onChange` reports each value change: a number for a single value or a tuple for a range. `onChangeComplete` runs after an interaction that changed the value, for example to save the final value. Reset controlled fields by also restoring `value` in application state.

#### Forms and keyboard

Set `name` for native form submission. A range submits two values under the same name; read them with `FormData.getAll`. Uncontrolled fields restore their initial value on form reset. See [Form](/en/components/form) for form integration.

Arrow keys move by one step, Home / End go to the bounds, and Shift + arrows or PageUp / PageDown move ten steps. Discrete mode moves between adjacent marks.

## API

### Slider API

Configure a value or range, numeric bounds and slider interaction.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `min` | `number` | `0` | Lower bound, 0 by default. |
| `max` | `number` | `100` | Upper bound, 100 by default. |
| `step` | `number \| null` | `1` | Increment per adjustment; null restricts selection to marks. |
| `marks` | `readonly `[`SliderMark`](#slidermark)`[]` | `[]` | Marks |
| `vertical` | `boolean` | `false` | Use a vertical layout |
| `showValue` | `boolean` | `false` | Show the value above the rail on hover or focus; hidden by default |
| `onChangeComplete` | `(value: number \| readonly [number, number]) => void` | — | Called after an interaction that changed the value; returns a number or a range tuple. |
| `tooltip` | `boolean \| { formatter?: (value: number) => ReactNode }` | `false` | Show a thumb tooltip, optionally with custom formatting. |
| `range` | `false \| true` | `false` | Range selection |
| `value` | `number \| readonly [number, number]` | — | Controlled value. |
| `defaultValue` | `number \| readonly [number, number]` | `range ? [min, max] : min` | Initial uncontrolled value; defaults to min, or [min, max] in range mode. |
| `onChange` | `((value: number) => void) \| ((value: [number, number]) => void)` | — | Value changes; callback follows range mode |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Lock the value against typing, selection, clearing and removal. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |

### SliderMark

Display a mark and label at a specific numeric position.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | Required | Mark value. |
| `label` | `ReactNode` | — | Visible mark label. |
