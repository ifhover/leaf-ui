## API

### SpaceProps API

Configure the direction, spacing and separators of child content.

Native `div` attributes and DOM refs are supported. Explicit `style` takes precedence over layout props.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction of the items. |
| `size` | `'sm' \| 'md' \| 'lg' \| number \| readonly [number, number]` | `'md'` | Space between children; numbers are pixels and tuples are [row gap, column gap]. |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'center'` | Alignment |
| `wrap` | `boolean` | `false` | Wrap as needed |
| `split` | `ReactNode` | — | Decorative content between items; do not place interactive controls here. |
