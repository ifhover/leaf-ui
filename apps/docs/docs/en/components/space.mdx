## Usage

Set size to a preset, pixel value or [vertical, horizontal] gap. Enable wrap for wrapping, and use split to insert separators between items.

## Types

Import these types for data, callbacks and refs.

```ts
import type { SpaceProps } from '@sudden3/leaf-ui';
```

## SpaceProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout or movement direction |
| `size` | `'sm' \| 'md' \| 'lg' \| number \| readonly [number, number]` | `'md'` | Size or spacing preset |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'center'` | Alignment |
| `wrap` | `boolean` | `false` | Wrap as needed |
| `split` | `ReactNode` | — | Separator between elements |
