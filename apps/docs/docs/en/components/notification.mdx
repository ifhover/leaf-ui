# Notification

Present detailed feedback or follow-up actions in a page corner. Use [Message](/en/components/message) for brief feedback.

{/* leaf:section basic */}

## Basic usage

Wrap the application in [ConfigProvider](/en/components/config-provider), then call `useNotification()` in a child component. Applications already using it need no additional provider.

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## API

### NotificationProps API

For declarative rendering, handle `onClose` by setting `open` to `false`. `afterClose` runs after the exit animation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Controlled visibility |
| `title` | `ReactNode` | Required | Title content |
| `description` | `ReactNode` | — | Supporting description |
| `type` | `FeedbackType \| 'error'` | `'info'` | Notification status style; `error` is a compatibility alias. |
| `actions` | `ReactNode` | — | Follow-up actions; the application performs the work and closes this notification by its key. |
| `duration` | `number` | `4.5` | Seconds before automatic closing; zero or negative values keep it open. Hover or focus pauses the remaining time. |
| `placement` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | Placement |
| `closable` | `boolean` | `true` | Show close action |
| `onClose` | `() => void` | — | Called when closing is requested; declarative Notification requires the application to set open to false. |
| `afterClose` | `() => void` | — | Called after the closing animation and content unmount; does not replace updating controlled state in onClose. |
| `icon` | `ReactNode` | — | Custom icon |

### NotificationApi API

`useNotification()` returns this API directly. Nested `ConfigProvider` regions share a queue; each notification uses the theme and language of its calling component. Notifications remain after that component unmounts, but unmounting the entry provider clears them and their timers.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `(options: `[`NotificationOptions`](#notificationoptions-api)`) => string` | Required | Open or replace a notification by key, returning its key. |
| `success` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | Required | Show success |
| `info` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | Required | Show information |
| `warning` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | Required | Show warning |
| `danger` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | Required | Show a danger notification; `error` remains as a compatibility method |
| `error` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | Required | Content displayed instead of data rows after a request failure. |
| `close` | `(key?: string) => void` | Required | Close a key; omitting it closes every notification in the same Provider, not only this caller's notifications. |

### NotificationOptions API

Timers pause while the pointer or focus is inside a notification, then resume with the remaining duration.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Title content |
| `description` | `ReactNode` | — | Supporting description |
| `type` | `FeedbackType \| 'error'` | `'info'` | Notification status style; `error` is a compatibility alias. |
| `actions` | `ReactNode` | — | Follow-up actions; the application performs the work and closes this notification by its key. |
| `duration` | `number` | `4.5` | Seconds before automatic closing; zero or negative values keep it open. Hover or focus pauses the remaining time. |
| `placement` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | Placement |
| `closable` | `boolean` | `true` | Show close action |
| `key` | `string` | Generated | Unique key within a Provider; opening the same key replaces that notification and restarts its dismissal timer instead of appending. |
| `onClose` | `() => void` | — | Called when closing is requested; declarative Notification requires the application to set open to false. |
| `icon` | `ReactNode` | — | Custom icon |

### NotificationProviderProps API

Use `NotificationProvider` instead of `ConfigProvider` for standalone notifications, or add it explicitly to create an independent queue. `maxCount` applies across all placements; exceeding it closes the oldest notifications. Set it when mounting the provider; changing it later does not reconfigure the queue.

```tsx
import { NotificationProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <NotificationProvider maxCount={3}><App /></NotificationProvider>;
}
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Contents sharing this independent notification queue; ConfigProvider already supplies one, reused by nested ConfigProviders. |
| `maxCount` | `number` | `5` | Maximum visible notifications in this queue, set on mount; exceeding it closes the oldest notifications. |
