## Usage

Persist editable strokes with value / onChange. ref.export() returns PNG, JPEG or SVG Blobs. Uses the device pixel ratio and preserves strokes across resize. Provide an alternative for users who cannot draw.

## Types

Import these types for data, callbacks and refs.

```ts
import type { SignaturePadHandle, SignaturePadProps, SignaturePoint, SignatureStroke } from '@sudden3/leaf-ui';
```

## SignaturePadHandle API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `clear` | `() => void` | Required | Clear strokes |
| `undo` | `() => void` | Required | Undo last stroke |
| `isEmpty` | `() => boolean` | Required | Whether the pad is empty |
| `getData` | [`() => SignatureStroke[]`](#signaturestroke-api) | Required | Get editable strokes |
| `export` | `(type?: 'image/png' \| 'image/jpeg' \| 'image/svg+xml') => Promise<Blob>` | Required | Export as Blob |

## SignaturePadProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | [`readonly SignatureStroke[]`](#signaturestroke-api) | — | Controlled value |
| `defaultValue` | [`readonly SignatureStroke[]`](#signaturestroke-api) | `[]` | Initial strokes in uncontrolled mode |
| `onChange` | [`(strokes: SignatureStroke[]) => void`](#signaturestroke-api) | — | Value change callback |
| `onError` | `(error: Error) => void` | — | Error callback |
| `penColor` | `string` | `'#203329'` | Stroke color |
| `backgroundColor` | `string` | `'#ffffff'` | Background color |
| `minWidth` | `number` | `0.5` | Minimum stroke width |
| `maxWidth` | `number` | `2.5` | Maximum stroke width |
| `height` | `number` | `220` | Height, numbers are in pixels |
| `disabled` | `boolean` | `false` | Disable interactions |
| `controls` | `boolean` | `true` | Show controls |

## SignaturePoint API

| Property | Type | Default | Description |

| `y` | `number` | Required | Y coordinate |

| Property | Type | Default | Description |
