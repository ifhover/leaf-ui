# useImagePreview

Open a single image or a gallery from an event handler. Use native `img` elements for inline images; no image trigger component is required.

{/* leaf:section basic */}

## Basic usage

Call `useImagePreview()` inside [ConfigProvider](./config-provider). Without ConfigProvider, wrap the caller in `ImagePreviewProvider`. `preview` accepts a URL, an image object, or an array of either.

Example images live in the documentation site's `public/media/` directory. `withBase` only handles the documentation deployment path; replace these URLs with your own image paths in an application.

## Examples

### Galleries and downloads

Set a zero-based `index` to choose the initial image. `downloadable` enables downloading; individual images can use `download={false}` to hide that action. Cross-origin downloads require CORS.

Use the arrows on either side of the canvas or in the bottom toolbar, left/right arrow keys, or thumbnails to change images, wrapping at either end. You can also drag the thumbnail strip. Drag the image to pan; use the wheel or up/down arrow keys to zoom. Touch supports two-finger pinch and rotation, plus swipe navigation at the initial size. Double-click the image or choose “1:1” to toggle between original and initial size. “Reset image” restores zoom, position, rotation, and flips together.

The toolbar also offers rotation in both directions and horizontal/vertical flips, without slideshow or browser fullscreen modes. Escape, the top-right button, or clicking the backdrop closes the preview and returns focus to the opener.

`thumbnails: false` hides thumbnails without removing the previous / next buttons.

For large originals, provide `thumbnailSrc` so thumbnails do not also download the full-size images. `width` / `height` supply initial layout hints; the loaded image's natural dimensions take precedence.

`preview` returns an idempotent close function. A new request on the same Provider replaces the current gallery. Closing, replacing, or unmounting the caller invokes that gallery's `onClose`. `onIndexChange` reports the current zero-based index; the service manages navigation state for you.

## API

### ImagePreviewApi API

The preview invocation interface returned by `useImagePreview`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `preview` | `( images: string \| `[`ImagePreviewItem`](#imagepreviewitem-api)` \| readonly (string \| `[`ImagePreviewItem`](#imagepreviewitem-api)`)[], options?: `[`ImagePreviewOptions`](#imagepreviewoptions)`, ) => () => void` | Required | Preview one image or a gallery with an initial index and options; returns an idempotent close function. |

### ImagePreviewOptions

Presentation and close settings for an imperative image preview.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `index` | `number` | — | Initial image index, starting at zero. |
| `onIndexChange` | `(index: number) => void` | — | Called when the current image changes. |
| `thumbnails` | `boolean` | — | Show gallery thumbnails; defaults to true. |
| `downloadable` | `boolean` | — | Show the download action; defaults to false. |
| `onClose` | `() => void` | — | Called when preview ends, including user closing, the returned close function, replacement in the same Provider and caller unmount. |

### ImagePreviewItem API

Enable `downloadable` on the preview to offer downloads; set an item's `download` to `false` to hide its download action. Cross-origin download URLs must allow CORS. If downloading fails, the viewer provides an original-image link for saving it separately.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | Required | Image URL |
| `thumbnailSrc` | `string` | — | Optional thumbnail URL; falls back to src |
| `alt` | `string` | `''` | Image description |
| `width` | `number` | — | Optional original width in pixels for initial layout before loading; natural dimensions take precedence after loading. |
| `height` | `number` | — | Optional original height in pixels for initial layout before loading; natural dimensions take precedence after loading. |
| `download` | `string \| boolean` | — | With downloadable enabled, false disables this download, a string overrides its URL, otherwise src is used. Cross-origin downloads require CORS. |
| `downloadName` | `string` | — | Optional filename for the downloaded image |

### ImagePreviewProvider API

Props for supplying context to imperative image previews.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Content that can call useImagePreview; ConfigProvider already provides this service. |
