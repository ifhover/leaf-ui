## Divider API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientation |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Text alignment |
| `dashed` | `boolean` | `false` | Dashed line |
| `children` | `ReactNode` | — | Horizontal divider text |
