## API

### Divider API

Supports native `div` attributes. String children provide an accessible name automatically; use `aria-label` to name complex labels such as icons.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientation |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Text alignment |
| `dashed` | `boolean` | `false` | Dashed line |
| `children` | `ReactNode` | — | Content displayed within the divider. |
