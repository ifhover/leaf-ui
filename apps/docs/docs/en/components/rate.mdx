# Rate

Select or display a rating.

{/* leaf:section basic */}

## Basic usage

Click the selected rating again to clear it to `0`, or set `allowClear={false}` to prevent clearing. Hover previews a rating; leaving restores the selection.

#### Forms and keyboard

Use `FormField` for a label and `name` to include the value in FormData. Clearing submits an empty string. Uncontrolled ratings support form reset; set `required` to require a nonzero rating. See [Form](/en/components/form) for form integration.

Arrow keys adjust the rating, Home / End go to the ends, and Delete / Backspace clear when clearing is allowed.

## API

### Rate API

Configure the rating value, precision, read-only state and clearing behavior.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | — | Controlled rating. |
| `defaultValue` | `number` | `0` | Initial rating for uncontrolled usage. |
| `onChange` | `(value: number) => void` | — | Return the new rating, or 0 when cleared. |
| `count` | `number` | `5` | Number of stars, up to 20 |
| `allowHalf` | `boolean` | `false` | Allow half-star ratings. |
| `allowClear` | `boolean` | `true` | Clear to 0 when the current rating is selected again. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Prevent rating changes while retaining form submission. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Star size |
| `color` | `string` | — | Fixed rating color, taking precedence over colorByValue; gold when neither is set. |
| `colorByValue` | `boolean` | `false` | Use low, medium and high score colors |
| `colors` | `readonly [string, string, string]` | `['#ef5350', '#f49b23', '#ffc53d']` | Low, medium and high colors, with thresholds of 40% and 70% |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |
| `required` | `boolean` | `false` | Require a non-zero rating. |
