## Rate API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value / defaultValue` | `number` | `0` | Controlled / initial rating |
| `onChange` | `(value: number) => void` | — | Rating changes |
| `count` | `number` | `5` | Number of stars, up to 20 |
| `allowHalf / allowClear` | `boolean` | `false / true` | Half stars / click again to clear |
| `readOnly / disabled` | `boolean` | `false` | Read-only / disabled |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Star size |
| `color` | `string` | `'#ffc53d'` | Fixed color; takes precedence over score colors |
| `colorByValue` | `boolean` | `false` | Use low, medium and high score colors |
| `colors` | `readonly [string, string, string]` | `['#ef5350', '#f49b23', '#ffc53d']` | Low, medium and high colors, with thresholds of 40% and 70% |
| `name / form` | `string` | — | Field name / associated form |
| `required` | `boolean` | `false` | Require a nonzero rating |

## Usage notes

Hover previews the score and color; leaving restores the selected value. Arrow keys adjust rating, Home/End jump to the ends and Delete/Backspace clear. Read-only preserves display; disabled also prevents interaction. Supports FormData and uncontrolled form reset.
