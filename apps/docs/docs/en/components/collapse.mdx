# Collapse

Expand or collapse a group of sections on demand.

{/* leaf:section basic */}

## Basic usage

Provide headers and content through `items`, and set the initial expanded panels with `defaultActiveKey`. Multiple panels can be expanded by default. `disabled` prevents toggling that header.

### Preserve or destroy content

Content mounts when first opened and remains mounted after closing by default. Enter a draft, close the panel and reopen it to continue editing. With `destroyInactive`, content unmounts after the closing animation, so internal uncontrolled values return to their initial state on reopening. Controlled state outside the panel remains application-owned.

## API

### Collapse API

Configuration for panel entries, expanded state and accordion mode.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`CollapseItem`](#collapseitem)`[]` | Required | Panel items |
| `activeKey` | `string \| readonly string[]` | — | Controlled open keys as a string or array; accordion mode keeps only the first. |
| `defaultActiveKey` | `string \| readonly string[]` | `[]` | Initial open keys for uncontrolled usage. |
| `onChange` | `(keys: string[]) => void` | — | Always return a string array of open keys; an empty array means all are closed. |
| `accordion` | `boolean` | `false` | Expand one panel at a time |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Header size |
| `bordered` | `boolean` | `true` | Show border |
| `destroyInactive` | `boolean` | `false` | Unmount closed contents after the exit animation; visited contents are preserved by default, with unvisited items mounted lazily. |

### CollapseItem

The title, content and state of a collapsible panel entry.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique key |
| `label` | `ReactNode` | Required | Expandable item heading. |
| `children` | `ReactNode` | Required | Contents shown when expanded. |
| `disabled` | `boolean` | `false` | Prevent heading toggles without disabling independent extra actions. |
| `extra` | `ReactNode` | — | Header actions |
