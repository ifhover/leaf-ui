## API

### Switch API

Configure checked state, form submission and interaction state.

Supports native checkbox attributes such as `name`, `value`, `required` and `form`. Provide text or `aria-label` as its accessible name. `className` and `style` apply to the label container.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `loading` | `boolean` | `false` | Show loading and disable interaction |
| `checked` | `boolean` | — | Controlled switch state. |
| `defaultChecked` | `boolean` | — | Initial switch state for uncontrolled usage. |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Read the switch state from event.target.checked. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `children` | `ReactNode` | — | Clickable text label. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |
