# Form

Organize fields, labels and validation feedback, and collect form data.

### Settings layout

`layout="settings"` places the label and `description` to the left of the control. Override a wider field with `layout="vertical"`. `description` explains the field; `help` appears below the control and is replaced by `error`.

### Dynamic form lists

`FormList` manages row values, insertion, removal and ordering. Use `field.key` as the React key and pass `field.name` to the actual control. Moving a row updates its index and name. An uncontrolled list restores `defaultValue` on form reset.

`name` is only a field-name prefix. Dotted names remain literal strings in `FormData`; they do not create nested objects.

### Custom validation

`useFormValidation` reads `FormData` and manages errors and `pending`. Use `noValidate` to take over validation and pass field-keyed errors to `FormField`. This example validates synchronously and clears the field error on input.

Asynchronous `validate` and `onSubmit` callbacks must honor the provided `AbortSignal`. A new submission cancels the previous request; `clearErrors` also cancels the current request. Bind `handleReset` to the form reset event to cancel requests and clear errors.

### React Hook Form integration

{/* leaf:example react-hook-form */}

This third-party integration is a code-only example: the documentation site does not load React Hook Form. Install it in your application first. Use `register` for native inputs and `Controller` for value-based controls.

```bash
npm install react-hook-form
```

```tsx
import { Button, Form, FormField, Input, Select } from '@ifhover/leaf-ui';
import { Controller, useForm } from 'react-hook-form';

export function AccountForm() {
  const { register, control, handleSubmit, formState: { errors } } = useForm({
    defaultValues: { email: '', role: '' },
  });
  return (
    <Form noValidate onSubmit={handleSubmit((values) => console.log(values))}>
      <FormField label="Email" error={errors.email?.message}>
        <Input {...register('email', { required: 'Enter an email' })} />
      </FormField>
      <Controller
        name="role"
        control={control}
        rules={{ required: 'Choose a role' }}
        render={({ field, fieldState }) => (
          <FormField label="Role" error={fieldState.error?.message}>
            <Select {...field} options={[{ value: 'editor', label: 'Editor' }]} />
          </FormField>
        )}
      />
      <Button type="submit">Save</Button>
    </Form>
  );
}
```

Use React Hook Form’s `useFieldArray` for arrays.

## API

### Form API

#### Form integration

`FormData` values are strings or `File` objects. Convert numbers and assemble objects in your application. Unchecked checkboxes do not submit `false`; use `getAll()` for repeated names. Native reset restores uncontrolled defaults; reset controlled state in your application.

Leaf UI controls read the associations supplied by `FormField`. For native or third-party controls, provide matching `id` and `htmlFor` values. `Form disabled` passes disabled state to controls that consume its context; it does not disable arbitrary DOM elements or prevent submission.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `layout` | `'horizontal' \| 'vertical' \| 'settings'` | `'horizontal'` | Default field layout; settings places labels and descriptions on the left and controls on the right |
| `labelWidth` | `number \| 'auto'` | `'auto'` | Horizontal fields only: a pixel width, or auto to align labels to the widest label |
| `labelAlign` | `'left' \| 'right'` | `'right'` | Label alignment for horizontal fields |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `ref` | `Ref<HTMLFormElement>` | — | Reference to the form |

### FormField API

Props associating a field label, control and validation messages.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | Field label |
| `htmlFor` | `string` | Generated | The associated control ID; one field wraps one control or group |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `help` | `ReactNode` | — | Supporting text below the control, included in the field layout |
| `error` | `ReactNode` | — | Error message, displayed instead of help |
| `layout` | [`FormProps`](#form-api)`['layout']` | Inherited from Form | Override this field's layout; vertical allows wider controls to fill the row |
| `labelWidth` | `number` | — | Override this horizontal field’s label width in pixels |
| `description` | `ReactNode` | — | Description below the label, displayed independently of help and error below the control |

### FormGroupProps API

Props for the legend and description of a form field group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `legend` | `ReactNode` | — | Field group title |
| `description` | `ReactNode` | — | Supporting description |

### FormListProps API

Props for the data, field naming and rendering of a dynamic form list.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | Required | Field-name prefix; use field.name on the actual control. Dotted names do not construct nested objects. |
| `value` | `readonly T[]` | — | Controlled value |
| `defaultValue` | `readonly T[]` | `[]` | Initial value, restored by uncontrolled form resets |
| `onChange` | `(values: T[]) => void` | — | Value change callback |
| `itemKey` | `(value: T) => string` | — | Return a stable identifier |
| `children` | `(fields: readonly `[`FormListField`](#formlistfield-api)`<T>[], operations: `[`FormListOperations`](#formlistoperations-api)`<T>) => ReactNode` | Required | Render function for fields and row operations. |

### FormListField API

Information for one field passed to the list rendering function.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique stable identifier |
| `index` | `number` | Required | Current index, starting at zero |
| `name` | `string` | Required | Form field name |
| `value` | `T` | Required | Current value of this row. |

### FormListOperations API

Methods for inserting, removing, moving and updating dynamic form list entries.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `add` | `(value: T, index?: number) => void` | Required | Insert a field; omitted index appends |
| `remove` | `(index: number \| readonly number[]) => void` | Required | Remove one or multiple indices |
| `move` | `(from: number, to: number) => void` | Required | Move fields preserving stable keys |
| `update` | `(index: number, value: T) => void` | Required | Update field value |

### FormErrorSummaryProps API

Props for presenting field validation errors together.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `errors` | `readonly `[`FormError`](#formerror-api)`[]` | — | Omitted collects field errors in this Form |
| `title` | `ReactNode` | Localized default | Error-summary heading, localized by default. |

### FormError API

The field identity, label and message of an error summary entry.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `fieldId` | `string` | Required | Input id focused when error is clicked |
| `message` | `ReactNode` | Required | Error content |
| `label` | `ReactNode` | — | Display label |

### FormValidationApi

State and form event handlers returned by `useFormValidation`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `errors` | `Record<string, string>` | Required | Field-keyed errors for FormField. |
| `pending` | `boolean` | Required | Whether validation or submission is pending. |
| `setErrors` | `Dispatch<SetStateAction<Record<string, string>>>` | Required | Set server or business errors. |
| `handleSubmit` | `(event: FormEvent<HTMLFormElement>) => Promise<void>` | Required | Bind to Form.onSubmit. |
| `handleReset` | `(event: FormEvent<HTMLFormElement>) => void` | Required | Bind to Form.onReset to cancel requests and clear errors. |
| `cancel` | `() => void` | Required | Cancel the current request. |
| `clearErrors` | `(name?: string) => void` | Required | Clear one or all errors and cancel stale requests. |

### FormValidationOptions

Configuration for application validation, submission callbacks and error handling.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `validate` | `( data: FormData, signal: AbortSignal, ) => Record<string, string> \| Promise<Record<string, string>>` | Required | Validate FormData with a cancellation signal; return field-keyed errors. |
| `onSubmit` | `(data: FormData, signal: AbortSignal) => void \| Promise<void>` | — | Submit after validation, respecting cancellation. |
| `onError` | `(error: unknown) => void` | — | Called when validation or submission throws. |
| `focusError` | `boolean` | `true` | Focus the first invalid field. |
