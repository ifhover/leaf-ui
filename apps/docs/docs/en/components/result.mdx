## API

### Result API

Configure result status, title, description and follow-up actions.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `'empty' \| 'success' \| 'info' \| 'warning' \| 'danger' \| 'error'` | `'empty'` | Result status; `error` is a compatibility alias |
| `title` | `ReactNode` | — | Result title; defaults to the current status and locale. Set null to hide it. |
| `description` | `ReactNode` | — | Supporting description; omitted when unset or null. |
| `icon` | `ReactNode` | Status icon | Custom icon; null hides it |
| `extra` | `ReactNode` | — | Action buttons or links |
| `size` | `'sm' \| 'md'` | `'md'` | Content spacing and icon size |
| `children` | `ReactNode` | — | Additional result details. |

### Empty API

Compatibility component; prefer `Result` for new code. `EmptyProps` also accepts native `div` attributes.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `image` | `ReactNode` | Empty state icon | Custom icon; `null` hides it. |
| `description` | `ReactNode` | Localized title | Empty state description; `null` hides it. |
| `size` | `'sm' \| 'md'` | `'md'` | Content spacing and icon size. |
| `children` | `ReactNode` | — | Actions below the empty message. |
