## Result API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `'empty' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'empty'` | Result status |
| `title / description` | `ReactNode` | Localized title / — | Title / description; null hides them |
| `icon` | `ReactNode` | Status icon | Custom icon; null hides it |
| `extra` | `ReactNode` | — | Action buttons or links |
| `children` | `ReactNode` | — | Additional information |
| `size` | `'sm' \| 'md'` | `'md'` | Content spacing and icon size |


## Types

Import these types to define props or prepare data.

```ts
import type { ResultProps } from '@sudden3/leaf-ui';
```

## Usage notes

Use `status="empty"` for empty content. Success, warning, error and information have matching icons and colors. Customize `icon`, `title`, `description` and `extra` as needed.

The original `Empty` remains as a compatibility entry. Migrate to `Result`: rename `image` to `icon`, `description` to `title`, and move action buttons to `extra`.
