# Cascader

Choose a value through a hierarchy of options. Changing a parent updates the next column immediately, without a fade or movement animation. Moving to another branch only clears uncommitted descendants; returning to a selected branch restores its committed path.

## Basic selection

`children` defines nested options. Click a parent to open the next column, then click a leaf to commit the full path. `disabled` disables a whole branch, and each node needs a unique, stable `value`.

## Controlled path

`value` is the array of values from the root to the leaf, and `onChange` also supplies the full option path. Switching a parent clears uncommitted descendants; returning to the branch of a committed path restores its lower-level selection. Named fields submit a JSON array string.

## Popup width

The popup matches the field width by default (`popupWidth="trigger"`). Set `popupWidth="auto"` to fit the content, which may be narrower than the field, or `popupWidth={300}` for a fixed 300px width; CSS lengths are also supported. `popupMaxWidth` is unset by default. The example below fits the content and caps the maximum width. Viewport edge avoidance still applies.

## Lazy loading

## Refreshing cached data

When `cacheKey` changes, previously loaded children are treated as stale and fetched again on the next expand. The example uses a version counter as `cacheKey`; the button bumps it to force a reload.

## Single-line selections

Set `tagWrap={false}` to keep selected values on one line. Long labels truncate; extra values collapse into `+N`. In very narrow controls, only the count is shown. Open the popup to review or change selections. `maxTagCount` can further limit the visible tags; `maxTagCount="responsive"` also enables automatic single-line collapsing.

## Cascader API

| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `options` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | Required | Hierarchical options |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `placeholder` | `string` | Locale default | Placeholder when empty; localized by ConfigProvider |
| `name` | `string` | — | Field name / associated form ID |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `allowClear` | `boolean` | `true` | Clearing returns two empty arrays |
| `onOpenChange` | `(open: boolean) => void` | — | Panel open-state changes |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | — | Initial open state. |
| `readOnly` | `boolean` | — | Lock the value against typing, selection, clearing and removal. |
| `showSearch` | `boolean` | — | Enable search input. |
| `changeOnSelect` | `boolean` | — | Allow selecting intermediate levels. |
| `displayRender` | `(labels: ReactNode[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => ReactNode` | — | Customize displayed paths. |
| `optionRender` | `(option: `[`CascaderOption`](#cascaderoption)`) => ReactNode` | — | Customize option content. |
| `loadData` | `(option: `[`CascaderOption`](#cascaderoption)`, signal: AbortSignal) => Promise<readonly `[`CascaderOption`](#cascaderoption)`[]>` | — | Load child nodes asynchronously and respect AbortSignal. |
| `onLoadError` | `(error: unknown, option: `[`CascaderOption`](#cascaderoption)`) => void` | — | Called on loading failure, for retry feedback. |
| `cacheKey` | `string \| number` | — | Changing the data version clears lazy caches and cancels stale requests. |
| `tagWrap` | `boolean` | `true` | Allow selected tags to wrap; false keeps one line and collapses overflow. |
| `maxTagCount` | `number \| 'responsive'` | — | Maximum visible tags; responsive collapses them to the available width. |
| `popupWidth` | `number \| string` | `'trigger'` | Popup width; trigger matches the trigger, auto fits content (and may be narrower), numbers specify fixed pixels; CSS lengths are also supported. |
| `popupMaxWidth` | `number \| string` | — | Optional maximum popup width; no additional limit when unset, still bounded by the viewport. |
| `multiple` | `false \| true` | `false` | Enable multiple selection; value and callback types change accordingly. |
| `value` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | Controlled path; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | Initial path for uncontrolled usage; native form reset is supported. |
| `onChange` | `((value: string[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => void) \| ((value: string[][], selectedOptions: `[`CascaderOption`](#cascaderoption)`[][]) => void)` | — | Runs when a leaf is selected or the path is cleared |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `form` | `string` | — | ID of the associated native form. |
| `ref` | `Ref<HTMLButtonElement>` | — | DOM reference |

### CascaderOption

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Option value; unique within the same level. |
| `label` | `ReactNode` | Required | Visible option content. |
| `searchLabel` | `string` | — | Plain text used to search a rich label. |
| `isLeaf` | `boolean` | — | Identify a leaf node explicitly, including in lazy data. |
| `disabled` | `boolean` | `false` | Disable this option and all descendants. |
| `children` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | — | Child options. |

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.
