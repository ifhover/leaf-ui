# Cascader

Select hierarchical options such as regions or categories.

{/* leaf:section basic */}

## Basic usage

<a id="basic-selection"></a>

`children` defines nested options. Expand a parent and select a leaf to commit the full path. `disabled` disables a whole branch.

### Controlled path

`value` is an array of values from the root to the selected node. `onChange` also returns the full option path; clearing returns two empty arrays. Expanding a parent only changes the draft path. Returning to the first-level branch of a committed path restores its descendants.

### Lazy loading

Set `isLeaf={false}` on nodes without `children`; `loadData` returns their children on expansion. Keep `options` and `loadData` references stable, and use values unique across the entire tree.

Respect `AbortSignal`: changing the options, loader or `cacheKey`, or unmounting, cancels pending requests. Closing the popup does not. Use `onLoadError` for failure feedback; expand the node again to retry.

`popupWidth="auto"` fits the content, and `popupMaxWidth` caps its width. Without a width override, the popup matches the trigger. See [shared popup options](/en/api/popup-options) for other popup settings.

## API

### Cascader API

Other native `button` and `aria-*` attributes reach the trigger. `className` / `style` apply to the outer container.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | Required | Hierarchical options |
| `value` | `readonly string[] \| readonly (readonly string[])[]` | — | Controlled path; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | Initial path for uncontrolled usage; native form reset is supported. |
| `onChange` | `((value: string[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => void) \| ((value: string[][], selectedOptions: `[`CascaderOption`](#cascaderoption)`[][]) => void)` | — | Return a path and its options in single mode or path and option arrays in multiple mode; called on selection, removal or clearing, with two empty arrays when cleared. |
| `multiple` | `false \| true` | `false` | Enable multiple selection; value and callback types change accordingly. |
| `placeholder` | `string` | Locale default | Placeholder when empty; localized by ConfigProvider |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | — | Lock the value against typing, selection, clearing and removal. |
| `allowClear` | `boolean` | `true` | Clearing returns two empty arrays |
| `showSearch` | `boolean` | — | Enable search input. |
| `changeOnSelect` | `boolean` | — | Allow selecting intermediate levels. |
| `tagWrap` | `boolean` | `true` | Allow selected tags to wrap; false keeps one line and collapses overflow. |

### CascaderOption

The cascader option data structure, with child options organized through `children`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Option value; unique among siblings for static data and across the tree for lazy nodes to distinguish caches. |
| `label` | `ReactNode` | Required | Visible option content. |
| `searchLabel` | `string` | — | Plain text used to search a rich label. |
| `isLeaf` | `boolean` | — | Identify a leaf node explicitly, including in lazy data. |
| `disabled` | `boolean` | `false` | Disable this option and all descendants. |
| `children` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | — | Child options. |

### CascaderFieldNames

Use `mapCascaderOptions(records, fields)` to convert records to `CascaderOption[]`, then pass the result as `options`. `CascaderFieldNames` describes the mapping fields; it is not a `Cascader` prop.

```ts
import { mapCascaderOptions } from '@ifhover/leaf-ui';

const records = [{ id: 'design', name: 'Design', nodes: [{ id: 'interface', name: 'Interface design' }] }];
const options = mapCascaderOptions(records, {
  value: 'id',
  label: 'name',
  children: 'nodes',
});
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Business-object field containing the option value. |
| `label` | `string` | — | Business-object field containing the visible label. |
| `children` | `string` | — | Business-object field containing the child-node array. |
| `disabled` | `string` | — | Business-object field containing the disabled state. |
| `isLeaf` | `string` | — | Business-object field containing the leaf marker. |
