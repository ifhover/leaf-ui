# Message

Provide brief feedback about an operation. Use [Notification](/en/components/notification) when you need a title, detail or follow-up actions.

{/* leaf:section basic */}

## Basic usage

Wrap the application in [ConfigProvider](/en/components/config-provider), then call `useMessage()` in a child component. Applications already using it need no additional provider.

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## API

### Message API

For declarative rendering, handle `onClose` by setting `open` to `false`. `afterClose` runs after the exit animation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Controlled visibility |
| `content` | `ReactNode` | Required | Message content |
| `type` | `FeedbackType \| 'error' \| 'loading'` | `'info'` | Message type; `error` is a compatibility alias |
| `duration` | `number` | 3 normally; 0 for loading | Seconds before automatic closing; zero or negative values keep it open. Hover or focus pauses the remaining time. |
| `closable` | `boolean` | `false` | Close button |
| `onClose` | `() => void` | — | Called when closing is requested; declarative Message requires the application to set open to false. |
| `afterClose` | `() => void` | — | Called after the closing animation and content unmount; does not replace updating controlled state in onClose. |

### useMessage API

Access the message queue managed by the current provider.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `message` | [`MessageApi`](#messageapi) | — | Call the queue managed by the application provider |

### MessageApi

`close(key)` closes one message; `close()` closes every message in the shared queue.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `(options: `[`MessageOptions`](#messageoptions)`) => string` | Required | Open or replace a message by key, returning its key. |
| `success` | `(content: ReactNode, duration?: number) => string` | Required | Show feedback of the specified type; `error` remains as a compatibility method |
| `info` | `(content: ReactNode, duration?: number) => string` | Required | Show feedback of the specified type; `error` remains as a compatibility method |
| `warning` | `(content: ReactNode, duration?: number) => string` | Required | Show feedback of the specified type; `error` remains as a compatibility method |
| `danger` | `(content: ReactNode, duration?: number) => string` | Required | Show feedback of the specified type; `error` remains as a compatibility method |
| `error` | `(content: ReactNode, duration?: number) => string` | Required | Content displayed instead of data rows after a request failure. |
| `loading` | `(content: ReactNode) => string` | Required | Show a loading message without automatic dismissal and return its key; the application updates or closes it. |
| `close` | `(key?: string) => void` | Required | Close a key; omitting it closes every message in the same Provider, not only this caller's messages. |

### MessageOptions

Timers pause when the pointer or focus enters a message. After resuming, they use the remaining duration.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `content` | `ReactNode` | Required | Message content |
| `type` | `FeedbackType \| 'error' \| 'loading'` | `'info'` | Message type; `error` is a compatibility alias |
| `duration` | `number` | 3 normally; 0 for loading | Seconds before automatic closing; zero or negative values keep it open. Hover or focus pauses the remaining time. |
| `closable` | `boolean` | `false` | Show a close button |
| `key` | `string` | Generated | Unique key within a Provider; opening the same key replaces that message and restarts its dismissal timer instead of appending. |
| `onClose` | `() => void` | — | Called when closing is requested; declarative Message requires the application to set open to false. |

### MessageProvider API

Use `MessageProvider` instead of `ConfigProvider` for standalone message support, or add it explicitly to create an independent queue. Separate React applications and SSR requests have independent queues.

```tsx
import { MessageProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <MessageProvider><App /></MessageProvider>;
}
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Contents sharing this independent message queue; ConfigProvider already supplies one, reused by nested ConfigProviders. |
