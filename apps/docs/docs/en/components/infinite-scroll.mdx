# InfiniteScroll

Load more content when scrolling near the end of a list.

{/* leaf:section basic */}

## Basic usage

Return the loading task's Promise from `onLoadMore`. Only one load runs at a time. Update `dataLength` after appending items, and set `hasMore` to `false` when no more data remains.

The example specifies its scroll container with `target`. When omitted, the component finds the nearest scrollable ancestor, falling back to the page. Loading starts when the end enters the `threshold` preloading range, which can happen on the initial render.

Unmounting or setting `hasMore` to `false` aborts the task's `signal`. Pass it to `fetch` or another cancellation-aware API. For other asynchronous work, check `signal.aborted` before updating state, as this example does.

## Examples

### Retry after failure

Reject the Promise when loading fails. The component pauses automatic loading and shows a retry button. The example deliberately fails its first request, then appends the remaining records after retrying. Use `onError` to report errors; the application still owns data recovery.

## API

### InfiniteScrollProps API

Configuration for scroll-loading triggers, asynchronous tasks and loading feedback.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `dataLength` | `number` | Required | Loaded item count; update after appending data to allow another load. |
| `hasMore` | `boolean` | Required | Whether more data remains; false aborts the active task signal and displays the end content. |
| `onLoadMore` | `(signal: AbortSignal) => Promise<void>` | Required | Return the loading Promise; append data and pass on or check the cancellation signal. Rejection pauses automatic loading and shows Retry. |
| `target` | `() => HTMLElement \| null` | — | Return the scroll container; when omitted or null, use the nearest vertically scrollable ancestor, otherwise the viewport. |
| `threshold` | `number` | `200` | Preload within this pixel distance from the end; negative values are treated as zero. |
| `loader` | `ReactNode` | — | Loading placeholder |
| `endMessage` | `ReactNode` | — | Content after all items are loaded |
| `onError` | `(error: unknown) => void` | — | Called when the loading Promise rejects without cancellation; does not restore application data. |
