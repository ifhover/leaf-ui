## API

### Button API

Supports native `button` attributes such as `onClick`, `name`, `form`, `aria-*` and `data-*`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'outline'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `danger` | `boolean` | `false` | Danger colors; works with every variant |
| `loading` | `boolean` | `false` | Show loading and disable interaction |
| `fullWidth` | `boolean` | `false` | Fill the parent width |
| `startIcon` | `ReactNode` | — | Leading icon; replaced by the spinner during loading |
| `endIcon` | `ReactNode` | — | Trailing icon |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type |
| `ref` | `Ref<HTMLButtonElement>` | — | DOM reference |

### ButtonGroupProps API

Props for grouping related buttons.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | — | Button size. |
| `disabled` | `boolean` | — | Disable interaction. |
| `attached` | `boolean` | `true` | Join adjacent buttons |

### SplitButtonProps API

Props for a button combining a primary action with dropdown actions.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'outline'` | Button appearance |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Button size. |
| `danger` | `boolean` | `false` | Danger colors |
| `loading` | `boolean` | `false` | Loading state |
| `fullWidth` | `boolean` | `false` | Fill available width |
| `startIcon` | `ReactNode` | — | Leading icon |
| `endIcon` | `ReactNode` | — | Trailing icon |
| `items` | `readonly `[`DropdownItem`](dropdown#dropdownitem)`[]` | Required | Items; keep keys unique and stable |
| `menuLabel` | `string` | — | Accessible menu button label |
| `dropdownProps` | `Omit<`[`DropdownProps`](dropdown#dropdown-api)`, 'items' \| 'children' \| 'disabled'>` | — | Action menu props |
