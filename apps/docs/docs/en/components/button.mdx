# Button

Trigger an action, such as saving, submitting or deleting.

## Examples

Use solid for primary actions, outline for secondary actions with a white surface and a fine border, and ghost for low-priority actions. Link buttons use the theme color without padding, border or a fixed control height; use the Link component for navigation. Loading preserves the label and prevents duplicate clicks. Set type="submit" for form submission, and aria-label for icon-only actions.

On activation, solid and outlined buttons emit a wave that quickly expands outside the button and slowly fades while the button and label stay still. Ghost and link buttons do not emit a wave. Solid buttons brighten on hover and deepen on press; outlined buttons keep their surface and change their text and border colors. Danger actions use red. The wave follows the theme and respects regional and system motion preferences.

## Button API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'ghost' \| 'link'` | `'solid'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `danger` | `boolean` | `false` | Danger colors; works with every variant |
| `loading` | `boolean` | `false` | Show loading and disable interaction |
| `fullWidth` | `boolean` | `false` | Fill the parent width |
| `startIcon` | `ReactNode` | — | Leading icon; replaced by the spinner during loading |
| `endIcon` | `ReactNode` | — | Trailing icon |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type |
| `ref` | `Ref<HTMLButtonElement>` | — | DOM reference |

## Types

Import ButtonProps to describe component props. Option types in the API table link to their detailed fields above.

```ts
import type { ButtonProps } from '@ifhover/leaf-ui';
```

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.
