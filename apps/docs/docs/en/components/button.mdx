# Button

Trigger an action, such as saving, submitting or deleting.

## Basic usage

`variant` controls the button appearance. The default is `outline` for ordinary actions; use `solid` for a primary action and `link` for inline actions.

Outline buttons keep a subtle resting shadow and do not change on hover. While pressed, only the border deepens to the corresponding interaction color; the text, background and shadow stay unchanged, and releasing restores the border. `danger` uses readable danger ink and deepens the border from the danger base to a stronger danger interaction color while pressed. Disabled and loading buttons do not respond. Explicit component state settings override this default feedback.

## Button API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'link'` | `'outline'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `danger` | `boolean` | `false` | Danger colors; works with every variant |
| `loading` | `boolean` | `false` | Show loading and disable interaction |
| `fullWidth` | `boolean` | `false` | Fill the parent width |
| `startIcon` | `ReactNode` | — | Leading icon; replaced by the spinner during loading |
| `endIcon` | `ReactNode` | — | Trailing icon |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type |
| `ref` | `Ref<HTMLButtonElement>` | — | DOM reference |

## Types

Import ButtonProps to describe component props. Option types in the API table link to their detailed fields above.

```ts
import type { ButtonProps } from '@ifhover/leaf-ui';
```

## Forms and keyboard

`type` defaults to `button`, so a button inside a form will not submit accidentally. Set `type="submit"` to submit the form. Native keyboard behavior is preserved.
