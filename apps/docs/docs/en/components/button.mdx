## Examples

### Appearance

Use `variant` for `outline` (the default), `solid`, `text`, `link` or `danger` appearance. Default `outline` pairs a subtle bottom shadow with primary hover border and text colors that darken on press; `solid` also carries the subtle bottom shadow, brightens to the primary hover shade on hover and darkens on press; inline links use the theme color by default, brighten on hover and darken when pressed, with a default color transition of 200ms.

## API

### Button API

Supports native `button` attributes such as `onClick`, `name`, `form`, `aria-*` and `data-*`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link' \| 'danger'` | `'outline'` | Visual style |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon' \| 'icon-sm' \| 'icon-lg'` | `'md'` | Button size or square icon-only size |
| `danger` | `boolean` | `false` | Deprecated; use `variant="danger"`. Falls back to the danger variant when set |
| `loading` | `boolean` | `false` | Show loading and disable interaction |
| `fullWidth` | `boolean` | `false` | Fill the parent width |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type |
| `ref` | `Ref<HTMLButtonElement>` | — | DOM reference |

### ButtonGroupProps API

Props for grouping related buttons.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | — | Button size; also adapts `size="icon"` buttons inside the group |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link' \| 'danger'` | — | Default visual style for buttons in the group |
| `disabled` | `boolean` | — | Disable interaction. |
| `attached` | `boolean` | `true` | Join adjacent buttons |
