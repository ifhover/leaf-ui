### Responsive columns and spans

`columns` follows viewport width, not container width. Unspecified breakpoints inherit smaller ones. An item's `span` is capped at the current column count; its minimum is 1, so 0 cannot hide an item.

## API

### DescriptionsProps API

Configuration for field entries, column counts and the arrangement of labels and values.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`DescriptionItem`](#descriptionitem-api)`[]` | Required | Items; keep keys unique and stable |
| `title` | `ReactNode` | — | Title content |
| `extra` | `ReactNode` | — | Supplementary content or actions |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `{ xs: 1, md: 2, lg: 3 }` | Column count; responsive settings follow viewport width and inherit smaller breakpoints. |
| `layout` | `'horizontal' \| 'vertical'` | `'horizontal'` | Arrangement of labels and values |
| `bordered` | `boolean` | `false` | Show container outline |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Spacing preset between fields; does not change font size. |

### DescriptionItem API

The label, content and column span for an entry supplied through `items`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique stable identifier |
| `label` | `ReactNode` | Required | Field name. |
| `children` | `ReactNode` | Required | Field value. |
| `span` | `number` | `1` | Columns occupied by the field, from 1 up to the current column count. |
