## Empty API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `image` | `ReactNode` | Inbox icon | Custom image; null hides it |
| `description` | `ReactNode` | No data | Description; null hides it |
| `children` | `ReactNode` | — | Actions |
| `size` | `'sm' \| 'md'` | `'md'` | Display size |
