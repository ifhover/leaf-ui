`Empty` is a compatibility entry. For new empty states, use [Result](/en/components/result) with `status="empty"`.

## Migrate to Result

Rename `image` to `icon` and `description` to `title`, and move actions from `children` to `extra`.

```diff
- import { Empty } from '@ifhover/leaf-ui';
+ import { Result } from '@ifhover/leaf-ui';

- <Empty description="No projects yet" />
+ <Result status="empty" title="No projects yet" />
```

See [Empty API](/en/components/result#empty-api) for the full reference.
