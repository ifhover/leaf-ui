## Usage

Flows down each column. Use Grid when row order matters for reading or focus.

## Types

Import these types for data, callbacks and refs.

```ts
import type { MasonryProps } from '@sudden3/leaf-ui';
```

## MasonryProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `{ xs: 1, sm: 2, lg: 3 }` | Columns; unspecified breakpoints inherit smaller ones |
| `gap` | `number \| string` | `16` | Gap; tuples use [vertical, horizontal] |
