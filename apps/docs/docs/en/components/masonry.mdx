# Masonry

Arrange cards and images of varying heights.

Content flows down each column rather than across rows. Use [Grid](./grid) when reading or keyboard focus order needs to follow rows.

### Responsive columns

Set `columns` to a fixed number or a breakpoint map. Breakpoints use the viewport width, not the Masonry container width; larger unspecified breakpoints inherit the preceding value. This example uses one column on narrow screens and two on wider screens.

## API

### MasonryProps API

Configure the masonry columns and spacing between items.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `{ xs: 1, sm: 2, lg: 3 }` | Column count or viewport breakpoint map; omitted breakpoints inherit smaller ones. |
| `gap` | `number \| string` | `16` | Column and vertical item gaps; numbers are pixels and CSS lengths are supported. |
