`status="expired"` shows a refresh button. The `onRefresh` callback asks the application to refresh; it does not change `value` or `status`. This example generates a new demo token each time. When using an API, the application handles the request, errors, and state changes.

## API

### QRCodeProps API

Configure encoded content, QR code status and download actions.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Text or URL encoded in the QR code. |
| `size` | `number` | `160` | Square QR-code size in pixels, with a minimum of 64. |
| `status` | `'active' \| 'loading' \| 'expired'` | `'active'` | Display active, loading or expired state without loading data or calculating expiration. |
| `onRefresh` | `() => void` | — | Called when the expired-state refresh button is clicked; the application updates value and status. |
| `downloadable` | `boolean` | `false` | Show the download action, exporting an SVG file. |
| `fileName` | `string` | `'qrcode.svg'` | Download filename, including its extension. |
| `level` | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` | QR error correction level |
| `logo` | `string` | — | Center logo URL |
| `logoSize` | `number` | `32` | Center logo size |
| `color` | `string` | `'var(--leaf-color-text)'` | Color |
| `backgroundColor` | `string` | `'var(--leaf-color-surface)'` | Background color |
