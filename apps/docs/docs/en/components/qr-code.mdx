## Usage

value contains the encoded content. status can display a loading or expired state. Handle refresh through onRefresh and enable downloadable for SVG downloads.

## Types

Import these types for data, callbacks and refs.

```ts
import type { QRCodeProps } from '@sudden3/leaf-ui';
```

## QRCodeProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Controlled value |
| `size` | `number` | `160` | Size or spacing preset |
| `color` | `string` | `'var(--leaf-color-text)'` | Color |
| `backgroundColor` | `string` | `'var(--leaf-color-surface)'` | Background color |
| `level` | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` | QR error correction level |
| `logo` | `string` | — | Center logo URL |
| `logoSize` | `number` | `32` | Center logo size |
| `status` | `'active' \| 'loading' \| 'expired'` | `'active'` | Display state |
| `onRefresh` | `() => void` | — | Refresh expired QR code |
| `downloadable` | `boolean` | `false` | Show download action |
| `fileName` | `string` | `'qrcode.svg'` | Download filename |
