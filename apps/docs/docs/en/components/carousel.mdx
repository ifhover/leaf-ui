# Carousel

Browse images or content one slide at a time.

{/* leaf:section basic */}

## Basic usage

Pass each slide as a child. Previous/next controls and indicators appear by default, and navigation wraps at the ends. Set `infinite={false}` to stop at the boundaries. Give the carousel an `aria-label` that describes its content.

<ComponentExample exampleId="basic" preview={<CarouselBasic />} fileName="basic.tsx" width={600}>


</ComponentExample>

When the carousel has focus, use the left/right arrow keys to navigate and Home/End to reach the first or last slide. Editing controls retain their own arrow-key behavior. Inactive slides remain mounted but do not participate in focus navigation.

### Autoplay

Set a numeric `autoplay` interval and provide explicit start/stop controls through application state. This example advances every three seconds.

<ComponentExample exampleId="autoplay" preview={<CarouselAutoplay />} fileName="autoplay.tsx" width={600}>

```tsx lineNumbers file="../../../src/examples/en/carousel/autoplay.tsx"
```

</ComponentExample>

Focus entering the carousel pauses playback; leaving restores it. Pointer entry and exit also pause or restore playback by default; `pauseOnHover` controls only the pointer behavior. Hidden pages do not advance. Autoplay is disabled when the system requests reduced motion or ConfigProvider disables motion; manual navigation remains available.

## API

### Carousel API

Configuration for the active slide, navigation controls and autoplay behavior.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `activeIndex` | `number` | — | Controlled zero-based slide index; write onChange results back to it. |
| `defaultActiveIndex` | `number` | `0` | Initial zero-based index for uncontrolled usage. |
| `onChange` | `(index: number) => void` | — | Return the requested zero-based slide index. |
| `arrows` | `boolean` | `true` | Show previous and next controls. |
| `dots` | `boolean` | `true` | Show slide indicators. |
| `infinite` | `boolean` | `true` | Allow cycling through slides. |
| `autoplay` | `boolean \| number` | `false` | Autoplay; true uses 4000ms, and a nonzero number sets an interval of at least 500ms. Does not advance with motion disabled or the page hidden. |
| `pauseOnHover` | `boolean` | `true` | Pause autoplay on hover; focus inside always pauses it regardless of this option. |

### CarouselHandle

The reference interface for controlling the carousel through `ref`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `goTo` | `(index: number) => void` | Required | Navigate to a zero-based index; wraps in infinite mode and clamps to the valid range otherwise. |
| `next` | `() => void` | Required | Go to the next item. |
| `previous` | `() => void` | Required | Go to the previous item. |
