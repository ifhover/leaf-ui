## API

### Progress API

Configure the progress percentage, status and presentation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `percent` | `number` | `0` | Completion percentage, from 0 to 100 |
| `type` | `'line' \| 'circle'` | `'line'` | Line or circular progress |
| `status` | `'normal' \| 'success' \| 'error'` | `'normal'` | Progress state; normal becomes success at 100% unless indeterminate. |
| `showInfo` | `boolean` | `true` | Show percentage or status icon |
| `format` | `(percent: number) => ReactNode` | — | Custom progress text |
| `strokeWidth` | `number` | — | Stroke width; pixels for lines, view units for circles |
| `color` | `string` | — | Custom progress color |
| `size` | `number` | `100` | Circular diameter in pixels |
| `indeterminate` | `boolean` | `false` | Animated loading when the total progress is unknown; no percentage |
| `active` | `boolean` | `true` | Shimmer inside an unfinished line; false disables it. Completed, failed and indeterminate progress omit it. |
| `trailColor` | `string` | — | Track color |
| `segments` | `readonly `[`ProgressSegment`](#progresssegment)`[]` | — | Display multiple sections with proportions and colors. |
| `steps` | `number` | — | Number of discrete progress steps. |
| `dashboard` | `boolean` | `false` | Display progress as a dashboard gauge. |
| `successPercent` | `number` | — | Part of the progress completed successfully. |

### ProgressSegment

Describe the percentage and color of one progress segment.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable, unique identifier. |
| `percent` | `number` | Required | Completion percentage. |
| `color` | `string` | — | Color or semantic tone. |
