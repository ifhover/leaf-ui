### Controlled selection and displayed month

<a id="advanced-usage"></a>

`value` controls selection, while `visibleDate` controls the displayed month. Paging or clicking Today changes the displayed month without selecting a date; `onVisibleChange` returns the first day of the new month. The example uses `headerExtra` to return to the selected month.

### Schedule content

Use `cellRender` for text, icons or Tags. Content is placed inside the date button, so do not nest links, buttons or other interactive elements; provide schedule actions outside the calendar.

<ComponentExample exampleId="schedule" preview={<CalendarSchedule />} fileName="schedule.tsx" width="100%">

```tsx lineNumbers file="../../../src/examples/en/calendar/schedule.tsx"
```

</ComponentExample>

Dates use local `Date` values; `minDate` / `maxDate` include their boundary days. For SSR, provide the same initial date on the server and client; see [server-side rendering](/en/guide/ssr). Calendar does not provide native form submission or reset behavior; use [DatePicker](/en/components/date-picker) for those features.

## API

### Calendar API

Configuration for the selected date, visible month and selectable date range.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `Date` | — | Controlled selected date, independent of visibleDate. |
| `defaultValue` | `Date` | — | Initial selected date for uncontrolled usage. |
| `onChange` | `(date: Date) => void` | — | Called on selection; month mode returns the first day of the selected month. |
| `mode` | `'date' \| 'month'` | `'date'` | Select dates or months |
| `fullscreen` | `boolean` | `true` | Full calendar layout |
| `minDate` | `Date` | — | Date bounds |
| `maxDate` | `Date` | — | Date bounds |
| `disabledDate` | `(date: Date) => boolean` | — | Disable specific dates |
| `visibleDate` | `Date` | — | Controlled visible month, not the selected date. |
| `onVisibleChange` | `(date: Date) => void` | — | Return the first day when the visible month changes, without selecting a date. |
| `showToday` | `boolean` | `true` | Show navigation to today; changes the visible month without selecting a date. |
| `cellRender` | `(date: Date) => ReactNode` | — | Customize cell contents inside the selection button; do not nest interactive controls. |
| `headerExtra` | `ReactNode` | — | Additional header content |
