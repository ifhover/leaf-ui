## Calendar API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value / defaultValue` | `Date` | — | Controlled / initial selected date |
| `onChange` | `(date: Date) => void` | — | Date selection |
| `visibleDate` | `Date` | — | Controlled displayed period |
| `onVisibleChange` | `(date: Date) => void` | — | Displayed period changes |
| `mode` | `'date' \| 'month'` | `'date'` | Select dates or months |
| `fullscreen` | `boolean` | `true` | Full calendar layout |
| `minDate / maxDate` | `Date` | — | Date bounds |
| `disabledDate` | `(date: Date) => boolean` | — | Disable specific dates |
| `cellRender` | `(date: Date) => ReactNode` | — | Additional date content |
| `headerExtra` | `ReactNode` | — | Additional header content |
| `showToday` | `boolean` | `true` | Show a Today button in full layout to navigate to the current month |

## Usage notes

Use `fullscreen={false}` for a compact calendar. Place non-interactive text or icons in `cellRender`; avoid nested buttons. A disabled selection stays readable and cannot be selected again.

Use arrow keys to move dates, Home/End to jump within a row and PageUp/PageDown to switch months. Provide consistent initial dates for SSR; see [SSR usage](/guide/ssr).
