## Calendar API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value / defaultValue` | `Date` | — | Controlled / initial selected date |
| `onChange` | `(date: Date) => void` | — | Date selection |
| `visibleDate` | `Date` | — | Controlled displayed period |
| `onVisibleChange` | `(date: Date) => void` | — | Displayed period changes |
| `mode` | `'date' \| 'month'` | `'date'` | Select dates or months |
| `fullscreen` | `boolean` | `true` | Full calendar layout |
| `minDate / maxDate` | `Date` | — | Date bounds |
| `disabledDate` | `(date: Date) => boolean` | — | Disable specific dates |
| `cellRender` | `(date: Date) => ReactNode` | — | Additional date content |
| `headerExtra` | `ReactNode` | — | Additional header content |
| `showToday` | `boolean` | `true` | Show a Today button in full layout to navigate to the current month |

## Usage notes

The full calendar uses an editorial, borderless grid: a large month heading, a lighter year, and trailing Today and navigation controls form the header. Date, month and year views use open 7-, 4- and 3-column layouts. Selection fills the whole date cell with a quiet primary tint and marks the numeral with a solid circular label; Today uses primary-colored text and a small dot instead of an outline.

Use `fullscreen={false}` for a compact calendar with a 32px borderless date grid. `cellRender` content sits below the numeral and truncates to one line; use non-interactive text or icons and avoid nested buttons. A disabled selection stays readable and cannot be selected again.

Use arrow keys to move dates, Home/End to jump within a row and PageUp/PageDown to switch months. Provide consistent initial dates for SSR; see [server-side rendering](/en/guide/ssr).
