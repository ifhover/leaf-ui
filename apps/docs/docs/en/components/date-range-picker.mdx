## DateRangePicker API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value / defaultValue` | [`DateRange \| null`](#daterange) | `null` | Controlled / initial range |
| `onChange` | [`(value: DateRange \| null, dateStrings: readonly [string, string]) => void`](#daterange) | — | Returns an ordered range and formatted strings; clearing returns null |
| `picker` | `'year' \| 'month' \| 'week' \| 'weekday' \| 'date' \| 'datetime'` | `'date'` | Selection granularity |
| `minDate / maxDate` | `Date` | — | Earliest / latest allowed values |
| `use12Hours` | `boolean` | `false` | Display a 12-hour clock with AM/PM options |
| `minuteStep / secondStep` | `number` | `1` | Minute / second step, an integer from 1 to 60 |
| `allowClear` | `boolean` | `true` | Show the clear button |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `disabled / required` | `boolean` | `false` | Disabled / required; inherited from FormField |
| `placeholder / name / form` | `string` | — | Placeholder / field name / form ID |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the panel opens or closes |
| `ref` | `Ref<HTMLButtonElement>` | — | Reference to the trigger button |

## Usage notes

DateRange is readonly [Date, Date]; import it when assembling values. Years use January 1, months use the first day, and weeks start on Monday with ISO week numbers. weekday selects a concrete date within a week and displays its weekday. Dates use local time.

The second selection commits non-datetime ranges and sorts reversed endpoints. In datetime mode, choose both dates and times, including seconds, then confirm. Bounds compare the selected year, month or week for coarse modes, and exact times for datetime.

FormData submits a start/end string: YYYY for years, YYYY-MM for months, YYYY-Www for weeks, YYYY-MM-DD for dates, or YYYY-MM-DD HH:mm:ss for datetime. Import DateRange for reusable typed values; its positions are detailed above.
