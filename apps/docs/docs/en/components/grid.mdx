# Grid

Arrange content in equal-width columns or a 24-column grid. Use [Flex](/en/components/flex) or [Space](/en/components/space) for a simple group of elements.

{/* leaf:section basic */}

`Grid` defaults to three columns. Set `columns` to change the number of equal-width columns.

## API

### GridProps API

`Grid`, `Row` and `Col` support native `div` attributes and DOM refs.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `3` | Columns; unspecified breakpoints inherit smaller ones |
| `gap` | `number \| string \| readonly [number \| string, number \| string]` | `16` | Gap; tuples use [vertical, horizontal] |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | Alignment |

### RowProps API

Props for alignment and column spacing in a 24-column grid row.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | Alignment |
| `gutter` | [`GridProps`](#gridprops-api)`['gap']` | `16` | Grid gap; tuples use [vertical, horizontal] |

### ColProps API

Props for spans, offsets and responsive settings in a 24-column grid.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `span` | `number` | `24` | Column span; Col span 0 hides a column |
| `offset` | `number` | `0` | Preceding empty columns |
| `xs` | `number` | — | Base breakpoint |
| `sm` | `number` | — | At 576px and above |
| `md` | `number` | — | At 768px and above |
| `lg` | `number` | — | At 992px and above |
| `xl` | `number` | — | At 1200px and above |
