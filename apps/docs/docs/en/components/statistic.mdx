Numbers use the current locale; strings display as provided. When supplying `formatter`, handle the formatting in that callback.

### Value animation

Numbers start from 0 by default; later changes continue from the currently displayed value. Use `initialValue` for the initial starting point and `duration` for the timing. Set `animation={false}` or `duration={0}` for immediate updates.

<ComponentExample exampleId="animation" preview={<StatisticAnimation />} fileName="animation.tsx" width="fit-content">

```tsx lineNumbers file="../../../src/examples/en/statistic/animation.tsx"
```

</ComponentExample>

Only finite `number` values animate, and `formatter` receives intermediate values during the animation. Counting starts after loading ends and respects reduced-motion preferences.

### Countdown

`value` is a deadline as a `Date` or millisecond timestamp, not a remaining duration. Each run lasts 10 seconds and updates the completion feedback through `onFinish`. The component does not automatically announce every numeric update.

<ComponentExample exampleId="countdown" preview={<StatisticCountdown />} fileName="countdown.tsx" width="fit-content">

```tsx lineNumbers file="../../../src/examples/en/statistic/countdown.tsx"
```

</ComponentExample>

For server rendering, pass the same `initialRemaining` on the server and client to keep the first render consistent. After mounting, the countdown follows the actual deadline.

## API

### Statistic API

Configure the metric name, value format and change animation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Title content. |
| `value` | `number \| string` | Required | Number or text to display. |
| `precision` | `number` | — | Decimal precision. |
| `grouping` | `boolean` | `true` | Use localized digit grouping. |
| `prefix` | `ReactNode` | — | Leading content. |
| `suffix` | `ReactNode` | — | Trailing content. |
| `formatter` | `(value: number \| string) => ReactNode` | — | Customize the displayed metric value. |
| `loading` | `boolean` | — | Show a loading state. |
| `animation` | `boolean` | `true` | Animate numeric value changes. |
| `initialValue` | `number` | `0` | Starting value for the first animation; later changes start from the current displayed value. |
| `duration` | `number` | `1000` | Animation duration in milliseconds at the default motion speed, scaled by the regional motion duration; 0 updates immediately. |

### Countdown API

Configure the countdown target time and completion feedback.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Title content. |
| `prefix` | `ReactNode` | — | Leading content. |
| `suffix` | `ReactNode` | — | Trailing content. |
| `loading` | `boolean` | — | Show a loading state. |
| `value` | `number \| Date` | Required | Deadline as a Date or a millisecond timestamp. |
| `format` | `string` | `'HH:mm:ss'` | Format using DD, HH, mm, ss, SSS; HH can show total hours. |
| `onFinish` | `() => void` | — | Called once for the current deadline; the application provides completion feedback. |
| `onChange` | `(remaining: number) => void` | — | Called with remaining milliseconds on each update, or 0 when finished. |
| `initialRemaining` | `number` | — | Remaining milliseconds for SSR; updates from the deadline after mounting. |
