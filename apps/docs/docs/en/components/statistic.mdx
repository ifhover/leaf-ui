# Statistic

Display metrics and countdowns. Numbers initially count up or down from 0 to the target. Later changes animate from the currently displayed value to the new target.

## Value animation

Set `initialValue` to choose the starting number for the first animation. The default duration is 1000 milliseconds; use `duration` to adjust it. Repeated increases or decreases continue from the currently displayed value. Replay remounts the example to start again from 1,000.

<ComponentExample title="Value animation" preview={<StatisticAnimation english />} fileName="animation.tsx">

```tsx lineNumbers file="../../../src/examples/statistic/animation.tsx"
```

</ComponentExample>

Set `animation={false}` or `duration={0}` to display the target immediately. Animation follows the regional motion speed, `ConfigProvider`'s `theme.motion`, and the system reduced-motion preference. Counting starts after `loading` ends. Only finite `number` values animate; strings and nonfinite numbers display immediately. `formatter` receives the intermediate numbers. Server rendering outputs the target, and animation starts after the client mounts. Countdown updates remain immediate.

## Statistic API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Title content. |
| `value` | `number \| string` | — | Required. Controlled value. |
| `precision` | `number` | — | Decimal precision. |
| `grouping` | `boolean` | `true` | Use localized digit grouping. |
| `prefix` | `ReactNode` | — | Leading content. |
| `suffix` | `ReactNode` | — | Trailing content. |
| `formatter` | `(value: number \| string) => ReactNode` | — | Customize the displayed metric value. |
| `loading` | `boolean` | — | Show a loading state. |
| `animation` | `boolean` | `true` | Animate numeric value changes. |
| `initialValue` | `number` | `0` | Starting value for the first animation; later changes start from the current displayed value. |
| `duration` | `number` | `1000` | Animation duration in milliseconds at the default motion speed, scaled by the regional motion duration; 0 updates immediately. |

## Countdown API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Title content. |
| `prefix` | `ReactNode` | — | Leading content. |
| `suffix` | `ReactNode` | — | Trailing content. |
| `loading` | `boolean` | — | Show a loading state. |
| `value` | `number \| Date` | — | Required. Deadline as a Date or a millisecond timestamp. |
| `format` | `string` | `'HH:mm:ss'` | Format using DD, HH, mm, ss, SSS; HH can show total hours. |
| `onFinish` | `() => void` | — | Called once on completion. |
| `onChange` | `(remaining: number) => void` | — | Called when the value changes. |
| `initialRemaining` | `number` | — | Remaining milliseconds for SSR; updates from the deadline after mounting. |

## Types and interaction

Import the props and data types when creating reusable configuration.

```ts
import type { StatisticProps, CountdownProps } from '@ifhover/leaf-ui';
```

Provide accessible labels for icon-only actions. Interactive controls support keyboard navigation and respect ConfigProvider themes and reduced motion.
