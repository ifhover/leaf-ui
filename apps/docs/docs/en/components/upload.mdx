## Usage notes

Without action or customRequest, files remain ready for business-managed submission. action uses XMLHttpRequest for progress: POST sends FormData, PUT sends the raw file. A JSON response may provide url and name; customRequest can return the same fields. Validation applies to chooser and drop; uploads can be cancelled, removed and retried. A custom request must observe signal. Removing files or unmounting cancels requests and releases local preview URLs. Server-side validation is still required.

## UploadFile API

Extends [`FileItem`](#fileitem-api) and adds the fields below.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `uid` | `string` | Required | Required. Unique identifier |
| `url` | `string` | — | Configure url. |
| `name` | `string` | — | Field name in native FormData. |
| `size` | `number` | — | Presentation size. |
| `type` | `string` | — | Configure type. |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | Configure status. |
| `percent` | `number` | — | Completion percentage. |
| `error` | `string` | — | Configure error. |
| `originFile` | `globalThis.File` | — | Configure origin file. |
| `response` | `unknown` | — | Server response |
