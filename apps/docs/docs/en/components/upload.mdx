## Usage notes

Without action or customRequest, files remain ready for business-managed submission. action uses XMLHttpRequest for progress: POST sends FormData, PUT sends the raw file. A JSON response may provide url and name; customRequest can return the same fields. Validation applies to chooser and drop; uploads can be cancelled, removed and retried. A custom request must observe signal. Removing files or unmounting cancels requests and releases local preview URLs. Server-side validation is still required.

## UploadProps API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `fileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | Controlled file list; the internal uncontrolled list is used when omitted. |
| `defaultFileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | Initial file list for uncontrolled usage; native form reset is supported. |
| `onChange` | `(files: `[`UploadFile`](#uploadfile-api)`[], info: `[`UploadChangeInfo`](#uploadchangeinfo-api)`) => void` | — | File list and status changes |
| `accept` | `string` | — | Accepted MIME types or extensions, e.g. image/*,.pdf |
| `multiple` | `boolean` | `false` | Whether multiple files can be selected. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `drag` | `boolean` | `false` | Whether the dropzone is enabled. |
| `maxCount` | `number` | — | Maximum total file count |
| `maxSize` | `number` | — | Maximum bytes per file |
| `beforeUpload` | `(file: File) => boolean \| File \| Promise<boolean \| File>` | — | Validate before upload; false rejects, File transforms it |
| `onReject` | `(rejections: readonly `[`UploadRejection`](#uploadrejection-api)`[]) => void` | — | Type, size, count or validation rejections |
| `action` | `string \| ((file: File) => string \| Promise<string>)` | — | Upload URL; omitted configuration selects files only |
| `method` | `'POST' \| 'PUT'` | `'POST'` | POST sends FormData; PUT sends the raw file |
| `headers` | `Readonly<Record<string, string>>` | — | Request headers |
| `data` | `Readonly<Record<string, string \| Blob>>` | — | Additional POST form data |
| `withCredentials` | `boolean` | `false` | Include credentials in cross-origin requests |
| `fieldName` | `string` | `'file'` | File field name for POST |
| `customRequest` | `(request: `[`UploadRequest`](#uploadrequest-api)`) => Promise<`[`UploadResult`](#uploadresult-api)` \| void>` | — | Custom async upload; use signal for cancellation |
| `onRemove` | `(file: `[`UploadFile`](#uploadfile-api)`) => boolean \| void \| Promise<boolean> \| Promise<void>` | — | Before removal; return false to keep the file |
| `showFileList` | `boolean` | `true` | Display the file list |
| `hint` | `ReactNode` | — | Help text below the chooser area. |
| `children` | `ReactNode` | — | Title of the chooser button or dropzone. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |
| `required` | `boolean` | — | Require a non-empty value; compound controls validate once. |
| `autoUpload` | `boolean` | `true` | Start after validation; use ref.upload() when false. |
| `concurrency` | `number` | `3` | Maximum concurrent upload requests. |
| `directory` | `boolean` | — | Choose a directory and its files, subject to browser support. |
| `paste` | `boolean` | — | Accept files from the clipboard. |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | File list presentation. |

## UploadFile API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `uid` | `string` | Required | Stable, unique file identity used to target upload and cancellation. |
| `url` | `string` | — | File URL for download or image preview. |
| `name` | `string` | — | File name, not the FormData field name. |
| `size` | `number` | — | File size in bytes. |
| `type` | `string` | — | MIME type; inferred from the extension when omitted. |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | Current upload status. |
| `percent` | `number` | — | Upload progress from 0 to 100. |
| `error` | `string` | — | Failure message. |

## UploadHandle
| Method | Type | Description |
| --- | --- | --- |
| `upload` | `(uid?: string) => void` | Start the file with the given uid, or all pending files when uid is omitted. |
| `abort` | `(uid?: string) => void` | Abort the upload with the given uid, or all uploads when uid is omitted. |
| `focus` | `() => void` | Focus the upload control. |
