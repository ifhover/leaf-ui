## Examples

### File restrictions

Use `accept`, `maxSize` and `maxCount` to limit formats, per-file size and total file count. Rejections appear below the control and are available in `onReject`. Accepted files from the same batch are still added. Always validate files on the server.

<ComponentExample exampleId="restrictions" preview={<UploadRestrictions />} fileName="restrictions.tsx" width={480}>

```tsx lineNumbers file="../../../src/examples/en/upload/restrictions.tsx"
```

</ComponentExample>

Validation runs in this order: format, size, count, then `beforeUpload`. Returning `false` or throwing rejects the file. Returning a `File` replaces the upload payload without rechecking its format or size. `multiple={false}` limits each selection to one file; use `maxCount={1}` to limit the entire list to one.

### Drag, progress and cancellation

Set `drag` to accept dropped files. This example simulates uploads locally and sends no requests. Cancel an active upload, then retry cancelled or failed files. A `customRequest` must use `signal` to abort the transport, report progress with `onProgress`, resolve on success and reject on failure.

<ComponentExample exampleId="advanced" preview={<UploadDrag />} fileName="advanced.tsx" width={480}>

```tsx lineNumbers file="../../../src/examples/en/upload/advanced.tsx"
```

</ComponentExample>

Set `action` to connect a service: `POST` sends `FormData` containing `data` and the file under `fieldName`; `PUT` sends the raw file. A JSON response or `customRequest` result can provide `url` and `name`. If both are configured, `customRequest` takes precedence over `action`.

### Manual upload

`autoUpload={false}` prevents uploads from starting immediately after selection. Call `upload()` on the ref to start. `abort()` cancels active requests and clears the queue without removing files. This example uses a simulated local request.

#### List and form integration

When providing `fileList`, write the new list back on every `onChange`, including progress, success, failure, cancellation and removal. Use `defaultFileList` for uncontrolled state. Form reset aborts uploads and restores the initial uncontrolled list; reset controlled state in your application.

`name` is the native `FormData` field, distinct from the request’s `fieldName`. Items contribute repeated fields containing their `originFile`, or their URL when no file is available. Items without either are skipped. Ready, failed and cancelled items are not excluded based on status. `required` checks for a non-empty list, not successful uploads.

Use `onRemove` to check whether a file can be removed; return `false` to keep it. For file display and custom actions, see [FileList](./file-list.mdx).

## API

### UploadProps API

Configure file selection, upload requests and file-list feedback.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `fileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | — | Controlled file list; the internal uncontrolled list is used when omitted. |
| `defaultFileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | Initial file list for uncontrolled usage; native form reset is supported. |
| `onChange` | `(files: `[`UploadFile`](#uploadfile-api)`[], info: `[`UploadChangeInfo`](#uploadchangeinfo-api)`) => void` | — | File list and status changes |
| `accept` | `string` | — | Accepted MIME types or extensions, e.g. image/*,.pdf |
| `multiple` | `boolean` | `false` | Allow multiple files per selection; use maxCount to limit total entries. |
| `maxCount` | `number` | — | Maximum total file count |
| `maxSize` | `number` | — | Maximum bytes per file |
| `beforeUpload` | `(file: File) => boolean \| File \| Promise<boolean \| File>` | — | Validate or transform before acceptance; false or rejection refuses the file. Replacement files are not rechecked for type and size. |
| `onReject` | `(rejections: readonly `[`UploadRejection`](#uploadrejection-api)`[]) => void` | — | Type, size, count or validation rejections |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `drag` | `boolean` | `false` | Whether the dropzone is enabled. |
| `paste` | `boolean` | — | Accept files from the clipboard. |
| `directory` | `boolean` | — | Choose a directory and its files, subject to browser support. |
| `autoUpload` | `boolean` | `true` | Start after validation; use ref.upload() when false. |
| `concurrency` | `number` | `3` | Maximum concurrent upload requests. |
| `action` | `string \| ((file: File) => string \| Promise<string>)` | — | Upload URL; files are only selected when neither action nor customRequest is configured. |
| `customRequest` | `(request: `[`UploadRequest`](#uploadrequest-api)`) => Promise<`[`UploadResult`](#uploadresult-api)` \| void>` | — | Custom transport taking precedence over action; resolve on success, reject on failure and honor signal cancellation. |
| `method` | `'POST' \| 'PUT'` | `'POST'` | POST sends FormData; PUT sends the raw file |
| `headers` | `Readonly<Record<string, string>>` | — | Request headers |
| `data` | `Readonly<Record<string, string \| Blob>>` | — | Additional POST form data |
| `withCredentials` | `boolean` | `false` | Include credentials in cross-origin requests |
| `fieldName` | `string` | `'file'` | File field name in the POST upload request, distinct from native form name. |
| `showFileList` | `boolean` | `true` | Display the file list |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | File list presentation. |
| `onRemove` | `(file: `[`UploadFile`](#uploadfile-api)`) => boolean \| void \| Promise<boolean> \| Promise<void>` | — | Called before removal; false or a rejected Promise prevents removal. |
| `hint` | `ReactNode` | — | Help text below the chooser area. |
| `children` | `ReactNode` | — | Title of the chooser button or dropzone. |
| `name` | `string` | — | Native FormData field name; entries submit Files or URL strings. Read repeated entries with getAll(). |
| `form` | `string` | — | ID of the associated native form. |
| `required` | `boolean` | — | Require at least one list entry, not a successfully uploaded file. |

### UploadHandle

Use the ref to start uploads manually or cancel them.

| Method | Type | Description |
| --- | --- | --- |
| `upload` | `(uid?: string) => void` | Start ready, failed or cancelled files with originFile; omit uid to process all eligible files. |
| `abort` | `(uid?: string) => void` | Abort the request and dequeue the given uid; omit uid to cancel all without clearing the file list. |
| `focus` | `() => void` | Focus the upload control. |

### UploadFile API

Describe a file key, status and metadata in the upload list.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `uid` | `string` | Required | Stable, unique file identity used to target upload and cancellation. |
| `url` | `string` | — | File URL for download or image preview. |
| `name` | `string` | — | File name, not the FormData field name. |
| `size` | `number` | — | File size in bytes. |
| `type` | `string` | — | Optional MIME type; display classification also checks originFile.type and the extension without filling this field. |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | Current upload status. |
| `percent` | `number` | — | Upload progress from 0 to 100. |
| `error` | `string` | — | Failure message. |
| `originFile` | `globalThis.File` | — | File used for upload, which may be a replacement returned by beforeUpload. |
| `response` | `unknown` | — | Raw server response. |

### UploadChangeInfo API

Current file and list information returned when the upload list changes.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `file` | [`UploadFile`](#uploadfile-api) | — | File associated with this change; for batch addition, the last accepted file. |
| `reason` | `'add' \| 'progress' \| 'success' \| 'error' \| 'remove' \| 'cancel'` | Required | Reason for the change. |

### UploadRejection API

Describe a rejected file and the reason it was rejected.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `file` | `File` | Required | Rejected file. |
| `reason` | `'type' \| 'size' \| 'count' \| 'validation'` | Required | Rejection reason. |
| `message` | `string` | Required | User-readable rejection message. |

### UploadRequest API

File, progress and cancellation information supplied to a custom upload request.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `file` | `File` | Required | File to upload. |
| `signal` | `AbortSignal` | Required | Cancellation signal, also triggered by removal or unmount. |
| `onProgress` | `(percent: number) => void` | Required | Report upload progress. |

### UploadResult API

The file URL and other results returned when a custom request completes.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `url` | `string` | — | Uploaded file URL. |
| `name` | `string` | — | Uploaded file name. |
| `response` | `unknown` | — | Original application response. |

### FileItem API

See [FileItem](file-list#fileitem-api) for display fields; UploadFile requires uid and adds response.
