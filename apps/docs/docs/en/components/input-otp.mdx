# InputOTP

Enter and paste verification codes.

{/* leaf:section basic */}

## Basic usage

The default code contains six digits. Paste the entire code or use one-time-code autofill; characters outside the selected mode are removed. `onComplete` only indicates that the code is filled. Validate it on your server.

<ComponentExample exampleId="basic" preview={<InputOTPBasic />} width="fit-content" fileName="basic.tsx">

```tsx lineNumbers file="../../../src/examples/en/input-otp/basic.tsx"
```

</ComponentExample>

Set `name` to include the code in FormData. Uncontrolled form reset restores `defaultValue`; controlled values must be reset in application state.

## API

### InputOTPProps API

Configuration for code length, accepted characters, controlled values and completion events.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `length` | `number` | `6` | Code length, rounded down and constrained to 1–32. |
| `value` | `string` | — | Controlled verification-code text. |
| `defaultValue` | `string` | `''` | Initial uncontrolled text, restored on form reset. |
| `onChange` | `(value: string) => void` | — | Return filtered, length-limited text after user editing. |
| `onComplete` | `(value: string) => void` | — | Called when user input reaches the specified length; the server must still verify the code. |
| `mode` | `'numeric' \| 'alphanumeric'` | `'numeric'` | Accept digits or alphanumeric characters. |
| `mask` | `boolean \| string` | `false` | Hide visible slot characters with dots for true or the specified string; input and submitted values remain unchanged. |
| `separator` | `(index: number) => ReactNode` | — | Insert separator content after the character at a zero-based index; not called after the last character. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input cell size. |
| `status` | `'error' \| 'warning'` | — | Display state |
