## Vertical menu groups

Use `type: 'group'` in `items`, with `label` for the group title and `children` for menu items. Titles accept ReactNode and are skipped by selection and arrow navigation. Collapsed menus hide titles while keeping items available.

## Reuse group titles

`MenuGroup` shares the menu group title style. Its `title` accepts ReactNode and its `children` can contain a menu, descriptions, buttons or any custom elements. For groups containing only menu items, prefer the `items` API above to share selection state and keyboard navigation within one Menu.

Place custom content in a standalone `MenuGroup` beside Menu so controls keep their own Tab order and keyboard behavior. `MenuGroup` does not manage selection, expansion or collapse. The application decides whether to hide this section when a sidebar collapses.

## MenuProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`MenuItem`](#menuitem-api)`[]` | Required | Items; keep keys unique and stable |
| `variant` | `'default' \| 'raised' \| 'primary'` | `'default'` | Selection appearance: default, raised or primary. |
| `selectedKey` | `string` | — | Controlled selected key |
| `defaultSelectedKey` | `string` | `''` | Initial selected key |
| `onSelect` | `(key: string, item: `[`MenuItem`](#menuitem-api)`) => void` | — | Select an item |
| `openKeys` | `readonly string[]` | — | Controlled open keys |
| `defaultOpenKeys` | `readonly string[]` | `[]` | Initially open keys |
| `onOpenChange` | `(keys: string[]) => void` | — | Open state changes |
| `collapsed` | `boolean` | `false` | Controlled collapsed state |
| `itemRender` | `(item: `[`MenuItem`](#menuitem-api)`, content: ReactNode) => ReactNode` | — | Customize item content. |
| `linkRender` | `(item: `[`MenuItem`](#menuitem-api)`, link: ReactNode) => ReactNode` | — | Render a router link while retaining supplied accessibility and event props. |
| `itemClassName` | `string \| ((item: `[`MenuItem`](#menuitem-api)`) => string)` | — | Item class, or a class computed from an item. |

## MenuItem API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique stable identifier |
| `label` | `ReactNode` | Required | Display label |
| `icon` | `ReactNode` | — | Custom icon |
| `extra` | `ReactNode` | — | Trailing content. |
| `href` | `string` | — | Destination URL |
| `disabled` | `boolean` | — | Disable interaction. |
| `danger` | `boolean` | — | Danger colors |
| `children` | `readonly `[`MenuItem`](#menuitem-api)`[]` | — | Menu entries. |
| `type` | `'item' \| 'group' \| 'divider'` | — | Menu entry type: item, group or divider. |
