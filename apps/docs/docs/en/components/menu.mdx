## Reuse group titles

`MenuGroup` shares the menu group title style. Its `title` accepts ReactNode and its `children` can contain a menu, descriptions, buttons or any custom elements. For groups containing only menu items, prefer the `items` API above to share selection state and keyboard navigation within one Menu.

Place custom content in a standalone `MenuGroup` beside Menu so controls keep their own Tab order and keyboard behavior. `MenuGroup` does not manage selection, expansion or collapse. The application decides whether to hide this section when a sidebar collapses.

## Usage

The vertical menu defaults to 240px (60px when collapsed); use style.width to customize it. items supports nesting, groups, dividers and links. selectedKey controls the current item and openKeys controls expanded items. Horizontal and collapsed modes display submenus in floating panels.

Horizontal submenus open below their trigger. Collapsed sidebar submenus open to the side with a parent title. Popups share aligned icons, labels, group headings and selected backgrounds; the current page and its parent remain highlighted. RTL reverses the side placement, and popups adjust near viewport edges.

Submenus animate in both directions, and the sidebar width transitions when collapsed. Closed items are excluded from keyboard navigation. Transitions are disabled when the system requests reduced motion.

Menu items, hover backgrounds and selection highlights share the base radius with buttons. Set `ConfigProvider`'s `theme.borderRadius` to adjust them together, or use `theme.components.Menu.borderRadius` to customize the menu radius.

## MenuItem API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Required. Unique stable identifier |
| `label` | `ReactNode` | Required | Required. Display label |
| `icon` | `ReactNode` | — | Custom icon |
| `href` | `string` | — | Destination URL |
| `disabled` | `boolean` | — | Disable interaction. |
| `danger` | `boolean` | — | Danger colors |
| `children` | `readonly `[`MenuItem`](#menuitem-api)`[]` | — | Content or child items |
| `type` | `'item' \| 'group' \| 'divider'` | — | Visual or item type |

## MenuProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`MenuItem`](#menuitem-api)`[]` | Required | Required. Items; keep keys unique and stable |
| `mode` | `'vertical' \| 'horizontal' \| 'inline'` | `'vertical'` | Menu orientation and behavior |
| `selectedKey` | `string` | — | Controlled selected key |
| `defaultSelectedKey` | `string` | `''` | Initial selected key |
| `onSelect` | `(key: string, item: `[`MenuItem`](#menuitem-api)`) => void` | — | Select an item |
| `openKeys` | `readonly string[]` | — | Controlled open keys |
| `defaultOpenKeys` | `readonly string[]` | `[]` | Initially open keys |
| `onOpenChange` | `(keys: string[]) => void` | — | Open state changes |
| `collapsed` | `boolean` | `false` | Controlled collapsed state |
| `itemRender` | `(item: `[`MenuItem`](#menuitem-api)`, content: ReactNode) => ReactNode` | — | Customize item content. |
| `linkRender` | `(item: `[`MenuItem`](#menuitem-api)`, link: ReactNode) => ReactNode` | — | Render a router link while retaining supplied accessibility and event props. |
| `itemClassName` | `string \| ((item: `[`MenuItem`](#menuitem-api)`) => string)` | — | Item class, or a class computed from an item. |

## MenuGroup API

Accepts native div attributes and a ref to `HTMLDivElement`. The title provides an accessible name; override it with `aria-label` or `aria-labelledby`. Import from the package root or `@ifhover/leaf-ui/menu`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Required. Group title, sharing the style used by Menu groups |
| `children` | `ReactNode` | — | Menu or any custom content |
