## Usage

ConfigProvider provides the bar. start() returns the completion function for that task; call it in finally. Concurrent tasks keep the bar active until all finish.

## Types

Import these types for data, callbacks and refs.

```ts
import type { LoadingBarApi, LoadingBarProps, LoadingBarProviderProps } from '@ifhover/leaf-ui';
```

## LoadingBarApi API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `start` | `() => () => void` | Required | Start a task; returns its completion function |
| `finish` | `() => void` | Required | Finish one task; hide after all finish |
| `set` | `(progress: number) => void` | Required | Set displayed progress |
| `reset` | `() => void` | Required | Reset or retry |

## LoadingBarProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | Loading is active |
| `progress` | `number` | — | Progress 0–100; omitted estimates progress |
| `color` | `string` | — | Color |
| `height` | `number` | `3` | Height, numbers are in pixels |
| `position` | `'top' \| 'bottom'` | `'top'` | Display or insertion position |
| `className` | `string` | — | Container class name |
| `style` | `CSSProperties` | — | Container inline styles |
