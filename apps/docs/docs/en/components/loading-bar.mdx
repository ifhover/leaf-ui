# LoadingBar

Show page or task loading progress at the edge of the viewport.

{/* leaf:section basic */}

## Basic usage

Call `useLoadingBar()` inside [ConfigProvider](/en/components/config-provider). If one is already present, do not add another wrapper. Use `LoadingBarProvider` when you need an independent bar; nesting ConfigProvider reuses the existing bar.

`start()` returns a completion function for that task. Call it in `finally` whether the request succeeds or fails. Concurrent tasks keep the bar active until all finish.

`reset()` clears every task in the current provider, not just the calling component's task. Use the function returned by `start()` to finish one specific task, including when cancelling a request or cleaning it up on unmount.

### Control progress manually

For a known percentage, render `LoadingBar` directly with `active` and `progress`. Progress ranges from 0 to 100; set `active` to `false` when the task finishes. The bar does not start or stop the underlying task.

## API

### LoadingBarProps API

Props for loading state, progress and indicator placement.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | Loading is active |
| `progress` | `number` | — | Progress 0–100; omitted estimates progress |
| `color` | `string` | — | Color |
| `height` | `number` | `3` | Height, numbers are in pixels |
| `position` | `'top' \| 'bottom'` | `'top'` | Display or insertion position |
| `className` | `string` | — | Container class name |
| `style` | `CSSProperties` | — | Container inline styles |

### LoadingBarApi API

The task tracking and progress control interface returned by `useLoadingBar`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `start` | `() => () => void` | Required | Start a task and return its completion function; call it in finally or cancellation cleanup. |
| `finish` | `() => void` | Required | Complete the oldest pending task and hide once all finish; prefer the function returned by start. |
| `set` | `(progress: number) => void` | Required | Set displayed progress from 0 to 100 without starting or completing a task. |
| `reset` | `() => void` | Required | Clear all tasks and progress in the current provider without cancelling requests. |

### LoadingBarProviderProps API

Props for the container and presentation of an independent loading bar context.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | — | Color |
| `height` | `number` | `3` | Height, numbers are in pixels |
| `position` | `'top' \| 'bottom'` | `'top'` | Display or insertion position |
| `className` | `string` | — | Container class name |
| `style` | `CSSProperties` | — | Container inline styles |
| `children` | `ReactNode` | — | Children sharing this loading bar task scope. |
