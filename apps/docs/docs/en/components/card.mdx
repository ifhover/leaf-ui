## Card API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title / extra` | `ReactNode` | — | Title / header actions |
| `cover / footer` | `ReactNode` | — | Cover / footer |
| `children` | `ReactNode` | — | Body content |
| `loading` | `boolean` | `false` | Replace the body with a skeleton |
| `bordered / hoverable` | `boolean` | `true / false` | Outer outline / hover emphasis |
| `size` | `'sm' \| 'md'` | `'md'` | Content spacing |

## Types

Import the exported types when defining props or building item lists.

```ts
import type { CardProps } from '@sudden3/leaf-ui';
```

## Usage notes

Place buttons or links in extra and footer. hoverable adds visual feedback; use an explicit button or link for actions.
