## API

### Card API

Configuration for card headings, content regions, embedded tabs and loading state.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Card heading. |
| `description` | `ReactNode` | — | Supporting text below the title; only supported by the default appearance, not layered. |
| `extra` | `ReactNode` | — | Heading actions; shown at the trailing edge of tabs without a heading. |
| `tabs` | [`CardTabsProps`](#cardtabs-api) | — | Embedded tabs; replace the heading without a title or sit beneath it. |
| `cover` | `ReactNode` | — | Top cover. |
| `footer` | `ReactNode` | — | Footer content or actions; layered places them on the canvas below the content card. |
| `loading` | `boolean` | `false` | Replace body and tab-page content with skeletons; headings, tabs and actions remain enabled. |
| `bordered` | `boolean` | `true` | Show the outer border; set to `false` to remove it. |
| `shadow` | `boolean` | `true` | Show the card's resting shadow; layered cards apply it to the inner content surface. |
| `selected` | `boolean` | `false` | Mark the card as selected; use a button or selection control to manage selection. |
| `variant` | `'default' \| 'layered'` | `'default'` | Card appearance; layered separates the content surface from the heading and footer on a muted canvas. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Card size; embedded tabs follow it by default, while other children use their own sizes. |

### CardTabs API

See the <a href="tabs.html#tabs-api" target="_blank" rel="noopener noreferrer">Tabs API</a> (opens in a new tab) for embedded tab props. Card fixes `type="line"` and `placement="top"`, adds loading skeletons to tab content, and keeps `tabs.extra` on the tab bar; an empty `items` list restores an ordinary card.

```ts
type CardTabsProps = Omit<TabsProps, 'type' | 'placement' | 'children'>;
```

### CardTitle API

Supports native heading attributes and a ref to the actual heading element. `ConfigProvider` defaults for `components.CardTitle` affect directly rendered titles only; internal Card headings follow the Card size.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Visual size, matching the heading in the corresponding Card size. |
| `description` | `ReactNode` | — | Supporting text beneath the heading. |
| `extra` | `ReactNode` | — | Trailing heading actions. |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `3` | Optional semantic level; defaults to h3 like Card without changing visual size. |
| `containerProps` | `Omit<HTMLAttributes<HTMLDivElement>, 'children'>` | — | Native attributes for the title-region wrapper; heading attributes, events and ref still target the actual heading element. |
| `children` | `ReactNode` | — | Heading content. |
| `ref` | `Ref<HTMLHeadingElement>` | — | Reference to the heading element. |
