## Card API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Title / header actions |
| `description` | `ReactNode` | — | Additional description. |
| `extra` | `ReactNode` | — | Title / header actions |
| `cover` | `ReactNode` | — | Cover / footer |
| `footer` | `ReactNode` | — | Cover / footer |
| `loading` | `boolean` | `false` | Replace the body with a skeleton |
| `bordered` | `boolean` | `true` | Outer outline / hover emphasis |
| `divided` | `boolean` | `false` | Separate the heading, content and footer with subtle borders. |
| `hoverable` | `boolean` | `false` | Outer outline / hover emphasis |
| `size` | `'sm' \| 'md'` | `'md'` | Content spacing |

## Types

Import the exported types when defining props or building item lists.

```ts
import type { CardProps } from '@ifhover/leaf-ui';
```

## Usage notes

Place buttons or links in extra and footer. hoverable adds visual feedback; use an explicit button or link for actions.

## Surfaces and rich content

`description` adds supporting text beneath the title. Cards have no internal dividers by default; `divided` adds section borders and a muted footer. Customize surfaces and borders through `ConfigProvider` `components.Card`.
