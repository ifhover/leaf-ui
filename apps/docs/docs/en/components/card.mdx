# Card

Group related content and actions in a container.

Titles use a semibold weight of 600 by default. Customize it through ConfigProvider's `theme.headingWeight`.

## Sizes

`size` offers small, default and large cards, adjusting padding, heading typography and heading height together. Embedded Tabs follow the card size unless overridden with `tabs.size`. Buttons, inputs and other controls inside the card use their own `size`.

These cards share the same content to compare headings, tab bars and content spacing. Each card's tabs switch independently.

## Standalone title

Use `CardTitle` outside a card to reuse its heading style without a `Card` wrapper. Its default heading level matches Card and renders `<h3>`, so most usages need no `level`. `size` controls visual size: with the default 14px base font, `sm`, `md` and `lg` are 13px, 14px and 16px. `description` sits beneath the heading and `extra` sits at its trailing edge, matching the Card heading area.

These three content sections show small, default and large sizes with descriptions and trailing actions. Import `CardTitle` from `@ifhover/leaf-ui` or `@ifhover/leaf-ui/card`.

## Heading with tabs

With a `title` or `description`, tabs sit beneath the heading. There is no divider between the heading and tabs; the divider runs below the tab bar. Control selection with `tabs.activeKey` / `tabs.onChange`. Visited pages retain input state by default.

## Card API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Card heading. |
| `description` | `ReactNode` | — | Additional description. |
| `extra` | `ReactNode` | — | Heading actions; shown at the trailing edge of tabs without a heading. |
| `tabs` | [`CardTabsProps`](#cardtabs-api) | — | Embedded tabs; replace the heading without a title or sit beneath it. |
| `cover` | `ReactNode` | — | Top cover. |
| `footer` | `ReactNode` | — | Footer content or actions. |
| `loading` | `boolean` | `false` | Replace the body with a skeleton |
| `bordered` | `boolean` | `true` | Show the outer border |
| `variant` | `'default' \| 'inset'` | `'default'` | Card appearance; inset nests a white content surface inside a muted canvas. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Card size: padding, heading typography and height, and the default size of embedded Tabs. |

## CardTitle API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Visual size, matching the heading in the corresponding Card size. |
| `description` | `ReactNode` | — | Supporting text beneath the heading. |
| `extra` | `ReactNode` | — | Trailing heading actions. |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `3` | Optional semantic level; defaults to h3 like Card without changing visual size. |
| `containerProps` | `Omit<HTMLAttributes<HTMLDivElement>, 'children'>` | — | Native attributes for the title-region wrapper; heading attributes, events and ref still target the actual heading element. |
| `children` | `ReactNode` | — | Heading content. |
| `ref` | `Ref<HTMLHeadingElement>` | — | Reference to the heading element. |

Supports native heading attributes, including `id`, `className`, `style`, `aria-*` and events. `description` and `extra` extend the heading area only; the heading remains an `HTMLHeadingElement`, and its ref points to the actual heading. Set defaults through `ConfigProvider` `components.CardTitle` for directly rendered `CardTitle` instances. Internal Card headings continue to follow the Card size.

## Types

Import the exported types when defining props or building item lists.

```ts
import type { CardProps, CardTitleProps, CardTabsProps, TabItem } from '@ifhover/leaf-ui';
```

## Usage notes

Place buttons or links in extra and footer. Use an explicit button or link for actions.

`tabs` reuses Tabs configuration and interaction with top-aligned line tabs. `tabs.items[].children` provides each page; Card's `children` may hold shared content below all pages. `loading` replaces the content with skeletons while headings, tabs and actions stay available. Tabs follow the card's `size`; set `tabs.size` to override. An empty item list restores the ordinary card layout.

Use `tabs` to configure disabled tabs, icons, manual keyboard activation, retained or destroyed pages, overflow scroll controls and add, close or reorder callbacks. `tabs.extra` always belongs to the tab bar; with a title, Card's `extra` stays alongside the heading.

## Surfaces and rich content

`description` adds supporting text beneath the title. Cards use a subtle resting shadow offset downward and a frame lighter than ordinary dividers by default. Ordinary cards have no internal dividers; the heading, body and footer are grouped with spacing. Tabbed cards always have a divider below navigation. `variant="inset"` adds a muted canvas and white content surface that follow the active light or dark theme. Customize surfaces, borders and shadows through `ConfigProvider` `components.Card`.

## CardTabs API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`TabItem`](tabs#tabitem)`[]` | Required | Tab labels and pages; an empty list restores an ordinary card. |
| `activeKey` | `string` | First enabled item | Controlled active tab. |
| `defaultActiveKey` | `string` | First enabled item | Initially active tab. |
| `onChange` | `(key: string) => void` | — | Called when the active tab changes. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tab size; may be overridden independently. |
| `block` | `boolean` | `false` | Make the tabs share the available width equally. |
| `activationMode` | `'automatic' \| 'manual'` | `'automatic'` | Activate with arrow keys or with Enter / Space. |
| `destroyInactive` | `boolean` | `false` | Unmount pages on leaving; visited pages are retained by default. |
| `extra` | `ReactNode` | — | Trailing tab bar content. |
| `onClose` | `(key: string, event: MouseEvent<HTMLButtonElement>) => void` | — | Request removal by the application; default switching can be prevented. |
| `onAdd` | `() => void` | — | Show the add button and request a new tab. |
| `addLabel` | `string` | Localized prompt | Accessible name of the add button. |
| `overflow` | `boolean` | `true` | Show directional scroll buttons when tabs overflow. |
| `sortable` | `boolean` | `false` | Enable sorting alongside `onReorder`. |
| `onReorder` | `(items: `[`TabItem`](tabs#tabitem)`[]) => void` | — | Return the reordered original items for the application to store. |
