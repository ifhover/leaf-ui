## ConfigProvider API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | Inherited controls, forms, menus, lists and overlay spacing; explicit sizes override the preset. |
| `locale` | `LeafLocale` | `'zh-CN'` | Built-in language; nested providers inherit |
| `theme` | [`LeafTheme`](#leaftheme) | — | Regional settings; omitted fields inherit |
| `messages` | `Partial<`[`LeafMessages`](#leafmessages)`>` | — | Override built-in component messages. |
| `textMessages` | `Record<string, string>` | — | Override extended component labels using the English source text as the key. |
| `direction` | `'ltr' \| 'rtl'` | — | Text and interaction direction. |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | First day of the week; 0 is Sunday and 1 is Monday. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `maskBlur` | `boolean` | `true` | Enable mask blur for Modal, Drawer and Modal-based overlays such as confirmations and command palettes. Disable to reduce rendering cost; nested providers inherit it. |

Other native div attributes, className and style apply to the container. Configure themes through theme.

Mask blur transitions on opening and closing. Use `<ConfigProvider maskBlur={false}>` on performance-sensitive pages to keep the translucent mask without blur. This setting is independent of `theme.motion`.

| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#20834a'` | Primary color with derived interaction states; dark appearance defaults to a lighter green |

| `tokens` | [`LeafThemeTokens`](#leafthemetokens) | — | Optional advanced overrides |

## Types

```ts
import type { ConfigProviderProps, LeafTheme, LeafThemeTokens, LeafLocale } from '@sudden3/leaf-ui';

const theme: LeafTheme = { primaryColor: '#7654c6', borderRadius: 8 };
const advanced: LeafThemeTokens = { controlHeightLg: 44 };
```

`LeafLocale` is `'zh-CN' | 'en-US'`. ConfigProviderProps corresponds to the [ConfigProvider API](#configprovider-api).

## Usage notes

Nested regions merge tokens by field; explicit derived-size overrides remain inherited. Floating panels, Modal, confirmations and messages inherit the calling region’s configuration. ConfigProvider manages confirmations, messages, notifications and loading bars automatically; descendants call the corresponding hooks. See [Confirm](/en/components/confirm) and [Message](/en/components/message).

Translate application content, labels and options yourself. Configure themes through ConfigProvider and consume CSS variables in custom components. See [theming](/en/guide/theming) and [SSR usage](/en/guide/ssr).
