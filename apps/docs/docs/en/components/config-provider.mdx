# ConfigProvider

Set a shared language, theme and component defaults for an application or a local region. Nested providers inherit settings that they do not override.

## Examples

### Switch languages

#### Multilingual

`locale` changes built-in text such as date panels and empty states. Translate application headings, field labels and options separately.

#### Built-in languages

| Language | `locale` |
| --- | --- |
| Simplified Chinese | `zh-CN` |
| Traditional Chinese | `zh-TW` |
| English | `en-US` |
| Japanese | `ja-JP` |
| Korean | `ko-KR` |

The default language is Simplified Chinese, regardless of the documentation language. These five resources are included; other languages need [translation resources](#add-your-own-language).

Update `locale`, then open a date panel or the empty select to inspect the built-in text. Application labels stay unchanged.

Nested regions inherit the language unless overridden. `direction` sets text and interaction direction; `weekStartsOn` sets the first day of the week. Popups inherit these settings.

### Add your own language

Pass resources keyed by language tag through `translations`. This example supplies three French entries; missing entries use English. The field labels remain application content.

<ComponentExample exampleId="translations" preview={<ConfigProviderTranslations />} fileName="translations.tsx" width={480}>

```tsx lineNumbers file="../../../src/examples/en/config-provider/translations.tsx"
```

</ComponentExample>

`locale={['fr-FR', 'en-US']}` searches each entry in order, with built-in English as the final fallback. The first tag controls regional date and number formatting. A string is a one-item chain; empty arrays are invalid. Regional fallback such as `fr-CA → fr` is not added automatically.

Nested resources merge by language and entry. An omitted `locale` inherits the chain; an explicit value replaces it. Component text props and `components` defaults take precedence. For a complete resource, download the <a href={withBase('/locales/en-US.json')} download>English JSON template</a>. See [Translation resources](/en/api/translations) for types, JSON Schema and validation.

### Inheritance and overrides

The priority is **instance props > inner defaults > outer defaults > built-in defaults**.

<ComponentExample exampleId="inheritance" preview={<ConfigProviderInheritance />} fileName="inheritance.tsx" width={480}>

```tsx lineNumbers file="../../../src/examples/en/config-provider/inheritance.tsx"
```

</ComponentExample>

Defaults merge by component and prop. Only `undefined` falls back; values such as `false`, `0` and empty strings are retained. Objects, arrays, class names and callbacks replace the previous value rather than merging.

### Clear inherited defaults

Set a component entry to `null` to restore its built-in defaults in that region. An empty object or `undefined` continues to inherit. Other components and the theme are unaffected.

<ComponentExample exampleId="reset" preview={<ConfigProviderReset />} fileName="reset.tsx" width={480}>

```tsx lineNumbers file="../../../src/examples/en/config-provider/reset.tsx"
```

</ComponentExample>

Use `LeafComponentDefaults` to check reusable configuration. Keys match public component names; compound names use keys such as `DataTableSearch`. Aliases use their canonical key, such as `FloatButton` for `FAB`. See the [complete defaults reference](/en/api/component-defaults#leafcomponentdefaults).

Keep instance data, controlled state and events on each component. Pass a new configuration object when updating it. Internal controls are configured through their owner, such as `Modal.confirmButtonProps`; global `Button` defaults do not apply to them.

## API

### ConfigProvider API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `locale` | `LeafLocale \| readonly LeafLocale[]` | `'zh-CN'` | Current language and per-entry fallback order; inherited when omitted |
| `translations` | `Readonly<Record<string, `[`LeafTranslation`](../api/translations#leaftranslation)`>>` | — | JSON resources indexed by language tag; nested entries merge |
| `theme` | [`LeafTheme`](#leaftheme) | — | Regional settings; omitted fields inherit |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | Inherited controls, forms, menus, lists and overlay spacing; explicit sizes override the preset. |
| `components` | [`LeafComponentDefaults`](../api/component-defaults#leafcomponentdefaults) | — | Regional component defaults, inherited by component and prop. |
| `direction` | `'ltr' \| 'rtl'` | — | Text and interaction direction. |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | First day of the week; 0 is Sunday and 1 is Monday. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `maskBlur` | `boolean` | `false` | Enable mask blur for Modal, Drawer and Modal-based overlays such as confirmations and command palettes. Disable to reduce rendering cost; nested providers inherit it. |

Native div props, `className` and `style` apply to the region wrapper. The default is a translucent gray mask without blur; `maskBlur={true}` explicitly enables blur; this is independent of `theme.motion`.

### LeafTheme

Common theme options. Unspecified fields inherit from the outer region.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#1e964f'` | Primary base color shared by light and dark appearances; interaction colors are derived automatically. |
| `appearance` | `'light' \| 'dark'` | `'light'` | Light or dark; inherits explicit ancestor settings |
| `borderRadius` | `number \| string` | `8` | Base radius; small / medium / large radii use × 0.5 / 1.5 / 2 |
| `controlHeight` | `number \| string` | `34` | Base height; small / large heights use − / + 6px |
| `fontSize` | `number \| string` | `14` | Base font; small font − 1px, large font + 2px |
| `fontFamily` | `string` | System sans-serif | Font family |
| `motion` | `boolean` | `true` | Enable interaction motion in this region; reduced-motion preferences take precedence and portals inherit it. |
| `spacing` | `number` | — | Base spacing; other spacing values are derived. |
| `lineHeight` | `number \| string` | `20` | Body line height. Numbers are pixels, except numbers greater than 0 and up to 4 which keep the legacy multiplier meaning; strings are CSS lengths. |
| `headingWeight` | `400 \| 500 \| 700` | `700` | Card and Typography heading weight, default 700; other component labels use `tokens.fontWeight`, default 500. |
| `elevation` | `'none' \| 'soft' \| 'medium'` | — | Overall shadow strength. |
| `breakpoints` | `Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | — | Responsive thresholds used by useBreakpoint. |
| `tokens` | [`LeafThemeTokens`](../api/theme-tokens#leafthemetokens) | — | Optional advanced overrides |
| `components` | `Record<string, `[`LeafComponentTokens`](../api/theme-tokens#leafcomponenttokens)`>` | — | Override local styles by component name. |
