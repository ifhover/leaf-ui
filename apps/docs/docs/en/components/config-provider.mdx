# ConfigProvider

Set a shared theme, language and component defaults for an application or a local region.

Wrap the application to configure it globally, or nest providers to customize one region.

| Configure | Prop |
| --- | --- |
| Built-in text and custom languages | `locale`, `translations` |
| Primary color, appearance, size and spacing | `theme`, `density` |
| Shared component props | `components` |

## Multilingual

`locale` changes built-in text in date panels, empty states and clear actions. Translate business headings, field labels and options in your application.

### Built-in languages

These translations are included without importing a language pack. The default is Simplified Chinese when `locale` is not configured.

| Language | `locale` |
| --- | --- |
| 简体中文 (Simplified Chinese) | `zh-CN` |
| 繁體中文 (Traditional Chinese) | `zh-TW` |
| English | `en-US` |
| 日本語 (Japanese) | `ja-JP` |
| 한국어 (Korean) | `ko-KR` |

For another language, [provide translation resources](#add-your-own-language). A language tag alone does not translate built-in text. Missing entries ultimately fall back to English.

### Switch languages

Update `locale` to switch languages. Select a language from the dropdown, then open the date or empty-options control to compare built-in text in all five languages.

Nested regions inherit their parent language unless overridden. `direction` controls text direction; `weekStartsOn` sets the first day of the week. Popups inherit these settings too.

### Add your own language

Copy the <a href={withBase('/locales/en-US.json')} download>complete English JSON</a>, translate it, and pass your imported file through `translations`. Each key is a language tag. The JSON contains component groups and text only; do not repeat the language tag inside it. Partial resources are supported.

👽 A small Easter egg: this example uses [“Martian” text](https://en.wikipedia.org/wiki/Martian_language), a playful style of Chinese internet writing that mixes homophones, lookalike characters, and symbols.

Missing entries fall back to English. Application content such as field names and confirmation descriptions remains under your control.

It uses the private-use language tag `zh-CN-x-mars`, so dates and numbers retain Simplified Chinese regional formatting. This is a demonstration, not a built-in language.

The imported `zh-CN-x-mars.json`:

```json file="../../../src/examples/config-provider/zh-CN-x-mars.json"
```

`locale={['zh-CN-x-mars', 'en-US']}` looks up each missing entry in order, with built-in English as the final fallback. The first tag always controls the current language and regional date and number formatting. A string equals a one-item array; empty arrays are invalid. No implicit `zh-CN-x-mars → zh-CN` or `fr-CA → fr` fallback is added.

Nested `translations` merge by language and entry. An omitted `locale` inherits the chain; an explicit value replaces it. Text supplied through component props or `components` takes precedence. See [Translation resources](/en/api/translations) for types, JSON Schema and validation.

## Component defaults

**Set common props once instead of repeating them on every component.** Use `components` to share button styles, input hints and modal closing behavior. Change the configuration once when your conventions change.

Configure the app root to apply defaults throughout the app, or wrap a region to keep them local. Individual components can still override them with their own props.

<DocsCollapse title="Configuration keys, merging rules and usage advice">

Use `LeafComponentDefaults` for type completion. See [the complete reference](/en/api/component-defaults#leafcomponentdefaults) for configurable props.

- Keys match component names, such as `Input` and `Modal`. `Table.Cell` uses `TableCell`, and `Table.Root` uses `Table`. The aliases `FAB` and `ResizablePanels` use `FloatButton` and `Splitter`.
- Only `undefined` falls back to a default; `false`, `0`, empty strings and allowed `null` values are preserved. Objects, arrays, class names and callbacks are replaced as a whole.
- A `null` component entry clears inherited defaults; an empty object and `undefined` continue to inherit. Other components and the theme are unaffected.
- Keep instance data and events on the component, such as `Select.options`, `Modal.open` and `onChange`.
- Pass a new object when updating configuration; do not mutate the existing one.
- Configure internal actions through their owner, such as `Modal.confirmButtonProps`. They do not inherit shared `Button` defaults.

</DocsCollapse>

## API

### ConfigProvider API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `locale` | `LeafLocale \| readonly LeafLocale[]` | `'zh-CN'` | Current language and per-entry fallback order; inherited when omitted |
| `translations` | `Readonly<Record<string, `[`LeafTranslation`](../api/translations#leaftranslation)`>>` | — | JSON resources indexed by language tag; nested entries merge |
| `theme` | [`LeafTheme`](#leaftheme) | — | Regional settings; omitted fields inherit |
| `direction` | `'ltr' \| 'rtl'` | — | Text and interaction direction. |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | First day of the week; 0 is Sunday and 1 is Monday. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `maskBlur` | `boolean` | `true` | Enable mask blur for Modal, Drawer and Modal-based overlays such as confirmations and command palettes. Disable to reduce rendering cost; nested providers inherit it. |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | Inherited controls, forms, menus, lists and overlay spacing; explicit sizes override the preset. |
| `components` | [`LeafComponentDefaults`](../api/component-defaults#leafcomponentdefaults) | — | Regional component defaults, inherited by component and prop. |

Native div props, `className` and `style` apply to the region wrapper. `maskBlur={false}` disables backdrop blur while preserving the translucent mask; this is independent of `theme.motion`.

### LeafTheme

Common theme options. Unspecified fields inherit from the outer region.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#20834a'` | Primary color with derived interaction states; dark appearance defaults to a lighter green |
| `borderRadius` | `number \| string` | `10` | Base radius; small / medium / large radii use × 0.6 / 1.2 / 1.6 |
| `controlHeight` | `number \| string` | `36` | Base height; small / large heights use − / + 6px |
| `fontSize` | `number \| string` | `14` | Base font; small font − 1px, large font + 2px |
| `fontFamily` | `string` | System sans-serif | Font family |
| `appearance` | `'light' \| 'dark'` | `'light'` | Light or dark; inherits explicit ancestor settings |
| `motion` | `boolean` | `true` | Enable interaction motion in this region; reduced-motion preferences take precedence and portals inherit it. |
| `tokens` | [`LeafThemeTokens`](../api/theme-tokens#leafthemetokens) | — | Optional advanced overrides |
| `spacing` | `number` | — | Base spacing; other spacing values are derived. |
| `lineHeight` | `number` | — | Body line height. |
| `headingWeight` | `number` | — | Weight of Typography document headings; component titles use `tokens.fontWeight`. |
| `elevation` | `'none' \| 'soft' \| 'medium'` | — | Overall shadow strength. |
| `breakpoints` | `Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | — | Responsive thresholds used by useBreakpoint. |
| `components` | `Record<string, `[`LeafComponentTokens`](../api/theme-tokens#leafcomponenttokens)`>` | — | Override local styles by component name. |

### Types and complete reference

Import types when creating reusable configuration:

```ts
import type { ConfigProviderProps, LeafComponentDefaults, LeafTheme } from '@ifhover/leaf-ui';
```

- [LeafComponentDefaults](/en/api/component-defaults#leafcomponentdefaults): component keys and configurable props.
