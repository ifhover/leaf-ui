### Missing targets

`missingTarget` determines whether to center the step, skip it or request closure. If the last step is missing, `skip` also requests closure. An omitted `target` follows the same policy.

Wait until the target is mounted before starting the tour. Inserting an element later does not automatically trigger another target lookup for the current step.

## API

### Tour API

Escape and the close button request `onClose`; clicking the mask does not. The finish button calls `onFinish` followed by `onClose`. The application must update `open` to close the tour.

`defaultCurrent` is only an initial value; closing does not reset the step. Control `current` when you need a different restart position. With the default mask, focus stays inside the panel; closing returns focus to the trigger.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Control whether the panel is open. |
| `steps` | `readonly `[`TourStep`](#tourstep)`[]` | Required | Steps in the guided tour. |
| `current` | `number` | — | Controlled zero-based step index; write onChange results back to it. Reopening does not automatically reset it. |
| `defaultCurrent` | `number` | `0` | Initial zero-based step index for uncontrolled usage. |
| `onChange` | `(current: number) => void` | — | Called when the value changes. |
| `onClose` | `() => void` | — | Close request from the close button, Escape, finishing or missing-target policy; the application must set open to false. |
| `onFinish` | `() => void` | — | Called when Finish is clicked on the last step, followed by onClose. |
| `missingTarget` | `'center' \| 'skip' \| 'close'` | `'center'` | When entering a step without a target: center displays it centrally, skip advances or requests closing at the last step, and close requests closing immediately. |
| `mask` | `boolean` | `true` | Show a mask and restrict background interaction; false keeps the page interactive. |
| `padding` | `number` | `8` | Gap in pixels between the target element and its highlighted area. |
| `getPopupContainer` | [`PopupOptions`](../api/popup-options#popupoptions)`['getPopupContainer']` | — | Return a popup container, including a ShadowRoot. |

### TourStep

Use a valid CSS selector or an element getter for `target`. A getter returning `null` is treated as a missing target.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Title content. |
| `description` | `ReactNode` | — | Additional description. |
| `target` | `string \| (() => HTMLElement \| null)` | — | Target selector or function returning an element; when omitted, missingTarget policy applies. |
| `placement` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupPlacement']` | `'bottom'` | Popup placement relative to the target. |
| `key` | `string` | — | Stable, unique identifier. |
