## FloatButton API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'outline'` | Configure variant. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Presentation size. |
| `danger` | `boolean` | `false` | Configure danger. |
| `loading` | `boolean` | `false` | Show a loading state. |
| `fullWidth` | `boolean` | `false` | Configure full width. |
| `startIcon` | `ReactNode` | — | Configure start icon. |
| `endIcon` | `ReactNode` | — | Configure end icon. |
| `tooltip` | `ReactNode` | — | Tooltip content shown on hover or focus. |
| `fixed` | `boolean` | `true` | Fix to a viewport corner; false keeps it in layout. |

## FloatButtonAction

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Stable, unique identifier. |
| `label` | `ReactNode` | Required | Visible label or content. |
| `icon` | `ReactNode` | — | Icon content. |
| `onClick` | `() => void` | — | Called on click. |
| `disabled` | `boolean` | — | Disable interaction. |

## FloatButtonGroup API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `actions` | `readonly `[`FloatButtonAction`](#floatbuttonaction)`[]` | Required | Actions for the item. |
| `fixed` | `boolean` | `true` | Fix to a viewport corner; false keeps it in layout. |
| `expandable` | `boolean` | `true` | Provide a button to expand the action group. |
| `icon` | `ReactNode` | — | Icon content. |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the panel opens or closes. |
| `className` | `string` | — | Configure class name. |

## Types and interaction

Import the props and data types when creating reusable configuration.

```ts
import type { FloatButtonProps, FloatButtonAction, FloatButtonGroupProps } from '@ifhover/leaf-ui';
```

Provide an aria-label for icon-only buttons. The expanded group is keyboard operable and follows ConfigProvider themes and reduced motion.
