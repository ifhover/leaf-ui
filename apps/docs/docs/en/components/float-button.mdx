# FloatButton

Keep quick actions within reach. Use a regular [Button](/en/components/button) for actions that belong in the page content.

{/* leaf:section basic */}

## Basic usage

The button is fixed at the viewport's bottom-end corner by default. A positioned containing block bounds this preview; remove that wrapper for page-level placement. Icon-only buttons need an `aria-label`; `tooltip` does not replace it.

## API

### FloatButton API

Configuration for floating-action tooltips, positioning and button state.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `tooltip` | `ReactNode` | — | Tooltip content shown on hover or focus. |
| `fixed` | `boolean` | `true` | Fix to a viewport corner; false keeps it in layout. |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'solid'` | Button appearance; solid by default. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Presentation size. |
| `danger` | `boolean` | `false` | Use destructive-action colors without changing button behavior. |
| `loading` | `boolean` | `false` | Show a loading state. |
| `startIcon` | `ReactNode` | — | Icon before the label; icon-only buttons also need aria-label. |
| `endIcon` | `ReactNode` | — | Icon after the label. |
| `fullWidth` | `boolean` | `false` | Stretch the button to its container width. |

### FloatButtonGroup API

Set `expandable={false}` to keep the actions visible without an expansion trigger. String action labels also provide accessible names for the icon buttons.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `actions` | `readonly `[`FloatButtonAction`](#floatbuttonaction)`[]` | Required | Actions in array order; activating one calls its onClick, then closes an expandable group. |
| `open` | `boolean` | — | Controlled expanded state; update with onOpenChange. |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the trigger, outside pointer, Escape or an action requests an expanded-state change. |
| `expandable` | `boolean` | `true` | Provide a button to expand the action group. |
| `fixed` | `boolean` | `true` | Fix to a viewport corner; false keeps it in layout. |
| `icon` | `ReactNode` | — | Icon content. |
| `className` | `string` | — | CSS class added to the component root. |

### FloatButtonAction

Data for an individual action in a floating action group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Stable, unique identifier. |
| `label` | `ReactNode` | Required | Action tooltip; strings also label the button accessibly, while other content uses key as the accessible name. |
| `icon` | `ReactNode` | — | Icon content. |
| `onClick` | `() => void` | — | Called on click. |
| `disabled` | `boolean` | — | Disable interaction. |
