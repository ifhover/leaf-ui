# Tabs

Switch between content views within the same region.

Content and panel height update immediately without transition animations. Line tabs show a short rounded indicator beneath the selected label and move it to the next selection.

Line tabs use the body text color for the selected label and muted neutral text for the others, without drawing a full-width baseline. The short rounded indicator beneath the selected label uses the primary indicator color. The indicator sits on the tab's bottom edge, grows to 2 / 3 / 4 px by size and keeps a visible gap below the label because line tabs add 4 px of height. Card tabs use a light rounded selected surface, with unselected labels rendered in a lighter neutral color and no surrounding container. Segmented tabs add a muted rounded track and a white moving selection surface for compact view switching; the surface moves directly with the standard non-overshooting easing. `size` controls 32 / 38 / 44 px line tabs and 28 / 34 / 40 px card and segmented tabs. Set `block` for equal-width tabs; content panels use the available width. When labels overflow, outlined arrow buttons appear in the scrollable directions; they are visible only while the tab bar is hovered or keyboard-focused.

## Tabs API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`TabItem`](#tabitem)`[]` | Required | Tab items; an empty array hides the component |
| `activeKey` | `string` | First enabled item | Controlled / initial active key |
| `defaultActiveKey` | `string` | First enabled item | Controlled / initial active key |
| `onChange` | `(key: string) => void` | — | Active key change |
| `type` | `'line' \| 'card' \| 'segmented'` | `'line'` | Tab appearance |
| `placement` | `'top' \| 'bottom'` | `'top'` | Tab bar placement |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tab height (32 / 38 / 44 px line, 28 / 34 / 40 px card and segmented) and font size |
| `block` | `boolean` | `false` | Fill the available width with equal-width tabs |
| `activationMode` | `'automatic' \| 'manual'` | `'automatic'` | Activate on arrow navigation / Enter or Space |
| `destroyInactive` | `boolean` | `false` | Unmount content when inactive |
| `extra` | `ReactNode` | — | Extra tab bar content |
| `onClose` | `(key: string, event: MouseEvent<HTMLButtonElement>) => void` | — | Close request: remove the item in the application; preventDefault cancels selection changes |
| `onAdd` | `() => void` | — | Add tab; enables add button |
| `addLabel` | `string` | — | Accessible add button label |
| `overflow` | `boolean` | `true` | Show directional scroll buttons on overflow |
| `sortable` | `boolean` | `false` | Enable sorting; use with onReorder |
| `onReorder` | `(items: `[`TabItem`](#tabitem)`[]) => void` | — | Reordered tabs |

## TabItem

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique identifier |
| `label` | `ReactNode` | Required | Tab label |
| `children` | `ReactNode` | — | Optional panel content; omit it to render only the tab bar |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `icon` | `ReactNode` | — | Leading icon |
| `closable` | `boolean` | `false` | Show a close button; requires onClose |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { TabsProps, TabItem } from '@ifhover/leaf-ui';
```

## Usage notes

Content mounts on first visit. Visited panels and their input state are kept by default. Arrow keys skip disabled tabs, and Home / End move to the first / last tab. Use manual activation when changing content takes time.
