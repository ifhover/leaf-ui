# Modal

View or edit content in a dialog.

Use [Confirm](/en/components/confirm) for a brief decision, or [Popconfirm](/en/components/popconfirm) for a confirmation beside a trigger.

### Destroy content on close

Content is preserved after the first opening by default. `destroyOnClose` unmounts it after the closing transition, so uncontrolled inputs return to their initial values when reopened. `preserve` takes precedence over `destroyOnClose`, while `forceRender` keeps content mounted. Controlled state held outside the dialog must still be reset by the application.


</ComponentExample>

### Initial focus

Focus moves to the first focusable control by default. Use `initialFocus` to choose a different target. Closing restores the previously focused element; `returnFocus` can specify another destination.

### Async submission

Return a Promise to show loading and prevent duplicate actions. Default cancellation, close-button, backdrop and Escape dismissal are blocked while it is pending. The application must still update `open` after `onConfirm` succeeds; rejection keeps the dialog open and displays the error.

## API

### Modal API

Control modal visibility, content and footer actions.

Provide `aria-label` when omitting `title`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Controlled open state, updated by the application. |
| `title` | `ReactNode` | — | Dialog title. |
| `description` | `ReactNode` | — | Additional description. |
| `onClose` | `() => void` | — | Requests closure; update open in the application |
| `onConfirm` | `() => void \| Promise<void>` | — | Default confirm-button action, optionally returning a Promise; blocks repeated confirmation and built-in closing while pending. The application must still update open after success. |
| `onCancel` | `() => void` | — | Called when Cancel, the close button, the mask or Escape requests closing; falls back to onClose. |
| `confirmText` | `ReactNode` | Locale default | Button labels |
| `cancelText` | `ReactNode` | Locale default | Button labels |
| `confirmLoading` | `boolean` | `false` | Confirm loading state |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | Customize the default buttons |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | Customize the default buttons |
| `footer` | `ReactNode \| ((actions: `[`ModalFooterActions`](#modalfooteractions)`) => ReactNode)` | Cancel + OK | Custom footer; null hides it; a function receives default buttons |
| `variant` | `'plain' \| 'card'` | `'plain'` | Content appearance; card places the body on a separate surface. |
| `icon` | `ReactNode` | — | Decorative icon to the left of the heading. |
| `divided` | `boolean` | `false` | Separate the heading, content and footer with subtle borders. |
| `width` | `number \| string` | `480` | Width; numbers are pixels |
| `closable` | `boolean` | `true` | Show the close button. |
| `maskClosable` | `boolean` | `true` | Request closing when the mask is clicked. |
| `keyboard` | `boolean` | `true` | Allow Escape to request closing. |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Specify initial focus; defaults to the first focusable element, which may be the close button. |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Restore focus on close; specify a destination or use false. |
| `afterClose` | `() => void` | — | Called after the closing animation finishes |
| `destroyOnClose` | `boolean` | `false` | Unmount contents after closing; preserve takes precedence and forceRender keeps contents mounted. |
| `preserve` | `boolean` | — | Control content preservation, taking precedence over destroyOnClose; does not reset external controlled state. |
| `forceRender` | `boolean` | `false` | Mount before opening and keep hidden while closed. |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | Portal mount target; may also return a ShadowRoot. |

### ModalFooterActions

The default confirm and cancel buttons received by the footer render function.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `confirmButton` | `ReactNode` | Required | Default confirm button with loading state |
| `cancelButton` | `ReactNode` | Required | Default cancel button |

### DialogFocusOptions

Configure focus handling when a dialog opens or closes.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Specify initial focus after opening. |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Restore focus on close; specify a destination or use false. |
