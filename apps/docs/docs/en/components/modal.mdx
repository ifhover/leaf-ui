## Card surface

Both `plain` and `card` use the same muted canvas. `variant="card"` places the body on a borderless inset content surface 6px from the Modal frame. Its heading uses 14px type at weight 700 with a 22px line box and aligns with the content text start. The 24px close target contains a 16px icon using the stronger body text color and sits 8px inside the content card's right edge; its background is transparent at rest and gains a deeper standard neutral hover background, with the small radius (4px by default). The header uses a 12px top inset, with a single 12px section gap before the content surface and a 10px gap from the content card to footer buttons. Footer top padding is zero to avoid doubling that gap; the bottom inset is 10px, and heading text is offset 2px downward within its text column; body padding independently controls the distance from content to the card edge.

| `icon` | `ReactNode` | — | Decorative icon to the left of the heading. |
| `divided` | `boolean` | `false` | Separate the heading, content and footer with subtle borders. |
| `footer` | `ReactNode \| ((actions: `[`ModalFooterActions`](#modalfooteractions)`) => ReactNode)` | Cancel + OK | Custom footer; null hides it; a function receives default buttons |
| `confirmText` | `ReactNode` | Locale default | Button labels |
| `cancelText` | `ReactNode` | Locale default | Button labels |

| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | Customize the default buttons |
| `onConfirm` | `() => void \| Promise<void>` | — | Application controls open; rejection displays an error |
| `onCancel` | `() => void` | — | Cancel or dismiss; falls back to onClose |
| `width` | `number \| string` | `480` | Width; numbers are pixels |
| `closable` | `boolean` | `true` | Close button / backdrop dismissal / Escape dismissal |

| `keyboard` | `boolean` | `true` | Close button / backdrop dismissal / Escape dismissal |

## Usage notes

Focus moves into the dialog when opened and returns to the trigger on dismissal. Tab stays within the dialog. Use maskClosable and keyboard to control backdrop and Escape dismissal. Supply aria-label when omitting title.

Customize footer actions or place a Form inside the body. Picker overlays inside a dialog retain its regional theme.

The default footer has an outlined Cancel followed by OK. With onConfirm, update open after the action; without it, OK calls onClose. Promises show loading and prevent duplicates. Submit forms with requestSubmit() in onConfirm or a submit type and form ID in confirmButtonProps. Native validation still applies. A footer function extends default buttons; `footer={null}` hides the footer.

## Surfaces and rich content

Use `description` for supporting text and `icon` for a decorative heading icon. Dialogs use a muted canvas and spacing between sections by default, with matching heading and footer inline spacing and an outlined cancel button; set `divided` for subtle dividers and a muted footer. The soft, blurred backdrop follows the regional light or dark appearance; set `ConfigProvider`'s `maskBlur={false}` to disable blur. A `footer` function can add status text on the left. Group its buttons with `Space` so they wrap together and stay aligned to the right on narrow screens.
