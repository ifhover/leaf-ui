# FileList

Display file information with preview, download and removal actions. Your application owns the file data; use [Upload](./upload.mdx) for uploads.

{/* leaf:section basic */}

## Basic usage

Pass file information through `items`, with a stable `uid` for each item. Sizes are in bytes and fall back to `originFile.size`; no size is displayed if neither is available. Remote file metadata is not fetched.

Set both `removable` and `onRemove` to show removal actions. Update `items` in the callback to remove the item; the return value itself does not change the list. This example uses a short delay to simulate asynchronous deletion. The button prevents repeated actions while pending. A rejected Promise displays an error in that row and allows another attempt.

## API

### FileListProps API

#### File data and actions

Names fall back from `name` to `originFile.name`, then the URL filename, and finally a default name. File icons and media detection use MIME types or extensions. Failed thumbnails fall back to a type icon. These inferences do not modify your file data.

Media playback depends on browser codec support. Cross-origin downloads may open in a new tab; use `onDownload` to connect a download service. When adding controls through `renderActions`, provide accessible names and handle their disabled state.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`FileItem`](#fileitem-api)`[]` | Required | Files to display |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | File list presentation. |
| `previewable` | `boolean` | `true` | Show preview actions for images, video and audio with a URL |
| `downloadable` | `boolean` | `true` | Show download actions for files with a URL |
| `removable` | `boolean` | `false` | Show removal actions when `onRemove` is also provided |
| `onPreview` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | Replace preview for images, video and audio with a usable URL; other files and entries without a URL have no preview button. |
| `onDownload` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | Replace built-in download for a usable URL; no download button appears without a URL. |
| `onRemove` | `(file: `[`FileItem`](#fileitem-api)`) => void \| boolean \| Promise<void> \| Promise<boolean>` | — | Await removal and prevent repeated clicks; the application must update items. Boolean results do not control the list; Promise rejection shows an inline error. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `renderActions` | `(file: `[`FileItem`](#fileitem-api)`, actions: ReactNode) => ReactNode` | — | Customize row actions; provide accessible names and disabled handling for custom actions. |
| `emptyContent` | `ReactNode` | No files | Empty list content |

### FileItem API

The file, state and presentation metadata of a file list entry.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `uid` | `string` | — | Stable identifier, recommended |
| `name` | `string` | — | Display name; falls back to originFile.name, the URL filename, then File. Data URLs do not provide a filename. |
| `url` | `string` | — | File URL |
| `size` | `number` | — | Size in bytes; falls back to originFile.size and is hidden only when both are absent. |
| `type` | `string` | — | Optional MIME type; display classification also checks originFile.type and the extension without filling this field. |
| `originFile` | `globalThis.File` | — | Original browser File |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | Optional upload status |
| `percent` | `number` | — | Upload progress from 0 to 100 |
| `error` | `string` | — | Error description |
