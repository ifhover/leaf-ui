## Usage notes

Size is optional and no file metadata is fetched automatically. Icons follow MIME types or extensions; failed thumbnails fall back to a type icon. Preview is available for images, video and audio; other files show download only. Browser codec support determines media playback. Cross-origin downloads may open in a new tab; use `onDownload` for your download service. Use [Upload](./upload.mdx) to handle file uploads.

## FileListProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`FileItem`](#fileitem-api)`[]` | Required | Files to display |
| `downloadable` | `boolean` | `true` | Show download actions for files with a URL |
| `previewable` | `boolean` | `true` | Show preview actions for images, video and audio with a URL |
| `removable` | `boolean` | `false` | Show removal actions when `onRemove` is also provided |
| `onPreview` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | Override media preview; uses the built-in preview when omitted |
| `onDownload` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | Override download; uses the file URL when omitted |
| `onRemove` | `(file: `[`FileItem`](#fileitem-api)`) => void \| boolean \| Promise<void> \| Promise<boolean>` | — | Request removal; the caller updates `items`. Waits for async callbacks and shows rejections in the affected row. Return `false` to deny removal |
| `renderActions` | `(file: `[`FileItem`](#fileitem-api)`, actions: ReactNode) => ReactNode` | — | Customize the action area |
| `emptyContent` | `ReactNode` | No files | Empty list content |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | File list presentation. |

## FileItem API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `uid` | `string` | — | Stable identifier, recommended |
| `url` | `string` | — | File URL |
| `name` | `string` | — | Name, inferred from URL if omitted |
| `size` | `number` | — | Bytes; omitted sizes are not displayed |
| `type` | `string` | — | MIME type; inferred from the extension if omitted |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | Optional upload status |
| `percent` | `number` | — | Upload progress from 0 to 100 |
| `error` | `string` | — | Error description |
| `originFile` | `globalThis.File` | — | Original browser File |
