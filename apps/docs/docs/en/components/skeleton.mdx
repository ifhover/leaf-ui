## API

### Skeleton API

Configure placeholder rows, shapes and animation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `loading` | `boolean` | `true` | Show placeholders; children render only when false. |
| `active` | `boolean` | `true` | Animate the placeholders. |
| `avatar` | `boolean` | `false` | Show an avatar placeholder. |
| `title` | `boolean` | `true` | Title placeholder |
| `titleWidth` | `number \| string` | `'38%'` | Title width |
| `rows` | `number` | `3` | Body rows, up to 20 |
| `rowWidths` | `readonly (number \| string)[]` | — | Widths of each row |
| `round` | `boolean` | `false` | Use pill-shaped title and body placeholders; the avatar is unchanged. |
| `children` | `ReactNode` | — | Content shown after loading finishes. |
