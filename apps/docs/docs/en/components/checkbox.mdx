## Checkbox API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `variant` | `'plain' \| 'card'` | `'plain'` | Plain choice or a card with a full clickable surface. |
| `description` | `ReactNode` | — | Additional description. |
| `icon` | `ReactNode` | — | Icon content. |
| `extra` | `ReactNode` | — | Supplementary status or tags; avoid interactive controls. |
| `indeterminate` | `boolean` | `false` | Partially checked state |
| `checked` | `boolean` | — | Controlled checked state / initial checked state |
| `defaultChecked` | `boolean` | — | Controlled checked state / initial checked state |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Called when the value changes. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `children` | `ReactNode` | — | Content, or child nodes for hierarchical records. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.

## Surfaces and rich content

Checkbox variant="card" makes the whole label clickable. CheckboxGroup variant="card" arranges cards; variant="list" groups rows into one surface. description and extra provide accessible descriptions; icon is decorative. Keep extra to non-interactive status, without buttons or links. Native names, values, forms, reset and keyboard behavior remain available.
