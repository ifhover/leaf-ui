#### Forms and reset

With `name`, only checked and enabled choices are submitted. A checkbox group submits repeated values under the same name; read them with `FormData.getAll(name)`.

Uncontrolled fields return to `defaultChecked` or `defaultValue` on form reset. For controlled fields, reset the corresponding application state as well.

## API

### Checkbox API

Native checkbox attributes such as `name`, `value`, `required` and `form` are supported. Provide `aria-label` when there is no text label. `className` and `style` apply to the label container.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `variant` | `'plain' \| 'card'` | `'plain'` | Plain choice or a card with a full clickable surface. |
| `description` | `ReactNode` | — | Additional description. |
| `icon` | `ReactNode` | — | Icon content. |
| `extra` | `ReactNode` | — | Supplementary status or tags; avoid interactive controls. |
| `indeterminate` | `boolean` | `false` | Partially checked state |
| `checked` | `boolean` | — | Controlled checked state. |
| `defaultChecked` | `boolean` | — | Initial checked state for uncontrolled usage. |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Read the selection from event.target.checked. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `children` | `ReactNode` | — | Clickable choice label. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

### CheckboxGroupProps API

Props for managing the options and values of a checkbox group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly (`[`CheckboxOption`](#checkboxoption-api)` \| string)[]` | Required | Available options |
| `value` | `readonly string[]` | — | Controlled value |
| `defaultValue` | `readonly string[]` | `[]` | Initial value, restored by uncontrolled form resets |
| `onChange` | `(values: string[]) => void` | — | Value change callback |
| `legend` | `ReactNode` | — | Field group title |
| `size` | `'sm' \| 'md' \| 'lg'` | — | Checkbox size. |
| `variant` | `'plain' \| 'card' \| 'list'` | `'plain'` | Plain choices, a card grid or a list with shared borders and dividers. |
| `required` | `boolean` | — | Require a non-empty value; compound controls validate once. |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Layout direction of the options. |

### CheckboxOption API

Option data supplied through a checkbox group's `options`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Option value; unique within the group. |
| `label` | `ReactNode` | Required | Display label |
| `description` | `ReactNode` | — | Additional description. |
| `icon` | `ReactNode` | — | Icon content. |
| `extra` | `ReactNode` | — | Supplementary status or tags; avoid interactive controls. |
| `disabled` | `boolean` | — | Disable interaction. |
