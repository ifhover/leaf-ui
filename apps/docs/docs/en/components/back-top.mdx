## Usage

The default target is the window. Return a scrolling element from target to use a custom container. The button appears after visibilityHeight and respects reduced-motion preferences.

## Types

Import these types for data, callbacks and refs.

```ts
import type { BackTopProps } from '@ifhover/leaf-ui';
```

## BackTopProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `target` | `() => HTMLElement \| Window \| null` | — | Returns the scroll container; listens to the page when omitted. |
| `visibilityHeight` | `number` | `400` | Show after this scroll distance |
| `behavior` | `ScrollBehavior` | `'smooth'` | Scroll behavior |
