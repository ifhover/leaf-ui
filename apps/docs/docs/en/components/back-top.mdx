# BackTop

Return to the top of a page or scroll container.

## Basic usage

<a id="page-scrolling"></a>

By default, BackTop listens to the window and appears in a viewport corner when the scroll position reaches `visibilityHeight`. Click the example button to scroll this page, then use the bottom-right button to return to the top.

## API

### BackTopProps API

Omitting `target`, or returning `null`, uses the window. When reduced motion is requested or [ConfigProvider](/en/components/config-provider) disables motion, scrolling uses `auto` regardless of `behavior`.

You can supply a native `onClick` handler. Calling `event.preventDefault()` prevents the built-in scroll action.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `target` | `() => HTMLElement \| Window \| null` | — | Return the scroll container; omitted or null uses window. |
| `visibilityHeight` | `number` | `400` | Show when the scroll distance is at or above this pixel value. |
| `behavior` | `ScrollBehavior` | `'smooth'` | Scroll-to-top behavior; auto is used when motion is disabled or reduced motion is preferred. |
