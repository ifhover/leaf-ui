Show the color text with `showText` and set its initial format with `defaultFormat`. Switching formats preserves the current value; the next adjustment uses the new format.

### Gradients

Set `mode="gradient"` to edit the angle and color stops. The value is a `linear-gradient(...)` string.

<ComponentExample exampleId="gradient" preview={<ColorPickerGradient />} fileName="gradient.tsx" width="fit-content">

```tsx lineNumbers file="../../../src/examples/en/color-picker/gradient.tsx"
```

</ComponentExample>

For structured stops, `gradientString` converts a [`ColorGradient`](#colorgradient) into a string. `parseGradient` parses supported linear gradients and returns `null` for values it cannot parse.

### Controlled value and clearing

<a id="advanced-usage"></a>

Manage the color with `value` and `onChange`. `allowClear` clears the value to an empty string. `onChange` fires while dragging; use `onChangeComplete` when you only need the final value.

<ComponentExample exampleId="controlled" preview={<ColorPickerControlled />} fileName="controlled.tsx" width={360}>

```tsx lineNumbers file="../../../src/examples/en/color-picker/controlled.tsx"
```

</ComponentExample>

Color text is submitted on Enter or blur; invalid input displays an error. Set `name` for native form submission. Uncontrolled fields support form reset; reset controlled application state yourself.

## API

### ColorPicker API

Configuration for color values, output formats, presets and panel interactions.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: ReactNode) => ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `value` | `string` | — | Controlled color; accepts HEX, RGB, HSL and CSS named colors, or a linear-gradient string in gradient mode. |
| `defaultValue` | `string` | `'#1e964f'` | Initial uncontrolled color, restored when the form resets. |
| `onChange` | `(color: string) => void` | — | Fires continuously while adjusting; clearing returns an empty string. |
| `onChangeComplete` | `(color: string) => void` | — | Fires once when an adjustment ends; clearing returns an empty string. |
| `format` | `'hex' \| 'rgb' \| 'hsl'` | `'hex'` | Color text format, applied to each stop in gradient mode. |
| `defaultFormat` | `'hex' \| 'rgb' \| 'hsl'` | `'hex'` | Initial color text format. |
| `onFormatChange` | `(format: 'hex' \| 'rgb' \| 'hsl') => void` | — | Called when the color text format changes. |
| `disableAlpha` | `boolean` | `false` | Hide opacity and output opaque colors |
| `showText` | `boolean \| ((color: string) => ReactNode)` | `false` | Show color text or custom content |
| `allowClear` | `boolean` | `false` | Allow clearing |
| `presets` | `readonly `[`ColorPreset`](#colorpreset)`[]` | Built-in colors | Groups of preset colors. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Trigger size |
| `status` | `'error' \| 'warning'` | — | Validation status |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `readOnly` | `boolean` | — | Lock the value against typing, selection, clearing and removal. |
| `popupWidth` | `number \| string` | `280` | Panel width |
| `onOpenChange` | `(open: boolean) => void` | — | Open state changes |
| `gradient` | `boolean` | `false` | Enable gradient color selection. |
| `mode` | `'solid' \| 'gradient'` | — | Presentation or editing mode. |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | — | Initial open state. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |

### ColorPreset

The title and color values of a preset color group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | Required | Group heading |
| `colors` | `readonly string[]` | Required | Color values in the group |

### ColorGradient

A color value describing gradient direction and stops.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `angle` | `number` | Required | Gradient angle in degrees. |
| `stops` | `readonly `[`ColorGradientStop`](#colorgradientstop)`[]` | Required | Color stops in the gradient. |

### ColorGradientStop

A color and its position within a gradient.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable, unique identifier. |
| `color` | `string` | Required | Color or semantic tone. |
| `offset` | `number` | Required | Offset; color stops use a percentage from 0 to 100. |
