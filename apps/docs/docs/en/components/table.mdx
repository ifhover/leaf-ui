## API

### Table API

Configure data, columns, row interactions, and presentation options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | Required | Data to display; provide a new array when updating. |
| `columns` | `readonly `[`TableColumn`](#tablecolumn)`<TData>[]` | Required | Column definitions. |
| `rowKey` | [`TableRowKey`](#tablerowkey)`<TData>` | Required | A required string/number identity field, or a function returning a string/number identity. |
| `size` | `'sm' \| 'md'` | `'md'` | Presentation size. |
| `bordered` | `boolean` | `false` | Show outer border and cell grid lines. |
| `striped` | `boolean` | `false` | Show alternating row backgrounds. |
| `rowSelection` | [`TableRowSelection`](#tablerowselection)`<TData>` | — | Row selection options (multiple or single). |
| `expandable` | [`TableExpandable`](#tableexpandable)`<TData>` | — | Expandable detail row and tree row options. |
| `sort` | [`TableSorterState`](#tablesorterstate)` \| readonly `[`TableSorterState`](#tablesorterstate)`[] \| null` | — | Controlled sorting state. |
| `defaultSort` | [`TableSorterState`](#tablesorterstate)` \| readonly `[`TableSorterState`](#tablesorterstate)`[] \| null` | — | Initial sorting state in uncontrolled mode. |
| `onSortChange` | `(sorter: `[`TableSorterState`](#tablesorterstate)` \| null, sorters: `[`TableSorterState`](#tablesorterstate)`[]) => void` | — | Called when sorting changes with the primary sorter and full sorter list. |
| `multiSort` | `boolean` | `false` | Allow Shift+clicking column headers to layer multiple sorters. |
| `manualSorting` | `boolean` | `false` | Server-side sorting mode; tracks sorting state without reordering data locally. |
| `pagination` | `boolean \| `[`TablePaginationProps`](#tablepagination-api) | `true` | Pagination visibility or options; see <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a>. Set false to disable pagination. |
| `manualPagination` | `boolean` | — | Skip local page slicing for server pagination; enabled automatically when pagination.total is negative or exceeds data.length. |
| `resizable` | `boolean` | `false` | Show resize handles for eligible columns. |
| `onColumnResize` | `(columnKey: string, width: number) => void` | — | Called when a column is resized via pointer or keyboard. |
| `virtual` | `boolean \| `[`TableVirtualOptions`](#tablevirtualoptions) | `false` | Explicit row virtualization. |
| `maxHeight` | `CSSProperties['maxHeight']` | — | Maximum viewport height; headers stay fixed while the body scrolls. Defaults to 400 in virtual mode. |
| `minWidth` | `CSSProperties['minWidth']` | — | Minimum content-area width; adapts to the container and column widths by default. |
| `loading` | `boolean` | `false` | Show a loading state. |
| `emptyContent` | `ReactNode` | — | Empty content. |
| `error` | `ReactNode` | — | Error content; null, undefined and false do not show an error. |
| `onRetry` | `() => void` | — | Retry callback. |
| `getRowLabel` | `(record: TData, index: number) => string` | — | Accessible row-action name; defaults to the resolved row key. |
| `onRow` | `(record: TData, index: number) => `[`TableRowProps`](#tablerow-api) | — | Customize data row native attributes, events, and selection appearance. |
| `tableRef` | `Ref<HTMLTableElement>` | — | Native table DOM ref. |

`aria-label` / `aria-labelledby` apply to the inner native table; other div attributes apply to the wrapper.

- <a id="tablekey"></a><a id="tablerowkey"></a>`TableRowKey<TData>`: a required string/number field name or `(record: TData, index: number) => TableKey` function (`TableKey = string | number`); must resolve to a stable unique identifier rather than array indices.
- <a id="tablesortorder"></a><a id="tablesorterstate"></a>`TableSorterState`: `{ columnKey: string; order: 'asc' | 'desc' }`; `TableSortOrder` is `'asc' | 'desc' | null`.
- <a id="tablerow-api"></a>`TableRowProps` (returned by `onRow`): supports native `tr` attributes and events, plus `selected?: boolean` for selected-row styling.
- <a id="tablecell-api"></a><a id="tableheadercell-api"></a>`TableCellProps` / `TableHeaderCellProps` (returned by `onCell` / `onHeaderCell`): support native `td` / `th` attributes, events, and `colSpan` / `rowSpan` (a `0` span omits the cell), plus `align` (`'start' | 'center' | 'end'`).
- <a id="tablepresentation-api"></a>`TablePresentationProps`: configures shared presentation defaults (such as `size`, `bordered`, `striped`, and `pagination`) in [ConfigProvider](config-provider#configprovider-api) via `components.Table`.

### TableColumn

Configure column heading, value path, rendering, sorting, pinning, ellipsis, and sizing.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Unique column key; falls back to dataIndex then column index. |
| `dataIndex` | `keyof TData \| readonly (string \| number)[]` | — | Field name or nested path array for reading cell values. |
| `title` | `ReactNode` | Required | Column header content. |
| `label` | `string` | — | Plain-text column name for sorting and resize controls when title is not a string. |
| `render` | `(value: unknown, record: TData, index: number) => ReactNode` | — | Custom cell renderer. |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Header and cell alignment. |
| `width` | `number` | — | Fixed column width in pixels. |
| `minWidth` | `number` | `20` | Minimum column width in pixels. |
| `maxWidth` | `number` | — | Maximum column width in pixels. |
| `flex` | `number` | — | Positive weight for sharing available width, bounded by minWidth / maxWidth; ignored on pinned or manually resized columns. |
| `fixed` | `'left' \| 'right' \| 'start' \| 'end'` | — | Pin the column to the start or end edge. |
| `ellipsis` | `boolean` | `false` | Truncate overflowing cell content onto a single line; automatically enables fixed layout. |
| `sorter` | `boolean \| ((a: TData, b: TData) => number)` | — | Enable sorting; true uses default comparison or pass a custom comparator. |
| `sortDirections` | `readonly ('asc' \| 'desc')[]` | `['asc', 'desc']` | Order cycle for toggling sort direction. |
| `resizable` | `boolean` | `true` | Control whether this column can be resized when table resizable is enabled. |
| `className` | `string` | — | Cell class name. |
| `headerClassName` | `string` | — | Header cell class name. |
| `onCell` | `(record: TData, index: number) => `[`TableCellProps`](#tablecell-api) | — | Cell attributes, styles, or spans; a zero colSpan / rowSpan omits the cell. |
| `onHeaderCell` | `(column: `[`TableColumn`](#tablecolumn)`<TData>) => `[`TableHeaderCellProps`](#tableheadercell-api) | — | Header cell attributes and events. |

### TablePagination API

Passes through all other <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a> props (such as `current`, `defaultCurrent`, `pageSize`, `defaultPageSize`, and `showTotal`). Differences from standalone Pagination:

- For local pagination, `total` can be omitted (defaults to top-level row count); pass total count for server pagination or `-1` when unknown.
- Defaults to `10` items per page with `showSizeChanger` enabled; `size` follows the table size (`md` or `sm`).
- When total count is unknown (`total < 0`), only Previous, current page number, and Next buttons are shown; `hasNextPage` controls whether Next is enabled.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `total` | `number` | — | Total row count; optional for local pagination, pass -1 when unknown. |
| `onChange` | `(page: number, pageSize: number) => void` | — | Called when page or page size changes. |
| `hasNextPage` | `boolean` | — | Control next-page availability when the total is unknown. |
