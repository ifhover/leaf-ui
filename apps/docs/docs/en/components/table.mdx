# DataTable

Browse and work with structured data.

Import from the `@ifhover/leaf-ui/table` subpath; styles load automatically. Install the optional peer dependency before use:

```bash
npm install @tanstack/react-table@^8.21.3
```

{/* leaf:section basic */}

## Basic usage

Pass data, column definitions, and a stable unique `rowKey`. Tables use clean surface headers (muted text, 500 weight), a 2px header bottom divider, rounded top corners, fine row dividers, and `tabular-nums` numeric alignment. The default `size` is `md` (`10px 14px` padding, with `43px` single-line body rows and `44px` headers); use `lg` (`55px`) for larger padding or `sm` (`39px`) for compact spacing. Local pagination is enabled by default. This example sets 5 rows per page so you can switch pages. Ordinary tables without configured widths distribute space based on content and wrap long text, or set `meta.ellipsis` to truncate onto a single line.

### Column sizing

Set a column's `size` for a fixed width; columns without `size` share the remaining space. Set a positive `meta.flex` weight to control that share. The product and description columns below use a 2:1 ratio, constrained by `minSize` and `maxSize`. If the minimum widths exceed the available space, the table scrolls horizontally.

<ComponentExample exampleId="sizing" preview={<TableSizing />} fileName="sizing.tsx" width="100%">

```tsx lineNumbers file="../../../src/examples/en/table/sizing.tsx"

```

</ComponentExample>

When every column has a fixed width, extra space remains on the right. Leave a column without `size` or use `meta.flex` to fill the container. Flexible columns use `minSize` and `maxSize` as bounds; `size` does not participate in their proportional allocation. Body text wraps by default without automatic ellipsis; custom non-wrapping content must handle its own overflow.

### Pinning and resizing

Set `resizable` to enable column resizing, and configure `size`, `minSize`, and `maxSize` in column definitions. Use `options.initialState.columnPinning` to pin columns, and `maxHeight` to keep headers fixed while scrolling internally. Render header actions outside DataTable.

Pinned, resizable, and virtual tables use deterministic widths. Unsized columns start at 150px and share remaining space. Pinned columns ignore `meta.flex`. Manually resizing a column keeps the new width; double-click its handle or reset column sizing to restore flexible allocation.

## API

### DataTable API

<a id="datatableinstance-api"></a>
<a id="datatabledata-api"></a>

Column definitions and state use native TanStack APIs; see [column definitions](https://tanstack.com/table/v8/docs/guide/column-defs) and [controlled state](https://tanstack.com/table/v8/docs/framework/react/guide/table-state).

Pass `data`, `columns`, and `rowKey` directly, or pass a table instance created via `useDataTable` or `useReactTable` through `table`. The two approaches are mutually exclusive.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | Required without table | Data to display; provide a new array when updating. |
| `columns` | `readonly ColumnDef<TData>[]` | Required without table | Native TanStack column definitions. |
| `rowKey` | [`DataTableRowKey`](#datatablerowkey)`<TData>` | Required without table | A required string/number identity field, or a function returning a string/number identity. |
| `options` | `Omit<TableOptions<TData>, 'data' \| 'columns' \| 'getCoreRowModel' \| 'getRowId'>` | — | Customize TanStack state, callbacks and server configuration. |
| `localPagination` | `boolean` | — | Whether TanStack slices rows into local pages. Disable it to keep pagination state and controls while rendering all supplied rows. |
| `table` | `TanStackTable<TData>` | — | Instance from useDataTable or useReactTable; mutually exclusive with data, columns, rowKey, options and localPagination. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Presentation size. |
| `bordered` | `boolean` | `false` | Add only an outer border and four rounded corners while keeping internal dividers and headers unchanged. |
| `striped` | `boolean` | `false` | Fine row dividers are shown by default; true enables zebra striping from the second row with an alternating light gray background and hides row dividers. |
| `maxHeight` | `CSSProperties['maxHeight']` | — | Maximum table viewport height. Headers always stay fixed while the body scrolls internally; virtual mode defaults to 400 when omitted. |
| `minWidth` | `CSSProperties['minWidth']` | — | Minimum content-area width; adapts to the container and column widths by default. |
| `loading` | `boolean` | `false` | Show a loading state. |
| `emptyContent` | `ReactNode` | — | Empty content. |
| `error` | `ReactNode` | — | Error content; null, undefined and false do not show an error. |
| `onRetry` | `() => void` | — | Retry action. |
| `selection` | `false \| 'single' \| 'multiple'` | `false` | None, single or multiple row selection. |
| `resizable` | `boolean` | `false` | Show resize handles for eligible columns. |
| `virtual` | `boolean \| `[`DataTableVirtualOptions`](#datatablevirtualoptions) | `false` | Explicit row virtualization. |
| `pagination` | `boolean \| `[`DataTablePaginationProps`](#datatablepagination-api) | `true` | Pagination visibility or display options; see <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a>. With direct data input, false also disables local slicing. |
| `tableRef` | `Ref<HTMLTableElement>` | — | Native table DOM ref. |
| `getRowLabel` | `(row: Row<TData>) => string` | — | Accessible row-action name; defaults to row.id. |
| `renderExpandedRow` | `(row: Row<TData>) => ReactNode` | — | Leaf-row details; configure getRowCanExpand. |
| `getRowProps` | `(row: Row<TData>) => `[`DataTableRowProps`](#datatablerow-api) | — | Customize data row attributes and events. |
| `getCellProps` | `(cell: Cell<TData, unknown>) => `[`DataTableCellProps`](#datatablecell-api) | — | Cell attributes, styles or spans; a zero colSpan / rowSpan omits the cell. |

`aria-label` / `aria-labelledby` apply to the inner native table; other div attributes apply to the wrapper.

<a id="datatablerowkey"></a>

`DataTableRowKey<TData>` accepts a non-optional string or number field name, or a `(row: TData, index: number) => string | number` function. When records lack a natural identity, generate stable unique keys instead of using array indices after sorting or pagination.

<a id="datatablerow-api"></a>

`DataTableRowProps`, returned by `getRowProps`, supports native `tr` attributes and events, plus `selected?: boolean` to apply the selected row appearance.

<a id="datatablecell-api"></a>

`DataTableCellProps`, returned by `getCellProps`, supports native `td` attributes, events and `colSpan` / `rowSpan`. Its additional `align` accepts `'start' | 'center' | 'end'` and defaults to `'start'`. A zero span omits the cell.

<a id="datatablepresentation-api"></a>

[ConfigProvider](config-provider#configprovider-api) configures shared presentation defaults (such as `size`, `striped`, and `pagination`) via `components.DataTable`. Import `DataTablePresentationProps` from `@ifhover/leaf-ui` for typing.

### useDataTable

<a id="usedatatableoptions"></a>

Creates and returns a native TanStack table instance. `UseDataTableOptions<TData>` reuses `data`, `columns`, `rowKey`, `localPagination`, and `options` from [DataTable API](#datatable-api).

```ts
function useDataTable<TData>(config: UseDataTableOptions<TData>): TanStackTable<TData>;
```

Core, filtering, pagination, and expanding row models are preconfigured. The sorting model is included but requires `options.enableSorting: true` to enable header sorting interactions. Detail rows require `options.getRowCanExpand`.

### useDataTableSelection

```ts
function useDataTableSelection(options?: UseDataTableSelectionOptions): UseDataTableSelectionResult;
```

Manage row selection using business row keys without manually synchronizing TanStack's `RowSelectionState`:

```tsx
const selection = useDataTableSelection({
  mode: 'multiple',
  selectedRowKeys: selectedKeys,
  onSelectedRowKeysChange: setSelectedKeys,
});

const table = useDataTable({
  data,
  columns,
  rowKey: 'id',
  options: selection.selectionOptions,
});
```

Pass `selection.selectionOptions` into the `options` of DataTable or `useDataTable`. Row keys must match the identity resolved by `rowKey`.

#### Parameters (UseDataTableSelectionOptions)

<a id="usedatatableselectionoptions"></a>

Configure controlled or uncontrolled selection using business row keys.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `'single' \| 'multiple'` | `multiple` | Single keeps only the most recently requested key; multiple keeps every selected key. |
| `selectedRowKeys` | `readonly DataTableRowSelectionKey[]` | — | Controlled selected business row keys; array order determines which key single mode retains. |
| `defaultSelectedRowKeys` | `readonly DataTableRowSelectionKey[]` | `[]` | Initial selected business row keys for uncontrolled usage. |
| `onSelectedRowKeysChange` | `(selectedRowKeys: string[]) => void` | — | Called with normalized, unique string keys whenever selection changes. |

#### Return value (UseDataTableSelectionResult)

<a id="usedatatableselectionresult"></a>

Return business row keys, native selection state and a clear action.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `selectedRowKeys` | `string[]` | Required | Current selected business row keys; sourced from selectedRowKeys when controlled, otherwise from internal state. |
| `rowSelection` | `RowSelectionState` | Required | Native TanStack rowSelection map derived from business keys. |
| `onRowSelectionChange` | `OnChangeFn<RowSelectionState>` | Required | Pass directly to useDataTable or native useReactTable. |
| `selectionOptions` | [`DataTableSelectionOptions`](#datatableselectionoptions) | Required | Complete selection options ready to spread into useDataTable options. |
| `clearSelection` | `() => void` | Required | Clear controlled or uncontrolled selection and notify the change callback. |

#### TanStack integration (DataTableSelectionOptions)

<a id="datatableselectionoptions"></a>

Use `DataTableSelectionOptions` when merging TanStack configuration manually. Preserve other application state when merging `state`.

<details className="leaf-api-details">
<summary>View native selection configuration</summary>

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `{ rowSelection: RowSelectionState }` | Required | Controlled rowSelection state for useDataTable options. |
| `onRowSelectionChange` | `OnChangeFn<RowSelectionState>` | Required | Native TanStack selection callback; business keys are normalized internally. |
| `enableMultiRowSelection` | `boolean` | Required | Derived from mode: false for single and true for multiple. |

</details>

### DataTableColumnMeta

<a id="datatablecolumndef"></a>

Configure Leaf UI column metadata on `meta`. Use `DataTableColumnDef` for typed column definitions. When using custom header components, supply `label` for accessible names and resize tooltips.

```tsx
import type { DataTableColumnDef } from '@ifhover/leaf-ui/table';

type Member = { id: string; name: string };

const columns = [
  { accessorKey: 'name', header: 'Name', meta: { align: 'start', label: 'Name' } },
] satisfies DataTableColumnDef<Member>[];
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Plain-text column name for sorting and resize controls. |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Header and cell alignment. |
| `ellipsis` | `boolean` | — | Truncate overflowing cell content onto a single line with an ellipsis; automatically enables fixed width allocation. |
| `cellClassName` | `string` | — | Cell class. |
| `headerClassName` | `string` | — | Header class. |
| `flex` | `number` | — | Positive weight for sharing available width, bounded by minSize / maxSize; ignored on pinned or manually resized columns. |

### DataTableVirtualOptions

Configure the estimated virtual row height and overscan.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `estimateRowHeight` | `number` | `48` | Estimated record height before measurement, including the data row and expanded details. |
| `overscan` | `number` | `5` | Additional rows before/after the viewport. |

### DataTablePagination API

See <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a> (opens in a new tab) for general display options. The table manages pagination state automatically; only differences are listed below:

- `total`, `current`, `pageSize`, and `onChange` are owned by the table instance; configure initial pagination via `initialState.pagination`.
- `showSizeChanger` defaults to true; `size` defaults to `md` for `lg` and `md` tables and `sm` for `sm` tables.
- When total count is unknown (`pageCount: -1`), only Previous and Next buttons are shown; `hasNextPage` explicitly controls whether the Next button is enabled.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `hasNextPage` | `boolean` | — | Control next-page availability when the total is unknown. |
