## Drawer API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Specify initial focus after opening. |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Restore focus on close; specify a destination or use false. |
| `open` | `boolean` | Required | Required. Whether the drawer is open |
| `title` | `ReactNode` | — | Title |
| `footer` | `ReactNode` | — | Footer content |
| `extra` | `ReactNode` | — | Actions beside the title |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'right'` | Opening edge |
| `width` | `number \| string` | `380` | Width for left and right drawers |
| `height` | `number \| string` | `300` | Height for top and bottom drawers |
| `closable` | `boolean` | `true` | Close button / backdrop click / Escape |
| `maskClosable` | `boolean` | `true` | Close button / backdrop click / Escape |
| `keyboard` | `boolean` | `true` | Close button / backdrop click / Escape |
| `onClose` | `() => void` | — | Close request; update open in application state |
| `afterClose` | `() => void` | — | Called after the closing transition |
| `forceRender` | `boolean` | — | Mount before opening and keep hidden while closed. |
| `destroyOnClose` | `boolean` | — | Unmount content after the closing transition; preserved by default. |
| `preserve` | `boolean` | — | Explicitly preserve closed content; overrides destroyOnClose. |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | Custom portal or scroll container. |
| `push` | `boolean \| number` | — | Push the parent overlay when a nested drawer opens; accepts a distance. |
| `resizable` | `boolean` | — | Allow resizing by dragging or arrow keys. |
| `minSize` | `number` | — | Minimum size in pixels. |
| `maxSize` | `number` | — | Maximum size in pixels. |
| `onResize` | `(size: number) => void` | — | Called while resizing. |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { DrawerProps } from '@sudden3/leaf-ui';
```

## Usage notes

Place actions in footer. A submit button can use its form attribute to target a form inside the drawer. Provide aria-label if there is no title. Nested dialogs are supported, and focus returns to the opener after closing.
