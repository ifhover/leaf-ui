### Resizing

<a id="advanced-usage"></a>

Enable `resizable` to drag the edge or focus the separator and use arrow keys. `minSize` and `maxSize` limit the resize value reported by `onResize`; the visible size remains constrained by the viewport. Changing `width` or `height` resets the manual adjustment.


</ComponentExample>

### Nested push

Set `push` on the child drawer to shift its nearest parent overlay. `true` means 40px, or pass a distance directly. Escape closes only the topmost drawer, then focus returns to its opener. Reset the child's `open` when closing the parent to avoid reopening both layers.

## API

### Drawer API

Configuration for controlled visibility, placement, content regions and dismissal.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Controlled open state, updated by the application. |
| `title` | `ReactNode` | — | Drawer title. |
| `description` | `ReactNode` | — | Additional description. |
| `onClose` | `() => void` | — | Close request; update open in application state |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'right'` | Opening edge |
| `width` | `number \| string` | `380` | Width for left and right drawers |
| `height` | `number \| string` | `300` | Height for top and bottom drawers |
| `footer` | `ReactNode` | — | Footer content |
| `extra` | `ReactNode` | — | Actions beside the title |
| `variant` | `'plain' \| 'card'` | `'card'` | Content appearance; card places the body on a separate surface. |
| `icon` | `ReactNode` | — | Decorative icon to the left of the heading. |
| `divided` | `boolean` | `false` | Separate the heading, content and footer with subtle borders. |
| `closable` | `boolean` | `true` | Show the close button. |
| `maskClosable` | `boolean` | `true` | Request closing when the mask is clicked. |
| `keyboard` | `boolean` | `true` | Allow Escape to request closing. |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Specify initial focus after opening. |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Restore focus on close; specify a destination or use false. |
| `resizable` | `boolean` | `false` | Allow resizing by dragging or arrow keys. |
| `minSize` | `number` | `240` | Minimum size in pixels. |
| `maxSize` | `number` | `900` | Maximum size in pixels. |
| `onResize` | `(size: number) => void` | — | Return the new size on pointer or keyboard resizing; changing width or height resets the manual size. |
| `push` | `boolean \| number` | `false` | Push the nearest parent overlay; true uses 40px and a number specifies the distance. |
| `afterClose` | `() => void` | — | Called after the closing transition |
| `destroyOnClose` | `boolean` | `false` | Unmount contents after closing; preserve takes precedence and forceRender keeps contents mounted. |
| `preserve` | `boolean` | — | Control content preservation, taking precedence over destroyOnClose; does not reset external controlled state. |
| `forceRender` | `boolean` | `false` | Mount before opening and keep hidden while closed. |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | Portal mount target; may also return a ShadowRoot. |
