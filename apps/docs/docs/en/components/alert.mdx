## Alert API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Required. Main content |
| `description` | `ReactNode` | — | Additional details |
| `type` | `'success' \| 'info' \| 'warning' \| 'error'` | `'info'` | Feedback type |
| `icon` | `ReactNode` | — | Icon content. |
| `showIcon` | `boolean` | `true` | Show the feedback icon |
| `closable` | `boolean` | `false` | Allow dismissal |
| `onClose` | `() => void` | — | Called after dismissal |

## Types

Import types when defining reusable component props or assembling options.

```ts
import type { AlertProps, FeedbackType } from '@ifhover/leaf-ui';
```

## Usage notes

Success, information, warning and error messages use distinct semantic colors. Supply application text yourself; the close button follows the ConfigProvider language.

## Surfaces and rich content

The neutral surface keeps the icon color and announcement semantics of `type`. Override `icon` or use `showIcon={false}` to hide it.
