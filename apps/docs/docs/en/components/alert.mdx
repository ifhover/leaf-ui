## API

### Alert API

Configuration for alert content, feedback type and dismissal.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | Main content |
| `description` | `ReactNode` | — | Additional details |
| `extra` | `ReactNode` | — | Trailing content. |
| `type` | `FeedbackType \| 'error'` | `'info'` | Feedback type; `error` is a compatibility alias |
| `icon` | `ReactNode` | — | Icon content. |
| `showIcon` | `boolean` | `true` | Show the feedback icon |
| `closable` | `boolean` | `false` | Allow dismissal |
| `onClose` | `() => void` | — | Called when the close button is activated. |
