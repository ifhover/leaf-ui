## API

### Flex API

Native `div` attributes and DOM refs are supported. Explicit `style` takes precedence over layout props.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `'row' \| 'row-reverse' \| 'column' \| 'column-reverse'` | `'row'` | Flow direction. Reversing layout does not change DOM reading or keyboard order. |
| `gap` | `number \| string \| readonly [number \| string, number \| string]` | `0` | Numbers are px. Supports CSS lengths and themed `sm` / `md` / `lg` spacing. A pair means [row gap, column gap]. |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'stretch'` | Cross-axis alignment. |
| `justify` | `'start' \| 'center' \| 'end' \| 'space-between' \| 'space-around' \| 'space-evenly'` | `'start'` | Main-axis alignment. |
| `wrap` | `boolean \| 'nowrap' \| 'wrap' \| 'wrap-reverse'` | `false` | Enable wrapping or choose its direction. |
| `inline` | `boolean` | `false` | Use inline flex layout. |
