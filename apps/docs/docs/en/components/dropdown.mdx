## API

### Dropdown API

Use a single button that forwards its ref and events as the trigger. Escape closes the menu and returns focus to it. See [PopupOptions](/en/api/popup-options) for shared popup options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | Required | Menu entries |
| `children` | `ReactElement< ButtonHTMLAttributes<HTMLButtonElement> & { ref?: Ref<HTMLButtonElement> } >` | Required | A single Leaf Button or native button |
| `trigger` | `'click' \| 'hover' \| 'contextMenu' \| readonly ('click' \| 'hover' \| 'contextMenu')[]` | `'click'` | Trigger mode; Dropdown supports click, hover and context menu. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Presentation size. |
| `open` | `boolean` | — | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state for uncontrolled usage. |
| `onOpenChange` | `(open: boolean) => void` | — | Open-state changes |
| `onSelect` | `(key: string) => void` | — | Called with the activated leaf item key, including radio and checkbox items; opening a submenu does not call it. |
| `placement` | `'top-start' \| 'top-end' \| 'bottom-start' \| 'bottom-end'` | `'bottom-start'` | Menu placement; popupPlacement takes precedence. |
| `popupWidth` | `number \| string` | `—` | Popup width; grows with content from a 160px minimum when unset. |
| `popupMaxWidth` | `number \| string` | `420` | Maximum popup width, still bounded by the viewport. |
| `itemRender` | `(item: `[`DropdownItem`](#dropdownitem)`) => ReactNode` | — | Customize the item label content, not the whole row. |
| `mouseEnterDelay` | `number` | `100` | Delay in milliseconds before opening on hover. |
| `mouseLeaveDelay` | `number` | `150` | Delay in milliseconds before closing after pointer leave. |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |

### DropdownItem

Data for an action, group or submenu in a dropdown menu.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique key |
| `label` | `ReactNode` | — | Item label or group heading. |
| `icon` | `ReactNode` | — | Icon before the item label. |
| `extra` | `ReactNode` | — | Trailing item content for shortcuts, status labels or other non-interactive information. |
| `type` | `'item' \| 'divider' \| 'group' \| 'checkbox' \| 'radio'` | `'item'` | Regular item, divider, group, checkbox or radio item. |
| `children` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | — | Menu entries. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `danger` | `boolean` | `false` | Destructive-action colors without disabling the item. |
| `checked` | `boolean` | — | Controlled checked state; stored internally when omitted. |
| `group` | `string` | — | Mutual-exclusion group identifier for radio items. |
| `closeOnSelect` | `boolean` | — | Whether selection closes the menu; regular items close by default, radio and checkbox items stay open. |
| `onCheckedChange` | `(checked: boolean) => void` | — | Called with the next checked state when the item is activated. |
| `href` | `string` | — | Link destination. |
| `target` | `string` | — | Link target attribute, such as _blank; opens in the current tab when omitted. |
| `onClick` | `(event: MouseEvent<HTMLElement>) => void` | — | Runs when the item is selected |
