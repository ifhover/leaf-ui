# AutoComplete

Suggest values while allowing free-text input.

{/* leaf:section basic */}

## Basic usage

Suggestions use case-insensitive substring matching by default, without restricting free text. `onChange` responds to typing and selection; `onSelect` only responds to choosing a suggestion. An option with `disabled` cannot be selected.

<ComponentExample exampleId="basic" preview={<AutoCompleteBasic />} width={360} fileName="basic.tsx">


</ComponentExample>

Focus or type to open suggestions. Use the arrow keys to highlight available options, Enter to select and Escape to close. Tab continues to the next control. Enter during IME composition does not select a suggestion.

## Examples

### Dynamic suggestions

`onSearch` receives typed text, and receives an empty string when cleared. It does not run on selection. When suggestions are generated by your application or returned by a server, set `filterOption={false}` to display them without local filtering.

### Disabled and read-only

`disabled` prevents interaction with the entire control. `readOnly` allows focus and copying but prevents editing, selection and clearing.

<ComponentExample exampleId="states" preview={<AutoCompleteStates />} width={360} fileName="states.tsx">

Native input attributes such as `name`, `required` and `form` are supported. Uncontrolled fields follow native form reset; reset controlled values in application state. Application labels and options are not translated automatically.

## API

### AutoComplete API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly (`[`AutoCompleteOption`](#autocompleteoption)` \| `[`AutoCompleteOptionGroup`](#autocompleteoptiongroup)`)[]` | Required | Suggestions in this group. |
| `value` | `string` | — | Controlled text; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `string` | `''` | Initial text for uncontrolled usage; native form reset is supported. |
| `onChange` | `(value: string) => void` | — | Return the full text after editing, clearing or selecting a suggestion. |
| `onSelect` | `(value: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => void` | — | Called only when a suggestion is selected, with its inserted value and option. |
| `onSearch` | `(query: string) => void` | — | Return the query on user input, or an empty string on clearing; selecting a suggestion does not call it. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Lock the value against typing, selection, clearing and removal. |
| `allowClear` | `boolean` | — | Show a clear action. |
| `filterOption` | `false \| ((query: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => boolean)` | Substring match | false disables local filtering; a function customizes matching |
| `loading` | `boolean` | — | Show a loading state. |
| `errorContent` | `ReactNode` | — | Content for loading errors and retry actions. |
| `notFoundContent` | `ReactNode` | — | Content when no options match. |
| `optionRender` | `(option: `[`AutoCompleteOption`](#autocompleteoption)`) => ReactNode` | — | Customize option content. |
| `open` | `boolean` | — | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state for uncontrolled usage. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the panel opens or closes. |
| `virtual` | `boolean` | Enabled above 100 filtered suggestions | Render only visible suggestions; enabled by default above 100 filtered suggestions. |
| `listHeight` | `number` | `248` | Maximum visible height of the suggestions panel. |
| `optionHeight` | `number` | Theme and density dependent | Estimated virtual row height, calculated from the theme and density by default; actual rows are measured. |
| `popupWidth` | `number \| string` | `'trigger'` | Popup width; trigger matches the trigger, auto fits content (and may be narrower), numbers specify fixed pixels; CSS lengths are also supported. |
| `popupMaxWidth` | `number \| string` | — | Optional maximum popup width; no additional limit when unset, still bounded by the viewport. |
| `popupPlacement` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupPlacement']` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupStyle']` | — | Custom popup styles. |
| `popupRender` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupRender']` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | [`PopupOptions`](../api/popup-options#popupoptions)`['getPopupContainer']` | — | Return a popup container, including a ShadowRoot. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

`placeholder`, `name`, `required`, `form`, `maxLength` and `aria-*` are forwarded to the input. `className` and `style` apply to the outer container.

#### AutoCompleteOption

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Unique suggestion value; inserted into the input on selection. |
| `label` | `ReactNode` | — | Visible suggestion label, also used by the default local filter. |
| `searchLabel` | `string` | — | Plain search text; defaults to a string label, otherwise value. |
| `disabled` | `boolean` | `false` | Disable the suggestion. |

#### AutoCompleteOptionGroup

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | Required | Suggestion group heading. |
| `options` | `readonly `[`AutoCompleteOption`](#autocompleteoption)`[]` | Required | Suggestions in this group. |
