# AutoComplete

Suggest values while allowing free-text input.

## Examples

Use options for suggestions and onChange for typed or selected text. onSelect fires only when choosing a suggestion; onSearch fires only for typing. Set filterOption=false for server-generated suggestions. Handle debouncing and request order in your application.

## AutoComplete API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly (`[`AutoCompleteOption`](#autocompleteoption)` \| `[`AutoCompleteOptionGroup`](#autocompleteoptiongroup)`)[]` | Required | Required. Suggestion options |
| `value` | `string` | Required | Unique suggestion value; inserted into the input on selection |
| `defaultValue` | `string` | `''` | Controlled text / uncontrolled initial text |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `filterOption` | `false \| ((query: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => boolean)` | Substring match | false disables local filtering; a function customizes matching |
| `onChange` | `(value: string) => void` | — | Text after typing or selecting |
| `onSelect` | `(value: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => void` | — | Runs when selecting a suggestion |
| `onSearch` | `(query: string) => void` | — | Runs on typing, not on selection |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | — | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the panel opens or closes. |
| `loading` | `boolean` | — | Show a loading state. |
| `notFoundContent` | `ReactNode` | — | Content when no options match. |
| `errorContent` | `ReactNode` | — | Content for loading errors and retry actions. |
| `optionRender` | `(option: `[`AutoCompleteOption`](#autocompleteoption)`) => ReactNode` | — | Customize option content. |
| `allowClear` | `boolean` | — | Show a clear action. |
| `virtual` | `boolean` | — | Enable virtual scrolling; enabled by default for large option sets. |
| `listHeight` | `number` | `248` | Height of the visible list. |
| `optionHeight` | `number` | `36` | Estimated virtual option height; actual rows are measured. |
| `popupPlacement` | [`PopupOptions`](../guide/control-contracts#popupoptions)`['popupPlacement']` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | [`PopupOptions`](../guide/control-contracts#popupoptions)`['popupStyle']` | — | Custom popup styles. |
| `popupRender` | [`PopupOptions`](../guide/control-contracts#popupoptions)`['popupRender']` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | [`PopupOptions`](../guide/control-contracts#popupoptions)`['getPopupContainer']` | — | Return a popup container, including a ShadowRoot. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Lock the value against typing, selection, clearing and removal. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |
### AutoCompleteOption

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Unique suggestion value; inserted into the input on selection |
| `label` | `string` | — | Suggestion label, also used by the default filter |
| `disabled` | `boolean` | `false` | Disable the suggestion |

## Types

Import AutoCompleteProps to describe component props. Option types in the API table link to their detailed fields above.

```ts
import type { AutoCompleteProps, AutoCompleteOption } from '@sudden3/leaf-ui';
```

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.
