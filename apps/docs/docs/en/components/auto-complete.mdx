# AutoComplete

Suggest values while allowing free-text input.

## Basic input

Set suggestions with `options`; by default they match case-insensitively on the displayed text. `onChange` fires for typing and selection, `onSelect` only for choosing a suggestion. `disabled` on an option blocks that single suggestion (see `Archived Garden` in the example); `disabled` on AutoComplete disables the whole input.

## Dynamic suggestions

`onSearch` receives the typed text. When suggestions come from your own code or a server, set `filterOption={false}` to show the provided results as-is. Handle debouncing and request order in your application.

## Rich groups and loading states

The popup matches the field width by default (`popupWidth="trigger"`). Set `popupWidth="auto"` to fit the content, which may be narrower than the field, or `popupWidth={300}` for a fixed 300px width; CSS lengths are also supported. `popupMaxWidth` is unset by default. The example below fits the content with an explicit maximum width. Viewport edge avoidance still applies.

## AutoComplete API
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly (`[`AutoCompleteOption`](#autocompleteoption)` \| `[`AutoCompleteOptionGroup`](#autocompleteoptiongroup)`)[]` | Required | Suggestion options |
| `value` | `string` | `''` | Controlled text; the internal uncontrolled value is used when omitted. |
| `defaultValue` | `string` | `''` | Initial text for uncontrolled usage; native form reset is supported. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `filterOption` | `false \| ((query: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => boolean)` | Substring match | false disables local filtering; a function customizes matching |
| `onChange` | `(value: string) => void` | — | Text after typing or selecting |
| `onSelect` | `(value: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => void` | — | Runs when selecting a suggestion |
| `onSearch` | `(query: string) => void` | — | Runs on typing, not on selection |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | — | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the panel opens or closes. |
| `loading` | `boolean` | — | Show a loading state. |
| `notFoundContent` | `ReactNode` | — | Content when no options match. |
| `errorContent` | `ReactNode` | — | Content for loading errors and retry actions. |
| `optionRender` | `(option: `[`AutoCompleteOption`](#autocompleteoption)`) => ReactNode` | — | Customize option content. |
| `allowClear` | `boolean` | — | Show a clear action. |
| `virtual` | `boolean` | — | Enable virtual scrolling; enabled by default for large option sets. |
| `listHeight` | `number` | `248` | Height of the visible list. |
| `optionHeight` | `number` | `32` | Estimated virtual row height; follows the regional height and density. Actual rows are measured. |
| `popupWidth` | `number \| string` | `'trigger'` | Popup width; trigger matches the trigger, auto fits content (and may be narrower), numbers specify fixed pixels; CSS lengths are also supported. |
| `popupMaxWidth` | `number \| string` | — | Optional maximum popup width; no additional limit when unset, still bounded by the viewport. |
| `popupPlacement` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupPlacement']` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupStyle']` | — | Custom popup styles. |
| `popupRender` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupRender']` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | [`PopupOptions`](../api/popup-options#popupoptions)`['getPopupContainer']` | — | Return a popup container, including a ShadowRoot. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Lock the value against typing, selection, clearing and removal. |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |

### AutoCompleteOption
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Unique suggestion value; inserted into the input on selection. |
| `label` | `ReactNode` | — | Visible suggestion label, also used by the default local filter. |
| `searchLabel` | `string` | — | Plain search text for a rich label; readable text or value is used when omitted. |
| `disabled` | `boolean` | `false` | Disable the suggestion. |

## AutoCompleteOptionGroup
| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | Required | Suggestion group heading. |
| `options` | `readonly `[`AutoCompleteOption`](#autocompleteoption)`[]` | Required | Suggestions in this group. |

## Forms and localization

Use name to include values in FormData. Uncontrolled fields follow form reset; reset controlled values in application state. Place controls in [FormField](/en/components/form#formfield-api) for labels, help and errors. [ConfigProvider](/en/components/config-provider) supplies regional themes and translated built-in UI. Application labels and options are your responsibility.
