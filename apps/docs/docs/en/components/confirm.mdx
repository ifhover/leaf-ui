# Confirm

Ask for confirmation before an important action and await the user's choice.

Use [Modal](/en/components/modal) for editing, or [Popconfirm](/en/components/popconfirm) for a brief confirmation beside a trigger.

Set up [ConfigProvider](/en/components/config-provider) at the application entry, then call `useConfirm()` in a child component. Each confirmation inherits the caller's theme and language.

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return (
    <ConfigProvider>
      <App />
    </ConfigProvider>
  );
}
```

## API

### useConfirm API

The returned object is [`ConfirmApi`](#confirmapi). Requests in the same queue appear in sequence, after the previous dialog finishes closing. The Promise resolves when the decision closes the dialog, without waiting for its closing animation.

Unmounting the caller or provider resolves outstanding requests to `false`. It does not abort an async action already in progress or invoke `onCancel`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `confirm` | [`(options: ConfirmOptions) => Promise<boolean>`](#confirmoptions) | — | Resolves true on confirmation, false on cancellation or caller unmount. |

### ConfirmApi

The command interface returned by `useConfirm()`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `confirm` | `(options: `[`ConfirmOptions`](#confirmoptions)`) => Promise<boolean>` | Required | Resolve to a boolean on decision: true after successful confirmation, false on cancellation or caller unmount, without waiting for the closing animation. |

### ConfirmOptions

Content, actions and interaction settings supplied to `confirm()`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | Confirmation heading. |
| `children` | `ReactNode` | — | A short explanation of the action's consequences. |
| `onConfirm` | `() => void \| Promise<void>` | — | Close after success; keep the dialog open and show the error on rejection. |
| `onCancel` | `() => void` | — | Called on cancellation. |
| `type` | `'default' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'default'` | Semantic icon and color; only danger changes the confirm button color. |
| `icon` | `ReactNode` | — | Semantic icon beside the explanation; null hides the icon. |
| `confirmText` | `ReactNode` | Locale default | Confirm button label. |
| `cancelText` | `ReactNode` | Locale default | Cancel button label. |
| `showCancel` | `boolean` | false for success; otherwise true | Show the cancel button. |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | Confirm button props. |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | Cancel button props. |
| `width` | `number \| string` | `420` | Dialog width, in pixels for numbers. |
| `closable` | `boolean` | `false` | Show a close button in the corner. |
| `maskClosable` | `boolean` | `false` | Cancel when the backdrop is clicked. |
| `keyboard` | `boolean` | `true` | Cancel when Escape is pressed. |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Initial focus target. |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | Return focus after closing; set a target or disable with false. |
| `className` | `string` | — | Dialog class name. |
| `style` | `CSSProperties` | — | Dialog styles. |

### ConfirmProvider API

Without `ConfigProvider`, wrap the application in `ConfirmProvider`. An explicit `ConfirmProvider` creates an independent queue; a nested `ConfigProvider` continues to share the existing queue.

```tsx
import { ConfirmProvider } from '@ifhover/leaf-ui';

export function Root() {
  return (
    <ConfirmProvider>
      <App />
    </ConfirmProvider>
  );
}
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Contents sharing this independent confirmation queue; ConfigProvider already supplies a queue and nested ConfigProviders reuse it. |
