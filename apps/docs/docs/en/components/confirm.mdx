# Confirm

Ask for confirmation before an important action.

## Application setup

Place `ConfigProvider` at the application entry. Descendants call `useConfirm()` directly and inherit their region’s theme and language.

```tsx
import { ConfigProvider } from '@sudden3/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## Confirm API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | Required | Whether the dialog is visible |
| `title / children` | `ReactNode` | — | Title / confirmation content |
| `width` | `number \| string` | `480` | Width; numbers are pixels |
| `closable / keyboard` | `boolean` | `true` | Close button / Escape dismissal |
| `maskClosable` | `boolean` | `false` | Backdrop dismissal |
| `onClose` | `() => void` | — | Requests closure; update open in the application |
| `afterClose` | `() => void` | — | Called after the closing animation finishes |
| `confirmText / cancelText` | `ReactNode` | Locale default | Confirm / cancel labels from the current locale |
| `type` | `'default' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'default'` | Icon and color; only danger changes the confirm button |
| `showCancel` | `boolean` | false for success; true otherwise | Show the cancel button |
| `danger` | `boolean` | `false` | Legacy shorthand for type="danger" |
| `onConfirm` | `() => void \| Promise<void>` | — | Confirm action; resolves to close, rejects to show an error |

## useConfirm API

The returned object is typed as [`ConfirmApi`](#useconfirm-api).

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `confirm` | [`(options: ConfirmOptions) => Promise<boolean>`](#confirmoptions) | — | Resolves true on confirmation, false on cancellation or unmount |

## ConfirmProvider API

Without `ConfigProvider`, wrap the application in `ConfirmProvider`. An explicit provider also creates an independent confirmation queue for a region.

```tsx
import { ConfirmProvider } from '@sudden3/leaf-ui';

export function Root() {
  return <ConfirmProvider><App /></ConfirmProvider>;
}
```

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Components sharing the confirmation queue |

## Usage notes

`useConfirm()` returns `{ confirm }`. Requests under the same entry appear in order, with the next dialog opening after the previous dismissal finishes. Confirmation resolves to `true`; cancellation or unmounting the calling component or provider resolves to `false`.

Async confirmation shows a loading state and prevents duplicate actions. Rejection displays an error and keeps the dialog open for retry. Nested `ConfigProvider` regions share the queue while preserving each caller’s theme and language.

You can also render `Confirm` directly and control `open` and `onClose`.

See [Modal API](/en/components/modal#modal-api) for inherited attributes.

default has no icon. info, warning, success and danger have distinct icons and colors. Only danger has a red OK button; success hides Cancel by default. Use showCancel to override it. Button props follow Modal. onCancel notifies cancellation before onClose.
