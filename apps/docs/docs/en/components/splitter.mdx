## SplitterPanel

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Required. Stable, unique identifier. |
| `children` | `ReactNode` | — | Required. Panel content. |
| `min` | `number` | — | Minimum panel percentage. |
| `max` | `number` | — | Maximum panel percentage. |
| `collapsible` | `boolean` | — | Allow collapsing and restoring a panel. |
| `resizable` | `boolean` | — | Allow resizing by dragging or arrow keys. |

## Splitter API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `panels` | `readonly `[`SplitterPanel`](#splitterpanel)`[]` | — | Required. Workspace panels. |
| `sizes` | `readonly number[]` | — | Controlled panel proportions, normalized to 100. |
| `defaultSizes` | `readonly number[]` | — | Initial panel proportions. |
| `onResize` | `(sizes: number[]) => void` | — | Called while resizing. |
| `onResizeEnd` | `(sizes: number[]) => void` | — | Called when resizing ends. |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Arrange panels horizontally or vertically. |

## Types and interaction

Import the props and data types when creating reusable configuration.

```ts
import type { SplitterPanel, SplitterProps } from '@ifhover/leaf-ui';
```

Dividers use role="separator" and expose aria-valuenow; arrow keys resize panels, and the layout follows ConfigProvider themes and reduced motion.
