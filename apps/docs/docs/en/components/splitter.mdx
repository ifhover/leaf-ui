# Splitter

Resize panels in a workspace.

{/* leaf:section basic */}

## Basic usage

Drag a divider to resize its adjacent panels. Focus the divider and use the arrow keys, holding `Shift` for larger steps. Give each panel a stable `key`; panels start with equal proportions when no sizes are provided.

### Collapsible panels

Set `collapsible` to add a button that collapses and restores the panel before the divider. Double-clicking the divider or pressing `Enter` while it is focused does the same. The next panel receives the freed space, and collapsed content leaves the keyboard focus order. The last panel has no following divider and cannot be collapsed this way.

### Controlled proportions

When passing `sizes`, update that state in `onResize`. External controls can update the same state. `defaultSizes` only sets the uncontrolled initial value; it does not reset panels. Proportions are normalized to a total of `100`. Use `onResizeEnd` to save results after dragging, arrow-key resizing, or collapsing and restoring a panel.

## API

### Splitter API

Configure panel sizes, orientation and resizing behavior.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `panels` | `readonly `[`SplitterPanel`](#splitterpanel)`[]` | Required | Workspace panels. |
| `sizes` | `readonly number[]` | — | Controlled panel proportions; a valid array is normalized to 100. Update with onResize. |
| `defaultSizes` | `readonly number[]` | Equal shares | Initial uncontrolled proportions; omitted, mismatched or invalid totals use equal shares. |
| `onResize` | `(sizes: number[]) => void` | — | Called with new proportions after dragging, arrow keys or collapsing changes sizes. |
| `onResizeEnd` | `(sizes: number[]) => void` | — | Called after dragging ends, a keyboard adjustment, or collapse/restore. |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | Arrange panels horizontally or vertically. |

### SplitterPanel

Configuration for each item in `panels`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Stable, unique identifier. |
| `children` | `ReactNode` | Required | Panel content. |
| `min` | `number` | `5` | Minimum panel percentage. |
| `max` | `number` | `100` | Maximum panel percentage. |
| `collapsible` | `boolean` | — | Allow collapse/restore through this panel's following handle, exchanging space with the next panel; the last panel has no handle. |
| `resizable` | `boolean` | — | False disables handle dragging and removes it from the Tab order. |
