## API

### Badge API

Configuration for badge counts, dot indicators and attachment placement.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Attach the indicator to this content |
| `count` | `number \| string` | — | Badge content |
| `max` | `number` | `99` | Display max+ above this count |
| `showZero` | `boolean` | `false` | Show a zero count |
| `dot` | `boolean` | `false` | Use a notification dot |
| `placement` | `'outside' \| 'inside'` | `'outside'` | Attached indicator position: outside by default, or inside the top-right corner; mirrored in RTL and ignored without children |
| `color` | `string` | — | Custom indicator color |
