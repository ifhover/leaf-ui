## Inside placement

Use `placement="inside"` to keep the indicator with a white ring inside the top-right corner of a button or other content. Leave enough room to avoid covering content; placement mirrors in RTL.

## Badge API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Attach the indicator to this content |
| `count` | `number \| string` | — | Badge content |
| `max` | `number` | `99` | Display max+ above this count |
| `showZero` | `boolean` | `false` | Show a zero count |
| `dot` | `boolean` | `false` | Use a notification dot |
| `placement` | `'outside' \| 'inside'` | `'outside'` | Attached indicator position: outside by default, or inside the top-right corner; mirrored in RTL and ignored without children |
| `color` | `string` | — | Custom indicator color |

## Types

Import the component props and item types when preparing your own values.

```ts

```

## Usage notes

Use alone for counts or short text. When attaching a notification dot to another control, provide aria-label to explain the notification.
