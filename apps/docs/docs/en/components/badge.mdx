## Badge API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Attach the indicator to the content's top-right corner and expand it outward when its content grows |
| `count` | `number \| string` | — | Badge content |
| `max` | `number` | `99` | Display max+ above this count |
| `showZero` | `boolean` | `false` | Show a zero count |
| `dot` | `boolean` | `false` | Use a notification dot |
| `status` | `'success' \| 'warning' \| 'danger' \| 'info' \| 'default'` | — | Use a semantic status dot; `error` is a compatibility alias |
| `text` | `ReactNode` | — | Text beside the indicator |
| `color` | `string` | — | Custom indicator color |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { BadgeProps } from '@ifhover/leaf-ui';
```

## Usage notes

Use alone for counts or status text. When attaching a notification dot to another control, provide aria-label to explain the notification.
