# TreeSelect

Choose one or more values from hierarchical options. Use [Select](select) for a flat list.

{/* leaf:section basic */}

## Basic usage

<a id="basic-selection-and-search"></a>

Search and clearing are enabled by default. Use unique, stable values. Categories with `selectable={false}` cannot be selected; clicking the row expands the branch.

### Linked checks and output values

`treeCheckable` enables multiple selection with linked parent and child checks. `showCheckedStrategy` affects tags, callbacks and form values: the default `child` outputs children, `parent` consolidates fully checked branches, and `all` outputs every checked node. Use `checkStrictly` for independent parent and child checks.

### Loading branches asynchronously

`loadData` requests children when an unloaded branch expands and caches the result. This example simulates a request with a delay and checks cancellation before returning; pass `signal` to `fetch` for a real request. Handle failures with `onLoadError`; expanding again retries. Change `cacheKey` when the data version changes to clear caches and cancel stale requests.

## API

### TreeSelect API

Configure tree options, selected values, search and lazy loading.

Single and multiple modes constrain the types of `value`, `defaultValue` and `onChange`. Uncontrolled fields respond to native form reset. In checkbox mode, clicking a row or pressing Enter / Space toggles its check; the arrow only controls expansion. See [PopupOptions](../api/popup-options) for shared popup settings.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | `readonly `[`TreeSelectOption`](#treeselectoption)`[]` | Required | Hierarchical options |
| `value` | `string \| null \| readonly string[]` | — | Controlled value; use a string or null in single mode and an array with multiple or treeCheckable. |
| `defaultValue` | `string \| null \| readonly string[]` | `null` | Initial uncontrolled value, restored on form reset; no option is selected when omitted. |
| `onChange` | `((value: string \| null) => void) \| ((value: readonly string[]) => void)` | — | Return a string or null in single mode, or an array in multiple mode; checked results follow showCheckedStrategy. Clearing retains disabled entries that cannot be removed. |
| `multiple` | `boolean` | `false` | Whether multiple values can be selected. |
| `treeCheckable` | `boolean` | `false` | Whether checkbox mode is enabled; it implies multiple selection. |
| `checkStrictly` | `boolean` | `false` | Check parents and children independently |
| `showCheckedStrategy` | `'child' \| 'parent' \| 'all'` | `'child'` | Output child, parent or all checked nodes in linked mode, affecting tags, callbacks and form values; ignored with checkStrictly. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation status |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `allowClear` | `boolean` | `true` | Allow clearing enabled selections |
| `showSearch` | `boolean` | `true` | Filter nodes by typing |
| `onSearch` | `(query: string) => void` | — | Search changes |
| `filterTreeNode` | `(option: `[`TreeSelectOption`](#treeselectoption)`, query: string) => boolean` | — | Customize search matching for nodes. |
| `notFoundContent` | `ReactNode` | No options | Content when no options match |
| `maxCount` | `number` | `Infinity` | Maximum number of output values; a linked action that exceeds it is rejected as a whole. |
| `maxTagCount` | `number \| 'responsive'` | — | Maximum visible tags; responsive collapses them to the available width. |
| `tagWrap` | `boolean` | `true` | Allow selected tags to wrap; false keeps one line and collapses overflow. |
| `defaultExpandAll` | `boolean` | `false` | Expand all initially |
| `treeDefaultExpandedKeys` | `readonly string[]` | `[]` | Values expanded initially |
| `treeExpandedKeys` | `readonly string[]` | — | Controlled expanded nodes. |
| `onExpand` | `(keys: string[]) => void` | — | Called when expanded nodes change. |
| `loadData` | `( option: `[`TreeSelectOption`](#treeselectoption)`, signal: AbortSignal, ) => Promise<readonly `[`TreeSelectOption`](#treeselectoption)`[]>` | — | Load children on expansion; signal supports cancellation |
| `onLoadError` | `(error: unknown, option: `[`TreeSelectOption`](#treeselectoption)`) => void` | — | Loading failed; expand again to retry |
| `cacheKey` | `string \| number` | — | Changing the data version clears lazy caches and cancels stale requests. |
| `nodeRender` | `(option: `[`TreeSelectOption`](#treeselectoption)`) => ReactNode` | — | Customize node content. |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Open state changes |
| `inputReadOnly` | `boolean` | — | Disable typing while retaining panel selection. |
| `virtual` | `boolean` | `false` | Render visible items only |
| `listHeight` | `number` | `256` | List height |
| `itemHeight` | `number` | Theme and density dependent | Estimated virtual row height, calculated from the theme and density by default. |
| `popupWidth` | `number \| string` | `'trigger'` | Popup width; trigger matches the trigger, auto fits content (and may be narrower), numbers specify fixed pixels; CSS lengths are also supported. |
| `popupMaxWidth` | `number \| string` | — | Optional maximum popup width; no additional limit when unset, still bounded by the viewport. |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |

### TreeSelectOption

Describe a tree-select node and its children.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Unique value, required |
| `label` | `ReactNode` | Required | Display label, required |
| `children` | `readonly `[`TreeSelectOption`](#treeselectoption)`[]` | — | Child options using the same structure |
| `disabled` | `boolean` | — | Disable interaction. |
| `selectable` | `boolean` | — | Set false to make a category non-selectable |
| `disableCheckbox` | `boolean` | — | Disable checks and stop propagation |
| `icon` | `ReactNode` | — | Node icon |
| `searchLabel` | `string` | — | Search and accessible text for non-text labels |
| `isLeaf` | `boolean` | — | Identify a leaf node, including in lazy data. |
