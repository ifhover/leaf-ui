# Transfer

Select and move items between two lists.

{/* leaf:section basic */}

## Basic usage

Check items, then use the middle buttons to move them to the other panel. Built-in search filters labels and descriptions. Select-all affects only enabled items in the current filtered results; checked items hidden by search still move.

## Examples

### Controlled value and selection

`value` contains items already in the right panel. `selectedKeys` contains checked items pending a move across both panels; checking alone does not move an item. Synchronize them with `onChange` and `onSelectionChange`. A move also clears the moved items from the checked selection.

## API

### TransferProps API

Configure list data, target values and transfer events.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `readonly `[`TransferItem`](#transferitem-api)`[]` | Required | Items; keep keys unique and stable |
| `value` | `readonly string[]` | — | Controlled right-panel item keys, not the checked items pending a move. |
| `defaultValue` | `readonly string[]` | `[]` | Initial right-panel keys for uncontrolled usage, restored on form reset without resetting searches or pending checks. |
| `onChange` | `(keys: string[], info: `[`TransferChangeInfo`](#transferchangeinfo-api)`) => void` | — | Return right-panel keys after a move, with direction and movedKeys in info. |
| `selectedKeys` | `readonly string[]` | — | Controlled pending checked keys across both panels; checking does not move items. |
| `onSelectionChange` | `(keys: string[]) => void` | — | Return pending checked keys after checks change or moved keys are removed from the checks. |
| `titles` | `readonly [ReactNode, ReactNode]` | — | Left and right titles |
| `disabled` | `boolean` | — | Disable interaction. |
| `searchable` | `boolean` | `true` | Show search inputs |
| `filterOption` | `(query: string, item: `[`TransferItem`](#transferitem-api)`) => boolean` | — | Custom search rule |
| `oneWay` | `boolean` | `false` | Hide the move-left button; the right panel remains searchable and checkable. |
| `renderItem` | `(item: `[`TransferItem`](#transferitem-api)`) => ReactNode` | — | Custom item renderer |
| `virtual` | `boolean` | `false` | Render visible items only |
| `height` | `number` | `180` | Height of each scrollable list area, excluding the heading and search field. |
| `name` | `string` | — | Native FormData field name; nonempty values submit a JSON array and empty values submit an empty string. |
| `form` | `string` | — | Associated form ID |
| `required` | `boolean` | — | Require a non-empty value; compound controls validate once. |

### TransferItem API

An individual data item that can be transferred between lists.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique stable identifier |
| `label` | `ReactNode` | Required | Display label |
| `description` | `string` | — | Supporting description |
| `disabled` | `boolean` | — | Disable interaction. |
| `searchLabel` | `string` | — | Plain-text search label |

### TransferChangeInfo API

Describe the direction and affected items of a transfer.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `'left' \| 'right'` | Required | Move direction: 'left' moves to the left list, 'right' to the right list. |
| `movedKeys` | `string[]` | Required | Moved keys |
