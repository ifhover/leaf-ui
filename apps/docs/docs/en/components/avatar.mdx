# AvatarGroup

Display member avatars together, with text fallbacks and overflow counts. Use `Avatar` for each member.

{/* leaf:section basic */}

## Basic usage

Place member avatars inside `AvatarGroup` and provide each member name through `Avatar.alt`.

<ComponentExample exampleId="basic" preview={<AvatarBasic />} fileName="basic.tsx" width="fit-content">

```tsx lineNumbers file="../../../src/examples/en/avatar/basic.tsx"
```

</ComponentExample>

Text avatar colors distinguish members; they do not indicate status.

## API

### AvatarGroup API

Props for displaying member avatars as a group with overflow counts.

#### AvatarGroupProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `maxCount` | `number` | `Infinity` | Maximum visible avatars; the rest collapse into +N. |
| `size` | [`AvatarProps`](#avatar-api)`['size']` | — | Avatar size preset; a number is treated as pixels. |
| `shape` | [`AvatarProps`](#avatar-api)`['shape']` | — | Crop shape |
| `maxContent` | `(hiddenCount: number) => ReactNode` | — | Custom overflow count content |

### Avatar API

Props for an individual member avatar within a group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | — | Avatar image URL. |
| `srcSet` | `string` | — | Responsive image candidates. |
| `imageProps` | `Omit<ImgHTMLAttributes<HTMLImageElement>, 'src' \| 'srcSet' \| 'alt' \| 'onError'>` | — | Image attributes such as loading, sizes, crossOrigin and objectFit styles |
| `alt` | `string` | Text or localized default | Accessible name |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | Preset size or pixel value |
| `shape` | `'circle' \| 'square'` | `'circle'` | Shape |
| `icon` | `ReactNode` | — | Icon displayed without an image. |
| `onError` | `() => void` | — | Image loading error callback |
| `children` | `ReactNode` | — | Text or content displayed without an image. |
