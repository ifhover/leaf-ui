## Avatar API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | — | Image source |
| `alt` | `string` | — | Accessible name |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | Preset size or size in pixels |
| `shape` | `'circle' \| 'square'` | `'circle'` | Avatar shape |
| `icon` | `ReactNode` | — | Fallback icon |
| `children` | `ReactNode` | — | Text or custom content, also displayed when the image fails |
| `onError` | `() => void` | — | Called when the image fails |

## Types

Import the exported types when defining props or building item lists.

```ts
import type { AvatarProps } from '@sudden3/leaf-ui';
```

## Usage notes

Supply alt to name the avatar. A failed image falls back to children or icon; changing src retries the new image.
