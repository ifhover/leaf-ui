## Avatar API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `src / srcSet` | `string` | — | Image source / responsive candidates |
| `alt` | `string` | Text or localized default | Accessible name |
| `imageProps` | `Omit<ImgHTMLAttributes<HTMLImageElement>, 'src' \| 'srcSet' \| 'alt' \| 'onError'>` | — | Image attributes such as loading, sizes, crossOrigin and objectFit styles |
| `onError` | `() => void` | — | Image loading error callback |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | Preset size or pixel value |
| `shape` | `'circle' \| 'square'` | `'circle'` | Shape |
| `icon / children` | `ReactNode` | — | Fallback icon / text |


## Types

Import these types to define props or prepare data.

```ts
import type { AvatarProps } from '@sudden3/leaf-ui';
```

## Usage notes

Failed images fall back to children, icon or the default avatar. Changing the source retries loading. Alt provides an accessible name without duplicate image announcements. Use imageProps.style to customize cropping.

## Extension types

```ts
import type { AvatarGroupProps } from '@sudden3/leaf-ui';
```

## AvatarGroupProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `maxCount` | `number` | `Infinity` | Maximum selections or visible items |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | — | Size or spacing preset |
| `shape` | `'circle' \| 'square'` | — | Crop shape |
| `maxContent` | `(hiddenCount: number) => ReactNode` | — | Custom overflow count content |
