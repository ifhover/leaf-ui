## Tag API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Tag content |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| string` | `'primary'` | Semantic or custom color; `default` and `error` are compatibility aliases |
| `variant` | `'soft' \| 'solid'` | `'soft'` | Tinted or solid appearance, borderless and using the small radius |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size |
| `icon` | `ReactNode` | — | Leading dot or custom icon |
| `closable` | `boolean` | `false` | Show a close button |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | Called on close |

## Usage notes

Tags use borderless fills and the small radius, with tinted and solid appearances. The default is 6px; set `ConfigProvider`'s `theme.components.Tag.borderRadius` for a component override. Label weight is fixed at 500 and no weight prop is exposed. An unspecified color uses the theme color; `default` maps to the theme color and `error` normalizes to `danger`. Tinted labels follow the tag's own color, except warning uses the derived readable warning ink; solid labels use white, except warning uses `--leaf-color-on-warning` against the warning fill. Unchecked `CheckableTag` and `TagGroup` options use the tinted theme color, while selected options use the solid theme color.

Call event.preventDefault() to prevent removal. In a dynamic list, onClose can update application state to remove the matching item.
