## API

### Tag API

Configure tag content, appearance and closing.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Tag content |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| string` | `'primary'` | Semantic or custom color; `default` and `error` are compatibility aliases |
| `variant` | `'soft' \| 'outline'` | `'soft'` | Tinted fill or neutral outlined surface |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size |
| `dot` | `boolean` | `true` | Show the built-in status dot when no custom icon is provided |
| `icon` | `ReactNode` | — | Custom icon replacing the built-in dot |
| `closable` | `boolean` | `false` | Show a close button |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | Called on close |

### CheckableTagProps API

Configure selection state and change events for a checkable tag.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | Controlled checked state |
| `defaultChecked` | `boolean` | `false` | Initial checked state |
| `onChange` | `(checked: boolean) => void` | — | Value change callback |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size. |

### TagGroupProps API

Manage selected values and presentation for a group of tag options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | [`readonly TagOption[]`](#tagoption-api) | Required | Available options |
| `value` | `readonly string[]` | — | Controlled value |
| `defaultValue` | `readonly string[]` | `[]` | Initial value, restored by uncontrolled form resets |
| `onChange` | `(values: string[]) => void` | — | Value change callback |
| `disabled` | `boolean` | — | Disable interactions |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size. |
| `name` | `string` | — | Form field name |
| `form` | `string` | — | Associated form ID |
| `required` | `boolean` | — | Required form validation |

### TagOption API

An individual option supplied to a tag group.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | Required | Controlled value |
| `label` | `ReactNode` | Required | Display label |
| `disabled` | `boolean` | — | Disable interactions |
