## Tag API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Tag content |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'error' \| 'info' \| string` | `'default'` | Semantic or custom color |
| `variant` | `'soft' \| 'solid'` | `'soft'` | Tinted or solid appearance, both borderless with rounded corners |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size |
| `bold` | `boolean` | `true` | Use bold text; set to false for regular text |
| `icon` | `ReactNode` | — | Leading icon |
| `closable` | `boolean` | `false` | Show a close button |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | Called on close |

## Usage notes

Tags use borderless fills and rounded corners, with tinted and solid appearances. The radius follows the regional theme's base radius (10px by default); set `ConfigProvider`'s `theme.components.Tag.borderRadius` for a component override. Bold text follows the theme's `headingWeight` (600 by default), while regular text uses 400. Set regional defaults separately with `ConfigProvider`'s `components.Tag.bold`, `components.CheckableTag.bold`, and `components.TagGroup.bold`; instance props take precedence.

Call event.preventDefault() to prevent removal. In a dynamic list, onClose can update application state to remove the matching item.
