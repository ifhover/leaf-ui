## Tag API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Tag content |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| string` | `'primary'` | Semantic or custom color; `default` and `error` are compatibility aliases |
| `variant` | `'soft' \| 'outline'` | `'soft'` | Tinted fill or neutral outlined surface |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Tag size |
| `dot` | `boolean` | `true` | Show the built-in status dot when no custom icon is provided |
| `icon` | `ReactNode` | — | Custom icon replacing the built-in dot |
| `closable` | `boolean` | `false` | Show a close button |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | Called on close |

## Types

Import the component props and item types when preparing your own values.

```ts
import type { TagProps, CheckableTagProps, TagGroupProps, TagOption } from '@ifhover/leaf-ui';
```

## Usage notes

Use `soft` for tinted labels or `outline` for a pill-shaped neutral surface with a border and semantic dot; dark mode follows the regional surface. Checkable tags use outline when unchecked and soft when checked.

Call event.preventDefault() to prevent removal. In a dynamic list, onClose can update application state to remove the matching item.
