# InputMask

Enter text in a specified format.

{/* leaf:section basic */}

## Basic usage

Use `0` for a digit, `a` for a letter and `*` for a letter or digit. Masking constrains the format; validate phone numbers and other business rules in your application.

## Examples

### Unmasked value

`unmask` makes `value`, `defaultValue` and the first `onChange` argument use the unmasked value. The second argument is always the formatted display value. Clearing returns an empty string.

<ComponentExample exampleId="controlled" preview={<InputMaskControlled />} width={360} fileName="controlled.tsx">

```tsx lineNumbers file="../../../src/examples/en/input-mask/controlled.tsx"
```

</ComponentExample>

Native form submission still uses the display value when `name` is set. Uncontrolled form reset restores `defaultValue`; reset controlled values in application state. External value updates do not trigger user change or completion callbacks.

### Persistent placeholders

Set `lazy={false}` to show placeholders for unfilled positions.

## API

### InputMaskProps API

Configuration for input patterns, controlled values, formatted output and completion events.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `mask` | `string` | Required | Pattern: 0 for digits, a for letters, * for alphanumeric |
| `value` | `string` | — | Controlled value; unmask selects an unmasked value or the formatted display value. |
| `defaultValue` | `string` | `''` | Initial uncontrolled value in the format selected by unmask, restored on form reset. |
| `onChange` | `(value: string, formatted: string) => void` | — | Return the component value and formatted display value; unmask affects only the first argument. |
| `onComplete` | `(value: string) => void` | — | Called when user input completes the format, using the unmask value format; this is not business validation. |
| `unmask` | `boolean` | `false` | Use unmasked component values for value, defaultValue and callbacks without changing the formatted native form value. |
| `lazy` | `boolean` | `true` | Hide placeholders for unfilled positions; false keeps them visible. |
| `definitions` | `Record<string, RegExp>` | — | Custom character rules |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input size. |
| `status` | `'error' \| 'warning'` | — | Display state |
| `allowClear` | `boolean` | `false` | Show the clear button |
| `prefix` | `ReactNode` | — | Content before the input |
| `suffix` | `ReactNode` | — | Content after the input |
| `onClear` | `() => void` | — | Called after clearing the input |
| `showCount` | `boolean \| ((value: string, maxLength?: number) => ReactNode)` | `false` | Display count or a custom renderer |
| `onPressEnter` | `KeyboardEventHandler<HTMLInputElement>` | — | Called when Enter is pressed |
