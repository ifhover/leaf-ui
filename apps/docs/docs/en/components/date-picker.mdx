# DatePicker

Choose a date, time or date and time. Calendar modes use local `Date` values; `picker="time"` uses time strings. Use [DateRangePicker](/en/components/date-range-picker) for ranges.

{/* leaf:section basic */}

Set an initial date with `defaultValue`; choosing a date closes the panel. Use `null` for an empty value.

### Display format and form submission

<a id="advanced-usage"></a>

`format` changes display and the string argument of `onChange`, not the canonical FormData value. This example displays `DD/MM/YYYY` and submits `YYYY-MM-DD`. Clearing submits an empty string; resetting an uncontrolled field restores `defaultValue`.

<ComponentExample exampleId="format" preview={<Format />} fileName="format.tsx">

```tsx lineNumbers file="../../../src/examples/en/date-picker/format.tsx"
```

</ComponentExample>

Canonical values are `date: YYYY-MM-DD`, `year: YYYY`, `quarter: YYYY-QN`, `month: YYYY-MM` and `week: YYYY-Www`; datetime uses `YYYY-MM-DD HH:mm[:ss]`. Dates use local time. Handle business timezone conversion in the application rather than treating UTC date strings as local calendar values.

String formats support `YYYY`, `MM`, `DD`, `HH`, `mm`, `ss` and `Q`. Escape literals with brackets, for example `YYYY-[Q]Q`. If a function formatter produces text the default parser cannot recognize, provide `parse`, returning `null` on failure. See [Form](/en/components/form) for other form configuration.

### Date shortcuts

#### Input and confirmation

Type or paste a complete value, and select date segments with the mouse or Left / Right. Enter commits valid input; Escape discards the current edit. Invalid or incomplete input reverts to the committed value when focus leaves the whole picker. Alt + ArrowDown moves focus into the panel.

Date and time-only modes do not require confirmation by default; valid changes may commit when focus leaves. With `needConfirm`, unconfirmed edits are discarded on dismissal. Clearing and presets still commit directly.

## API

### DatePicker API

The main table includes props for different `picker` modes: `format`, `parse`, `presets`, `minDate` / `maxDate` and calendar display props apply to calendar modes; `minTime` / `maxTime` apply to time-only mode. In datetime mode, `disabledTime` also receives the current `Date`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `picker` | `'date' \| 'datetime' \| 'year' \| 'quarter' \| 'month' \| 'week' \| 'time'` | `'date'` | Select a date, time, date-time, week, month, quarter or year. |
| `value` | `Date \| null \| string` | — | Controlled value: Date for dates/date-times, HH:mm[:ss] string for time; null when empty. |
| `defaultValue` | `Date \| null \| string` | `null` | Initial uncontrolled value, matching picker, restored on form reset. |
| `onChange` | `((value: Date \| null, dateString: string) => void) \| ((value: string \| null) => void)` | — | Called on commit: Date and formatted string for date modes, only HH:mm[:ss] or null for time. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `inputReadOnly` | `boolean` | — | Disable typing while retaining panel selection. |
| `allowClear` | `boolean` | `true` | Show a clear button |
| `minDate` | `Date` | — | Earliest selectable date; datetime compares the complete timestamp, inclusive. |
| `maxDate` | `Date` | — | Latest selectable date; datetime compares the complete timestamp, inclusive. |
| `disabledDate` | `(date: Date) => boolean` | — | Restrict selectable dates |
| `minTime` | `string` | — | Earliest selectable time, inclusive, as HH:mm or HH:mm:ss. |
| `maxTime` | `string` | — | Latest selectable time, inclusive, as HH:mm or HH:mm:ss. |
| `disabledTime` | `((parts: `[`TimeParts`](#timeparts)`, date: Date) => boolean) \| ((parts: `[`TimeParts`](#timeparts)`) => boolean)` | — | Disable times; typing and panel selection use the same rules. |
| `needConfirm` | `boolean` | `picker === "datetime"` | Require OK or Enter to commit; discard the draft on blur when enabled. |
| `showSeconds` | `boolean` | `false` | Display and edit seconds; otherwise seconds are zero. |
| `use12Hours` | `boolean` | `false` | Use a 12-hour clock with AM/PM. |

| `secondStep` | `number` | `1` | Second segment step and column interval, retaining existing off-step values. |
| `format` | `string \| ((date: Date) => string)` | — | Display format; dates support YYYY, MM, DD, HH, mm, ss and Q. |

| `presets` | `readonly `[`DatePreset`](#datepreset)`[]` | — | Presets; value may be computed on demand. |
| `showToday` | `boolean` | `true` | Show the Today shortcut |
| `todayText` | `ReactNode` | Locale default | Customize the Today label |
| `renderExtraFooter` | `ReactNode` | — | Additional footer content |
| `panelValue` | `Date` | — | Controlled date displayed by the calendar panel. |
| `onPanelChange` | `(date: Date) => void` | — | Called when the displayed calendar period changes. |
| `cellRender` | `(date: Date) => ReactNode` | — | Customize calendar cell content. |
| `open` | `boolean` | — | Control whether the panel is open. |
| `defaultOpen` | `boolean` | — | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Calendar open-state changes |
| `panelVariant` | `'plain' \| 'card'` | `'card'` | Panel appearance; card places the content on an inset surface above a muted canvas. |
| `name` | `string` | — | Field name in native FormData. |
| `form` | `string` | — | ID of the associated native form. |
| `required` | `boolean` | `false` | Require a non-empty value; compound controls validate once. |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |

### DatePreset

Preset entries used by `presets`. `T` is `Date` for a single value or a date tuple for a range. Functions must be synchronous, free of side effects and safe to evaluate repeatedly.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | — | Stable, unique identifier. |
| `label` | `ReactNode` | Required | Visible label or content. |
| `value` | `T \| (() => T)` | Required | Preset value or synchronous function; functions must be pure and allow repeated evaluation. |
