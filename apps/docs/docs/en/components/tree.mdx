### Drag nodes

`draggable` enables handles. `onDrop` returns the reordered tree; update `data` in the application. Drop on the upper, middle or lower part of a row to place before, inside or after the target.

On a focused handle, Space picks up or drops, Up / Down chooses a target, Left / Right chooses before / after, and Escape cancels.

### Lazy loading

`loadData` returns children when a node without `children` expands, unless it is marked as a leaf. This example fails the first request and reports it through `onLoadError`; collapse and expand again to retry.

Keep `data` and `loadData` references stable and respect `AbortSignal`. Changing the data, loader or `cacheKey`, or unmounting, cancels old requests. Collapsing a node does not.

## API

### Tree API

Configure tree data, selection, checking, expansion and drag-and-drop.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `readonly `[`TreeNode`](#treenode)`[]` | Required | Tree nodes |
| `selectedKeys` | `readonly string[]` | — | Controlled selected node keys. |
| `defaultSelectedKeys` | `readonly string[]` | `[]` | Initial selected node keys in uncontrolled mode. |
| `onSelect` | `(keys: string[], info: `[`TreeSelectInfo`](#treeselectinfo)`) => void` | — | Return selected keys and node information on selection changes; activating the current node again clears single selection. |
| `multiple` | `boolean` | `false` | Whether multiple selection is allowed. |
| `selectable` | `boolean` | `true` | Whether row selection is enabled. |
| `checkable` | `boolean` | `false` | Whether checkboxes are shown. |
| `checkStrictly` | `boolean` | `false` | Keep parent and child checks independent; use with checkable. |
| `checkedKeys` | `readonly string[]` | — | Controlled checked node keys. |
| `defaultCheckedKeys` | `readonly string[]` | `[]` | Initial checked node keys in uncontrolled mode. |
| `onCheck` | `(keys: string[], info: `[`TreeCheckInfo`](#treecheckinfo)`) => void` | — | Return all checked keys and node information; half-checked keys are in info.halfCheckedKeys. |
| `expandedKeys` | `readonly string[]` | — | Controlled expanded node keys. |
| `defaultExpandedKeys` | `readonly string[]` | `[]` | Initial expanded node keys in uncontrolled mode. |
| `defaultExpandAll` | `boolean` | `false` | Expand all nodes initially |
| `onExpand` | `(keys: string[], info: `[`TreeExpandInfo`](#treeexpandinfo)`) => void` | — | Expansion changes |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `showLine` | `boolean` | `false` | Show hierarchy connector lines. |
| `showIcon` | `boolean` | `false` | Show default folder or file icons; custom node icons are displayed regardless. |
| `searchValue` | `string` | `''` | Filter nodes, retaining matches and ancestors |
| `filterTreeNode` | `(node: `[`TreeNode`](#treenode)`, query: string) => boolean` | — | Custom search predicate |
| `notFoundContent` | `ReactNode` | No options | Content when no nodes match |
| `loadData` | `(node: `[`TreeNode`](#treenode)`, signal: AbortSignal) => Promise<readonly `[`TreeNode`](#treenode)`[]>` | — | Load children on expansion; signal supports cancellation |
| `onLoad` | `(node: `[`TreeNode`](#treenode)`, children: readonly `[`TreeNode`](#treenode)`[]) => void` | — | Children loaded |
| `onLoadError` | `(error: unknown, node: `[`TreeNode`](#treenode)`) => void` | — | Loading failed; expand again to retry |
| `cacheKey` | `string \| number` | — | Changing the data version clears lazy caches and cancels stale requests. |
| `nodeRender` | `(node: `[`TreeNode`](#treenode)`) => ReactNode` | — | Customize node content. |
| `draggable` | `boolean \| ((node: `[`TreeNode`](#treenode)`) => boolean)` | `false` | Enable node drag handles |
| `allowDrop` | `(info: Omit<`[`TreeDropInfo`](#treedropinfo-api)`, 'data'>) => boolean` | — | Restrict drop positions |
| `onDrop` | `(info: `[`TreeDropInfo`](#treedropinfo-api)`) => void` | — | Return the drop position and new tree data; the application must write info.data back to data. |
| `virtual` | `boolean` | `false` | Render visible nodes only; enable for large trees. |
| `height` | `number` | `320` | Visible height of the virtual list; applies only with virtual enabled. |
| `itemHeight` | `number` | Theme and density dependent | Estimated virtual row height, calculated from the theme and density by default; actual rows are measured. |

### TreeNode

Describe the stable key, content and children of a tree node.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `key` | `string` | Required | Unique key, required |
| `title` | `ReactNode` | Required | Node content, required |
| `children` | `readonly `[`TreeNode`](#treenode)`[]` | — | Child nodes using this same structure |
| `icon` | `ReactNode` | — | Custom icon |
| `disabled` | `boolean` | — | Prevent selection, checking and dragging for this node; it can still expand. |
| `selectable` | `boolean` | — | Whether this node can be selected; enabled by default. |
| `checkable` | `boolean` | — | With Tree checkable enabled, false hides this node checkbox and blocks linked checks. |
| `disableCheckbox` | `boolean` | — | Disable checks and stop check propagation |
| `searchLabel` | `string` | — | Search and accessible text for non-text titles |
| `isLeaf` | `boolean` | — | True marks a leaf and prevents loading children; nodes with supplied children are not loaded either. |

### TreeSelectInfo

The affected node and selection result returned when a node is selected.

| Property | Type | Default | Description |
| --- | --- | --- | --- |

| `selected` | `boolean` | Required | Whether the node is now selected |
| `selectedNodes` | `readonly `[`TreeNode`](#treenode)`[]` | Required | All selected nodes |

### TreeCheckInfo

The affected node, checked nodes and indeterminate keys returned when checking changes.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | Required | Operated node |
| `checked` | `boolean` | Required | Whether the node is now checked |
| `checkedNodes` | `readonly `[`TreeNode`](#treenode)`[]` | Required | All fully checked nodes |
| `halfCheckedKeys` | `readonly string[]` | Required | Partially checked keys |

### TreeExpandInfo

Information returned when a node is expanded or collapsed.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | Required | Operated node |
| `expanded` | `boolean` | Required | Whether the node is now expanded |

### TreeDropInfo API

The target, position and updated data returned after dropping a node.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | Required | Operated node |
| `target` | [`TreeNode`](#treenode) | Required | Target node receiving the drop. |
| `position` | `'before' \| 'inside' \| 'after'` | Required | Place before, inside or after the target node. |
| `data` | [`TreeNode`](#treenode)`[]` | Required | Hierarchical data |

### moveTreeNode

Use this pure function for custom tree updates. It returns a new tree without changing the input, or `null` for missing targets, self moves or moves into descendants. `Tree` already provides the reordered data in `onDrop`.

```ts
import { moveTreeNode } from '@ifhover/leaf-ui';

const next = moveTreeNode(data, 'design', 'archive', 'inside');
```

| Parameter | Type | Description |
| --- | --- | --- |
| `data` | [`readonly TreeNode[]`](#treenode) | Source tree |
| `key` | `string` | Node key to move |
| `target` | `string` | Target node key |
| `position` | `'before' \| 'inside' \| 'after'` | Position relative to the target |
| Return value | [`TreeNode[] \| null`](#treenode) | New tree, or null for an invalid move |
