## Extended features

Drag a handle to the upper, middle or lower part of a target row to place a node before, inside or after it. With the keyboard, Space picks up or drops, Up/Down chooses a target, Left/Right places before/after it, and Escape cancels. Update `data` with the new tree returned by `onDrop`.

## Usage notes

Each node needs a unique, stable `key`. Example data:

```ts lineNumbers file="../../../src/examples/en/tree/data.ts"
```

Checking a parent checks enabled children; disabled nodes are unaffected. Partially checked children create a mixed parent. `checkStrictly` keeps checks independent. In multiple mode, clicking toggles selection; Shift selects a range of visible nodes.

Use up/down to move, right/left to expand/collapse, Home/End to jump, Enter to select and Space to check. Typing locates nodes. Search temporarily reveals matching paths; clearing it restores the original expansion.

## moveTreeNode

Move a node in a custom data operation. This pure function returns a new tree without changing its input. It returns `null` for missing targets, self moves or moves into descendants. Tree already includes the new data in its `onDrop` callback.

```ts
import { moveTreeNode } from '@sudden3/leaf-ui';

const next = moveTreeNode(data, 'design', 'team', 'inside');
```

| Parameter | Type | Description |
| --- | --- | --- |
| `data` | [`readonly TreeNode[]`](#treenode) | Source tree |
| `key` | `string` | Node key to move |
| `target` | `string` | Target node key |
| `position` | `'before' \| 'inside' \| 'after'` | Position relative to the target |
| Return value | [`TreeNode[] \| null`](#treenode) | New tree, or null for an invalid move |
