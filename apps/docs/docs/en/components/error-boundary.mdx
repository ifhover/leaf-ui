## Usage

Catches descendant rendering and lifecycle errors. Handle event, async request and server errors in the operation or framework. Report through onError and avoid exposing internal stacks.

## Types

Import these types for data, callbacks and refs.

```ts
import type { ErrorBoundaryFallbackProps, ErrorBoundaryProps } from '@sudden3/leaf-ui';
```

## ErrorBoundaryFallbackProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `error` | `Error` | Required | Error object or notification |
| `reset` | `() => void` | Required | Reset or retry |

## ErrorBoundaryProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Content or child items |
| `fallback` | [`ReactNode \| ((props: ErrorBoundaryFallbackProps) => ReactNode)`](#errorboundaryfallbackprops-api) | — | Loading error content |
| `resetKeys` | `readonly unknown[]` | — | Reset errors when these values change |
| `onError` | `(error: Error, info: ErrorInfo) => void` | — | Error callback |
| `onReset` | `() => void` | — | Reset callback |
