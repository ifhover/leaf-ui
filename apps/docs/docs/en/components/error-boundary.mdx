# ErrorBoundary

Catch descendant rendering errors and replace the failed section with a fallback.

{/* leaf:section basic */}

## Basic usage

Without `fallback`, the boundary shows its default error view and retry button. Retrying clears the boundary's error state and renders the subtree again; the application must still fix the data or state that caused the error. This example clears its error switch in `onReset`.

Error boundaries do not handle errors from event handlers, ordinary async requests, or server-side rendering. Handle those in the operation or framework.

### Recover when the record changes

Put external dependencies such as a record ID in `resetKeys`. A dependency change resets the boundary while it is displaying an error. The application clears the previous record's error state in `onReset` before displaying the new record.

## API

### ErrorBoundaryProps API

Configuration for the protected subtree, error fallback and reset behavior.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Subtree whose render errors are caught. |
| `fallback` | `ReactNode \| ((props: `[`ErrorBoundaryFallbackProps`](#errorboundaryfallbackprops-api)`) => ReactNode)` | — | Fallback after a caught error; defaults to an error Result with Retry. The function receives error and reset. |
| `onReset` | `() => void` | — | Called synchronously on manual or resetKeys resets; repair the failing data in the application. Async results are not awaited. |
| `resetKeys` | `readonly unknown[]` | — | After an error, shallow-compare entries with Object.is; a changed length or entry resets the boundary. |
| `onError` | `(error: Error, info: ErrorInfo) => void` | — | Receive the Error and React ErrorInfo after a render or lifecycle error is caught, for reporting. |

### ErrorBoundaryFallbackProps API

The error and retry method passed to a custom `fallback`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `error` | `Error` | Required | Caught Error. |
| `reset` | `() => void` | Required | Call onReset synchronously, clear the error and rerender the subtree without automatically repeating business requests. |
