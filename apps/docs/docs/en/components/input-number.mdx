# InputNumber

Enter numeric values such as quantities or prices.

{/* leaf:section basic */}

## Basic usage

Set bounds with `min` and `max`. `onChange` returns a number, or `null` when cleared. Partial minus signs and decimal points are preserved while typing; blur or Enter normalizes bounds and precision.

### Display formatting

<a id="advanced-usage"></a>

Use `grouping` for localized digit grouping. For custom formats, `formatter` controls display and `parser` converts the entered text back into a value. Formatting does not change the canonical value submitted by a native form.

<ComponentExample exampleId="formatting" preview={<InputNumberFormatting />} fileName="formatting.tsx" width={360}>

```tsx lineNumbers file="../../../src/examples/en/input-number/formatting.tsx"
```

</ComponentExample>

### Exact decimal values

Use `stringMode` for values beyond JavaScript Number precision. Pass strings for `value`, `defaultValue`, `step`, `min` and `max`; `onChange` returns a string or `null`. Do not convert these values to Number first.

## API

### InputNumber API

#### Forms

Set `name` to submit the canonical value through FormData. Uncontrolled fields support form reset; reset controlled values in application state. Native attributes such as `required` and `form` reach the input. See [Form](/en/components/form) for form integration.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null \| string` | — | Controlled number, or string in stringMode; null represents an empty field. |
| `defaultValue` | `number \| null \| string` | `null` | Initial uncontrolled value, a string in stringMode; restored on form reset. |
| `onChange` | `((value: number \| null) => void) \| ((value: string \| null) => void)` | — | Called for a valid number or clearing |
| `min` | `number \| string` | Unbounded | Allowed number range |
| `max` | `number \| string` | Unbounded | Allowed number range |
| `step` | `number \| string` | `1` | Increment and decrement step |
| `precision` | `number` | — | Decimal precision, from 0 to 15 |
| `controls` | `boolean` | `true` | Show increment and decrement buttons |
| `keyboard` | `boolean` | `true` | Support arrow key increments |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation status |
| `prefix` | `ReactNode` | — | Leading / trailing decoration |
| `suffix` | `ReactNode` | — | Leading / trailing decoration |
| `stringMode` | `false \| true` | — | Use strings for exact values, steps and bounds. |
| `formatter` | `( value: number \| string \| null, info: { userTyping: boolean; input: string }, ) => string` | — | Format displayed text without changing the canonical form value. |
| `parser` | `(text: string) => number \| string` | — | Parse displayed text back into a value. |
| `grouping` | `boolean` | — | Use localized digit grouping. |
| `locale` | `string` | — | Locale for language or numeric formatting. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `readOnly` | `boolean` | `false` | Lock the value against typing, selection, clearing and removal. |
| `ref` | `Ref<HTMLInputElement>` | — | Input element ref |
