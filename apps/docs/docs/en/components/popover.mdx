### Controlled editing

Control visibility with `open` and `onOpenChange`. Saving updates the project name; reopening after an unsaved close restores the saved value. Click mode moves focus into the panel by default; saving or pressing Escape returns it to the trigger.

## API

### Popover API

Configure popup content, triggers and controlled visibility.

The trigger must forward its ref and events. Provide `aria-label` when there is no `title`. Tab can leave the panel; focus is not trapped. See [PopupOptions](/en/api/popup-options) for shared popup options.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | `—` | Popover title. |
| `content` | `ReactNode` | Required | Popover content; use click mode for interactive content. |
| `children` | `ReactElement< HTMLAttributes<HTMLElement> & { ref?: Ref<HTMLElement>; disabled?: boolean } >` | Required | Trigger element, with ref and event support |
| `trigger` | `'click' \| 'hover'` | `'click'` | Trigger mode |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | `'top'` | Popup placement |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `open` | `boolean` | — | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state for uncontrolled usage. |
| `onOpenChange` | `(open: boolean) => void` | — | Open state change |
| `autoFocus` | `boolean` | `true` | In click mode, focus the first focusable element or the panel if none exists; hover mode does not move focus. |
| `aria-label` | `string` | — | Accessible name for a popover without a visible title. |
| `width` | `number \| string` | `'max-content'` | Popover width; numbers are pixels. |
| `maxWidth` | `number \| string` | `320` | Maximum popover width; numbers are pixels. |
| `enterDelay` | `number` | `100` | Delay in milliseconds before opening on hover. |
| `leaveDelay` | `number` | `100` | Delay in milliseconds before closing after pointer leave. |
| `className` | `string` | — | CSS class applied to the popover panel. |
| `style` | `CSSProperties` | — | Inline styles applied to the popover panel. |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | Placement relative to the trigger. |
| `popupClassName` | `string` | — | Custom class for the popup. |
| `popupStyle` | `CSSProperties` | — | Custom popup styles. |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | Wrap or extend popup content; retain the supplied content to preserve interaction. |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | Return a popup container, including a ShadowRoot. |
