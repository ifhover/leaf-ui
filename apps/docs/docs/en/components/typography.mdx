## API

### Typography API

Configure paragraph density within a typography content area.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `compact` | `boolean` | — | Use tighter paragraph spacing. |

### Text API

Configure text style, semantic color, copying and editing.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `tone` | `'default' \| 'muted' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Semantic text tone. |
| `strong` | `boolean` | — | Use bold text. |
| `italic` | `boolean` | — | Use italic text. |
| `underline` | `boolean` | — | Show an underline. |
| `code` | `boolean` | — | Display as inline code. |
| `mark` | `boolean` | — | Highlight text. |
| `ellipsis` | `boolean \| { rows?: number; expandable?: boolean }` | — | Truncate one or more lines, optionally with an expand action. |
| `copyable` | `boolean \| { text?: string; onCopy?: (text: string) => void; onError?: (error: unknown) => void }` | — | Provide a copy action with optional content and callbacks. |
| `editable` | `{ onChange: (text: string) => void; text?: string }` | — | Provide editing; update the text after onChange. |

### Paragraph API

Configure paragraph style, truncation, copying and editing.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `tone` | `'default' \| 'muted' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | Semantic text tone. |
| `strong` | `boolean` | — | Use bold text. |
| `italic` | `boolean` | — | Use italic text. |
| `underline` | `boolean` | — | Show an underline. |
| `code` | `boolean` | — | Display as inline code. |
| `mark` | `boolean` | — | Highlight text. |
| `ellipsis` | `boolean \| { rows?: number; expandable?: boolean }` | — | Truncate one or more lines, optionally with an expand action. |
| `copyable` | `boolean \| { text?: string; onCopy?: (text: string) => void; onError?: (error: unknown) => void }` | — | Provide a copy action with optional content and callbacks. |
| `editable` | `{ onChange: (text: string) => void; text?: string }` | — | Provide editing; update the text after onChange. |

### Title API

Set the semantic heading level of the content.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2` | Heading level, rendering h1–h6. |

### Link API

Configure disabled state, underlining and external navigation.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | — | Disable interaction. |
| `underline` | `boolean` | `true` | Show an underline. |
| `external` | `boolean` | — | Open in a new tab with a safe rel attribute. |
| `icon` | `ReactNode` | — | Icon content. |
