## Usage

The image stays fixed. Move the selection or drag its edges to resize it; touch and keyboard are supported. The canvas is square by default. Omit aspect for free resizing; round crops use 1:1. export() returns a Blob. Remote images require CORS permissions; round PNGs keep transparent corners and JPEGs use white.

## Types

Import these types for data, callbacks and refs.

```ts
import type { CropArea, ImageCropperHandle, ImageCropperProps, ImageCropResult } from '@sudden3/leaf-ui';
```

## CropArea API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `x` | `number` | Required | X coordinate |
| `y` | `number` | Required | Y coordinate |
| `width` | `number` | Required | Width, numbers are in pixels |
| `height` | `number` | Required | Height, numbers are in pixels |

## ImageCropperHandle API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `export` | [`() => Promise<ImageCropResult>`](#imagecropresult-api) | Required | Export as Blob |
| `reset` | `() => void` | Required | Reset or retry |

## ImageCropperProps API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | Required | Image URL |
| `aspect` | `number` | — | Fixed crop aspect ratio; omitted means free resizing |
| `shape` | `'rect' \| 'round'` | `'rect'` | Crop shape |
| `minWidth / minHeight` | `number` | `24` | Minimum selection size in displayed pixels |
| `disabled` | `boolean` | `false` | Disable moving and resizing |
| `showActions` | `boolean` | `true` | Show reset and export actions |
| `showGrid` | `boolean` | `true` | Crop guides |
| `crossOrigin` | `'anonymous' \| 'use-credentials'` | `'anonymous'` | Image cross-origin mode; export needs server CORS permission |
| `type` | `'image/png' \| 'image/jpeg' \| 'image/webp'` | `'image/png'` | Export image format |
| `quality` | `number` | `0.92` | Export quality, 0–1 |
| `onChange` | [`(area: CropArea) => void`](#croparea-api) | — | Crop area change, measured in original image pixels |
| `onExport` | [`(result: ImageCropResult) => void`](#imagecropresult-api) | — | Export completed |
| `onError` | `(error: Error) => void` | — | Error callback |
| `extra` | `ReactNode` | — | Supplementary content or actions |

## ImageCropResult API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `blob` | `Blob` | Required | Exported Blob |
| `width` | `number` | Required | Width, numbers are in pixels |
| `height` | `number` | Required | Height, numbers are in pixels |
