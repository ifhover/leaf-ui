## Pagination API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `total` | `number` | Required | Total number of items. |
| `current` | `number` | — | Controlled page, starting at 1. |
| `defaultCurrent` | `number` | `1` | Initial page in uncontrolled mode. |
| `pageSize` | `number` | — | Controlled number of items per page. |
| `defaultPageSize` | `number` | `10` | Initial page size in uncontrolled mode. |
| `onChange` | `(page: number, pageSize: number) => void` | — | Called once when the page or size actually changes, with both values. |
| `showSizeChanger` | `boolean` | `false` | Show the page size selector. |
| `pageSizeOptions` | `readonly number[]` | `[10, 20, 50, 100]` | Available sizes; includes the current size, removes duplicates and ignores invalid values. |
| `showQuickJumper` | `boolean` | `false` | Commit on Enter or when leaving the pagination region; other pagination controls take precedence. |
| `showTotal` | `boolean \| ((total: number, range: readonly [number, number]) => ReactNode)` | `false` | true shows a localized total; pass a function for a custom total and visible item range. |
| `simple` | `boolean` | `false` | Show only previous/next controls and the current / total page count. |
| `disabled` | `boolean` | `false` | Disable interaction. |
| `hideOnSinglePage` | `boolean` | `false` | Hide when there are fewer than two pages. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of page buttons, size selector and jump input. |
| `variant` | `'outline' \| 'ghost'` | `'outline'` | Button appearance: outlined or borderless. |

The component also accepts native `<nav>` attributes such as `aria-label`, `className` and `style`.

## Usage notes

Only `total` is required for basic use; uncontrolled pages and page sizes are managed internally. Use `current` and `pageSize` when loading remote data, and update both in `onChange`. Keep `total` equal to the full result count, rather than the number of items on the current page.

Changing page size preserves the current item position where possible. For example, page 3 at 10 items per page becomes page 2 at 20 items per page. Out-of-range pages are clamped; an empty dataset displays page 1 and disables both arrows. Changes to props do not emit `onChange`.

`showTotal` uses the nearest ConfigProvider language. To describe the visible range, pass a render function:

```tsx
<Pagination
  total={240}
  showTotal={(total, [start, end]) => `${start}–${end} / ${total} items`}
/>
```
