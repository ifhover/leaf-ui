## API

### Input API

#### Forms

Set `name` to include the value in FormData. Uncontrolled fields restore their initial value on form reset; reset controlled values in application state. See [Form](/en/components/form) for labels, help and errors.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control size |
| `status` | `'error' \| 'warning'` | — | Validation appearance |
| `prefix` / `suffix` | `ReactNode` | — | Decorative content before / after the input |
| `onPressEnter` | `KeyboardEventHandler<HTMLInputElement>` | — | Runs when Enter is pressed |
| `type` | `HTMLInputTypeAttribute` | `'text'` | Input type; use `'password'` for passwords |
| `visibilityToggle` | `boolean` | `true` | Show the password visibility toggle |
| `visible` / `defaultVisible` | `boolean` | `false` | Controlled / initial password visibility |
| `onVisibleChange` | `(visible: boolean) => void` | — | Password visibility change |
| `visibilityIcon` | `(visible: boolean) => ReactNode` | — | Custom visibility toggle icon |
| `value` / `defaultValue` | `string \| number \| readonly string[]` | — | Controlled value / initial uncontrolled value |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | Read event.target.value |
| `disabled` / `readOnly` | `boolean` | `false` | Disabled / read-only |
| `ref` | `Ref<HTMLInputElement>` | — | DOM reference |
| `allowClear` | `boolean` | `false` | Show clear button |
| `onClear` | `() => void` | — | After clearing; onChange also fires |
| `showCount` | `boolean \| ((value: string, maxLength?: number) => ReactNode)` | `false` | Show or customize the character count |

### InputSearchProps API

Props for the submission behavior and actions of a search input.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input size. |
| `status` | `'error' \| 'warning'` | — | Display state |
| `prefix` | `ReactNode` | — | Content before the input |
| `suffix` | `ReactNode` | — | Content after the input |
| `allowClear` | `boolean` | `false` | Show the clear button |
| `onClear` | `() => void` | — | Called after clearing the input |
| `showCount` | `boolean \| ((value: string, maxLength?: number) => ReactNode)` | `false` | Display count or a custom renderer |
| `visibilityToggle` | `boolean` | `true` | Show the password visibility toggle |
| `visible` | `boolean` | — | Controlled password visibility |
| `defaultVisible` | `boolean` | `false` | Initial password visibility |
| `onVisibleChange` | `(visible: boolean) => void` | — | Password visibility change |
| `visibilityIcon` | `(visible: boolean) => ReactNode` | — | Custom password visibility icon |
| `onPressEnter` | `KeyboardEventHandler<HTMLInputElement>` | — | Called when Enter is pressed |
| `onSearch` | `(value: string) => void` | — | Search or Enter callback |
| `loading` | `boolean` | `false` | Loading state |
| `enterButton` | `ReactNode` | — | Search button label; omitted shows an icon |
