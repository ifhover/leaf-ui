# 视觉与交互规范

统一使用语义颜色、尺寸与间距变量，组件在深浅色、舒适与紧凑模式下保持一致。完整规范维护在仓库 `DESIGN-STANDARDS.md`。

基础外观使用白色与中性浅灰表面、细边框和柔和圆角；普通输入保持平面感，描边按钮仅使用一层向下的轻微静止阴影，Card 与 Table 使用最轻的静态阴影并向下偏移，更明显的阴影主要用于浮层。主题色主要强调关键操作，可以自由替换；Input 聚焦和 Select 展开使用主题色边框，下拉选中项保持中性。默认单行控件高 34px，小 / 大尺寸为 28 / 40px。

Input 聚焦或 Select 展开时，边框使用主题色，不添加外圈；其他字段保持中性边框，错误与警告保留语义色，强制颜色模式保留可见焦点。

Card 的小、默认和大尺寸统一调整留白、标题字号和标题栏高度，Card 与独立 CardTitle 默认都渲染 h3。内嵌 Tabs 默认跟随卡片尺寸。标签页与标题共用一个头部区域：有标题时在标题下方，没有标题时占满标题栏高度并垂直居中，分割线只位于整条标签栏下方，选中指示线覆盖该分割线并与独立线形 Tabs 保持相同粗细。标签文字与正文左边缘对齐，页面内容沿用卡片内边距，底部操作区与正文通过留白衔接。

警告状态统一使用明亮的黄橙色，图标、控件边框和状态填充保持一致；文字使用独立派生的可读颜色。可通过 ConfigProvider 的 `theme.tokens.warningColor` 定制警告色。

下拉选项的悬停、键盘候选与选中背景使用中性灰色。这一规则覆盖 Select、Dropdown、AutoComplete、Cascader、Tree、TreeSelect 的选项层与 Menu；时间列和分页保留各自的选中外观。Select、TreeSelect 与 Tree 的灰底从已选项开始；打开的 TreeSelect 尚无选中值时，从首个可用行开始。悬停或键盘移动到其他项时高亮跟随目标，鼠标离开列表后回到已选项；勾选标记始终留在已选项，勾选模式使用复选框作为持久标记。Select、TreeSelect 与 Tree 的行之间没有额外空隙，普通行高等于控件高度（舒适 34px、紧凑 30px，显式组件尺寸继续跟随 token），长文字换行时行高自然增加，树的层级缩进保留。切换选中项时，框内文字直接更新，不播放位移动画。级联切换一级时立即替换下一级内容，不再使用闪动式淡入；已选中项使用正文色与勾选标记。自动完成、提及、命令面板、Dropdown 与 Menu 的候选项同样保持中性。移动背景平滑切换位置，不会同时留下第二块灰底；禁用项不响应交互，危险操作保留红色提示。输入框、按钮、菜单和浮层选项的颜色过渡统一使用 `--leaf-motion-color`。配色随 ConfigProvider 的区域主题与深浅外观调整。

Select、TreeSelect 和 Cascader 的多选标签使用一致的尺寸与间距。默认可换行，`tagWrap={false}` 保持单行并以 `+N` 折叠超出部分；长标签自动省略，搜索框和操作按钮始终保留空间。折叠只影响展示，不改变已选值。

按钮不展示点击波纹或鼠标操作的主题色光圈。按钮默认使用描边外观；主按钮按下加深，链接按钮按下时加深文字，所有按钮悬停保持静止外观。描边按钮带有一层轻微静止阴影，按下时仅将边框加深为 `primary-active`，危险外观使用可读的危险文字色，边框从危险基色加深为 `danger-active`，文字、背景和阴影保持不变。键盘聚焦保留中性轮廓。菜单和标签页通过颜色、透明度、边框和阴影反馈，选中指示器可以移动到目标项。抽屉平滑滑入；提示内容整体出现，图标和文字不单独回弹。系统减少动态效果偏好优先于区域动效设置。

层级由圆角、边框和文字共同建立。圆角由外向内递减：弹窗、抽屉和浮层使用大圆角，卡片、提示与选项卡片等内容表面使用中圆角，按钮、输入框和表格外框使用基础圆角，复选框等小元素和状态标签使用小圆角。内容表面依靠细边框和浅灰底区分；Card 与 Table 额外使用最轻的静态阴影，阴影整体向下偏移，其他内容表面不叠加阴影，更明显的阴影只留给真正浮起的层，例如浮层、弹窗、拖动中的项目和滑块把手。Card 与 Table 的外框，以及 Card 的内部划分线使用减淡的分隔线颜色（70% 分隔线混入表面色），比独立分隔线更轻。文字层级依靠字号、行高与颜色：正文 14px / 20px、辅助文字 13px / 18px、大号文字 16px / 22px，Card 标题和文档标题使用 600 字重，其他组件标题、标签和按钮使用 500 字重；选项分组等小标题最小 12px，使用加字距的灰色样式。

默认几何沿用整像素网格：正文、辅助文字和大号文字的行盒分别为 20 / 18 / 22px，28 / 34 / 40px 的控件、Card 标题行盒（18 / 20 / 22px）、浮层选项行与步骤条指示器都使用整像素；步骤条指示器至少为 24px，大尺寸为 28px。显式使用小数 token、自定义字号、相对宽度或 SVG 内部坐标时仍可能出现小数，不应为此裁切或强行取整业务内容。

紧贴容器的内部背景采用嵌套圆角：`内部圆角 = max(0px, 外框圆角 − 内边距 − 边框厚度)`。默认浮层的外框为 16px、内边距为 6px、边框为 1px，因此选项为 9px。悬停、选中和移动高亮背景使用同一轮廓，并随主题自动更新；非等距留白按各方向计算，多层结构计入额外留白。小圆角和直角主题收敛到 0，独立控件、日历格子、标签和图标继续使用各自的语义圆角。

Menu 仅提供垂直布局，布局与键盘语义独立于外观。`variant` 支持 `default`、`raised`、`primary`；三种外观分别提供完整的状态配色、边框、阴影及进退场时长，内嵌菜单和导航浮层共用状态绘制逻辑，不通过事后覆盖默认选中样式实现。`default` 保留 8% 黑色的中性悬停、按下与选中背景，未选中文字以 80% 正文色混合区域表面色，选中使用完整正文色。`raised` 使用柔和画布，选中项为主题表面色、1px 中性边框和 `0 2px 3px -1px rgb(0 0 0 / 0.08)` 阴影，通过 `inset(0 0 -4px)` 裁切仅向下溢出；悬停只加深正文色，按下使用 4% 黑色。`primary` 选中使用可读的主题文字色 `primary-ink` 与 10% 主题色背景，悬停只将文字与图标变为相同主题色，按下使用 4% 主题色，不附加边框或阴影。后两种外观进入采用标准时长的 1.2 倍（默认 240ms），旧选中项立即清除，不残留灰底退场。所有外观的危险项保留语义色，禁用项不响应交互，键盘焦点保留轮廓；系统减少动态效果、区域关闭动效与强制颜色模式保持有效。只有当前页面被选中，祖先不跟随高亮。菜单项圆角为基础圆角减 2px（默认 8px），浮层外框为基础圆角；一级行高为控件高度加 2px（默认 36 / 32px），子级为选项行高（30 / 26px），图标为 20px 区域中的 16px 图形，图文间距 12px。内嵌子菜单与竖线之间保留 8px，文字保持对齐；文字、图标和行位置不随背景动画移动，子菜单展开与浮层保留共享动效。

Pagination 默认使用描边按钮，也可切换为无边框样式；尺寸沿用控件高度，按下时保持位置与大小，选中背景平滑移动。描边按钮按下时仅加深边框，文字和背景保持不变；无边框按钮使用中性背景。

卡片标签使用无外层容器的浅灰圆角选中底，选项间距为 4px，未选中文字更淡，尺寸为 28 / 34 / 40px。分段标签使用浅灰圆角外轨、3px 内边距与间距，以及带轻阴影的白色移动滑块；内层标签和滑块圆角由外轨圆角减去实际留白和边框派生，最小为零。线形标签仅在选中项下方显示短圆角指示条。标签栏随内容收缩，正文仍使用可用宽度；`block` 让选项等宽，省略面板内容可只显示标签栏。按下保持尺寸不变，选中指示器可移动到新的选项。

Tag 仅提供无边框的浅底和实色形态，圆角使用主题小圆角，默认 6px；组件级圆角配置优先。标签字号最小为 12px，字重固定为 500，不再提供字重参数。未指定颜色时使用主题色，`default` 作为兼容别名同样映射到主题色。浅底形态的文字跟随标签自身颜色，警告色使用派生的可读警告文字色；实色形态使用白色文字，警告色使用 `--leaf-color-on-warning` 对比色。CheckableTag 与 TagGroup 未选中时使用浅底主题色，选中时使用实色主题色。默认浅色外观的危险基色为 `rgb(221, 63, 46)`，由全局 `--leaf-color-danger` token 提供并被所有危险语义组件共用。

组件验收要覆盖默认、悬停、按下、键盘焦点、选中、禁用、加载、错误、空状态。状态同时用文字或 ARIA 表达，不能只依靠颜色。图标按钮需要可访问名称；图标与文本的基线、弹窗表单与页脚边缘需要对齐。

紧凑模式面向鼠标和键盘的信息密集页面，不缩小正文字号。触屏优先舒适或更大的显式尺寸；必要操作目标至少 24px，推荐 44px。尺寸覆盖的顺序是局部组件设置、显式主题尺寸、区域密度、默认值。

按钮的横向留白随实际高度按比例生成，各尺寸都可以用组件级 `padding` 定制。小尺寸步骤条保留正文字号，卡片和列表形式的选项组使用统一的分区标题。Card 标题区域的上下留白一致，与正文衔接时不重复叠加间距。Modal 默认使用浅色为 `#f9f9f9` 的柔和画布和留白分区，标题与 footer 使用相同的左右间距，默认取消按钮使用描边外观；`divided` 可启用浅分隔线与浅底页脚。`variant="card"` 沿用同一画布，将正文放入距离 Modal 外框 6px、无边框的内容卡；标题使用 14px、标题字重和 22px 行高，并与内容文字起始边缘对齐；关闭按钮向内容卡右边缘内收 8px，底部操作区与内容卡对齐，组件级横向 `padding` 变化时仍保持正文内边距关系。24px 关闭按钮内的 16px 图标使用正文色，背景默认透明，悬停时显示更深一级的中性背景，并使用小圆角（默认 6px）。标题区使用 12px 顶部留白，标题区与内容卡之间使用 12px 的区域间距；内容卡到按钮的实际距离为 10px，footer 不再叠加顶部内边距，按钮到底边的留白为 10px，标题文字在文字列内向下偏移 2px；正文内边距独立控制内容与内容卡边缘的距离。日期与时间选择器通过 `panelVariant="card"` 复用这一层级。弹窗遮罩使用柔和底色与背景虚化，可通过 ConfigProvider 的 `maskBlur={false}` 关闭虚化。Confirm 是通过 API 调用的简短提示，使用留白分区，图标放在正文旁。没有副标题时减少头部留白，分区 Modal 和 Drawer 的底部操作区使用一致的紧凑留白；Confirm 沿用相同的底部留白。

完整日历采用编辑式无边框网格：大号本地化月份作为标题，年份以轻量副标题跟随，今天与成组翻页按钮位于尾端。日期、月份、年份视图分别使用开放的 7 列、4 列和 3 列布局，日期格不绘制独立边框。选中日期使用整格淡主题色背景，并以实心圆形标签标记数字；今天使用主题色数字和小圆点，不增加描边。`cellRender` 内容位于数字下方并单行省略。紧凑日历保留 32px 无边框日期网格，日期浮层继续使用原有紧凑面板结构。

步骤条的文字背景保持透明，横向连线排在文字之后。头像只保留一圈 2px 白色边缘，组合头像也不叠加外圈阴影。DataTable 默认开启斑马纹，并始终展示基础圆角的外框、与表格一致的表面、表头下方的 1px 分割线，以及与 Card 一致的减淡外框和向下偏移静止阴影。`bordered` 只增加列分隔线，表头文字使用略淡于正文的正文色。斑马纹将 2% 表格文字色混入当前表面并隐藏行间线，`striped={false}` 恢复行间细线。悬停时普通行和条纹行统一使用 3% 主色与表格表面的不透明混合背景，选中行使用主题浅色背景，并优先于悬停样式。固定列阴影在滚动到对应逻辑边界后隐藏。

链接按钮无背景、边框、内边距和固定控件高度，悬停不变，按下只改变文字颜色，不展示波纹。页面跳转使用 Link；Button 的链接样式用于文字操作。
