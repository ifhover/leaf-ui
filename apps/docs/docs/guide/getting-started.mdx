# 安装&快速开始

Leaf UI 的 React 组件包名为 `@sudden3/leaf-ui`，支持 React 18 与 React 19。安装组件包并引入样式后，就可以在 React 页面中使用。

## 安装组件包

在你的 React 项目目录下执行：

```bash
pnpm add @sudden3/leaf-ui
```

也可以使用 npm 或 Yarn：

```bash
npm install @sudden3/leaf-ui
# 或者
yarn add @sudden3/leaf-ui
```

React 和 React DOM 由你的应用提供。如果项目尚未安装，请先执行 `pnpm add react react-dom`。可在 [npm](https://www.npmjs.com/package/@sudden3/leaf-ui) 查看最新版本。

## 引入样式

在应用入口导入一次 Leaf UI 样式：

```tsx title="src/main.tsx"
import '@sudden3/leaf-ui/styles.css';
```

样式已编译为 CSS，使用组件无需安装 Sass。调整颜色、圆角或尺寸时使用 [ConfigProvider](/components/config-provider)，业务 CSS 可以读取主题变量复用样式。Next.js 等框架的入口配置见 [SSR 使用](/guide/ssr)。

## 使用原生属性

组件保留原生 `button` 属性，例如 `onClick`、`disabled`、`type`、`className` 和 `aria-*`。

```tsx
<Button type="submit" disabled={submitting}>
  提交表单
</Button>
```

`Button` 的默认类型为 `button`。在表单中提交数据时，请显式设置 `type="submit"`。

## 换一种颜色

在应用或需要定制的区域外包裹 ConfigProvider：

```tsx
import { Button, ConfigProvider } from '@sudden3/leaf-ui';

<ConfigProvider theme={{ primaryColor: '#3264d9', borderRadius: 6 }}>
  <Button>保存</Button>
</ConfigProvider>
```

更多配置与样式复用见[定制主题](/guide/theming)。使用 Next.js 等框架时，可阅读 [SSR 使用](/guide/ssr)。

## 添加图标

在自己的应用代码中导入 Lucide 图标时，执行 `pnpm add lucide-react` 将它声明为应用依赖。具体示例见[使用图标](/guide/icons)。

## 兼容性

- React 18 / 19。
- TypeScript 项目可以直接使用随包提供的类型声明。
- 提供 ESM 和 CommonJS 模块入口。
- 样式面向支持 CSS 变量和 `color-mix()` 的现代浏览器。
