# 安装&快速开始

Leaf UI 支持 React 18 与 React 19。安装后即可在 React 页面中使用，基础样式与组件样式会自动加载。

## 安装组件包

在你的 React 项目目录下执行：

<PackageInstall>

```bash
npm install @ifhover/leaf-ui
```

```bash
yarn add @ifhover/leaf-ui
```

```bash
pnpm add @ifhover/leaf-ui
```

```bash
bun add @ifhover/leaf-ui
```

</PackageInstall>

React 和 React DOM 由你的应用提供。如果项目尚未安装，请先执行 `pnpm add react react-dom`。可在 [npm](https://www.npmjs.com/package/@ifhover/leaf-ui) 查看最新版本。

浏览器打包时，组件入口会自动加载主题变量、公共样式与所需的组件和服务样式，无需手动导入 CSS 或安装 Sass。Next.js、TanStack Start 等框架的额外配置见[服务端渲染](/guide/ssr)。

示例通过 Flex、Space、Grid 和 FormField 组织布局，无需安装 Tailwind CSS。

直接从 `@ifhover/leaf-ui` 导入组件，添加内容和事件即可：

根入口是推荐的默认写法。在 Vite、Rsbuild / Rspack 的生产构建中，具名导入会按需保留组件及其内部依赖的样式，无需改用组件子路径。直接使用 esbuild 打包时，它会保留根入口遍历到的 CSS；此时可使用 `@ifhover/leaf-ui/button` 等子路径缩小样式体积。
