## 使用原生属性

组件保留原生 `button` 属性，例如 `onClick`、`disabled`、`type`、`className` 和 `aria-*`。

```tsx
<Button type="submit" disabled={submitting}>
  提交表单
</Button>
```

`Button` 的默认类型为 `button`。在表单中提交数据时，请显式设置 `type="submit"`。

## 换一种颜色

在应用或需要定制的区域外包裹 ConfigProvider：

```tsx
import { Button, ConfigProvider } from '@sudden3/leaf-ui';

<ConfigProvider theme={{ primaryColor: '#3264d9', borderRadius: 6 }}>
  <Button>保存</Button>
</ConfigProvider>
```

更多配置与样式复用见[定制主题](/guide/theming)。使用 Next.js 等框架时，可阅读 [SSR 使用](/guide/ssr)。
