# 安装&快速开始

Leaf UI 支持 React 18 与 React 19。安装组件包并引入样式后，就可以在 React 页面中使用。

## 安装组件包

在你的 React 项目目录下执行：

```bash
pnpm add @ifhover/leaf-ui
```

也可以使用 npm 或 Yarn：

```bash
npm install @ifhover/leaf-ui
# 或者
yarn add @ifhover/leaf-ui
```

React 和 React DOM 由你的应用提供。如果项目尚未安装，请先执行 `pnpm add react react-dom`。可在 [npm](https://www.npmjs.com/package/@ifhover/leaf-ui) 查看最新版本。

## 引入样式

在应用入口导入一次基础样式，包含主题变量、公共浮层和 Confirm、Message 等 API 服务的样式：

```tsx title="src/main.tsx"
import '@ifhover/leaf-ui/styles.css';
```

浏览器打包时，组件入口会自动加载组件样式，无需再手动导入每个组件的 CSS，也无需安装 Sass。Next.js 等框架的配置见 [SSR 使用](/guide/ssr)。
