# 认识 Leaf UI

Leaf UI 是一个轻盈、自然、可定制的 React 组件库。以绿色为起点，让组件融入你的产品，也保留你的个性。

## 轻盈自然

克制的色彩、舒适的圆角和清晰的交互状态，让内容成为主角。你可以直接使用默认的绿色主题，也可以调整主题色，让组件与品牌保持一致。

## 可定制

颜色、圆角、字体与动效均由 CSS 变量控制。变量可以全局设置，也可以放在局部容器上，同一页面能同时使用多套主题。

## 熟悉的使用方式

组件支持 React 18 / 19，提供 TypeScript 类型，保留原生 HTML 属性与 DOM ref。你可以沿用 React 中处理事件、表单与状态的方式。

## 照顾每一次交互

组件包含键盘焦点、禁用与加载状态，并响应减少动态效果的系统偏好。只有图标的按钮需要设置 `aria-label`，为辅助技术提供清晰的名称。
