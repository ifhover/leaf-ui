# 定制主题

通过 [ConfigProvider](/components/config-provider) 设置组件的主题。通常只需调整主题色、基础圆角和控件高度，其余样式会自动配合。

## 从几个设置开始

在应用最外层放置 ConfigProvider，并引入一次组件样式：

```tsx
import { Button, ConfigProvider, Input } from '@sudden3/leaf-ui';
import '@sudden3/leaf-ui/styles.css';

export function App() {
  return (
    <ConfigProvider theme={{
      primaryColor: '#7654c6',
      borderRadius: 8,
      controlHeight: 34,
    }}>
      <Input aria-label="项目名称" placeholder="项目名称" />
      <Button>保存</Button>
    </ConfigProvider>
  );
}
```

未传入的选项使用默认值。悬停、按下、浅色背景和焦点颜色会跟随主题色，不需要分别配置。

## 试试你的风格

## 自动生成大小尺寸

默认基础圆角为 10px，单行控件高度为 34px，字号为 14px。修改基础值后，其他尺寸会同步调整：

| 基础设置 | 自动生成的值 | 默认结果 |
| --- | --- | --- |
| `borderRadius` | 小圆角为基础值的 0.6 倍，大圆角为 1.6 倍 | `6px / 16px` |
| `controlHeight` | 小尺寸减 6px，大尺寸加 6px | `28px / 40px` |
| `fontSize` | 小字号减 2px，大字号加 2px | `12px / 16px` |

数字表示像素，也可以传入带单位的 CSS 长度。按钮、输入框和选择器共用这套尺寸，放在一起时保持一致。

## 局部主题与嵌套

ConfigProvider 可以包裹整个应用，也可以只包裹一个区域。内层只覆盖明确设置的选项：

```tsx
<ConfigProvider theme={{ primaryColor: '#20834a', controlHeight: 36 }}>
  <Button>默认区域</Button>
  <ConfigProvider theme={{ primaryColor: '#7654c6', borderRadius: 16 }}>
    <Button>活动区域</Button>
  </ConfigProvider>
</ConfigProvider>
```

浮层、Modal、确认框与消息会继承调用区域的主题。ConfigProvider 自动托管确认框和消息，子组件通过 useConfirm 和 useMessage 调用。语言通过 ConfigProvider 的 `locale` 单独设置。

## 深色外观与动态切换

使用 `appearance` 切换浅色与深色；主题是普通 React 属性，可以用状态动态更新：

```tsx
import { useState } from 'react';
import { Button, ConfigProvider } from '@sudden3/leaf-ui';

export function ThemeSwitch() {
  const [dark, setDark] = useState(false);
  return (
    <ConfigProvider theme={{ appearance: dark ? 'dark' : 'light' }}>
      <Button onClick={() => setDark(!dark)}>切换外观</Button>
    </ConfigProvider>
  );
}
```

深色外观会提供适合深色表面的文字、边框和状态色。显式设置的主题色保留原值；很浅的品牌色可以在高级配置中搭配 `onPrimaryColor`。

## 有特殊需求时再覆盖

`theme.tokens` 可以单独调整自动生成的尺寸、语义色、表面色、文字色、动效或浮层层级：

```tsx
import type { LeafTheme } from '@sudden3/leaf-ui';

const theme: LeafTheme = {
  controlHeight: 36,
  borderRadius: 8,
  tokens: {
    controlHeightSm: 28,
    borderRadiusLg: 18,
    infoColor: '#1677ff',
    motionDuration: 200,
  },
};
```

手动设置的小 / 大尺寸优先于自动生成的值。嵌套配置按字段合并，包括 tokens；未覆盖的配置继续继承。完整选项见 [LeafThemeTokens](/components/config-provider#leafthemetokens)。

`motion: false` 关闭过渡并暂停加载图标的旋转。系统的“减少动态效果”偏好仍会生效。

## 在自己的组件中复用样式

CSS 变量用于读取当前区域的主题，方便自己编写的组件与 Leaf UI 保持一致。调整库组件的主题时使用 ConfigProvider；在业务 CSS 中通过 `var()` 消费这些变量：

```tsx
<ConfigProvider theme={{ primaryColor: '#7654c6', borderRadius: 8 }}>
  <button className="product-button" type="button">自己的按钮</button>
  <Button>Leaf UI 按钮</Button>
</ConfigProvider>
```

```scss
.product-button {
  min-height: var(--leaf-control-height);
  padding: 0 14px;
  border: 0;
  border-radius: var(--leaf-radius);
  background: var(--leaf-color-primary);
  color: var(--leaf-color-on-primary);
  font-family: var(--leaf-font-family);
  font-size: var(--leaf-font-size);
  font-weight: var(--leaf-font-weight);
  cursor: pointer;
}
```

| 可读取的变量 | 用途 |
| --- | --- |
| `--leaf-color-primary` / `--leaf-color-on-primary` | 主题背景与其上的文字 |
| `--leaf-color-danger` / `--leaf-color-success` / `--leaf-color-warning` / `--leaf-color-info` | 语义状态色 |
| `--leaf-color-text` / `--leaf-color-text-muted` | 主要 / 次要文字 |
| `--leaf-color-surface` / `--leaf-color-surface-muted` / `--leaf-color-border` | 表面与边框 |
| `--leaf-radius` / `--leaf-radius-sm` / `--leaf-radius-lg` | 基础 / 小 / 大圆角 |
| `--leaf-control-height` / `--leaf-control-height-sm` / `--leaf-control-height-lg` | 基础 / 小 / 大控件高度 |
| `--leaf-font-family` / `--leaf-font-size` / `--leaf-font-weight` | 字体、字号与字重 |
| `--leaf-motion-duration` / `--leaf-motion-easing` | 状态过渡 |

业务组件需要位于相应的 ConfigProvider 区域内，才能读取该区域的主题。使用者只需引入编译好的 `styles.css`，无需安装 Sass。

## 服务端渲染

静态 CSS 与动态主题可以一起使用，不需要运行时生成 CSS。Next.js 与其他 SSR 框架的接入方法见 [SSR 使用](/guide/ssr)。

## 间距、字体与组件覆盖

基础 `spacing` 会生成小、大间距，`lineHeight`、`headingWeight` 和 `elevation` 分别调整正文行高、标题字重和阴影。继续通过 ConfigProvider 配置；组件专属覆盖放在 `theme.components`：

```tsx
const theme = {
  spacing: 8,
  lineHeight: 1.6,
  headingWeight: 600,
  elevation: 'soft',
  components: {
    Button: { borderRadius: 6, padding: '0 18px' },
    Input: { borderRadius: 6, controlHeight: 36 },
    Card: { padding: 16, shadow: '0 6px 20px #0001' },
  },
} satisfies LeafTheme;
```

组件名使用导出的名称。覆盖只作用于该区域中对应组件；每类组件使用与其布局相关的 token：输入组件支持圆角、高度、背景、字号，容器支持内边距和阴影，排列组件支持间距。通过组件本身的 `className` / `style` 与浮层的 `popupClassName` / `popupStyle` 可进一步定制。

## 系统外观、响应断点与对比度

```tsx
import { ConfigProvider, colorContrast, useBreakpoint, useSystemAppearance } from '@sudden3/leaf-ui';

function Application() {
  const appearance = useSystemAppearance('light');
  return <ConfigProvider theme={{ appearance, breakpoints: { md: 800 } }}><Content /></ConfigProvider>;
}
function Content() {
  const { md } = useBreakpoint({ md: false });
  return <p>{md ? '宽屏布局' : '紧凑布局'}</p>;
}
const contrast = colorContrast('#ffffff', '#20834a');
```

`useBreakpoint` 按当前区域的断点生成布尔值，可用于业务布局。Grid 的现有 `sm/md/lg` CSS 响应规则仍使用组件文档中的固定断点。`colorContrast` 返回 WCAG 对比度比值，无法解析颜色时返回 `null`；透明颜色会先与背景和可选第三参数的底色合成。普通文字建议至少 4.5，较大文字至少 3。

系统偏好在客户端接管后更新；SSR 的首次外观应来自服务端 Cookie 或一致的初始值，见 [SSR 使用](/guide/ssr)。

## LeafComponentTokens

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `borderRadius` | `string \| number` | — | 圆角；数字表示像素。 |
| `controlHeight` | `string \| number` | — | 基础控件高度；其他尺寸由此生成。 |
| `padding` | `string \| number` | — | 内容或高亮目标的内边距。 |
| `gap` | `string \| number` | — | 子项之间的间距；数字表示像素。 |
| `fontSize` | `string \| number` | — | 字号；数字表示像素。 |
| `color` | `string` | — | 颜色或语义色。 |
| `background` | `string` | — | 组件表面背景。 |
| `shadow` | `string` | — | CSS box-shadow 的值。 |

## LeafThemeStyle

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `` [key: `--leaf-${string}`] `` | `string \| number \| undefined` | — | 可复用的 CSS 自定义属性。 |
