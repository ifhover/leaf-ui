# 颜色

Leaf UI 使用语义变量组织颜色。默认主题提供 <PaletteVariableCount /> 个调色板变量；下面先展示核心语义色和常用角色，完整变量在页末折叠。

## 核心语义色

主题、成功、危险、警告和信息色表达含义，实色背景上的前景色保持独立入口。`-ink` 变量用于可读文字，`on-*` 变量用于实色背景上的内容。每张色卡左侧是浅色，右侧是深色。

## 配置颜色

通过 ConfigProvider 设置主题色，单个语义色使用 `theme.tokens`。业务 CSS 读取生成后的 `--leaf-color-*` 变量。

```tsx
<ConfigProvider theme={{ primaryColor: brandColor }}>
  <App />
</ConfigProvider>
```

`primary-soft` 系列没有默认值；需要时通过 `theme.tokens.primarySoftColor` 等字段显式设置。只覆盖基础 CSS 变量不会重新生成派生色。完整字段见 [ConfigProvider](/components/config-provider)、[LeafThemeTokens](/api/theme-tokens#leafthemetokens) 和[定制主题](/guide/theming)。
