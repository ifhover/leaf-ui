# Tailwind CSS

在 Tailwind 中复用 Leaf UI 的颜色、圆角和间距。

## 快速接入

在已安装 Tailwind 的项目中，按版本选择下面的配置。支持 3.x 和 4.x，2.x 及更早版本请先升级。

### Tailwind CSS 4

在 CSS 入口增加一行导入即可：

```css title="app.css"
@import 'tailwindcss';
@import '@ifhover/leaf-ui/tailwind.css';
```

<DocsCollapse title="沿用项目的基础样式">

如果不需要 Tailwind 的 Preflight 重置样式，改用下面的入口：

```css title="app.css"
@layer theme, base, components, utilities;
@import 'tailwindcss/theme.css' layer(theme);
@import 'tailwindcss/utilities.css' layer(utilities);
@import '@ifhover/leaf-ui/tailwind.css';
```

</DocsCollapse>

### Tailwind CSS 3

在配置中加入 preset，`content` 按项目目录调整：

```js title="tailwind.config.cjs"
const leafPreset = require('@ifhover/leaf-ui/tailwind').default;

module.exports = {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  presets: [leafPreset],
};
```

CSS 入口保持 Tailwind 3 的写法：

```css title="app.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

已有配置只需追加 preset，保留自己的扫描目录和插件。

<DocsCollapse title="使用 TypeScript 配置（3.3+）">

```ts title="tailwind.config.ts"
import type { Config } from 'tailwindcss';
import leafPreset from '@ifhover/leaf-ui/tailwind';

export default {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  presets: [leafPreset],
} satisfies Config;
```

需要关闭 Preflight 时，在配置中添加 `corePlugins: { preflight: false }`。

</DocsCollapse>

## 使用提示

- **透明度**：Tailwind 4 支持 `bg-leaf-primary/50`；Tailwind 3 不支持这些颜色的 `/50`、`bg-opacity-*` 或 `text-opacity-*`，半透明色需在业务 CSS 中定义。
- **源码扫描**：写完整类名，如 `bg-leaf-primary`，不要拼接 `bg-leaf-${color}`。
- **基础样式**：没有导入 Leaf UI 组件的纯 CSS 页面，还需引入 `@ifhover/leaf-ui/styles.css`。
- **响应式断点**：`sm:`、`md:` 使用项目的 Tailwind 配置，不随 ConfigProvider 的断点变化。Tailwind 4 的浏览器要求以其官方支持范围为准。
- **区域与浮层**：自定义 Portal 内容也需放在对应主题区域。Leaf UI 自带浮层会自动同步主题；组件专用变量通过 [ConfigProvider](/guide/theming) 调整。
