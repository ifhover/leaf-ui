## API

### VirtualListProps API

配置虚拟列表的数据、尺寸和条目渲染方式。

```ts
import type { VirtualListProps } from '@ifhover/leaf-ui';
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly T[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `itemKey` | `(item: T, index: number) => Key` | 必填 | 提取稳定的项目标识 |
| `renderItem` | `(item: T, index: number) => ReactNode` | 必填 | 自定义项目内容 |
| `height` | `number` | `320` | 高度，数字按像素计算 |
| `estimateSize` | `number \| ((item: T, index: number) => number)` | `40` | 预估项目尺寸，挂载后测量实际尺寸 |
| `overscan` | `number` | `5` | 可见区域外预渲染数量 |
| `horizontal` | `boolean` | `false` | 横向虚拟列表 |
| `emptyContent` | `ReactNode` | — | 空列表内容 |

### VirtualListHandle API

通过引用滚动到指定条目或位置。

```ts
import type { VirtualListHandle } from '@ifhover/leaf-ui';
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `element` | `HTMLDivElement \| null` | 必填 | 滚动容器元素 |
| `scrollToIndex` | `(index: number, align?: 'auto' \| 'start' \| 'center' \| 'end') => void` | 必填 | 滚动至项目 |
| `scrollToOffset` | `(offset: number) => void` | 必填 | 滚动至偏移量 |
