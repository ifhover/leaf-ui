控制元素的排列方向、对齐与换行。只需统一间距时使用 [Space](/components/space)，等宽分列使用 [Grid](/components/grid)。

## API

### Flex API

支持原生 `div` 属性和 DOM ref；显式 `style` 优先于布局属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `'row' \| 'row-reverse' \| 'column' \| 'column-reverse'` | `'row'` | 排列方向。反向排列不改变 DOM 阅读与键盘顺序。 |
| `gap` | `number \| string \| readonly [number \| string, number \| string]` | `0` | 间距；数字为 px，支持 CSS 长度和 `sm` / `md` / `lg` 主题间距。数组为 [行间距, 列间距]。 |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'stretch'` | 交叉轴对齐。 |
| `justify` | `'start' \| 'center' \| 'end' \| 'space-between' \| 'space-around' \| 'space-evenly'` | `'start'` | 主轴对齐。 |
| `wrap` | `boolean \| 'nowrap' \| 'wrap' \| 'wrap-reverse'` | `false` | 是否换行或具体换行方向。 |
| `inline` | `boolean` | `false` | 使用行内弹性布局。 |
