# LoadingBar 顶部加载条

在视口边缘展示页面或任务的加载进度。

{/* leaf:section basic */}

## 基础用法

在 [ConfigProvider](/components/config-provider) 的子组件中调用 `useLoadingBar()`，已有上下文时无需重复包裹。需要独立加载条时使用 `LoadingBarProvider`；嵌套 ConfigProvider 仍复用现有加载条。

`start()` 返回当前任务的完成函数，无论请求成功还是失败，都应在 `finally` 中调用。多个任务并发时，全部完成后加载条才会收起。

`reset()` 会清空当前 Provider 中的全部任务，不只影响调用组件。结束单个任务时应使用 `start()` 返回的函数；取消请求或卸载时的任务清理也应如此。

## 示例

### 手动控制进度

已知百分比时，可直接使用 `LoadingBar` 的 `active` 和 `progress`。进度范围为 0 到 100，任务结束后将 `active` 设为 `false`。加载条不会自动启动或停止实际任务。

## API

### LoadingBarProps API

加载状态、进度及条形指示器展示位置的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | 正在加载 |
| `progress` | `number` | — | 进度 0–100，省略时自动估计 |
| `color` | `string` | — | 颜色 |
| `height` | `number` | `3` | 高度，数字按像素计算 |
| `position` | `'top' \| 'bottom'` | `'top'` | 显示或插入位置 |
| `className` | `string` | — | 容器类名 |
| `style` | `CSSProperties` | — | 容器内联样式 |

### LoadingBarApi API

`useLoadingBar` 返回的任务计数与进度控制接口。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `start` | `() => () => void` | 必填 | 开始任务，返回仅完成该任务的函数；应在 finally 或取消清理时调用。 |
| `finish` | `() => void` | 必填 | 完成最早的一个待完成任务，全部任务完成后收起；优先使用 start 返回的函数。 |
| `set` | `(progress: number) => void` | 必填 | 设置显示进度，范围 0–100；不启动或完成任务。 |
| `reset` | `() => void` | 必填 | 清空当前 Provider 的全部任务与进度，不取消实际请求。 |

### LoadingBarProviderProps API

独立加载条上下文的容器与展示参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | `string` | — | 颜色 |
| `height` | `number` | `3` | 高度，数字按像素计算 |
| `position` | `'top' \| 'bottom'` | `'top'` | 显示或插入位置 |
| `className` | `string` | — | 容器类名 |
| `style` | `CSSProperties` | — | 容器内联样式 |
| `children` | `ReactNode` | — | 共享此加载条任务作用域的子内容。 |
