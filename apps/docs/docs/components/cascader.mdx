# Cascader 级联选择

逐级选择地区、分类等有层级关系的选项。

{/* leaf:section basic */}

## 基础用法

<a id="基础选择"></a>

`children` 定义子选项。展开父项后选择末级选项，确认完整路径；`disabled` 禁用整个分支。

## 示例

### 受控路径

`value` 是从根节点到选中节点的值数组，`onChange` 同时返回完整的选项对象路径。清除时，两者都为空数组。展开父项只改变待选路径；返回已提交路径所属的一级分支时，会恢复下级选择。

### 异步加载

为尚无 `children` 的节点设置 `isLeaf={false}`，展开时由 `loadData` 返回子选项。保持 `options` 和 `loadData` 的引用稳定，节点值在整棵树中唯一。

请求应响应 `AbortSignal`：更换选项、加载函数、`cacheKey` 或卸载时会取消旧请求，关闭浮层不会取消。通过 `onLoadError` 提供失败反馈，再次展开节点可重试。

</ComponentExample>

## API

### Cascader API

其余原生 `button` 属性和 `aria-*` 透传至触发按钮；`className` / `style` 作用于外层容器。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | 必填 | 层级选项列表 |
| `value` | `readonly string[] \| readonly (readonly string[])[]` | — | 受控路径；省略时使用内部非受控值。 |
| `defaultValue` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | 非受控模式的初始路径；支持表单重置。 |
| `onChange` | `((value: string[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => void) \| ((value: string[][], selectedOptions: `[`CascaderOption`](#cascaderoption)`[][]) => void)` | — | 单选返回路径和对应选项，多选返回路径数组和对应选项数组；选择、取消或清除时触发，清除的两参数均为空数组。 |
| `multiple` | `false \| true` | `false` | 启用多选；value 和回调的类型随之变化。 |
| `placeholder` | `string` | `'请选择'` | 未选择时的提示文字 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 选择器尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | — | 锁定业务值，禁止输入、选择、清除和删除。 |
| `allowClear` | `boolean` | `true` | 清除后返回两个空数组 |
| `showSearch` | `boolean` | — | 启用搜索输入。 |
| `changeOnSelect` | `boolean` | — | 允许选择中间层级。 |
| `tagWrap` | `boolean` | `true` | 允许多选标签换行；false 单行显示并自动折叠溢出项。 |
| `maxTagCount` | `number \| 'responsive'` | — | 最多展示的标签数；responsive 根据可用宽度自动折叠。 |
| `displayRender` | `(labels: ReactNode[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => ReactNode` | — | 自定义每条已选路径的显示内容，参数为该路径的标签和选项。 |
| `optionRender` | `(option: `[`CascaderOption`](#cascaderoption)`) => ReactNode` | — | 自定义选项内容。 |
| `loadData` | `(option: `[`CascaderOption`](#cascaderoption)`, signal: AbortSignal) => Promise<readonly `[`CascaderOption`](#cascaderoption)`[]>` | — | 展开 isLeaf 为 false 且未提供 children 的节点时请求子项；使用 signal 处理取消。 |
| `onLoadError` | `(error: unknown, option: `[`CascaderOption`](#cascaderoption)`) => void` | — | 加载失败时调用，可展示重试提示。 |
| `cacheKey` | `string \| number` | — | 数据版本改变时清空懒加载缓存，并取消旧请求。 |
| `open` | `boolean` | — | 受控的展开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控模式的初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `name` | `string` | — | 原生 FormData 的字段名；非空值提交 JSON 路径，空值提交空字符串。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `ref` | `Ref<HTMLButtonElement>` | — | 触发按钮引用 |

### CascaderOption

级联选项的数据结构，子选项通过 `children` 组织。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 选项值；静态数据同层唯一，异步加载的节点须全树唯一以区分缓存。 |
| `label` | `ReactNode` | 必填 | 选项的显示内容。 |
| `searchLabel` | `string` | — | 复杂 label 的搜索纯文本。 |
| `isLeaf` | `boolean` | — | 明确指定是否为叶子节点；配合懒加载使用。 |
| `disabled` | `boolean` | `false` | 禁用该选项及其所有子级。 |
| `children` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | — | 子选项列表。 |

### CascaderFieldNames

通过 `mapCascaderOptions(records, fields)` 将业务数据转换为 `CascaderOption[]`，再传给 `options`。`CascaderFieldNames` 描述映射字段，不是 `Cascader` 的属性。

```ts
import { mapCascaderOptions } from '@ifhover/leaf-ui';

const records = [{ id: 'design', name: '设计', nodes: [{ id: 'interface', name: '界面设计' }] }];
const options = mapCascaderOptions(records, {
  value: 'id',
  label: 'name',
  children: 'nodes',
});
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | 选项值在业务对象中的字段名。 |
| `label` | `string` | — | 显示文字在业务对象中的字段名。 |
| `children` | `string` | — | 子节点数组在业务对象中的字段名。 |
| `disabled` | `string` | — | 禁用状态在业务对象中的字段名。 |
| `isLeaf` | `string` | — | 叶子标记在业务对象中的字段名。 |
