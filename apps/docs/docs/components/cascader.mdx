# Cascader 级联选择

用于逐级选择地区、分类等有层级关系的选项。切换一级选项时会立即更新下一级内容，不使用淡入或位移动画；切换到其他分支只清除尚未确认的后续选择，返回已选分支时会恢复其已提交的完整路径。

## 基础选择

`children` 定义子选项。点击父项展开下一列，点击末级选项确认完整路径；`disabled` 可以禁用一个分支。

## 受控路径

`value` 是从根节点到末级节点的 value 数组，`onChange` 同时提供完整的选项对象路径。切换父项会清除尚未确认的后续选择；返回已提交路径所属的一级分支时，下级选择会恢复。

## Cascader API
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `options` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | 必填 | 层级选项列表 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 选择器尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `placeholder` | `string` | `'请选择'` | 未选择时的提示文字 |
| `name` | `string` | — | 字段名 / 关联的表单 ID |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `allowClear` | `boolean` | `true` | 清除后返回两个空数组 |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | — | 面板初始展开状态。 |
| `readOnly` | `boolean` | — | 锁定业务值，禁止输入、选择、清除和删除。 |
| `showSearch` | `boolean` | — | 启用搜索输入。 |
| `changeOnSelect` | `boolean` | — | 允许选择中间层级。 |
| `displayRender` | `(labels: ReactNode[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => ReactNode` | — | 自定义路径的显示内容。 |
| `optionRender` | `(option: `[`CascaderOption`](#cascaderoption)`) => ReactNode` | — | 自定义选项内容。 |
| `loadData` | `(option: `[`CascaderOption`](#cascaderoption)`, signal: AbortSignal) => Promise<readonly `[`CascaderOption`](#cascaderoption)`[]>` | — | 异步加载子节点；应响应 AbortSignal。 |
| `onLoadError` | `(error: unknown, option: `[`CascaderOption`](#cascaderoption)`) => void` | — | 加载失败时调用，可展示重试提示。 |
| `cacheKey` | `string \| number` | — | 数据版本改变时清空懒加载缓存，并取消旧请求。 |
| `tagWrap` | `boolean` | `true` | 允许多选标签换行；false 单行显示并自动折叠溢出项。 |
| `maxTagCount` | `number \| 'responsive'` | — | 最多展示的标签数；responsive 根据可用宽度自动折叠。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `multiple` | `false \| true` | `false` | 启用多选；value 和回调的类型随之变化。 |
| `value` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | 受控路径；省略时使用内部非受控值。 |
| `defaultValue` | `readonly string[] \| readonly (readonly string[])[]` | `[]` | 非受控模式的初始路径；支持表单重置。 |
| `onChange` | `((value: string[], selectedOptions: `[`CascaderOption`](#cascaderoption)`[]) => void) \| ((value: string[][], selectedOptions: `[`CascaderOption`](#cascaderoption)`[][]) => void)` | — | 末级选择完成或清除时触发 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `ref` | `Ref<HTMLButtonElement>` | — | 触发按钮引用 |

同一层内的 value 应唯一，传入路径应完整且存在于 options 中。其余原生 button 属性和 `aria-*` 透传至触发按钮；`className` / `style` 作用于外层容器。

## 类型

[`CascaderProps`](#cascader-api) 用于定义组件属性。单独组装层级选项时，可以使用 [`CascaderOption`](#cascaderoption)：

```ts
import type { CascaderProps, CascaderOption, ControlSize, ControlStatus } from '@ifhover/leaf-ui';

const options: CascaderOption[] = [
  {
    label: '浙江',
    value: 'zhejiang',
    children: [{ label: '杭州', value: 'hangzhou' }],
  },
];
```

### CascaderOption
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 选项值；同一层内应唯一。 |
| `label` | `ReactNode` | 必填 | 选项的显示内容。 |
| `searchLabel` | `string` | — | 复杂 label 的搜索纯文本。 |
| `isLeaf` | `boolean` | — | 明确指定是否为叶子节点；配合懒加载使用。 |
| `disabled` | `boolean` | `false` | 禁用该选项及其所有子级。 |
| `children` | `readonly `[`CascaderOption`](#cascaderoption)`[]` | — | 子选项列表。 |

## 表单与键盘

设置 `name` 后，FormData 的值为 JSON 数组字符串，例如 `["zhejiang","hangzhou","xihu"]`，清除后为空字符串。可用 JSON.parse 读取路径。非受控组件支持表单 reset，受控组件需同步重置自己的状态。

Enter、空格或 ↓ 打开面板，↑ / ↓ 在列内移动，Home / End 移至首尾，→ 展开子级，← 返回上一级，Enter 选择。Tab 在各列之间移动，离开面板时聚焦表单中的后续控件；Escape 收起并聚焦触发按钮。关闭时未确认的路径不会提交。

面板沿用局部主题，较深层级可以横向滚动查看。为控件提供 label 或 aria-label。
