# InfiniteScroll 无限滚动

滚动接近列表末尾时加载更多内容。

{/* leaf:section basic */}

## 基础用法

<a id="基本用法"></a>

`onLoadMore` 返回加载任务的 Promise，同一时间只执行一次加载。追加数据后同步 `dataLength`；没有后续数据时将 `hasMore` 设为 `false`。

示例通过 `target` 指定滚动容器。省略时会查找最近的可滚动祖先，找不到时使用页面滚动。末尾进入 `threshold` 的预加载范围便会触发，首次显示时也可能开始加载。

卸载或将 `hasMore` 设为 `false` 会中止本次任务的 `signal`。实际请求需把它传给 `fetch` 等支持取消的接口；其他异步操作应像示例一样，在写入状态前检查 `signal.aborted`。

## 示例

### 失败重试

加载失败时让 Promise 拒绝，组件会暂停自动加载并显示重试按钮。示例第一次请求故意失败，点击重试后追加剩余记录。`onError` 可用于记录错误，不负责替应用恢复数据。

## API

### InfiniteScrollProps API

滚动加载的触发条件、异步任务与加载反馈配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `dataLength` | `number` | 必填 | 已加载数量；数据追加后更新，允许下一次加载。 |
| `hasMore` | `boolean` | 必填 | 是否还有后续数据；false 中止当前任务的 signal 并显示结束内容。 |
| `onLoadMore` | `(signal: AbortSignal) => Promise<void>` | 必填 | 返回加载任务的 Promise；应用追加数据并传递或检查取消信号，拒绝时暂停自动加载并显示重试。 |
| `target` | `() => HTMLElement \| null` | — | 返回滚动容器；省略或返回 null 时查找最近的纵向滚动祖先，否则使用视口。 |
| `threshold` | `number` | `200` | 距离末尾多少像素时预加载；负值按 0 处理。 |
| `loader` | `ReactNode` | — | 加载占位内容 |
| `endMessage` | `ReactNode` | — | 全部加载后的内容 |
| `onError` | `(error: unknown) => void` | — | 加载 Promise 拒绝且任务未取消时调用；不替应用恢复数据。 |
