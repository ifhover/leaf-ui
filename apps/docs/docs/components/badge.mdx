# Badge 角标

展示数量或未读提醒。

{/* leaf:section basic */}

## 基础用法

使用 `count` 设置数量，传入 `children` 将角标附着到内容上。


</ComponentExample>

## 示例

### 数值规则

超过 `max` 的数值展示为上限加号。零值默认隐藏，设置 `showZero` 后显示。

<ComponentExample exampleId="counts" preview={<BadgeCounts />} fileName="counts.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/badge/counts.tsx"
```

</ComponentExample>

### 红点提醒

设置 `dot` 只提示有新内容。请通过 `aria-label` 说明提醒的含义。

设置 `placement="inside"`，将提醒放在内容内部。为角标留出空间，避免遮挡文字或图标。

## API

### Badge API

角标的计数、圆点提醒及附着位置配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 设置后将角标附着在该内容上 |
| `count` | `number \| string` | — | 角标内容 |
| `max` | `number` | `99` | 超过该值时展示 max+ |
| `showZero` | `boolean` | `false` | 允许展示 0 |
| `dot` | `boolean` | `false` | 使用圆点提醒 |
| `placement` | `'outside' \| 'inside'` | `'outside'` | 附着角标的位置：默认外置，inside 放在右上角内部；RTL 下镜像，独立使用时无效 |
| `color` | `string` | — | 自定义角标颜色 |
