<ComponentExample title="数值规则" preview={<BadgeCounts />} fileName="counts.tsx">


## 红点提醒

## 内置角标

使用 `placement="inside"` 将带白色外圈的提醒放在按钮等内容的右上角内部，并为角标预留足够空间，避免遮挡内容；RTL 下位置镜像。

<ComponentExample title="内置角标" preview={<BadgeInside />} fileName="inside.tsx">

```tsx lineNumbers file="../../src/examples/badge/inside.tsx"
```

</ComponentExample>

## 独立使用

## Badge API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 设置后将角标附着在该内容上 |
| `count` | `number \| string` | — | 角标内容 |
| `max` | `number` | `99` | 超过该值时展示 max+ |
| `showZero` | `boolean` | `false` | 允许展示 0 |
| `dot` | `boolean` | `false` | 使用圆点提醒 |
| `placement` | `'outside' \| 'inside'` | `'outside'` | 附着角标的位置：默认外置，inside 放在右上角内部；RTL 下镜像，独立使用时无效 |
| `color` | `string` | — | 自定义角标颜色 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { BadgeProps } from '@ifhover/leaf-ui';
```

## 使用说明

独立使用时可展示数量或简短文字。附着在按钮等内容上时，为圆点提醒提供 aria-label，以说明提醒的含义。
