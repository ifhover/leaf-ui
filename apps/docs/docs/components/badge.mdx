## Badge API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 设置后将角标附着在该内容右上方；内容变宽时向外侧延伸 |
| `count` | `number \| string` | — | 角标内容 |
| `max` | `number` | `99` | 超过该值时展示 max+ |
| `showZero` | `boolean` | `false` | 允许展示 0 |
| `dot` | `boolean` | `false` | 使用圆点提醒 |
| `status` | `'success' \| 'warning' \| 'danger' \| 'info' \| 'default'` | — | 使用对应颜色的状态圆点；`error` 为兼容别名 |
| `text` | `ReactNode` | — | 圆点旁的说明 |
| `color` | `string` | — | 自定义角标颜色 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { BadgeProps } from '@ifhover/leaf-ui';
```

## 使用说明

独立使用时可展示数量或状态。附着在按钮等内容上时，为圆点提醒提供 aria-label，以说明提醒的含义。
