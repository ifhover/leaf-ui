## DateRangePicker API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value / defaultValue` | [`DateRange \| null`](#daterange) | `null` | 受控区间 / 初始区间 |
| `onChange` | [`(value: DateRange \| null, dateStrings: readonly [string, string]) => void`](#daterange) | — | 完成选择后返回有序区间与字符串；清除返回 null |
| `picker` | `'year' \| 'month' \| 'week' \| 'weekday' \| 'date' \| 'datetime'` | `'date'` | 选择粒度 |
| `minDate / maxDate` | `Date` | — | 最早 / 最晚可选边界 |
| `use12Hours` | `boolean` | `false` | 使用 12 小时制展示及上午、下午选项 |
| `minuteStep / secondStep` | `number` | `1` | 分钟 / 秒间隔，1–60 的整数 |
| `allowClear` | `boolean` | `true` | 展示清除按钮 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 控件尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `disabled / required` | `boolean` | `false` | 禁用 / 必填，可继承 FormField |
| `placeholder / name / form` | `string` | — | 提示文字 / 字段名 / 表单 ID |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起 |
| `ref` | `Ref<HTMLButtonElement>` | — | 触发按钮引用 |

## DateRange

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `0` | `Date` | 必填 | 起始值，早于或等于终止值 |
| `1` | `Date` | 必填 | 终止值 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { DateRangePickerProps, DateRange } from '@sudden3/leaf-ui';
```

## 使用说明

DateRange 是 readonly [Date, Date]，可导入它组装变量。年取 1 月 1 日，月取当月 1 日，周从星期一开始并使用 ISO 周编号；weekday 选择某周的具体日期并显示星期。日期使用本地时间。

非 datetime 模式第二次选择后自动完成，逆序选择会自动排列；datetime 模式选择起止日期及时间后点击确定，包含秒。minDate / maxDate 在粗粒度模式按对应年、月、周比较，datetime 按准确时间比较。

FormData 提交 start/end 格式字符串（年份 YYYY，月份 YYYY-MM，周 YYYY-Www，日期 YYYY-MM-DD，日期时间 YYYY-MM-DD HH:mm:ss）。需要日期区间类型时导入 DateRange，查看上方字段表格。
