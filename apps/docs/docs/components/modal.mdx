# Modal 弹窗

在独立弹窗中查看或编辑内容。

仅需确认或取消时使用 [Confirm](/components/confirm)，希望在触发按钮旁确认时使用 [Popconfirm](/components/popconfirm)。

### 关闭后销毁内容

默认在首次打开后保留内容。`destroyOnClose` 在关闭过渡结束后卸载内容，再次打开时非受控输入恢复初始值。`preserve` 优先于 `destroyOnClose`，而 `forceRender` 会保持内容挂载；组件外保存的受控状态仍需应用自行重置。

## API

### Modal API

控制弹窗的显示状态、内容与底部操作。

没有 `title` 时，通过 `aria-label` 提供弹窗名称。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必填 | 受控的打开状态，应用负责更新。 |
| `title` | `ReactNode` | — | 弹窗标题。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `onClose` | `() => void` | — | 请求关闭，由应用更新 open |
| `onConfirm` | `() => void \| Promise<void>` | — | 默认确认按钮的操作，可返回 Promise；等待期间阻止重复确认和默认关闭。成功后应用仍须更新 open。 |
| `onCancel` | `() => void` | — | 取消按钮、关闭按钮、遮罩或 Escape 请求关闭时调用；省略时调用 onClose。 |
| `confirmText` | `ReactNode` | 语言默认值 | 按钮文字 |
| `cancelText` | `ReactNode` | 语言默认值 | 按钮文字 |
| `confirmLoading` | `boolean` | `false` | 确认加载状态 |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | 定制默认按钮属性 |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | 定制默认按钮属性 |
| `footer` | `ReactNode \| ((actions: `[`ModalFooterActions`](#modalfooteractions)`) => ReactNode)` | 取消 + 确定 | 自定义底部；null 隐藏；函数接收默认按钮 |
| `variant` | `'plain' \| 'card'` | `'plain'` | 内容外观；card 将正文分为独立的内容面。 |
| `icon` | `ReactNode` | — | 标题左侧的装饰图标。 |
| `divided` | `boolean` | `false` | 用浅分隔线划分标题、内容和底部操作区。 |
| `width` | `number \| string` | `480` | 弹窗宽度，数字为像素 |
| `closable` | `boolean` | `true` | 显示右上角关闭按钮。 |
| `maskClosable` | `boolean` | `true` | 点击遮罩时请求关闭。 |
| `keyboard` | `boolean` | `true` | 允许按 Escape 请求关闭。 |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定初始焦点；默认聚焦首个可聚焦元素，可能是关闭按钮。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点；也可指定目标或设为 false。 |
| `afterClose` | `() => void` | — | 关闭动画完成后触发 |
| `destroyOnClose` | `boolean` | `false` | 关闭后卸载内容；preserve 优先，forceRender 会保持挂载。 |
| `preserve` | `boolean` | — | 指定是否保留内容，优先于 destroyOnClose；不重置组件外的受控状态。 |
| `forceRender` | `boolean` | `false` | 打开前也挂载内容，关闭时保持隐藏。 |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | 指定 Portal 挂载目标，也可返回 ShadowRoot。 |

### ModalFooterActions

底部渲染函数收到的默认确认与取消按钮。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `confirmButton` | `ReactNode` | 必填 | 默认确认按钮，保留加载状态 |
| `cancelButton` | `ReactNode` | 必填 | 默认取消按钮 |

### DialogFocusOptions

配置对话框打开和关闭时的焦点处理。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定打开后的初始焦点。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点；也可指定目标或设为 false。 |
