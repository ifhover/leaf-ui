## Modal API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定打开后的初始焦点。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点；也可指定目标或设为 false。 |
| `open` | `boolean` | 必填 | 必需。是否显示弹窗 |
| `title` | `ReactNode` | — | 标题 / 内容 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 标题左侧的装饰图标。 |
| `divided` | `boolean` | `true` | 用浅分隔线划分标题、内容和底部操作区。 |
| `footer` | `ReactNode \| ((actions: `[`ModalFooterActions`](#modalfooteractions)`) => ReactNode)` | 取消 + 确定 | 自定义底部；null 隐藏；函数接收默认按钮 |
| `confirmText` | `ReactNode` | 语言默认值 | 按钮文字 |
| `cancelText` | `ReactNode` | 语言默认值 | 按钮文字 |
| `confirmLoading` | `boolean` | `false` | 确认加载状态 |
| `confirmButtonProps` | [`ButtonProps`](../components/button#button-api) | — | 定制默认按钮属性 |
| `cancelButtonProps` | [`ButtonProps`](../components/button#button-api) | — | 定制默认按钮属性 |
| `onConfirm` | `() => void \| Promise<void>` | — | 由应用控制 open；Promise 拒绝时显示错误 |
| `onCancel` | `() => void` | — | 取消或关闭请求，未指定时使用 onClose |
| `width` | `number \| string` | `480` | 弹窗宽度，数字为像素 |
| `closable` | `boolean` | `true` | 关闭按钮 / 点击遮罩关闭 / Escape 关闭 |
| `maskClosable` | `boolean` | `true` | 关闭按钮 / 点击遮罩关闭 / Escape 关闭 |
| `keyboard` | `boolean` | `true` | 关闭按钮 / 点击遮罩关闭 / Escape 关闭 |
| `onClose` | `() => void` | — | 请求关闭，由应用更新 open |
| `afterClose` | `() => void` | — | 关闭动画完成后触发 |
| `forceRender` | `boolean` | `false` | 打开前也挂载内容，关闭时保持隐藏。 |
| `destroyOnClose` | `boolean` | `false` | 关闭过渡完成后卸载内容；默认保留。 |
| `preserve` | `boolean` | — | 显式控制关闭后是否保留内容，优先于 destroyOnClose。 |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | 自定义挂载或滚动容器。 |

## ModalFooterActions

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `confirmButton` | `ReactNode` | — | 必需。默认确认按钮，保留加载状态 |
| `cancelButton` | `ReactNode` | — | 必需。默认取消按钮 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { ModalProps, ModalFooterActions } from '@ifhover/leaf-ui';
```

## 使用说明

弹窗打开后聚焦内部控件，Tab 在弹窗中移动；Escape 关闭后恢复触发前的焦点。maskClosable、keyboard 可分别关闭遮罩、键盘退出。没有 title 时请提供 aria-label。

footer 可放确认、取消等操作；也可以在内容中使用 Form。弹窗中的选择器浮层沿用区域主题。

默认底部按取消、确定顺序靠右排列。传入 onConfirm 时，完成操作后自行更新 open；未传入时确定调用 onClose。Promise 执行期间显示加载状态并避免重复操作。提交表单可在 onConfirm 中调用 form.requestSubmit()，或通过 confirmButtonProps 设置 type="submit" 与 form ID，保留表单校验。footer 函数可扩展默认按钮，`footer={null}` 隐藏底部。

## 外观与丰富内容

`description` 为标题提供补充说明，`icon` 放在标题左侧。默认 `divided` 使用浅分隔线和淡灰操作区；`divided={false}` 使用留白分区。`footer` 函数可在左侧加入状态文字，使用 `Space` 把按钮放在同一组，窄屏时整组换行并靠右排列。
