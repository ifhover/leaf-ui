# TreeSelect 树选择

从层级选项中选择一项或多项；平铺选项使用 [Select](select)。

{/* leaf:section basic */}

### 勾选联动与输出值

`treeCheckable` 自动开启多选并联动父子节点。`showCheckedStrategy` 同时影响标签、回调值和表单值：默认 `child` 输出子节点，`parent` 合并为完整选中的父节点，`all` 输出所有选中节点。需要父子独立勾选时设置 `checkStrictly`。

### 异步加载分支

`loadData` 在展开未加载分支时请求子项，返回结果会被缓存。示例用延迟模拟请求并在返回前检查取消状态；真实请求应把 `signal` 传给 `fetch`。通过 `onLoadError` 处理失败，再次展开可重试；数据版本变化时更新 `cacheKey`，清空缓存并取消旧请求。


</ComponentExample>

### 受控展开

通过 `treeExpandedKeys` 与 `onExpand` 保存展开状态。重新打开会保留展开分支，搜索只临时展开匹配路径，不改写保存的状态。

## API

### TreeSelect API

配置树形选项、选择值与搜索和懒加载行为。

单选与多选的属性类型分别约束 `value`、`defaultValue` 和 `onChange`。非受控字段响应原生表单重置；勾选模式可点击整行或按 Enter / 空格勾选，箭头只控制展开。共享浮层参数见 [PopupOptions](../api/popup-options)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly `[`TreeSelectOption`](#treeselectoption)`[]` | 必填 | 层级选项 |
| `value` | `string \| null \| readonly string[]` | — | 受控值；单选使用字符串或 null，多选或 treeCheckable 使用数组。 |
| `defaultValue` | `string \| null \| readonly string[]` | `null` | 非受控初始值，表单重置时恢复；未设置时没有选中项。 |
| `onChange` | `((value: string \| null) => void) \| ((value: readonly string[]) => void)` | — | 单选返回字符串或 null，多选返回数组；勾选模式的结果受 showCheckedStrategy 影响。清除保留不可移除的禁用项。 |
| `multiple` | `boolean` | `false` | 是否启用多值选择。 |
| `treeCheckable` | `boolean` | `false` | 是否启用复选框模式，会自动开启多选。 |
| `checkStrictly` | `boolean` | `false` | 父子节点独立勾选 |
| `showCheckedStrategy` | `'child' \| 'parent' \| 'all'` | `'child'` | 联动勾选时输出子节点、父节点或全部节点；同时影响标签、回调和表单值，checkStrictly 时不生效。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 控件尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验反馈 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `allowClear` | `boolean` | `true` | 允许清除可用选项 |
| `showSearch` | `boolean` | `true` | 通过输入过滤节点 |
| `onSearch` | `(query: string) => void` | — | 搜索文字变化 |
| `filterTreeNode` | `(option: `[`TreeSelectOption`](#treeselectoption)`, query: string) => boolean` | — | 自定义节点的搜索匹配。 |
| `notFoundContent` | `ReactNode` | 暂无选项 | 无匹配内容 |
| `maxCount` | `number` | `Infinity` | 最终输出的选择数量上限；一次联动操作超限时整次不提交。 |
| `maxTagCount` | `number \| 'responsive'` | — | 最多展示的标签数；responsive 根据可用宽度自动折叠。 |
| `tagWrap` | `boolean` | `true` | 允许多选标签换行；false 单行显示并自动折叠溢出项。 |
| `defaultExpandAll` | `boolean` | `false` | 初始展开全部 |
| `treeDefaultExpandedKeys` | `readonly string[]` | `[]` | 初始展开的 value |
| `treeExpandedKeys` | `readonly string[]` | — | 受控的展开节点。 |
| `onExpand` | `(keys: string[]) => void` | — | 展开节点发生变化时调用。 |
| `loadData` | `( option: `[`TreeSelectOption`](#treeselectoption)`, signal: AbortSignal, ) => Promise<readonly `[`TreeSelectOption`](#treeselectoption)`[]>` | — | 展开时加载子项，signal 用于取消 |
| `onLoadError` | `(error: unknown, option: `[`TreeSelectOption`](#treeselectoption)`) => void` | — | 加载失败，再次展开可重试 |
| `cacheKey` | `string \| number` | — | 数据版本改变时清空懒加载缓存，并取消旧请求。 |
| `nodeRender` | `(option: `[`TreeSelectOption`](#treeselectoption)`) => ReactNode` | — | 自定义节点展示内容。 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | `false` | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化 |
| `inputReadOnly` | `boolean` | — | 只禁止手动输入，仍可在面板中选择。 |
| `virtual` | `boolean` | `false` | 仅渲染可见项目 |
| `listHeight` | `number` | `256` | 列表高度 |
| `itemHeight` | `number` | 由主题和密度计算 | 虚拟列表的预估行高；默认由主题和密度计算。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |

### TreeSelectOption

描述树选择器中的节点及其子节点。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 唯一值，必填 |
| `label` | `ReactNode` | 必填 | 展示内容，必填 |
| `children` | `readonly `[`TreeSelectOption`](#treeselectoption)`[]` | — | 子选项，结构相同 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `selectable` | `boolean` | — | 设为 false 可让分类节点仅用于浏览 |
| `disableCheckbox` | `boolean` | — | 禁止勾选并阻断联动 |
| `icon` | `ReactNode` | — | 节点图标 |
| `searchLabel` | `string` | — | label 为节点时提供搜索和读屏文字 |
| `isLeaf` | `boolean` | — | 明确指定是否为叶子节点，配合异步加载使用。 |
