## CarouselHandle

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `goTo` | `(index: number) => void` | 必填 | 切换到指定的索引。 |
| `next` | `() => void` | 必填 | 切换到下一项。 |
| `previous` | `() => void` | 必填 | 切换到上一项。 |

## Carousel API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `activeIndex` | `number` | — | 受控的当前幻灯片索引。 |
| `defaultActiveIndex` | `number` | `0` | 初始幻灯片索引。 |
| `onChange` | `(index: number) => void` | — | 值发生变化时调用。 |
| `arrows` | `boolean` | `true` | 显示前后切换按钮。 |
| `dots` | `boolean` | `true` | 显示幻灯片指示器。 |
| `autoplay` | `boolean \| number` | `false` | 启用自动播放；数字表示间隔毫秒数。 |
| `infinite` | `boolean` | `true` | 允许循环切换。 |
| `pauseOnHover` | `boolean` | `true` | 鼠标悬停时暂停播放；焦点进入也会暂停。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { CarouselHandle, CarouselProps } from '@ifhover/leaf-ui';
```

上一张与下一张按钮提供可读名称；轮播支持键盘操作，并跟随 ConfigProvider 的主题和减少动画设置。
