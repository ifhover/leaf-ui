## Divider API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | `'horizontal' \| 'vertical'` | `'horizontal'` | 分割方向 |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 文字位置 |
| `dashed` | `boolean` | `false` | 虚线样式 |
| `children` | `ReactNode` | — | 水平分割线上的文字 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { DividerProps } from '@sudden3/leaf-ui';
```

## 使用说明

垂直分割线适合放在行内内容之间。
