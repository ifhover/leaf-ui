# Divider 分割线

分隔内容、段落或行内信息。

{/* leaf:section basic */}

将 `Divider` 放在需要区分的内容之间，默认使用水平分割线。

## API

### Divider API

支持原生 `div` 属性。字符串内容自动作为可访问名称；使用图标等复杂内容时，通过 `aria-label` 提供名称。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `type` | `'horizontal' \| 'vertical'` | `'horizontal'` | 分割方向 |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 文字位置 |
| `dashed` | `boolean` | `false` | 虚线样式 |
| `children` | `ReactNode` | — | 显示在分割线中的内容。 |
