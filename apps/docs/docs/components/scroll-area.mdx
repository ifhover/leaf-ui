## 使用说明

通过 height 或 maxHeight 限制滚动区域。orientation 控制方向，scrollbar 控制滚动条显示；支持原生滚轮、触摸和键盘滚动。

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { ScrollAreaProps } from '@sudden3/leaf-ui';
```

## ScrollAreaProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `height` | `number \| string` | — | 高度，数字按像素计算 |
| `maxHeight` | `number \| string` | — | 最大高度 |
| `orientation` | `'vertical' \| 'horizontal' \| 'both'` | `'vertical'` | 滚动方向 |
| `scrollbar` | `'auto' \| 'always' \| 'hidden'` | `'auto'` | 滚动条显示方式 |
