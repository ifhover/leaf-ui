## 使用说明

通过 height 或 maxHeight 限制滚动区域。orientation 控制方向，scrollbar 控制滚动条显示；支持原生滚轮、触摸和键盘滚动。

滚动条默认悬浮并在鼠标移入时淡入，不占用内容空间。`ref` 指向实际滚动容器，`style` 与 `className` 用于外层。完整的样式扩展与键盘操作见 [Scrollbar](./scrollbar)。未溢出或到达边界时，滚轮继续滚动页面。

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { ScrollAreaProps } from '@ifhover/leaf-ui';
```

## ScrollAreaProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `height` | `CSSProperties['height']` | — | 高度，数字按像素计算 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 最大高度 |
| `orientation` | `'vertical' \| 'horizontal' \| 'both'` | `'vertical'` | 滚动方向 |
| `scrollbar` | `'auto' \| 'always' \| 'hidden'` | `'auto'` | 滚动条显示方式 |
| `viewportClassName` | `string` | — | 实际滚动容器的类名。 |
| `viewportStyle` | `CSSProperties` | — | 实际滚动容器的样式。 |
| `contentClassName` | `string` | — | 内容容器的类名。 |
| `contentStyle` | `CSSProperties` | — | 内容容器的样式。 |
| `verticalOffset` | `number` | `0` | 纵向轨道顶部预留空间。 |
