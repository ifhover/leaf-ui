## Calendar API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value / defaultValue` | `Date` | — | 受控 / 初始选中日期 |
| `onChange` | `(date: Date) => void` | — | 选择日期后触发 |
| `visibleDate` | `Date` | — | 受控展示范围 |
| `onVisibleChange` | `(date: Date) => void` | — | 展示范围变化 |
| `mode` | `'date' \| 'month'` | `'date'` | 选择日期或月份 |
| `fullscreen` | `boolean` | `true` | 完整日历布局 |
| `minDate / maxDate` | `Date` | — | 日期边界 |
| `disabledDate` | `(date: Date) => boolean` | — | 禁用指定日期 |
| `cellRender` | `(date: Date) => ReactNode` | — | 补充日程内容 |
| `headerExtra` | `ReactNode` | — | 标题区域补充内容 |
| `showToday` | `boolean` | `true` | 完整日历展示今天按钮，跳至当前月份 |

## 使用说明

`fullscreen={false}` 展示紧凑日历。`cellRender` 中使用文字、图标等非交互内容，避免在日期按钮内嵌套按钮。禁用选中项保留清晰的灰色状态，不会再次触发选择。

方向键移动日期，Home / End 跳至一行首尾，PageUp / PageDown 切换月份。SSR 页面应提供一致的初始日期，详见 [SSR 使用](/guide/ssr)。
