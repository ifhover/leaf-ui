# Calendar 日历

浏览和选择日期，也可在日期中补充日程信息。

通过 `defaultValue` 设置初始选中日期；选择日期时触发 `onChange`。

### 受控日期与展示月份

<a id="进阶用法"></a>

`value` 管理选中日期，`visibleDate` 管理正在查看的月份。翻页或点击“今天”只改变展示月份，不会选择日期；`onVisibleChange` 返回新月份的第一天。示例通过 `headerExtra` 提供返回所选月份的操作。

<ComponentExample exampleId="controlled" preview={<CalendarControlled />} fileName="controlled.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/calendar/controlled.tsx"
```

</ComponentExample>

### 日程内容

通过 `cellRender` 补充文字、图标或 Tag。内容放在日期按钮内，不能嵌套链接、按钮等交互元素；需要操作日程时，在日历外提供对应入口。

<ComponentExample exampleId="schedule" preview={<CalendarSchedule />} fileName="schedule.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/calendar/schedule.tsx"
```

</ComponentExample>

日期使用本地 `Date`；`minDate` / `maxDate` 包含边界日期。SSR 页面应提供服务端和客户端一致的初始日期，见 [服务端渲染](/guide/ssr)。Calendar 不提供原生表单提交或重置行为，需要这些能力时使用 [DatePicker](/components/date-picker)。

## API

### Calendar API

选中日期、显示月份与可选日期范围的配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `Date` | — | 受控的选中日期，与 visibleDate 独立。 |
| `defaultValue` | `Date` | — | 非受控模式的初始选中日期。 |
| `onChange` | `(date: Date) => void` | — | 选择日期时调用；month 模式返回所选月的第一天。 |
| `mode` | `'date' \| 'month'` | `'date'` | 选择日期或月份 |
| `fullscreen` | `boolean` | `true` | 完整月历布局；`false` 为 296px 紧凑日历 |
| `minDate` | `Date` | — | 日期边界 |
| `maxDate` | `Date` | — | 日期边界 |
| `disabledDate` | `(date: Date) => boolean` | — | 禁用指定日期 |
| `visibleDate` | `Date` | — | 受控的显示月份，不代表选中日期。 |
| `onVisibleChange` | `(date: Date) => void` | — | 显示月份变化时返回新月份的第一天；不触发选择。 |
| `showToday` | `boolean` | `true` | 显示回到今天的操作，仅切换显示月份，不改变选中值。 |
| `cellRender` | `(date: Date) => ReactNode` | — | 自定义单元格内容；内容位于选择按钮内，不要嵌套交互控件。 |
| `headerExtra` | `ReactNode` | — | 标题区域补充内容 |
