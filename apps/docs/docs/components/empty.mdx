## 迁移到 Result

将 `image` 改为 `icon`、`description` 改为 `title`，并把 `children` 中的操作移到 `extra`。

```diff
- import { Empty } from '@ifhover/leaf-ui';
+ import { Result } from '@ifhover/leaf-ui';

- <Empty description="暂无项目" />
+ <Result status="empty" title="暂无项目" />
```

完整参数见 [Empty API](/components/result#empty-api)。
