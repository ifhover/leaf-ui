# Tooltip 文字提示

为页面元素补充简短说明。

{/* leaf:section basic */}

## 基础用法

悬停或键盘聚焦可展示提示，Escape 关闭。提示只放简短说明；需要交互内容时使用 [Popover](popover)。

### 禁用提示

Tooltip 的 `disabled` 只关闭提示，不会禁用按钮。禁用按钮本身不能接收焦点；如需解释原因，可使用外层可聚焦的元素作为提示触发器。

## API

### Tooltip API

配置提示内容、出现位置和展开方式。

触发元素需透传 ref 与事件；现有的 `aria-describedby` 会与提示关联合并。共享浮层参数见 [PopupOptions](/api/popup-options)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `content` | `ReactNode` | 必填 | 提示内容；为空字符串、null 或 undefined 时不显示。 |
| `children` | `ReactElement< HTMLAttributes<HTMLElement> & { ref?: Ref<HTMLElement>; disabled?: boolean } >` | 必填 | 触发元素，需支持 ref 和事件 |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | `'top'` | 期望展示位置，空间不足时自动调整 |
| `disabled` | `boolean` | `false` | 禁止显示提示，不禁用触发元素。 |
| `open` | `boolean` | — | 受控的展开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控模式的初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化 |
| `enterDelay` | `number` | `100` | 悬停后等待多少毫秒再打开。 |
| `leaveDelay` | `number` | `100` | 指针离开后等待多少毫秒再关闭。 |
| `className` | `string` | — | 提示浮层类名 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
