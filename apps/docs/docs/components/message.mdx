# Message 消息提示

以短暂提示反馈操作结果。需要标题、详细说明或后续操作时使用 [Notification](/components/notification)。

{/* leaf:section basic */}

## 基础用法

在应用入口放置 [ConfigProvider](/components/config-provider)，再在子组件中调用 `useMessage()`。已有该配置时无需重复添加。

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## API

### Message API

直接渲染时，由应用响应 `onClose` 并设置 `open=false`；`afterClose` 在离场动画结束后触发。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必填 | 受控显示状态 |
| `content` | `ReactNode` | 必填 | 消息内容 |
| `type` | `FeedbackType \| 'error' \| 'loading'` | `'info'` | 消息类型；`error` 为兼容别名 |
| `duration` | `number` | 普通消息 3；loading 为 0 | 自动关闭的秒数；0 或负数不自动关闭。悬停或焦点进入时暂停，离开后继续剩余时间。 |
| `closable` | `boolean` | `false` | 关闭按钮 |
| `onClose` | `() => void` | — | 关闭请求时调用；声明式 Message 须由应用将 open 设为 false。 |
| `afterClose` | `() => void` | — | 关闭动画结束、内容卸载后调用，不代替 onClose 更新受控值。 |

### useMessage API

获取当前入口托管的消息队列。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `message` | [`MessageApi`](#messageapi) | — | 调用入口托管的消息队列 |

### MessageApi

`close(key)` 仅关闭指定消息；`close()` 关闭共享队列中的全部消息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `(options: `[`MessageOptions`](#messageoptions)`) => string` | 必填 | 打开或按 key 替换消息，返回该消息的 key。 |
| `success` | `(content: ReactNode, duration?: number) => string` | 必填 | 快捷显示对应类型；`error` 保留为兼容方法 |
| `info` | `(content: ReactNode, duration?: number) => string` | 必填 | 快捷显示对应类型；`error` 保留为兼容方法 |
| `warning` | `(content: ReactNode, duration?: number) => string` | 必填 | 快捷显示对应类型；`error` 保留为兼容方法 |
| `danger` | `(content: ReactNode, duration?: number) => string` | 必填 | 快捷显示对应类型；`error` 保留为兼容方法 |
| `error` | `(content: ReactNode, duration?: number) => string` | 必填 | 请求失败时显示的内容，替代数据行。 |
| `loading` | `(content: ReactNode) => string` | 必填 | 显示不自动关闭的加载消息，返回 key；应用负责更新或关闭。 |
| `close` | `(key?: string) => void` | 必填 | 关闭指定 key；不传 key 会关闭同一 Provider 内的全部消息，不限于当前调用组件。 |

### MessageOptions

鼠标停留或焦点进入消息时暂停计时，恢复后按剩余时长继续。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `content` | `ReactNode` | 必填 | 消息内容 |
| `type` | `FeedbackType \| 'error' \| 'loading'` | `'info'` | 消息类型；`error` 为兼容别名 |
| `duration` | `number` | 普通消息 3；loading 为 0 | 自动关闭的秒数；0 或负数不自动关闭。悬停或焦点进入时暂停，离开后继续剩余时间。 |
| `closable` | `boolean` | `false` | 展示关闭按钮 |
| `key` | `string` | 自动生成 | 同一 Provider 内的唯一标识；重复 open 会替换该条消息并重启关闭计时，不追加新消息。 |
| `onClose` | `() => void` | — | 关闭请求时调用；声明式 Message 须由应用将 open 设为 false。 |

### MessageProvider API

单独使用消息时，可用 `MessageProvider` 代替 `ConfigProvider`；显式添加它也可建立独立队列。不同 React 应用及 SSR 请求各自拥有队列。

```tsx
import { MessageProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <MessageProvider><App /></MessageProvider>;
}
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 共享此独立消息队列的内容；ConfigProvider 已提供队列，嵌套 ConfigProvider 复用上层队列。 |
