## 使用说明

未配置 action 或 customRequest 时只选择文件，保持待上传状态，可由业务统一提交。action 使用 XMLHttpRequest 报告进度：POST 发送 FormData，PUT 发送文件本身。JSON 响应可提供 url 和 name；customRequest 可返回相同字段。选择和拖拽共用校验，上传支持取消、移除与重试；自定义请求须响应 signal。移除或卸载会取消请求并释放本地预览 URL。服务端仍需进行文件校验。

## UploadProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | 受控 / 初始文件列表 |
| `defaultFileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | 受控 / 初始文件列表 |
| `onChange` | `(files: `[`UploadFile`](#uploadfile-api)`[], info: `[`UploadChangeInfo`](#uploadchangeinfo-api)`) => void` | — | 列表及上传状态变化 |
| `accept` | `string` | — | 允许的 MIME 或后缀，如 image/*,.pdf |
| `multiple` | `boolean` | `false` | 多文件选择 / 禁用 / 拖拽区域 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `drag` | `boolean` | `false` | 多文件选择 / 禁用 / 拖拽区域 |
| `maxCount` | `number` | — | 允许的文件总数 |
| `maxSize` | `number` | — | 单个文件最大字节数 |
| `beforeUpload` | `(file: File) => boolean \| File \| Promise<boolean \| File>` | — | 上传前校验，false 拒绝，File 可转换文件 |
| `onReject` | `(rejections: readonly `[`UploadRejection`](#uploadrejection-api)`[]) => void` | — | 格式、大小、数量或校验拒绝 |
| `action` | `string \| ((file: File) => string \| Promise<string>)` | — | 上传地址，未配置时只选择文件 |
| `method` | `'POST' \| 'PUT'` | `'POST'` | POST 使用 FormData，PUT 上传文件本身 |
| `headers` | `Readonly<Record<string, string>>` | — | 请求头 |
| `data` | `Readonly<Record<string, string \| Blob>>` | — | POST 的额外表单数据 |
| `withCredentials` | `boolean` | `false` | 跨域发送凭证 |
| `fieldName` | `string` | `'file'` | POST 中的文件字段名 |
| `customRequest` | `(request: `[`UploadRequest`](#uploadrequest-api)`) => Promise<`[`UploadResult`](#uploadresult-api)` \| void>` | — | 自定义异步上传，配合 signal 取消 |
| `onRemove` | `(file: `[`UploadFile`](#uploadfile-api)`) => boolean \| void \| Promise<boolean> \| Promise<void>` | — | 移除前回调，返回 false 保留文件 |
| `showFileList` | `boolean` | `true` | 展示文件列表 |
| `hint` | `ReactNode` | — | 提示 / 选择按钮或拖拽区域标题 |
| `children` | `ReactNode` | — | 提示 / 选择按钮或拖拽区域标题 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | — | 要求整体值非空，复合控件只校验一次。 |
| `autoUpload` | `boolean` | `true` | 文件校验通过后自动开始；false 时用 ref.upload()。 |
| `concurrency` | `number` | `3` | 同时进行的上传请求数。 |
| `directory` | `boolean` | — | 选择目录及其文件；依赖浏览器的目录选择能力。 |
| `paste` | `boolean` | — | 接收剪贴板中的文件。 |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | 文件列表的展示形式。 |

## UploadFile API

继承 [`FileItem`](#fileitem-api)，并增加以下字段。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | 必填 | 必需。唯一标识 |
| `url` | `string` | — | 设置 url。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `size` | `number` | — | 展示尺寸。 |
| `type` | `string` | — | 设置 type。 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 设置 status。 |
| `percent` | `number` | — | 完成百分比。 |
| `error` | `string` | — | 设置 error。 |
| `originFile` | `globalThis.File` | — | 设置 originFile。 |
| `response` | `unknown` | — | 服务端返回的数据 |

## FileItem API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | — | 稳定标识，建议提供 |
