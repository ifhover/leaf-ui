# Upload 文件上传

选择文件并管理上传进度、取消与重试。仅展示已有文件时使用 [FileList](./file-list.mdx)。

{/* leaf:section basic */}

## 基础用法

未配置 `action` 或 `customRequest` 时只选择文件，文件保持待上传状态，不发送请求。

文件校验未通过时保留原文件；校验通过后，列表立即切换为新文件，请在上传成功后再更新已保存的头像地址。上传失败会显示错误，可重新选择。

### 文件限制

使用 `accept`、`maxSize` 和 `maxCount` 限制格式、单文件大小与文件总数。被拒绝的文件显示错误并触发 `onReject`，同批次的有效文件仍会接收。服务端仍需校验文件。

<ComponentExample exampleId="restrictions" preview={<UploadRestrictions />} fileName="restrictions.tsx" width={480}>

```tsx lineNumbers file="../../src/examples/upload/restrictions.tsx"
```

</ComponentExample>

校验按格式、大小、数量、`beforeUpload` 的顺序执行。`beforeUpload` 返回 `false` 或抛出异常时拒绝文件；返回 `File` 可替换待上传文件，但不会再次检查其格式和大小。`multiple={false}` 只限制每次选择一个文件；列表总数限制为一个时使用 `maxCount={1}`。

### 受控文件列表

通过 `fileList` 回显已有文件，并在每次 `onChange` 中回写完整列表，包括上传状态变化和移除。本例使用内嵌文本地址演示已有文件，实际接入时替换为服务返回的文件地址；新选择的文件保持待上传状态。

### 手动上传

设置 `autoUpload={false}`，再通过 ref 的 `upload()` 开始上传。`abort()` 取消进行中的请求并清空队列，保留文件列表。按钮根据文件状态禁用无效操作，取消后可再次开始上传。

## API

### UploadProps API

配置文件选择、上传请求与文件列表反馈。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | — | 受控文件列表；省略时使用内部非受控列表。 |
| `defaultFileList` | `readonly `[`UploadFile`](#uploadfile-api)`[]` | `[]` | 非受控模式的初始文件列表；支持表单重置。 |
| `onChange` | `(files: `[`UploadFile`](#uploadfile-api)`[], info: `[`UploadChangeInfo`](#uploadchangeinfo-api)`) => void` | — | 列表及上传状态变化 |
| `accept` | `string` | — | 允许的 MIME 或后缀，如 image/*,.pdf |
| `multiple` | `boolean` | `false` | 允许一次选择多个文件；限制列表总数使用 maxCount。 |
| `maxCount` | `number` | — | 允许的文件总数 |
| `maxSize` | `number` | — | 单个文件最大字节数 |
| `beforeUpload` | `(file: File) => boolean \| File \| Promise<boolean \| File>` | — | 接收前校验或转换文件；false 或异常表示拒绝。返回的替换文件不会重新执行类型和大小检查。 |
| `onReject` | `(rejections: readonly `[`UploadRejection`](#uploadrejection-api)`[]) => void` | — | 格式、大小、数量或校验拒绝 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `drag` | `boolean` | `false` | 是否启用拖拽区域。 |
| `directory` | `boolean` | — | 选择目录及其文件；依赖浏览器的目录选择能力。 |
| `autoUpload` | `boolean` | `true` | 文件校验通过后自动开始；false 时用 ref.upload()。 |
| `concurrency` | `number` | `3` | 同时进行的上传请求数。 |
| `action` | `string \| ((file: File) => string \| Promise<string>)` | — | 上传地址；未配置 action 和 customRequest 时仅选择文件。 |
| `customRequest` | `(request: `[`UploadRequest`](#uploadrequest-api)`) => Promise<`[`UploadResult`](#uploadresult-api)` \| void>` | — | 自定义上传，优先于 action；成功时 resolve，失败时 reject，并响应 signal 取消请求。 |
| `method` | `'POST' \| 'PUT'` | `'POST'` | POST 使用 FormData，PUT 上传文件本身 |
| `headers` | `Readonly<Record<string, string>>` | — | 请求头 |
| `data` | `Readonly<Record<string, string \| Blob>>` | — | POST 的额外表单数据 |
| `withCredentials` | `boolean` | `false` | 跨域发送凭证 |
| `fieldName` | `string` | `'file'` | POST 上传请求中的文件字段名，与原生表单的 name 不同。 |
| `showFileList` | `boolean` | `true` | 展示文件列表 |
| `listType` | `'text' \| 'picture'` | `'text'` | 文件列表的展示形式。 |
| `onRemove` | `(file: `[`UploadFile`](#uploadfile-api)`) => boolean \| void \| Promise<boolean> \| Promise<void>` | — | 移除前调用；返回 false 或拒绝 Promise 可阻止移除。 |
| `hint` | `ReactNode` | — | 选择区域下方的说明文字。 |
| `children` | `ReactNode` | — | 选择按钮或拖拽区域的标题。 |
| `name` | `string` | — | 原生 FormData 字段名；每项提交 File 或 URL 字符串，同名多项用 getAll() 读取。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | — | 要求列表至少有一项，不保证文件已经上传成功。 |

#### 上传请求

接入服务可设置 `action`：`POST` 发送包含 `data` 和文件的 `FormData`，文件字段由 `fieldName` 指定；`PUT` 发送原始文件。JSON 响应和 `customRequest` 返回值可以提供 `url`、`name`。同时配置时，`customRequest` 优先于 `action`。

#### 列表与表单接入

使用受控 `fileList` 时，每次 `onChange` 都需回写，包括上传状态变化和移除。`defaultFileList` 设置非受控初始列表；原生表单重置会中止上传并恢复该列表，受控状态由应用同步重置。

`name` 用于原生 `FormData`，与上传请求的 `fieldName` 不同：文件以同名字段提交，有 `originFile` 时提交该 `File`，否则提交 URL，两者均缺少时跳过该项。待上传、失败和取消的文件不会因状态自动排除；`required` 只要求列表非空，不代表上传成功。

`onRemove` 返回 `false` 或拒绝 Promise 时保留文件。

### AvatarUploadProps API

单张图片上传封装，默认 `accept="image/*"` 并自动上传，不显示文件列表或移除按钮。`children` 设置初始文案，`reuploadText` 设置重新上传文案。

请求、校验和表单参数沿用 [UploadProps](#uploadprops-api)。受控 `fileList` 最多包含一个文件，需在每次 `onChange` 中回写。

### UploadHandle

通过引用调用手动上传和取消操作。

| 方法 | 类型 | 说明 |
| --- | --- | --- |
| `upload` | `(uid?: string) => void` | 启动带 originFile 的待上传、失败或取消文件；省略 uid 时处理所有符合条件的文件。 |
| `abort` | `(uid?: string) => void` | 取消指定 uid 的请求并移出队列；省略 uid 时取消全部，不清空文件列表。 |
| `focus` | `() => void` | 聚焦上传控件。 |

### UploadFile API

描述上传列表中文件的标识、状态和元信息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | 必填 | 稳定且唯一的文件标识；上传和取消操作按 uid 定位文件。 |
| `url` | `string` | — | 文件地址；可用于下载或图片预览。 |
| `name` | `string` | — | 文件名，不是 FormData 字段名。 |
| `size` | `number` | — | 文件大小，单位为字节。 |
| `type` | `string` | — | 可选 MIME 类型；展示分类还会参考 originFile.type 和扩展名，不回填此字段。 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 当前上传状态。 |
| `percent` | `number` | — | 上传进度，范围为 0–100。 |
| `error` | `string` | — | 失败说明。 |
| `originFile` | `globalThis.File` | — | 实际上传的 File，可能是 beforeUpload 返回的替换文件。 |
| `response` | `unknown` | — | 服务端返回的原始数据。 |

### UploadChangeInfo API

文件列表变化时返回的当前文件与列表信息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | [`UploadFile`](#uploadfile-api) | — | 本次变化关联的文件；批量添加时为最后一个接收的文件。 |
| `reason` | `'add' \| 'progress' \| 'success' \| 'error' \| 'remove' \| 'cancel'` | 必填 | 变化原因。 |

### UploadRejection API

描述被拒绝文件及拒绝原因。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 必填 | 被拒绝的文件。 |
| `reason` | `'type' \| 'size' \| 'count' \| 'validation'` | 必填 | 拒绝原因。 |
| `message` | `string` | 必填 | 面向用户的拒绝说明。 |

### UploadRequest API

自定义上传请求接收的文件、进度与取消信息。`customRequest` 必须通过 `signal` 中止实际传输，用 `onProgress` 报告进度，成功时 resolve、失败时 reject。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 必填 | 待上传文件。 |
| `signal` | `AbortSignal` | 必填 | 取消信号；移除文件或卸载组件时也会触发。 |
| `onProgress` | `(percent: number) => void` | 必填 | 报告上传进度。 |

### UploadResult API

自定义请求完成后返回的文件地址等结果。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `url` | `string` | — | 上传后的文件地址。 |
| `name` | `string` | — | 上传后的文件名。 |
| `response` | `unknown` | — | 保留业务响应原文。 |

### FileItem API

文件展示字段见 [FileItem](file-list#fileitem-api)；UploadFile 在其基础上要求 uid，并增加 response。
