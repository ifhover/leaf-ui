## 使用说明

未配置 action 或 customRequest 时只选择文件，保持待上传状态，可由业务统一提交。action 使用 XMLHttpRequest 报告进度：POST 发送 FormData，PUT 发送文件本身。JSON 响应可提供 url 和 name；customRequest 可返回相同字段。选择和拖拽共用校验，上传支持取消、移除与重试；自定义请求须响应 signal。移除或卸载会取消请求并释放本地预览 URL。服务端仍需进行文件校验。

import type { UploadProps, UploadFile, UploadChangeInfo, UploadRejection, UploadRequest, UploadResult, FileItem } from '@sudden3/leaf-ui';

## UploadProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fileList / defaultFileList` | [`readonly UploadFile[]`](#uploadfile-api) | `[]` | 受控 / 初始文件列表 |
| `onChange` | [`(files: UploadFile[], info: UploadChangeInfo) => void`](#uploadchangeinfo-api) | — | 列表及上传状态变化 |
| `accept` | `string` | — | 允许的 MIME 或后缀，如 image/*,.pdf |
| `multiple / disabled / drag` | `boolean` | `false` | 多文件选择 / 禁用 / 拖拽区域 |
| `maxCount` | `number` | — | 允许的文件总数 |
| `maxSize` | `number` | — | 单个文件最大字节数 |
| `beforeUpload` | `(file: File) => boolean \| File \| Promise<boolean \| File>` | — | 上传前校验，false 拒绝，File 可转换文件 |
| `onReject` | [`(rejections: readonly UploadRejection[]) => void`](#uploadrejection-api) | — | 格式、大小、数量或校验拒绝 |
| `action` | `string \| ((file: File) => string \| Promise<string>)` | — | 上传地址，未配置时只选择文件 |
| `method` | `'POST' \| 'PUT'` | `'POST'` | POST 使用 FormData，PUT 上传文件本身 |
| `headers` | `Readonly<Record<string, string>>` | — | 请求头 |
| `data` | `Readonly<Record<string, string \| Blob>>` | — | POST 的额外表单数据 |
| `withCredentials` | `boolean` | `false` | 跨域发送凭证 |
| `fieldName` | `string` | `'file'` | POST 中的文件字段名 |
| `customRequest` | [`(request: UploadRequest) => Promise<UploadResult> \| Promise<void>`](#uploadrequest-api) | — | 自定义异步上传，配合 signal 取消 |
| `onRemove` | [`(file: UploadFile) => boolean \| void \| Promise<boolean> \| Promise<void>`](#uploadfile-api) | — | 移除前回调，返回 false 保留文件 |
| `showFileList` | `boolean` | `true` | 展示文件列表 |
| `hint / children` | `ReactNode` | — | 提示 / 选择按钮或拖拽区域标题 |

## UploadFile API

继承 [`FileItem`](#fileitem-api)，并增加以下字段。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | 必填 | 唯一标识 |
| `response` | `unknown` | — | 服务端返回的数据 |

## UploadChangeInfo API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | [`UploadFile`](#uploadfile-api) | — | 本次变化的文件 |
| `reason` | `'add' \| 'progress' \| 'success' \| 'error' \| 'remove' \| 'cancel'` | 必填 | 变化原因 |

## UploadRejection API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 必填 | 被拒绝的文件 |
| `reason` | `'type' \| 'size' \| 'count' \| 'validation'` | 必填 | 拒绝原因 |
| `message` | `string` | 必填 | 用户可读的说明 |

## UploadRequest API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | `File` | 必填 | 待上传文件 |
| `signal` | `AbortSignal` | 必填 | 取消信号，移除或卸载也会取消 |
| `onProgress` | `(percent: number) => void` | 必填 | 报告上传进度 |

## UploadResult API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `url / name` | `string` | — | 上传后的地址 / 名称 |
| `response` | `unknown` | — | 保留业务响应 |

## FileItem API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | — | 稳定标识，建议提供 |
| `url` | `string` | — | 文件地址 |
| `name` | `string` | — | 文件名称，默认取 URL 的文件名 |
| `size` | `number` | — | 字节数，可不提供；未提供时不显示大小 |
| `type` | `string` | — | MIME 类型，未提供时根据扩展名识别 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 上传状态，可不提供 |
| `percent` | `number` | — | 上传进度 0–100 |
| `error` | `string` | — | 失败说明 |
| `originFile` | `File` | — | 浏览器选择的原始文件 |
