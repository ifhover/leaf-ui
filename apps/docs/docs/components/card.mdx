## API

### Card API

卡片的标题、内容区域、内嵌标签页与加载状态配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 卡片标题。 |
| `description` | `ReactNode` | — | 标题下方的补充说明，仅默认外观支持；layered 不展示。 |
| `extra` | `ReactNode` | — | 标题旁的操作；没有标题时显示在标签栏右侧。 |
| `tabs` | [`CardTabsProps`](#cardtabs-api) | — | 内嵌标签页；无标题时替代标题栏，有标题时位于其下方。 |
| `cover` | `ReactNode` | — | 顶部封面。 |
| `footer` | `ReactNode` | — | 底部内容或操作；layered 展示在内容卡下方的外层区域。 |
| `loading` | `boolean` | `false` | 将正文和标签页内容替换为骨架屏；不会禁用标题、标签页或操作。 |
| `bordered` | `boolean` | `true` | 显示外轮廓；设为 `false` 移除边框。 |
| `shadow` | `boolean` | `true` | 显示卡片的静止阴影；分层卡片将其应用于内层内容面。 |
| `selected` | `boolean` | `false` | 标记选中外观，不提供选择交互；使用按钮或选择控件管理选中状态。 |
| `variant` | `'default' \| 'layered'` | `'default'` | 卡片外观；layered 将内容卡与外层标题、底部操作分层展示。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 卡片尺寸；内嵌标签页默认跟随此尺寸，其他子组件独立配置。 |

### CardTabs API

内嵌标签页的可用属性见 <a href="tabs.html#tabs-api" target="_blank" rel="noopener noreferrer">Tabs API</a>（新标签页打开）。Card 固定使用 `type="line"` 与 `placement="top"`，并为标签页内容接入加载骨架；`tabs.extra` 仍属于标签栏，`items` 为空时恢复普通卡片。

```ts
type CardTabsProps = Omit<TabsProps, 'type' | 'placement' | 'children'>;
```

### CardTitle API

支持原生标题属性，ref 指向实际标题元素。`ConfigProvider` 的 `components.CardTitle` 默认参数只影响直接使用的标题；Card 内部标题继续跟随 Card 的尺寸。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标题的视觉尺寸，与 Card 对应尺寸的标题一致。 |
| `description` | `ReactNode` | — | 标题下方的补充说明。 |
| `extra` | `ReactNode` | — | 标题右侧的附加操作。 |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `3` | 可选语义层级；默认与 Card 标题相同为 h3，不改变视觉尺寸。 |
| `containerProps` | `Omit<HTMLAttributes<HTMLDivElement>, 'children'>` | — | 标题区域外层容器的原生属性；heading 自身的属性、事件与 ref 仍直接应用于实际标题元素。 |
| `children` | `ReactNode` | — | 标题内容。 |
| `ref` | `Ref<HTMLHeadingElement>` | — | 标题元素引用。 |
