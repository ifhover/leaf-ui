## Card API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title / extra` | `ReactNode` | — | 标题 / 标题旁的内容 |
| `cover / footer` | `ReactNode` | — | 顶部封面 / 底部内容 |
| `children` | `ReactNode` | — | 卡片正文 |
| `loading` | `boolean` | `false` | 使用骨架屏替换正文 |
| `bordered / hoverable` | `boolean` | `true / false` | 显示外轮廓 / 悬停强调卡片 |
| `size` | `'sm' \| 'md'` | `'md'` | 内容间距 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { CardProps } from '@sudden3/leaf-ui';
```

## 使用说明

extra 和 footer 可以放置按钮或链接。hoverable 提供视觉反馈，需要点击操作时请使用明确的按钮或链接。
