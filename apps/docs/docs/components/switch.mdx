## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| checked / defaultChecked | boolean | — | 受控 / 非受控初始值 |
| onChange | `ChangeEventHandler<HTMLInputElement>` | — | 读取 event.target.checked |
| size | `'sm' \| 'md' \| 'lg'` | md | 容器最小高度 28 / 34 / 40px |
| loading | boolean | false | 显示加载状态，设置 aria-busy 并禁用交互 |
| disabled | boolean | false | 禁用交互 |
| children | ReactNode | — | 可点击的文字标签 |
| ref | `Ref<HTMLInputElement>` | — | 原生 checkbox 节点 |

支持 name、value、required、form 等原生属性。未开启或被禁用的开关不参与原生表单提交。没有文字时使用 aria-label；className 与 style 作用于标签容器。
