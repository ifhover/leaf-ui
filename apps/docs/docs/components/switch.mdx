## API

### Switch API

配置开关的选中状态、提交字段与交互状态。

支持 `name`、`value`、`required`、`form` 等原生 checkbox 属性。通过文字或 `aria-label` 提供名称；`className` 和 `style` 作用于标签容器。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 开关尺寸 |
| `loading` | `boolean` | `false` | 显示加载状态并禁用交互 |
| `checked` | `boolean` | — | 受控的开关状态。 |
| `defaultChecked` | `boolean` | — | 非受控模式的初始开关状态。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 event.target.checked 读取开关状态。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `children` | `ReactNode` | — | 可点击的文字标签。 |
| `ref` | `Ref<HTMLInputElement>` | — | 开关引用 |
