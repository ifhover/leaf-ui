# Tabs 标签页

在同一区域切换不同内容。

切换时正文和内容区域高度立即更新，不使用过渡动画。线形标签仅在选中项下方显示短圆角指示条，切换时指示条会移动到新的选中项。

线形标签使用正文色显示选中项、较淡的中性色显示未选中项，不绘制整条底边；选中项下方的短圆角指示条使用主题色。指示条贴着标签底边，高度随尺寸为 2 / 3 / 4px，标签在此基础上下方多留 4px，使文字与指示条之间保持可见的间距。卡片标签使用浅灰圆角选中底，未选中文字颜色进一步减淡，标签栏本身不再增加外层容器。分段标签增加浅灰圆角外轨，以白色移动滑块突出选中项，适合紧凑的视图切换；滑块使用不回弹的标准缓动直接移动到选中项。卡片与分段标签高度为 28 / 34 / 40px，线形标签为 32 / 38 / 44px。设置 `block` 可让标签等宽铺满，正文区域仍使用可用宽度。页签宽度溢出时，可按滚动方向显示描边箭头按钮；按钮仅在悬停标签栏或键盘聚焦时出现。

## Tabs API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`TabItem`](#tabitem)`[]` | 必填 | 标签页列表；为空时不渲染组件 |
| `activeKey` | `string` | 首个可用项 | 受控激活项 / 初始项 |
| `defaultActiveKey` | `string` | 首个可用项 | 受控激活项 / 初始项 |
| `onChange` | `(key: string) => void` | — | 激活项变化 |
| `type` | `'line' \| 'card' \| 'segmented'` | `'line'` | 标签形态 |
| `placement` | `'top' \| 'bottom'` | `'top'` | 标签栏位置 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签高度（线形 32 / 38 / 44px，卡片与分段 28 / 34 / 40px）与字号 |
| `block` | `boolean` | `false` | 标签等宽铺满可用宽度 |
| `activationMode` | `'automatic' \| 'manual'` | `'automatic'` | 方向键直接激活 / 回车或空格激活 |
| `destroyInactive` | `boolean` | `false` | 切走时卸载内容 |
| `extra` | `ReactNode` | — | 标签栏附加内容 |
| `onClose` | `(key: string, event: MouseEvent<HTMLButtonElement>) => void` | — | 请求关闭，由应用移除 items 中的项；可阻止默认切换 |
| `onAdd` | `() => void` | — | 添加页签，传入后显示添加按钮 |
| `addLabel` | `string` | — | 添加按钮的可访问名称 |
| `overflow` | `boolean` | `true` | 溢出时显示两侧滚动按钮 |
| `sortable` | `boolean` | `false` | 启用排序，配合 onReorder 使用 |
| `onReorder` | `(items: `[`TabItem`](#tabitem)`[]) => void` | — | 返回排序后的页签 |

## TabItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一标识 |
| `label` | `ReactNode` | 必填 | 标签名称 |
| `children` | `ReactNode` | — | 可选的面板内容；省略时只显示标签栏 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `icon` | `ReactNode` | — | 前置图标 |
| `closable` | `boolean` | `false` | 展示关闭按钮，需配合 onClose |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { TabsProps, TabItem } from '@ifhover/leaf-ui';
```

## 使用说明

内容首次访问时挂载，默认保留访问过的内容和输入状态。方向键会跳过禁用项，Home / End 跳至首尾；manual 模式适合内容切换需要等待的场景。
