## 浮层宽度

浮层默认与控件等宽（`popupWidth="trigger"`）。设置 `popupWidth="auto"` 仅按内容定宽，也可以比控件窄；`popupWidth={300}` 固定为 300px，也支持 CSS 长度。`popupMaxWidth` 默认未设置，下面的示例按内容定宽并显式设置最大宽度。浮层仍会在视口边缘避让。

## MentionOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 受控值。 |
| `label` | `ReactNode` | — | 展示文字或内容。 |
| `searchLabel` | `string` | — | 搜索时使用的纯文本。 |
| `disabled` | `boolean` | — | 禁用交互。 |

## Mentions API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `status` | `'error' \| 'warning'` | — | 设置 status。 |
| `resize` | `'none' \| 'vertical' \| 'both'` | `'vertical'` | 设置 resize。 |
| `autoSize` | `boolean \| `[`TextareaAutoSize`](textarea#textareaautosize-api) | `false` | 设置 autoSize。 |
| `showCount` | `boolean \| ((value: string, maxLength?: number) => ReactNode)` | `false` | 设置 showCount。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `value` | `string` | — | 受控值。 |
| `defaultValue` | `string` | `''` | 初始值；非受控模式支持表单重置。 |
| `onChange` | `(value: string) => void` | — | 值发生变化时调用。 |
| `onSearch` | `(query: string, prefix: string) => void` | — | 搜索文字改变时调用。 |
| `onSelect` | `(option: `[`MentionOption`](#mentionoption)`, prefix: string) => void` | — | 条目被选择时调用。 |
| `options` | `readonly `[`MentionOption`](#mentionoption)`[]` | 必填 | 可供选择的选项。 |
| `prefixes` | `readonly string[]` | — | 可触发建议的文本前缀。 |
| `split` | `string` | `' '` | 插入引用后追加的分隔文字。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `notFoundContent` | `ReactNode` | — | 没有匹配选项时的内容。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { MentionOption, MentionsProps } from '@ifhover/leaf-ui';
```

建议列表支持方向键与 Enter 选择；输入框保持可聚焦，并跟随 ConfigProvider 的主题和减少动画设置。
