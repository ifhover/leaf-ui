## API

### QRCodeProps API

配置编码内容、二维码状态和下载操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 二维码编码的文本或链接。 |
| `size` | `number` | `160` | 正方形二维码的像素尺寸，最小 64。 |
| `status` | `'active' \| 'loading' \| 'expired'` | `'active'` | 展示正常、加载或过期状态；不自动加载或计算过期时间。 |
| `onRefresh` | `() => void` | — | 点击过期状态的刷新按钮时调用；应用负责更新 value 和 status。 |
| `downloadable` | `boolean` | `false` | 显示下载操作，导出 SVG 文件。 |
| `fileName` | `string` | `'qrcode.svg'` | 下载文件名，包含扩展名。 |
| `level` | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` | 二维码纠错等级 |
| `logo` | `string` | — | 中央标志地址 |
| `logoSize` | `number` | `32` | 中央标志尺寸 |
| `color` | `string` | `'var(--leaf-color-text)'` | 颜色 |
| `backgroundColor` | `string` | `'var(--leaf-color-surface)'` | 背景颜色 |
