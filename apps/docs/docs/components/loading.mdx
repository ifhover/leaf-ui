# Loading 加载

提示内容正在加载或操作正在进行。

### 区域加载

传入 `children` 后覆盖内容区域，加载层可见时阻止子内容交互。通过 `spinning` 控制加载状态，使用 `tip` 补充提示。

<ComponentExample exampleId="overlay" preview={<LoadingOverlay />} fileName="overlay.tsx">

```tsx lineNumbers file="../../src/examples/loading/overlay.tsx"
```

</ComponentExample>

### 延迟显示

经过 `delay` 毫秒后，若 `spinning` 仍为 `true`，才显示加载提示；在此之前结束加载则不显示。

`delay` 不会延迟请求，也不会在等待期间阻止内容交互。需要立即禁用的操作应单独处理。

```tsx lineNumbers file="../../src/examples/loading/delay.tsx"
```

</ComponentExample>

## API

### Loading API

加载状态、提示内容与延迟显示的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `spinning` | `boolean` | `true` | 是否加载中 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 图标尺寸 |
| `tip` | `ReactNode` | — | 提示文字 |
| `delay` | `number` | `0` | 延迟显示，单位毫秒 |
| `children` | `ReactNode` | — | 被加载遮罩覆盖的内容。 |
