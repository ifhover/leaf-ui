## Loading API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `spinning` | `boolean` | `true` | 是否加载中 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 图标尺寸 |
| `tip` | `ReactNode` | — | 提示文字 |
| `delay` | `number` | `0` | 延迟显示，单位毫秒 |
| `children` | `ReactNode` | — | 覆盖的内容 |


## 类型

可导入以下类型定义属性、组装数据或处理回调。

```ts
import type { LoadingProps } from '@sudden3/leaf-ui';
```

## 使用说明

独立使用展示加载提示；传入 `children` 后覆盖所在区域，并在显示加载层时阻止操作。`delay` 可避免短暂请求造成闪现。
