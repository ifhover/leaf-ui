## Select API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | [`ControlSize`](#controlsize) | `'md'` | 选择器尺寸 |
| `status` | [`ControlStatus`](#controlstatus) | — | 校验状态 |
| `options` | [`readonly SelectOption[]`](#selectoption) | 必填 | 选项列表 |
| `placeholder` | `string` | `'请选择'` | 未选择时的提示文字 |
| `value` / `defaultValue` | `string` | `''` | 受控值 / 非受控初始值 |
| `onChange` | [`(value: string, option?: SelectOption) => void`](#selectoption) | — | 返回值与选项；清除时返回空字符串和 `undefined` |
| `allowClear` | `boolean` | `false` | 展示清除按钮 |
| `disabled` | `boolean` | `false` | 禁用整个选择器 |
| `name` / `form` | `string` | — | 字段名 / 关联的表单 ID |
| `required` | `boolean` | `false` | 要求选择一项 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开或收起选项面板 |
| `ref` | `Ref<HTMLButtonElement>` | — | 触发按钮引用 |

支持 name、required、form 和非受控表单 reset；其余原生 button 属性及 aria-* 透传至触发按钮。className 与 style 作用于外层容器。选项 value 应唯一，不要将空字符串用作业务选项值。

## 类型

[`SelectProps`](#select-api) 用于定义组件属性。单独组装选项列表时，可以使用 [`SelectOption`](#selectoption)：

```ts
import type { SelectProps, SelectOption, ControlSize, ControlStatus } from '@sudden3/leaf-ui';

const options: SelectOption[] = [
  { label: '设计团队', value: 'design' },
  { label: '研发团队', value: 'engineering' },
];
```

### SelectOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 唯一选项值，不能使用空字符串 |
| `label` | `ReactNode` | 必填 | 选项内容，可以是文字或 React 节点 |
| `disabled` | `boolean` | `false` | 禁用该选项 |

### ControlSize

| 值 | 说明 |
| --- | --- |
| `'sm'` | 小尺寸 |
| `'md'` | 中尺寸，默认值 |
| `'lg'` | 大尺寸 |

### ControlStatus

| 值 | 说明 |
| --- | --- |
| `'error'` | 错误状态 |
| `'warning'` | 警告状态 |

未设置 `status` 时使用默认外观。

## 使用说明

为选择器提供 label 或 aria-label。FormData 提交选项的字符串 value，清除后为空字符串；受控组件的表单重置需同步重置自己的状态。

Enter、空格或方向键打开面板，↑ / ↓ 移动高亮并跳过禁用选项，Home / End 跳至首尾，Enter 或空格确认。Escape 收起，Tab 继续访问后续控件。点击外部或移走焦点会收起。

浮层随页面滚动定位，并在视口边缘避让；长列表可滚动。当前提供单选，适用于选项数量适中的场景。
