# Select 选择器

从给定选项中选择一项。默认高度 **34px**，与 Button、Input 对齐。使用浏览器原生选择菜单，保留键盘、触屏和表单能力。

## 基础选择

通过 options 传入选项；placeholder 在空值时提示选择，单个选项可以禁用。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `md` | 共用尺寸；单行控件为 28 / 34 / 40px |
| `status` | `'error' \| 'warning'` | — | 校验状态；error 同时设置 aria-invalid |
| options | readonly SelectOption[] | 必填 | 每项包含字符串 label、value 和可选 disabled |
| placeholder | string | — | 空值占位项；保留空字符串作为未选择值 |
| value / defaultValue | 原生 select 属性 | — | 受控值 / 非受控初始值 |
| onChange | `ChangeEventHandler<HTMLSelectElement>` | — | 读取 event.target.value |
| disabled | boolean | false | 禁用整个选择器 |
| ref | `Ref<HTMLSelectElement>` | — | 原生 select 节点 |

其余原生单选属性（name、required、form、autoFocus 等）直接透传。className 与 style 作用于外层容器。选项 value 应唯一；带 placeholder 时不要将空字符串用作业务选项值。

## 使用说明

为选择器提供 label 或 aria-label。弹出菜单的外观和打开方式由浏览器与操作系统控制，主题变量作用于闭合状态的组件。当前提供基础单选，适用于选项数量较少的场景。
