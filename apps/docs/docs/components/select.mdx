# Select 选择器

用于从下拉列表中选择一项或多项。展开时只加深现有的中性边框，不添加主题色外圈；已选中选项使用灰色背景、正文色和勾选标记。

| `onCreate` | `(option: `[`SelectOption`](#selectoption)`) => void` | — | 新选项创建回调 |

支持 name、required、form 和非受控表单 reset；其余原生 input 属性及 aria-* 透传至输入框。className 与 style 作用于外层容器。选项 value 应唯一，不要将空字符串用作业务选项值。

## 类型

[`SelectProps`](#select-api) 用于定义组件属性。单独组装选项列表时，可以使用 [`SelectOption`](#selectoption)：

```ts
import type { SelectProps, SelectOption, ControlSize, ControlStatus } from '@ifhover/leaf-ui';

const options: SelectOption[] = [
  { label: '设计团队', value: 'design' },
  { label: '研发团队', value: 'engineering' },
];
```

### SelectOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |

| `label` | `ReactNode` | 必填 | 选项内容，可以是文字或 React 节点。 |
| `disabled` | `boolean` | `false` | 禁用该选项。 |
| `searchLabel` | `string` | — | 复杂 label 的搜索纯文本；省略时使用可读文字或 value。 |

## 使用说明

为选择器提供 label 或 aria-label。FormData 提交选项的字符串 value，清除后为空字符串；受控组件的表单重置需同步重置自己的状态。

Enter、空格或方向键打开面板，↑ / ↓ 移动高亮并跳过禁用选项，Home / End 跳至首尾，Enter 或空格确认。Escape 收起，Tab 继续访问后续控件。点击外部或移走焦点会收起。

浮层随页面滚动定位，并在视口边缘避让；长列表可滚动。选项之间没有额外空隙，默认行高与 Select 本体一致（舒适 34px、紧凑 30px）；文字超出可用宽度时自然换行并增高。切换选中项时，框内文字直接更新，不播放位移动画。支持单选、多选及搜索，适用于选项数量适中的场景。

多选清除返回 `[]`；FormData 在同一个 name 下提交多个值，通过 `formData.getAll(name)` 读取。搜索文字为空时，Backspace 移除最后一个可用标签。离开控件会清空搜索文字，默认不创建选项；设置 allowCreate 可创建未匹配的选项。label 为 React 节点时，用 searchLabel 指定搜索文字。ref 与原生 input 属性作用于输入框。

控件保持页面中的布局宽度，浮层默认与控件等宽（`popupWidth="trigger"`）。设置 `popupWidth="auto"` 后，浮层仅按选项内容定宽，也可以比控件窄；通过 `popupWidth={300}` 固定为 300px，或传入 CSS 长度。`popupMaxWidth` 默认未设置，可按需指定最大宽度；所有宽度模式仍受可用视口宽度限制，内容超出实际浮层宽度时换行。
