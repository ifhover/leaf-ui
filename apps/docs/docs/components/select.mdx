# Select 选择器

从平铺选项中选择一项或多项；层级选项使用 [TreeSelect](tree-select)。

## API

### Select API

Select 的组件参数。

`name`、`required`、`form` 与非受控重置参与[表单](form)接入；其余原生 input 属性及 `aria-*` 传递给输入框，`className` 与 `style` 作用于外层容器。共享浮层参数见 [PopupOptions](../api/popup-options)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly (`[`SelectOption`](#selectoption)` \| `[`SelectOptionGroup`](#selectoptiongroup-api)`)[]` | 必填 | 选项列表 |
| `value` | `string \| readonly string[]` | — | 受控值；省略时使用内部非受控值。 |
| `defaultValue` | `string \| readonly string[]` | `multiple ? [] : ''` | 非受控初始值；单选默认为空字符串，多选默认为空数组，表单重置时恢复。 |
| `onChange` | `((value: string, option?: `[`SelectOption`](#selectoption)`) => void) \| ((value: string[], options: `[`SelectOption`](#selectoption)`[]) => void)` | — | 单选返回值和选项，清除时为 '' 和 undefined；多选返回值数组和选项数组，清除时均为空数组。 |
| `multiple` | `false \| true` | `false` | 多选时值为数组，默认 [] |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 选择器尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `allowClear` | `boolean` | `false` | 展示清除按钮 |
| `showSearch` | `boolean` | `false` | 允许输入搜索选项 |
| `filterOption` | `boolean \| ((query: string, option: `[`SelectOption`](#selectoption)`) => boolean)` | `true` | 自定义筛选，false 用于外部筛选 |
| `onSearch` | `(query: string) => void` | — | 搜索文字变化 |
| `loading` | `boolean` | `false` | 加载提示 |
| `notFoundContent` | `ReactNode` | — | 没有选项时的内容 |
| `maxCount` | `number` | — | 多选数量上限，已选项可继续取消 |
| `maxTagCount` | `number \| 'responsive'` | — | 最多展示的标签数；responsive 根据可用宽度自动折叠。 |
| `tagWrap` | `boolean` | `true` | 允许多选标签换行；false 单行显示并自动折叠溢出项。 |
| `allowCreate` | `boolean` | `false` | 允许选择新建项；查询文字与已有 value 或搜索文字完全相同时不出现新建项，同时启用搜索。 |
| `onCreate` | `(option: `[`SelectOption`](#selectoption)`) => void` | — | 选择新建项后返回该选项；组件内部保留它，需要持久保存时由应用更新 options。 |
| `labelRender` | `(option: `[`SelectOption`](#selectoption)`) => ReactNode` | — | 自定义选中值的展示。 |
| `optionRender` | `(option: `[`SelectOption`](#selectoption)`) => ReactNode` | — | 自定义选项内容 |
| `tagRender` | `(option: `[`SelectOption`](#selectoption)`, remove: () => void) => ReactNode` | — | 自定义选中标签；通过 remove 请求移除。 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | `false` | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开或收起选项面板 |
| `inputReadOnly` | `boolean` | — | 只禁止手动输入，仍可在面板中选择。 |
| `virtual` | `boolean` | 选项超过 100 时启用 | 仅渲染可见项目 |
| `listHeight` | `number` | `248` | 列表高度 |
| `optionHeight` | `number` | 由主题和密度计算 | 虚拟列表的预估行高；默认由主题和密度计算，实际行会被测量。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `onPopupScroll` | `(event: React.UIEvent<HTMLDivElement>) => void` | — | 浮层滚动事件，可用来加载下一页。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层样式 |
| `popupStyle` | `CSSProperties` | — | 浮层样式 |
| `popupRender` | `(content: ReactNode) => ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |

### SelectOption

通过 options 传入的选项；value 用于标识选项。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 唯一选项值；不能使用空字符串。 |
| `label` | `ReactNode` | 必填 | 选项内容，可以是文字或 React 节点。 |
| `disabled` | `boolean` | `false` | 禁用该选项。 |
| `searchLabel` | `string` | — | 搜索纯文本；省略时使用字符串或数字 label，其他内容使用 value。 |

### SelectOptionGroup API

包含分组标题和选项列表的选项分组。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | 必填 | 展示文字或内容。 |
| `options` | `readonly `[`SelectOption`](#selectoption)`[]` | 必填 | 可供选择的选项。 |
