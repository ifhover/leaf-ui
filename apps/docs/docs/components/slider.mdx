## Slider API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `min` | `number` | `0` | 范围与步长 |
| `max` | `number` | `100` | 范围与步长 |
| `step` | `number \| null` | `1` | 范围与步长 |
| `marks` | `readonly `[`SliderMark`](#slidermark)`[]` | `[]` | 刻度列表 |
| `vertical` | `boolean` | `false` | 使用垂直布局 |
| `showValue` | `boolean` | `false` | 悬停或聚焦时在右上方显示数值，默认隐藏 |
| `onChangeComplete` | `(value: number \| readonly [number, number]) => void` | — | 拖动或键盘操作完成后触发 |
| `tooltip` | `boolean \| { formatter?: (value: number) => ReactNode }` | `false` | 显示滑块提示，可定制数值格式。 |
| `range` | `false \| true` | `false` | 区间选择 |
| `value` | `number \| readonly [number, number]` | 必填 | 刻度位置 |
| `defaultValue` | `number \| readonly [number, number]` | `[min, max]` | 受控 / 初始数值，区间为二元数组 |
| `onChange` | `((value: number) => void) \| ((value: [number, number]) => void)` | — | 数值变化，回调类型由 range 决定 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |

### SliderMark

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number` | 必填 | 刻度位置 |
| `label` | `ReactNode` | — | 刻度文字 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { SliderProps, SliderMark } from '@sudden3/leaf-ui';
```

## 使用说明

方向键调整数值，Home / End 跳至边界，Shift + 方向键和 PageUp / PageDown 调整十个步长。区间的两个端点不会互相穿越。表单中 range 使用同一个 name 提交两个值，可用 FormData.getAll 读取，并支持表单 reset。

## SliderMark

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number` | — | 必需。受控值。 |
| `label` | `ReactNode` | — | 展示文字或内容。 |
