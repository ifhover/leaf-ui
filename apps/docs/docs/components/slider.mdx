### 受控值与操作完成

`onChange` 随数值变化触发，单值返回数字，区间返回二元数组。`onChangeComplete` 在操作结束且数值发生过变化后触发，可用于保存最终值。重置受控字段时，应用需同步恢复 `value`。

#### 表单与键盘

设置 `name` 可参与原生表单提交；区间以同一个字段名提交两个值，用 `FormData.getAll` 读取。非受控字段随表单重置恢复初始值，表单接入见 [Form](/components/form)。

方向键按步长调整，Home / End 跳至边界；Shift + 方向键和 PageUp / PageDown 调整十个步长。离散模式按相邻刻度调整。

## API

### Slider API

配置单值或区间值、数值范围和滑动交互。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `min` | `number` | `0` | 最小值，默认 0。 |
| `max` | `number` | `100` | 最大值，默认 100。 |
| `step` | `number \| null` | `1` | 每次调整的步长；null 时只允许选择 marks 中的值。 |
| `marks` | `readonly `[`SliderMark`](#slidermark)`[]` | `[]` | 刻度列表 |
| `vertical` | `boolean` | `false` | 使用垂直布局 |
| `showValue` | `boolean` | `false` | 悬停或聚焦时在右上方显示数值，默认隐藏 |
| `onChangeComplete` | `(value: number \| readonly [number, number]) => void` | — | 操作结束且数值发生过变化后触发；单值返回数字，区间返回二元数组。 |
| `tooltip` | `boolean \| { formatter?: (value: number) => ReactNode }` | `false` | 显示滑块提示，可定制数值格式。 |
| `range` | `false \| true` | `false` | 区间选择 |
| `value` | `number \| readonly [number, number]` | — | 受控数值。 |
| `defaultValue` | `number \| readonly [number, number]` | `range ? [min, max] : min` | 非受控模式的初始数值；单值默认为 min，区间默认为 [min, max]。 |
| `onChange` | `((value: number) => void) \| ((value: [number, number]) => void)` | — | 数值变化，回调类型由 range 决定 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |

### SliderMark

在指定数值位置显示刻度与标签。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number` | 必填 | 刻度数值。 |
| `label` | `ReactNode` | — | 刻度显示内容。 |
