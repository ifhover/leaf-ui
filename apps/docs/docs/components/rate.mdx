#### 表单与键盘

使用 `FormField` 提供字段名称，设置 `name` 参与 FormData 提交；清空时提交空字符串。非受控评分支持表单重置，设置 `required` 可要求非零评分。表单接入见 [Form](/components/form)。

方向键调整评分，Home / End 跳至首尾，允许清除时可用 Delete / Backspace 清空。

## API

### Rate API

配置评分值、步进精度以及只读和清除行为。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number` | — | 受控评分。 |
| `defaultValue` | `number` | `0` | 非受控模式的初始评分。 |
| `onChange` | `(value: number) => void` | — | 评分变化时返回新值，清空为 0。 |
| `count` | `number` | `5` | 星星数量，最多 20 |
| `allowHalf` | `boolean` | `false` | 允许按半星选择。 |
| `allowClear` | `boolean` | `true` | 重复选择当前评分时清空为 0。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 禁止修改评分，仍参与表单提交。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 星星尺寸 |
| `color` | `string` | — | 固定评分颜色，优先于 colorByValue；均未设置时使用金色。 |
| `colorByValue` | `boolean` | `false` | 按分数比例使用低、中、高档颜色 |
| `colors` | `readonly [string, string, string]` | `['#ef5350', '#f49b23', '#ffc53d']` | 低、中、高档颜色；阈值为总分的 40% 和 70% |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | `false` | 要求评分不为 0。 |
