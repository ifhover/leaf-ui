## Rate API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value / defaultValue` | `number` | `0` | 受控 / 初始评分 |
| `onChange` | `(value: number) => void` | — | 评分变化 |
| `count` | `number` | `5` | 星星数量，最多 20 |
| `allowHalf / allowClear` | `boolean` | `false / true` | 半星 / 重复点击清除 |
| `readOnly / disabled` | `boolean` | `false` | 只读 / 禁用 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 星星尺寸 |
| `color` | `string` | `'#ffc53d'` | 固定星星颜色；优先于按分数变色 |
| `colorByValue` | `boolean` | `false` | 按分数比例使用低、中、高档颜色 |
| `colors` | `readonly [string, string, string]` | — | 低、中、高档颜色；阈值为总分的 40% 和 70% |
| `name / form` | `string` | — | 字段名 / 关联表单 |
| `required` | `boolean` | `false` | 需要非零评分 |

## 使用说明

悬停可预览评分和颜色，离开恢复已选值。方向键调整评分，Home / End 跳至首尾，Delete / Backspace 可清除。只读保留展示，禁用也会阻止交互。支持 FormData 和非受控表单 reset。
