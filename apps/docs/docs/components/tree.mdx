## Tree API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | [`readonly TreeNode[]`](#treenode) | 必填 | 树节点 |
| `selectedKeys / defaultSelectedKeys` | `readonly string[]` | `[]` | 受控 / 初始选中节点 |
| `onSelect` | [`(keys: string[], info: TreeSelectInfo) => void`](#treeselectinfo) | — | 选择变化 |
| `multiple / selectable` | `boolean` | `false / true` | 多选 / 允许选择 |
| `checkedKeys / defaultCheckedKeys` | `readonly string[]` | `[]` | 受控 / 初始勾选节点 |
| `onCheck` | [`(keys: string[], info: TreeCheckInfo) => void`](#treecheckinfo) | — | 勾选变化，包含联动结果 |
| `checkable / checkStrictly` | `boolean` | `false / false` | 展示复选框 / 禁止父子联动 |
| `expandedKeys / defaultExpandedKeys` | `readonly string[]` | `[]` | 受控 / 初始展开节点 |
| `defaultExpandAll` | `boolean` | `false` | 初始展开全部节点 |
| `onExpand` | [`(keys: string[], info: TreeExpandInfo) => void`](#treeexpandinfo) | — | 展开变化 |
| `disabled / showIcon / showLine` | `boolean` | `false` | 禁用操作 / 显示图标 / 显示层级线 |
| `searchValue` | `string` | `''` | 过滤节点，保留匹配项和祖先 |
| `filterTreeNode` | [`(node: TreeNode, query: string) => boolean`](#treenode) | — | 自定义搜索规则 |
| `notFoundContent` | `ReactNode` | 暂无选项 | 无匹配内容 |

## TreeNode

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `key` | `string` | 唯一标识，必填 |
| `title` | `ReactNode` | 节点内容，必填 |
| `children` | [`readonly TreeNode[]`](#treenode) | 子节点；使用同一结构 |
| `disabled` | `boolean` | 禁止选择与勾选，仍可浏览子节点 |
| `selectable / checkable` | `boolean` | 该节点能否选择 / 是否展示复选框，默认可用 |
| `disableCheckbox` | `boolean` | 禁止勾选并阻断父子勾选联动 |
| `icon` | `ReactNode` | 自定义图标 |
| `searchLabel` | `string` | 标题为节点时提供用于搜索和读屏的文字 |

## TreeSelectInfo

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 本次操作节点 |
| `selected` | `boolean` | 操作后是否选中 |
| `selectedNodes` | [`readonly TreeNode[]`](#treenode) | 全部选中节点 |

## TreeCheckInfo

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 本次操作节点 |
| `checked` | `boolean` | 操作后是否勾选 |
| `checkedNodes` | [`readonly TreeNode[]`](#treenode) | 完整勾选节点 |
| `halfCheckedKeys` | `readonly string[]` | 半选节点标识 |

## TreeExpandInfo

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 本次操作节点 |
| `expanded` | `boolean` | 操作后是否展开 |

## 类型

```ts
import type { TreeProps, TreeNode, TreeSelectInfo, TreeCheckInfo, TreeExpandInfo } from '@sudden3/leaf-ui';
```

## 使用说明

每个节点的 `key` 应唯一且稳定。示例数据结构：

```ts lineNumbers file="../../src/examples/tree/data.ts"
```

勾选父节点会勾选可用子节点，禁用节点不会被联动修改。子节点部分选中时父节点呈半选；`checkStrictly` 让各节点独立勾选。多选时点击切换选择，Shift 可连续选择可见节点。

方向键上下移动，左右展开或收起，Home / End 跳至首尾，Enter 选择，空格勾选。输入文字可快速定位节点。搜索时会暂时展开匹配路径，清空后恢复原展开状态。
