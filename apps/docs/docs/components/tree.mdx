## 使用说明

每个节点的 `key` 应唯一且稳定。示例数据结构：

```ts lineNumbers file="../../src/examples/tree/data.ts"
```

勾选父节点会勾选可用子节点，禁用节点不会被联动修改。子节点部分选中时父节点呈半选；`checkStrictly` 让各节点独立勾选。多选时点击切换选择，Shift 可连续选择可见节点。

方向键上下移动，左右展开或收起，Home / End 跳至首尾，Enter 选择，空格勾选。输入文字可快速定位节点。搜索时会暂时展开匹配路径，清空后恢复原展开状态。

## moveTreeNode

需要自行调整树数据时可导入此纯函数。返回新树，不修改原数据；目标不存在、移动到自身或后代节点时返回 `null`。Tree 的 `onDrop` 已直接提供调整后的 data。

```ts
import { moveTreeNode } from '@sudden3/leaf-ui';

const next = moveTreeNode(data, 'design', 'team', 'inside');
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | [`readonly TreeNode[]`](#treenode) | 原始树数据 |
| `key` | `string` | 待移动的节点 key |
| `target` | `string` | 目标节点 key |
| `position` | `'before' \| 'inside' \| 'after'` | 相对目标的放置位置 |
| 返回值 | [`TreeNode[] \| null`](#treenode) | 新的树；无法移动时返回 null |
