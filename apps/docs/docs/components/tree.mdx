# Tree 树

按层级浏览、选择或勾选内容。

## 示例

### 多选

`multiple` 模式下，点击切换单个节点的选择，不需要按住 Ctrl。先选择一个节点，再按住 Shift 选择另一个节点，可连续选择两者之间的可见节点；禁用和不可选节点会被跳过。

<ComponentExample exampleId="multiple" preview={<TreeMultiple />} fileName="multiple.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/tree/multiple.tsx"
```

</ComponentExample>

### 父子勾选联动

`checkable` 启用复选框，父子节点默认联动。`onCheck` 返回全部完整勾选的节点，半选节点通过 `info.halfCheckedKeys` 返回；禁用节点不会被联动修改。

<ComponentExample exampleId="checkable" preview={<TreeCheckable />} fileName="checkable.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/tree/checkable.tsx"
```

</ComponentExample>

### 独立勾选

`checkStrictly` 让各节点独立勾选，勾选父节点不改变子节点。`checkedKeys` 与行选择的 `selectedKeys` 分别控制。

### 拖动节点

`draggable` 启用手柄，`onDrop` 返回调整后的树，由应用更新 `data`。拖到目标行的上方、中央或下方，分别放在目标之前、内部或之后。

键盘操作手柄时，空格开始或放置，上下选择目标，左 / 右选择前方 / 后方，Escape 取消。

<ComponentExample exampleId="drag" preview={<TreeDrag />} fileName="drag.tsx" width={360}>


</ComponentExample>

### 异步加载

展开没有 `children` 且未标记为叶子的节点时，`loadData` 返回其子节点。此例第一次请求失败，`onLoadError` 显示提示；收起后重新展开即可重试。

保持 `data` 和 `loadData` 的引用稳定，并响应 `AbortSignal`。更换数据、加载函数、`cacheKey` 或卸载时会取消旧请求；收起节点不会取消。

</ComponentExample>

## API

### Tree API

配置树数据、选择、勾选、展开和拖放行为。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly `[`TreeNode`](#treenode)`[]` | 必填 | 树节点 |
| `selectedKeys` | `readonly string[]` | — | 受控的选中节点 key 列表。 |
| `defaultSelectedKeys` | `readonly string[]` | `[]` | 非受控模式的初始选中节点 key 列表。 |
| `onSelect` | `(keys: string[], info: `[`TreeSelectInfo`](#treeselectinfo)`) => void` | — | 选择变化时返回选中 key 与节点信息；单选再次激活当前节点可取消选择。 |
| `multiple` | `boolean` | `false` | 是否支持多选。 |
| `selectable` | `boolean` | `true` | 是否启用行选择。 |
| `checkable` | `boolean` | `false` | 是否展示复选框。 |
| `checkStrictly` | `boolean` | `false` | 勾选时不联动父子节点；配合 checkable 使用。 |
| `checkedKeys` | `readonly string[]` | — | 受控的勾选节点 key 列表。 |
| `defaultCheckedKeys` | `readonly string[]` | `[]` | 非受控模式的初始勾选节点 key 列表。 |
| `onCheck` | `(keys: string[], info: `[`TreeCheckInfo`](#treecheckinfo)`) => void` | — | 返回完整勾选 key 与节点信息；半选 key 位于 info.halfCheckedKeys。 |
| `expandedKeys` | `readonly string[]` | — | 受控的展开节点 key 列表。 |
| `defaultExpandedKeys` | `readonly string[]` | `[]` | 非受控模式的初始展开节点 key 列表。 |
| `defaultExpandAll` | `boolean` | `false` | 初始展开全部节点 |
| `onExpand` | `(keys: string[], info: `[`TreeExpandInfo`](#treeexpandinfo)`) => void` | — | 展开变化 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `showLine` | `boolean` | `false` | 显示节点之间的层级连接线。 |
| `showIcon` | `boolean` | `false` | 显示默认文件夹或文件图标；节点自定义 icon 不受此开关影响。 |
| `searchValue` | `string` | `''` | 过滤节点，保留匹配项和祖先 |
| `filterTreeNode` | `(node: `[`TreeNode`](#treenode)`, query: string) => boolean` | — | 自定义搜索规则 |
| `notFoundContent` | `ReactNode` | 暂无选项 | 无匹配内容 |
| `loadData` | `(node: `[`TreeNode`](#treenode)`, signal: AbortSignal) => Promise<readonly `[`TreeNode`](#treenode)`[]>` | — | 展开时加载子项，signal 用于取消 |
| `onLoad` | `(node: `[`TreeNode`](#treenode)`, children: readonly `[`TreeNode`](#treenode)`[]) => void` | — | 子项加载成功 |
| `onLoadError` | `(error: unknown, node: `[`TreeNode`](#treenode)`) => void` | — | 加载失败，再次展开可重试 |
| `cacheKey` | `string \| number` | — | 数据版本改变时清空懒加载缓存，并取消旧请求。 |
| `nodeRender` | `(node: `[`TreeNode`](#treenode)`) => ReactNode` | — | 自定义节点展示内容。 |
| `draggable` | `boolean \| ((node: `[`TreeNode`](#treenode)`) => boolean)` | `false` | 允许通过手柄移动节点 |
| `allowDrop` | `(info: Omit<`[`TreeDropInfo`](#treedropinfo-api)`, 'data'>) => boolean` | — | 限制放置位置 |
| `onDrop` | `(info: `[`TreeDropInfo`](#treedropinfo-api)`) => void` | — | 返回放置位置和新树数据，应用须将 info.data 写回 data。 |
| `virtual` | `boolean` | `false` | 仅渲染可视节点；大量节点时建议启用。 |
| `height` | `number` | `320` | 虚拟列表的可视高度，仅 virtual 开启时生效。 |
| `itemHeight` | `number` | 由主题和密度计算 | 虚拟列表的预估行高；默认由主题和密度计算，实际行会被测量。 |

### TreeNode

描述树节点的稳定标识、内容和子节点。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一标识，必填 |
| `title` | `ReactNode` | 必填 | 节点内容，必填 |
| `children` | `readonly `[`TreeNode`](#treenode)`[]` | — | 子节点；使用同一结构 |
| `icon` | `ReactNode` | — | 自定义图标 |
| `disabled` | `boolean` | — | 禁止选择、勾选和拖动该节点，但仍可展开。 |
| `selectable` | `boolean` | — | 该节点是否可选，默认可用。 |
| `checkable` | `boolean` | — | Tree 开启 checkable 时，设为 false 隐藏该节点复选框并阻断联动。 |
| `disableCheckbox` | `boolean` | — | 禁止勾选并阻断父子勾选联动 |
| `searchLabel` | `string` | — | 标题为节点时提供用于搜索和读屏的文字 |
| `isLeaf` | `boolean` | — | true 标记为叶子节点，不请求异步子项；已提供 children 的节点也不请求。 |

### TreeSelectInfo

选择节点时返回的操作节点及选择结果。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 必填 | 本次操作节点 |
| `selected` | `boolean` | 必填 | 操作后是否选中 |
| `selectedNodes` | `readonly `[`TreeNode`](#treenode)`[]` | 必填 | 全部选中节点 |

### TreeCheckInfo

勾选节点时返回的操作节点、勾选和半选结果。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 必填 | 本次操作节点 |
| `checked` | `boolean` | 必填 | 操作后是否勾选 |
| `checkedNodes` | `readonly `[`TreeNode`](#treenode)`[]` | 必填 | 完整勾选节点 |
| `halfCheckedKeys` | `readonly string[]` | 必填 | 半选节点标识 |

### TreeExpandInfo

展开或收起节点时返回的操作信息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 必填 | 本次操作节点 |
| `expanded` | `boolean` | 必填 | 操作后是否展开 |

### TreeDropInfo API

拖放节点后返回的目标、位置和更新数据。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `node` | [`TreeNode`](#treenode) | 必填 | 操作节点 |
| `target` | [`TreeNode`](#treenode) | 必填 | 接收拖放的目标节点。 |
| `position` | `'before' \| 'inside' \| 'after'` | 必填 | 放在目标节点之前、内部或之后。 |
| `data` | [`TreeNode`](#treenode)`[]` | 必填 | 层级数据 |

### moveTreeNode

需要自行调整树数据时可使用此纯函数。返回新树，不修改原数据；目标不存在、移动到自身或后代节点时返回 `null`。`Tree` 的 `onDrop` 已直接提供调整后的数据。

```ts
import { moveTreeNode } from '@ifhover/leaf-ui';

const next = moveTreeNode(data, 'design', 'archive', 'inside');
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `data` | [`readonly TreeNode[]`](#treenode) | 原始树数据 |
| `key` | `string` | 待移动的节点 key |
| `target` | `string` | 目标节点 key |
| `position` | `'before' \| 'inside' \| 'after'` | 相对目标的放置位置 |
| 返回值 | [`TreeNode[] \| null`](#treenode) | 新的树；无法移动时返回 null |
