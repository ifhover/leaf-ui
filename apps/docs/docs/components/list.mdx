## List API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly T[]` | — | 展示的条目。 |
| `renderItem` | `(item: T, index: number) => ReactNode` | — | 渲染每个条目。 |
| `itemKey` | `(item: T, index: number) => string \| number` | — | 为动态条目提供稳定的标识。 |
| `children` | `ReactNode` | — | 子内容；嵌套数据类型表示子节点。 |
| `header` | `ReactNode` | — | 顶部内容。 |
| `footer` | `ReactNode` | — | 底部内容。 |
| `divider` | `boolean` | `false` | 显示条目之间的分隔。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 没有内容时的展示。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |

## ListItem API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 标题内容。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `avatar` | `ReactNode` | — | 前置头像或图标。 |
| `extra` | `ReactNode` | — | 尾部的补充内容。 |
| `actions` | `readonly ReactNode[]` | — | 条目操作区。 |
| `as` | `'li' \| 'div'` | `'li'` | 列表语义或独立块元素。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { ListProps, ListItemProps } from '@sudden3/leaf-ui';
```

为仅展示图标的操作提供可访问名称。交互控件支持键盘操作，并跟随 ConfigProvider 的主题和减少动画设置。
