# Space 间距

统一一组元素之间的间距。需要主轴对齐时使用 [Flex](/components/flex)，分列排列使用 [Grid](/components/grid)。

## API

### SpaceProps API

配置子内容的排列方向、间距与分隔符。

支持原生 `div` 属性和 DOM ref；显式 `style` 优先于布局属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 子元素的排列方向。 |
| `size` | `'sm' \| 'md' \| 'lg' \| number \| readonly [number, number]` | `'md'` | 子元素间距；数字为像素，数组为 [行间距, 列间距]。 |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'center'` | 对齐方式 |
| `wrap` | `boolean` | `false` | 空间不足时换行 |
| `split` | `ReactNode` | — | 相邻元素间的装饰性分隔内容，不放交互控件。 |
