## 使用说明

size 可使用预设、像素值或 [纵向, 横向] 间距。wrap 允许换行，split 在相邻内容之间插入分隔符。

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { SpaceProps } from '@ifhover/leaf-ui';
```

## SpaceProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 子元素的排列方向。 |
| `size` | `'sm' \| 'md' \| 'lg' \| number \| readonly [number, number]` | `'md'` | 子元素间距；数组为 [水平, 垂直]。 |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch' \| 'baseline'` | `'center'` | 对齐方式 |
| `wrap` | `boolean` | `false` | 空间不足时换行 |
| `split` | `ReactNode` | — | 相邻元素分隔内容 |
