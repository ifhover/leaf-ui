## API

### LayoutProps API

布局容器中子元素的排列方向。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'vertical'` | 子元素的排列方向。 |

### LayoutSiderProps API

视口重新变宽后，侧栏恢复手动或受控的折叠状态。`trigger` 仅替换内置折叠按钮的内容，点击处理和可访问名称仍由组件提供。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `collapsed` | `boolean` | — | 受控的手动折叠状态；断点仍可强制折叠。 |
| `defaultCollapsed` | `boolean` | `false` | 非受控模式的初始手动折叠状态。 |
| `onCollapse` | `(collapsed: boolean) => void` | — | 手动切换时返回下一状态；响应断点不触发此回调。 |
| `width` | `number \| string` | `220` | 宽度，数字按像素计算 |
| `collapsedWidth` | `number \| string` | `64` | 收起后的宽度 |
| `collapsible` | `boolean` | `false` | 显示收起操作 |
| `trigger` | `ReactNode` | — | 自定义触发内容 |
| `breakpoint` | `number` | — | 视口宽度不大于此像素值时折叠并隐藏内置触发器，不修改手动状态。 |
