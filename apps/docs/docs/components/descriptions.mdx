## API

### DescriptionsProps API

字段数据、列数与名称和值的排列方式配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`DescriptionItem`](#descriptionitem-api)`[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `title` | `ReactNode` | — | 标题内容 |
| `extra` | `ReactNode` | — | 补充内容或操作 |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `{ xs: 1, md: 2, lg: 3 }` | 列数；响应式配置按视口宽度生效，较大断点继承较小断点。 |
| `layout` | `'horizontal' \| 'vertical'` | `'horizontal'` | 标签与内容排列方式 |
| `bordered` | `boolean` | `false` | 显示容器外框 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 字段与值的间距预设，不改变字号。 |

### DescriptionItem API

通过 `items` 提供的字段名称、内容与跨列配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一且稳定的标识 |
| `label` | `ReactNode` | 必填 | 字段名称。 |
| `children` | `ReactNode` | 必填 | 字段值。 |
| `span` | `number` | `1` | 字段占用的列数；最小为 1，最多为当前列数。 |
