## API

### Skeleton API

配置加载占位的行数、形状和动画。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `loading` | `boolean` | `true` | 展示占位；false 时才渲染 children。 |
| `active` | `boolean` | `true` | 启用占位动画。 |
| `avatar` | `boolean` | `false` | 展示头像占位。 |
| `title` | `boolean` | `true` | 标题占位 |
| `titleWidth` | `number \| string` | `'38%'` | 标题宽度 |
| `rows` | `number` | `3` | 正文行数，最多 20 行 |
| `rowWidths` | `readonly (number \| string)[]` | — | 各行宽度 |
| `round` | `boolean` | `false` | 标题和正文占位使用胶囊圆角，不影响头像。 |
| `children` | `ReactNode` | — | 加载完成后展示的内容。 |
