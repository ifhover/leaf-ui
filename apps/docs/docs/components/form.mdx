## 设置布局

设置 `layout="settings"`，在左侧展示标签和 `description`，右侧展示保持自然宽度的控件，字段之间带有分隔线。较宽的控件可以单独设置 `FormField layout="vertical"`，让标签和描述位于控件上方，控件占满整行。窄屏下自动改为纵向排列。

`description` 用于说明字段含义，始终跟随标签；`help` 用于控件下方的操作提示，校验失败时由 `error` 替代。

## Form API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `layout` | `'horizontal' \| 'vertical' \| 'settings'` | `'horizontal'` | 字段默认布局；settings 将标签与描述放在左侧，控件靠右排列 |
| `labelWidth` | `number \| 'auto'` | `'auto'` | 仅用于 horizontal 字段；数字设置像素宽度，auto 统一使用最宽标签 |
| `labelAlign` | `'left' \| 'right'` | `'right'` | horizontal 字段的标签对齐方向 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `ref` | `Ref<HTMLFormElement>` | — | 表单引用 |

## FormField API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 字段标签 |
| `description` | `ReactNode` | — | 标签下方的字段说明；与控件下方的 help 和 error 独立展示 |
| `layout` | [`FormProps`](#form-api)`['layout']` | 继承 Form | 当前字段的布局；vertical 可用于占满整行的宽控件 |
| `htmlFor` | `string` | 自动生成 | 与输入控件的 id 关联；一个字段对应一个控件或组 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `help` | `ReactNode` | — | 显示在控件下方的辅助提示，占据正常布局空间 |
| `error` | `ReactNode` | — | 错误提示，优先于 help 展示 |
| `labelWidth` | `number` | — | 当前 horizontal 字段的标签宽度，单位像素 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { FormProps, FormFieldProps } from '@ifhover/leaf-ui';
```

## 使用说明

默认使用 horizontal 布局，自动计算同一 Form 中水平字段最宽的标签。标签文本、字体或可见字段变化时更新；窄屏和 vertical 布局按纵向排列。FormField 可以通过 layout 覆盖 Form 的默认布局；labelWidth 和 labelAlign 只作用于 horizontal 字段。支持 onSubmit、onReset、action、method 等表单属性。

help 和错误提示会占据正常布局空间，并与下一项保留表单间距；文字换行后自然增加高度。

用 FormData 读取控件上的 name。简单校验使用 required、type、minLength 等属性，错误提示跟随字段显示；业务与服务端错误通过 error 传入。设置 noValidate 可以接管校验。FormData 返回字符串，不会自动转换为数字或嵌套对象，未勾选复选框不会提交 false。受控字段的重置由应用处理。

## 接入 React Hook Form

在应用中安装 react-hook-form。原生输入使用 register；onChange 返回业务值的组件使用 Controller。Leaf Form 负责布局，表单库负责状态与校验，使用 noValidate 接管校验。FormList 的点号 name 只是字段名，不会自动生成嵌套对象；使用 React Hook Form 管理数组时优先使用 useFieldArray。

```tsx
import { useForm, Controller } from 'react-hook-form';
import { Form, FormField, FormErrorSummary, Input, Select, Button } from '@ifhover/leaf-ui';

export function AccountForm() {
  const { register, control, handleSubmit, formState: { errors } } = useForm({ defaultValues: { email: '', role: '' } });
  return <Form noValidate onSubmit={handleSubmit(values => console.log(values))}>
    <FormErrorSummary />
    <FormField label="Email" error={errors.email?.message}>
      <Input {...register('email', { required: 'Enter an email' })} />
    </FormField>
    <Controller name="role" control={control} rules={{ required: 'Choose a role' }} render={({ field, fieldState }) =>
      <FormField label="Role" error={fieldState.error?.message}>
        <Select {...field} options={[{ value: 'editor', label: 'Editor' }]} />
      </FormField>}
    />
    <Button type="submit">Save</Button>
  </Form>;
}
```

## FormValidationApi

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `errors` | `Record<string, string>` | — | 必需。按字段名组织的错误，可传给 FormField。 |
| `pending` | `boolean` | — | 必需。校验或提交是否进行中。 |
| `setErrors` | `Dispatch<SetStateAction<Record<string, string>>>` | — | 必需。设置服务端或业务错误。 |
| `handleSubmit` | `(event: FormEvent<HTMLFormElement>) => Promise<void>` | — | 必需。绑定到 Form.onSubmit。 |
| `handleReset` | `(event: FormEvent<HTMLFormElement>) => void` | — | 必需。绑定到 Form.onReset，取消请求并清除错误。 |
| `cancel` | `() => void` | — | 必需。取消当前请求。 |
| `clearErrors` | `(name?: string) => void` | — | 必需。清除一个或全部错误并取消旧请求。 |

## FormValidationOptions

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `validate` | `( data: FormData, signal: AbortSignal, ) => Record<string, string> \| Promise<Record<string, string>>` | — | 必需。接收 FormData 和取消信号，返回按字段名组织的错误。 |
| `onSubmit` | `(data: FormData, signal: AbortSignal) => void \| Promise<void>` | — | 校验通过后提交；应响应取消信号。 |
| `onError` | `(error: unknown) => void` | — | 操作失败时调用；命令面板会保留并展示错误。 |
| `focusError` | `boolean` | — | 出现错误时聚焦第一个字段。 |
