`useFormValidation` 读取 `FormData`，管理错误和 `pending` 状态。使用 `noValidate` 接管校验，把按字段名返回的错误传给 `FormField`。此例进行同步校验，输入时清除当前字段错误。

异步 `validate` 和 `onSubmit` 应响应传入的 `AbortSignal`。新的提交会取消旧请求；`clearErrors` 也会取消当前请求。把 `handleReset` 绑定到表单重置事件，以取消请求并清除错误。

### 接入 React Hook Form

{/* leaf:example react-hook-form */}

下面是第三方集成代码，文档站不加载 React Hook Form，因此不提供实时预览。请先在应用中安装依赖；原生输入使用 `register`，返回业务值的控件使用 `Controller`。

```bash
npm install react-hook-form
```

```tsx
import { Button, Form, FormField, Input, Select } from '@ifhover/leaf-ui';
import { Controller, useForm } from 'react-hook-form';

export function AccountForm() {
  const { register, control, handleSubmit, formState: { errors } } = useForm({
    defaultValues: { email: '', role: '' },
  });
  return (
    <Form noValidate onSubmit={handleSubmit((values) => console.log(values))}>
      <FormField label="邮箱" error={errors.email?.message}>
        <Input {...register('email', { required: '请输入邮箱' })} />
      </FormField>
      <Controller
        name="role"
        control={control}
        rules={{ required: '请选择角色' }}
        render={({ field, fieldState }) => (
          <FormField label="角色" error={fieldState.error?.message}>
            <Select {...field} options={[{ value: 'editor', label: '编辑者' }]} />
          </FormField>
        )}
      />
      <Button type="submit">保存</Button>
    </Form>
  );
}
```

数组字段使用 React Hook Form 的 `useFieldArray` 管理。

## API

### Form API

#### 表单接入

`FormData` 的值是字符串或 `File`；数字转换和对象组装由应用处理。未勾选的复选框不会提交 `false`；同名字段用 `getAll()` 读取。非受控字段由原生重置恢复默认值，受控字段需要应用同步重置状态。

Leaf UI 控件会读取 `FormField` 的关联信息。原生或第三方控件需要自行设置匹配的 `id` 与 `htmlFor`。`Form disabled` 只向支持表单上下文的控件传递禁用状态，不会禁用任意 DOM 元素或阻止提交。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `layout` | `'horizontal' \| 'vertical' \| 'settings'` | `'horizontal'` | 字段默认布局；settings 将标签与描述放在左侧，控件靠右排列 |
| `labelWidth` | `number` | `112` | horizontal 字段的标签宽度，单位像素；可由 FormField.labelWidth 单独覆盖。 |
| `labelAlign` | `'left' \| 'right'` | `'right'` | horizontal 字段的标签对齐方向 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `ref` | `Ref<HTMLFormElement>` | — | 表单引用 |

### FormField API

关联字段名称、控件与校验信息的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 字段标签 |
| `htmlFor` | `string` | 自动生成 | 与输入控件的 id 关联；一个字段对应一个控件或组 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `help` | `ReactNode` | — | 显示在控件下方的辅助提示，占据正常布局空间 |
| `error` | `ReactNode` | — | 错误提示，优先于 help 展示 |
| `layout` | [`FormProps`](#form-api)`['layout']` | 继承 Form | 当前字段的布局；vertical 可用于占满整行的宽控件 |
| `labelWidth` | `number` | — | 当前 horizontal 字段的标签宽度，单位像素 |
| `description` | `ReactNode` | — | 标签下方的字段说明；与控件下方的 help 和 error 独立展示 |

### FormGroupProps API

表单字段组的图例与说明参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `legend` | `ReactNode` | — | 字段组名称 |
| `description` | `ReactNode` | — | 补充说明 |

### FormListProps API

动态表单列表的数据、字段命名与渲染参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `name` | `string` | 必填 | 字段名前缀；将 field.name 用于实际控件，点号名称不自动生成嵌套对象。 |
| `value` | `readonly T[]` | — | 受控值 |
| `defaultValue` | `readonly T[]` | `[]` | 初始值；非受控表单 reset 时恢复 |
| `onChange` | `(values: T[]) => void` | — | 值变化回调 |
| `itemKey` | `(value: T) => string` | — | 提取稳定的项目标识 |
| `children` | `(fields: readonly `[`FormListField`](#formlistfield-api)`<T>[], operations: `[`FormListOperations`](#formlistoperations-api)`<T>) => ReactNode` | 必填 | 渲染列表项与操作的函数。 |

### FormListField API

传给列表渲染函数的单个字段信息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一且稳定的标识 |
| `index` | `number` | 必填 | 当前索引，从 0 开始 |
| `name` | `string` | 必填 | 表单字段名称 |
| `value` | `T` | 必填 | 该行当前值。 |

### FormListOperations API

动态表单列表的增删、移动与更新方法。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `add` | `(value: T, index?: number) => void` | 必填 | 插入字段，省略 index 时追加 |
| `remove` | `(index: number \| readonly number[]) => void` | 必填 | 移除一个或多个位置 |
| `move` | `(from: number, to: number) => void` | 必填 | 移动字段并保留稳定 key |
| `update` | `(index: number, value: T) => void` | 必填 | 更新字段值 |

### FormErrorSummaryProps API

集中展示字段校验错误的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `errors` | `readonly `[`FormError`](#formerror-api)`[]` | — | 省略时汇总同一 Form 内字段错误 |
| `title` | `ReactNode` | 语言默认值 | 错误汇总标题，默认使用当前语言的提示。 |

### FormError API

错误汇总中的字段标识、名称和错误消息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `fieldId` | `string` | 必填 | 关联输入控件 id，点击错误后聚焦 |
| `message` | `ReactNode` | 必填 | 错误内容 |
| `label` | `ReactNode` | — | 显示内容 |

### FormValidationApi

`useFormValidation` 返回的状态与表单事件处理方法。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `errors` | `Record<string, string>` | 必填 | 按字段名组织的错误，可传给 FormField。 |
| `pending` | `boolean` | 必填 | 校验或提交是否进行中。 |
| `setErrors` | `Dispatch<SetStateAction<Record<string, string>>>` | 必填 | 设置服务端或业务错误。 |
| `handleSubmit` | `(event: FormEvent<HTMLFormElement>) => Promise<void>` | 必填 | 绑定到 Form.onSubmit。 |
| `handleReset` | `(event: FormEvent<HTMLFormElement>) => void` | 必填 | 绑定到 Form.onReset，取消请求并清除错误。 |
| `cancel` | `() => void` | 必填 | 取消当前请求。 |
| `clearErrors` | `(name?: string) => void` | 必填 | 清除一个或全部错误并取消旧请求。 |

### FormValidationOptions

业务校验、提交回调与错误处理配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `validate` | `( data: FormData, signal: AbortSignal, ) => Record<string, string> \| Promise<Record<string, string>>` | 必填 | 接收 FormData 和取消信号，返回按字段名组织的错误。 |
| `onSubmit` | `(data: FormData, signal: AbortSignal) => void \| Promise<void>` | — | 校验通过后提交；应响应取消信号。 |
| `onError` | `(error: unknown) => void` | — | 校验或提交过程中抛出异常时调用。 |
| `focusError` | `boolean` | `true` | 出现错误时聚焦第一个字段。 |
