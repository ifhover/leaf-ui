# Steps 步骤条

展示任务的进展和当前步骤。

{/* leaf:section basic */}

## 基础用法

当前步骤索引从 `0` 开始。未指定单项 `status` 时，会根据 `current` 显示已完成、进行中和等待状态。

## API

### Steps API

配置当前步骤、步骤数据和排列方式。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`StepItem`](#stepitem)`[]` | 必填 | 步骤列表 |
| `current` | `number` | `0` | 当前步骤的索引，从 0 开始 |
| `status` | `'process' \| 'finish' \| 'error'` | `'process'` | 当前步骤状态 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 排列方向 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 步骤尺寸 |
| `loading` | `boolean` | `false` | 当前步骤展示加载图标 |
| `onChange` | `(current: number) => void` | — | 设置后可点击步骤 |
| `progressDot` | `boolean \| ((dot: ReactNode, info: { index: number; status: string }) => ReactNode)` | — | 使用点状步骤，可自定义点的内容。 |
| `percent` | `number` | — | 当前步骤图标内的进度（0–100）；点状模式不显示。 |

### StepItem

描述单个步骤的标题、状态与补充内容。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定标识 |
| `title` | `ReactNode` | 必填 | 步骤名称 |
| `description` | `ReactNode` | — | 补充说明 |
| `icon` | `ReactNode` | — | 自定义图标 |
| `status` | `'wait' \| 'process' \| 'finish' \| 'error'` | — | 覆盖该步骤状态 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
