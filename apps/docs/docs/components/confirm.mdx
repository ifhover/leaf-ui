# Confirm 确认框

在执行重要操作前征求确认，并等待用户的选择。

编辑内容使用 [Modal](/components/modal)，希望在触发按钮旁简短确认时使用 [Popconfirm](/components/popconfirm)。

在应用入口接入 [ConfigProvider](/components/config-provider)，子组件即可调用 `useConfirm()`。确认框沿用调用区域的主题和语言。

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return (
    <ConfigProvider>
      <App />
    </ConfigProvider>
  );
}
```

## API

### useConfirm API

返回的对象类型是 [`ConfirmApi`](#confirmapi)。同一队列的请求依次展示，上一个完成关闭过渡后才显示下一个；Promise 在作出决定并开始关闭时返回结果，不等待关闭动画。

调用组件或 Provider 卸载时，未结束的请求返回 `false`；这不会中止已经执行的异步操作，也不会触发 `onCancel`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `confirm` | [`(options: ConfirmOptions) => Promise<boolean>`](#confirmoptions) | — | 确认返回 true；取消或调用区域卸载返回 false。 |

### ConfirmApi

`useConfirm()` 返回的命令接口。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `confirm` | `(options: `[`ConfirmOptions`](#confirmoptions)`) => Promise<boolean>` | 必填 | 等待决定并返回 boolean；确认成功为 true，取消或调用区域卸载为 false，不等待关闭动画。 |

### ConfirmOptions

调用 `confirm()` 时提供的内容、操作和交互配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 确认标题。 |
| `children` | `ReactNode` | — | 简短说明本次操作的影响。 |
| `onConfirm` | `() => void \| Promise<void>` | — | 确认操作；等待 Promise 成功后关闭，失败时保留并显示错误。 |
| `onCancel` | `() => void` | — | 取消时调用。 |
| `type` | `'default' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'default'` | 状态图标与颜色；仅 danger 改变确定按钮颜色。 |
| `icon` | `ReactNode` | — | 正文左侧的状态图标；传入 null 隐藏图标。 |
| `confirmText` | `ReactNode` | 语言默认值 | 确认按钮文字。 |
| `cancelText` | `ReactNode` | 语言默认值 | 取消按钮文字。 |
| `showCancel` | `boolean` | success 为 false，其余 true | 是否展示取消按钮。 |
| `confirmButtonProps` | [`ButtonProps`](button#button-api) | — | 确认按钮属性。 |
| `cancelButtonProps` | [`ButtonProps`](button#button-api) | — | 取消按钮属性。 |
| `width` | `number \| string` | `420` | 确认框宽度，数字为像素。 |
| `closable` | `boolean` | `false` | 是否显示右上角关闭按钮。 |
| `maskClosable` | `boolean` | `false` | 点击遮罩时取消。 |
| `keyboard` | `boolean` | `true` | 按 Escape 时取消。 |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定打开后的初始焦点。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点，也可指定目标或设为 false。 |
| `className` | `string` | — | 确认框类名。 |
| `style` | `CSSProperties` | — | 确认框样式。 |

### ConfirmProvider API

未使用 `ConfigProvider` 时，在入口放置 `ConfirmProvider`。显式添加 `ConfirmProvider` 会建立独立队列，嵌套 `ConfigProvider` 则继续共享已有队列。

```tsx
import { ConfirmProvider } from '@ifhover/leaf-ui';

export function Root() {
  return (
    <ConfirmProvider>
      <App />
    </ConfirmProvider>
  );
}
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 共用此独立确认队列的内容；ConfigProvider 已自动提供队列，嵌套 ConfigProvider 不另建队列。 |
