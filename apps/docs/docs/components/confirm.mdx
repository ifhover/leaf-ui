# Confirm 确认框

在执行重要操作前征求确认。

## 入口配置一次

在应用入口使用 `ConfigProvider`，子组件直接调用 `useConfirm()`，确认框会沿用调用区域的主题和语言。

```tsx
import { ConfigProvider } from '@sudden3/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## Confirm API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必填 | 是否显示弹窗 |
| `title / children` | `ReactNode` | — | 标题 / 确认内容 |
| `width` | `number \| string` | `480` | 弹窗宽度，数字为像素 |
| `closable / keyboard` | `boolean` | `true` | 关闭按钮 / Escape 关闭 |
| `maskClosable` | `boolean` | `false` | 点击遮罩关闭 |
| `onClose` | `() => void` | — | 请求关闭，由应用更新 open |
| `afterClose` | `() => void` | — | 关闭动画完成后触发 |
| `confirmText / cancelText` | `ReactNode` | 语言默认值 | 确认 / 取消文字 |
| `type` | `'default' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'default'` | 图标与颜色，仅 danger 改变确定按钮颜色 |
| `showCancel` | `boolean` | success 为 false，其余 true | 是否展示取消按钮 |
| `danger` | `boolean` | `false` | 兼容属性，等同 type="danger" |
| `onConfirm` | `() => void \| Promise<void>` | — | 确认操作；Promise 完成后关闭，拒绝时显示错误 |

## useConfirm API

返回的对象类型是 [`ConfirmApi`](#useconfirm-api)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `confirm` | [`(options: ConfirmOptions) => Promise<boolean>`](#confirmoptions) | — | 确认返回 true，取消或卸载返回 false |

## ConfirmProvider API

未使用 `ConfigProvider` 时，在入口放置 `ConfirmProvider`。显式添加它也可以为某个区域建立独立的确认队列。

```tsx
import { ConfirmProvider } from '@sudden3/leaf-ui';

export function Root() {
  return <ConfirmProvider><App /></ConfirmProvider>;
}
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 共用此确认队列的组件 |

## ConfirmOptions

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title / children` | `ReactNode` | — | 标题与确认内容 |
| `confirmText / cancelText` | `ReactNode` | 语言默认值 | 按钮文字 |
| `type` | `'default' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'default'` | 图标与颜色，仅 danger 改变确定按钮颜色 |
| `showCancel` | `boolean` | success 为 false，其余 true | 是否展示取消按钮 |
| `danger` | `boolean` | `false` | 兼容属性，等同 type="danger" |
| `onConfirm` | `() => void \| Promise<void>` | — | 确认时运行，拒绝保留弹窗 |
| `width` | `number \| string` | `480` | 弹窗宽度 |
| `closable / keyboard` | `boolean` | `true` | 关闭按钮 / Escape 关闭 |
| `maskClosable` | `boolean` | `false` | 点击遮罩关闭 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { ConfirmProps, ConfirmOptions, ConfirmApi, ConfirmProviderProps } from '@sudden3/leaf-ui';
```

## 使用说明

`useConfirm()` 返回 `{ confirm }`。同一入口下的请求依次展示，上一个确认框完成关闭后再显示下一个。确认返回 `true`；取消、调用组件或入口卸载返回 `false`。

异步确认期间展示加载状态并阻止重复操作；失败时保留确认框并显示错误，可再次尝试。嵌套 `ConfigProvider` 共用队列，各个请求仍沿用调用区域的主题和语言。

也支持直接渲染 `Confirm`，控制 `open` 和 `onClose`。

其他属性参见 [Modal API](/components/modal#modal-api)。

default 不展示图标；info、warning、success、danger 使用对应图标和颜色。只有 danger 的确定按钮为红色；success 默认隐藏取消按钮，可通过 showCancel 覆盖。按钮属性与 Modal 一致，onCancel 在取消时触发，然后调用 onClose。
