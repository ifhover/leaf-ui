# FloatButton 悬浮按钮

提供随时可用的快捷操作。属于正文流程的操作使用普通 [Button](/components/button)。

{/* leaf:section basic */}

## API

### FloatButton API

悬浮操作的提示内容、定位与按钮状态配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tooltip` | `ReactNode` | — | 悬浮或聚焦时展示的提示内容。 |
| `fixed` | `boolean` | `true` | 固定在视口角落；false 时参与页面布局。 |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'solid'` | 按钮外观，默认使用实底。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `danger` | `boolean` | `false` | 使用危险语义颜色，不改变按钮行为。 |
| `loading` | `boolean` | `false` | 展示加载状态。 |
| `startIcon` | `ReactNode` | — | 按钮文字前的图标；仅图标按钮还需 aria-label。 |
| `endIcon` | `ReactNode` | — | 按钮文字后的图标。 |
| `fullWidth` | `boolean` | `false` | 让按钮填满所在容器的宽度。 |

### FloatButtonGroup API

设置 `expandable={false}` 后，操作始终显示且不提供展开按钮。操作的字符串 `label` 同时作为图标按钮的可访问名称。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `actions` | `readonly `[`FloatButtonAction`](#floatbuttonaction)`[]` | 必填 | 按数组顺序排列的操作；点击后调用对应 onClick，可展开的组随后关闭。 |
| `open` | `boolean` | — | 受控的展开状态，配合 onOpenChange 更新。 |
| `defaultOpen` | `boolean` | `false` | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 触发器、组外点击、Escape 或操作项请求改变展开状态时调用。 |
| `expandable` | `boolean` | `true` | 提供展开操作组的按钮。 |
| `fixed` | `boolean` | `true` | 固定在视口角落；false 时参与页面布局。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `className` | `string` | — | 添加到组件外层的 CSS 类名。 |

### FloatButtonAction

悬浮操作组中的单个操作数据。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 稳定且唯一的标识。 |
| `label` | `ReactNode` | 必填 | 操作提示；字符串也作为按钮的可访问名称，其他内容使用 key 作为名称。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `onClick` | `() => void` | — | 点击时调用。 |
| `disabled` | `boolean` | — | 禁用交互。 |
