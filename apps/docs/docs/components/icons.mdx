# 使用图标

通过组件的图标插槽，为操作和字段补充图标。

## 安装和导入

示例使用 [Lucide](https://lucide.dev/icons/)。直接导入图标时，需要将它声明为应用依赖。插槽接受 `ReactNode`，也可以使用项目已有的 React 图标库。

```bash
pnpm add lucide-react
```

## 按钮图标

使用 `startIcon` 或 `endIcon` 放置文字前后的图标。仅图标按钮必须通过 `aria-label` 提供操作名称，例如“添加项目”。

<ComponentExample title="按钮图标" preview={<IconButtons />} fileName="buttons.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/icons/buttons.tsx"
```

</ComponentExample>

## 输入框图标

通过 `prefix` 和 `suffix` 放置输入框图标。装饰性图标不能代替字段名称；使用 FormField 将标签与输入框关联。

<ComponentExample title="输入框图标" preview={<IconFields />} fileName="fields.tsx">

```tsx lineNumbers file="../../src/examples/icons/fields.tsx"
```

</ComponentExample>

图标继承组件文字色，不需要为按钮的不同状态单独固定图标颜色。
