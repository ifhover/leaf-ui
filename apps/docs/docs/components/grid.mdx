用等宽列或 24 栅格排列内容。只需排列一组元素时使用 [Flex](/components/flex) 或 [Space](/components/space)。

## API

### GridProps API

`Grid`、`Row` 和 `Col` 均支持原生 `div` 属性和 DOM ref。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `3` | 列数；较大断点继承较小断点 |
| `gap` | `number \| string \| readonly [number \| string, number \| string]` | `16` | 间距；数组为 [纵向, 横向] |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | 对齐方式 |

### RowProps API

24 栅格行的对齐和列间距参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | 对齐方式 |
| `gutter` | [`GridProps`](#gridprops-api)`['gap']` | `16` | 栅格间距；数组为 [纵向, 横向] |

### ColProps API

24 栅格列的跨度、偏移与响应式配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `span` | `number` | `24` | 跨列数，Col 的 0 表示隐藏 |
| `offset` | `number` | `0` | 前方空出的列数 |
| `xs` | `number` | — | 小屏配置 |
| `sm` | `number` | — | ≥ 576px 配置 |
| `md` | `number` | — | ≥ 768px 配置 |
| `lg` | `number` | — | ≥ 992px 配置 |
| `xl` | `number` | — | ≥ 1200px 配置 |
