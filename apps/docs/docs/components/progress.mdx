## API

### Progress API

配置进度比例、状态和显示形式。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `percent` | `number` | `0` | 完成百分比，范围 0–100 |
| `type` | `'line' \| 'circle'` | `'line'` | 直线或圆形进度 |
| `status` | `'normal' \| 'success' \| 'error'` | `'normal'` | 进度状态；非不确定进度达到 100% 时，normal 自动显示为 success。 |
| `showInfo` | `boolean` | `true` | 展示百分比或状态图标 |
| `format` | `(percent: number) => ReactNode` | — | 自定义进度文字 |
| `strokeWidth` | `number` | — | 进度线宽；直线为像素，圆形为视图单位 |
| `color` | `string` | — | 自定义进度颜色 |
| `size` | `number` | `100` | 圆形宽高，单位像素 |
| `indeterminate` | `boolean` | `false` | 总进度未知时展示加载动画，不显示百分比 |
| `active` | `boolean` | `true` | 未完成的线形进度默认显示流光；设为 false 关闭，完成、错误或不确定进度时自动停止。 |
| `trailColor` | `string` | — | 底轨颜色 |
| `segments` | `readonly `[`ProgressSegment`](#progresssegment)`[]` | — | 按比例和颜色显示多个分段。 |
| `steps` | `number` | — | 离散的进度段数。 |
| `dashboard` | `boolean` | `false` | 显示仪表盘式进度。 |
| `successPercent` | `number` | — | 已经成功完成的进度部分。 |

### ProgressSegment

描述一段进度的比例与颜色。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定且唯一的标识。 |
| `percent` | `number` | 必填 | 完成百分比。 |
| `color` | `string` | — | 颜色或语义色。 |
