## API

### Button API

支持 `onClick`、`name`、`form`、`aria-*`、`data-*` 等原生 `button` 属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link' \| 'danger'` | `'outline'` | 视觉样式 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon' \| 'icon-sm' \| 'icon-lg'` | `'md'` | 按钮尺寸或纯图标正方形尺寸 |
| `danger` | `boolean` | `false` | 已废弃，改用 `variant="danger"`；传入时统一回退为危险按钮外观 |
| `loading` | `boolean` | `false` | 显示加载指示器并禁用交互 |
| `fullWidth` | `boolean` | `false` | 填满父容器宽度 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | 原生按钮类型 |
| `ref` | `Ref<HTMLButtonElement>` | — | 按钮 DOM 引用 |

### ButtonGroupProps API

用于组合一组相关按钮的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | — | 按钮尺寸，同时会将组内 `size="icon"` 自动适配为对应尺寸的图标按钮 |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link' \| 'danger'` | — | 组内按钮默认视觉样式 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `attached` | `boolean` | `true` | 连接相邻按钮 |
