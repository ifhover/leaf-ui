# Button 按钮

用于触发操作，如提交表单、保存内容或删除记录。

## 基础用法

`variant` 控制按钮外观。默认使用 `outline`，适合一般操作；主要操作使用 `solid`，行内操作使用 `link`。

描边按钮带有一层轻微阴影，悬停时外观不变；按下时仅将边框加深为对应的交互色，文字、背景和阴影保持不变，松开后边框恢复。`danger` 使用可读的危险文字色，按下时边框从危险基色加深为更深的危险交互色。禁用和加载时不响应，显式组件状态配置优先于默认反馈。

## Button API
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'link'` | `'outline'` | 视觉样式 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 按钮尺寸 |
| `danger` | `boolean` | `false` | 使用红色危险语义，支持所有 variant |
| `loading` | `boolean` | `false` | 显示加载指示器并禁用交互 |
| `fullWidth` | `boolean` | `false` | 填满父容器宽度 |
| `startIcon` | `ReactNode` | — | 文字前的图标，加载时由指示器替代 |
| `endIcon` | `ReactNode` | — | 文字后的图标 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | 原生按钮类型 |
| `ref` | `Ref<HTMLButtonElement>` | — | 按钮 DOM 引用 |

支持其他原生 `button` 属性，例如 `onClick`、`name`、`value`、`form`、`className`、`style`、`aria-*` 和 `data-*`。

## 类型

可导入 [`ButtonProps`](#button-api) 定义组件属性，或单独使用以下样式、尺寸类型：

```ts
import type { ButtonProps, ButtonVariant, ButtonSize } from '@ifhover/leaf-ui';
```

## 表单与键盘

默认 `type="button"`，放进表单时不会意外提交。需要提交表单，请显式设置 `type="submit"`。

组件保留原生键盘行为：Tab 聚焦，Enter 或 Space 触发。禁用和加载状态会阻止交互；聚焦时显示清晰的焦点轮廓。

## 定制样式

```tsx
<ConfigProvider theme={{ primaryColor: '#7654c6', borderRadius: 18 }}>
  <Button>自定义主题</Button>
</ConfigProvider>
```

配置选项与实时示例见[定制主题](/guide/theming)。

## SplitButtonProps API
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'link'` | `'outline'` | 按钮样式 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 按钮尺寸。 |
| `danger` | `boolean` | `false` | 危险操作颜色 |
| `loading` | `boolean` | `false` | 加载状态 |
| `fullWidth` | `boolean` | `false` | 占满宽度 |
| `startIcon` | `ReactNode` | — | 前置图标 |
| `endIcon` | `ReactNode` | — | 后置图标 |
| `items` | `readonly `[`DropdownItem`](dropdown#dropdownitem)`[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `menuLabel` | `string` | — | 菜单按钮的可访问名称 |
| `dropdownProps` | `Omit<`[`DropdownProps`](dropdown#dropdown-api)`, 'items' \| 'children' \| 'disabled'>` | — | 操作菜单属性 |
