## API

### Button API

支持 `onClick`、`name`、`form`、`aria-*`、`data-*` 等原生 `button` 属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'outline'` | 视觉样式 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 按钮尺寸 |
| `danger` | `boolean` | `false` | 使用红色危险语义，支持所有 variant |
| `loading` | `boolean` | `false` | 显示加载指示器并禁用交互 |
| `fullWidth` | `boolean` | `false` | 填满父容器宽度 |
| `startIcon` | `ReactNode` | — | 文字前的图标，加载时由指示器替代 |
| `endIcon` | `ReactNode` | — | 文字后的图标 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | 原生按钮类型 |
| `ref` | `Ref<HTMLButtonElement>` | — | 按钮 DOM 引用 |

### ButtonGroupProps API

用于组合一组相关按钮的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | — | 按钮尺寸 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `attached` | `boolean` | `true` | 连接相邻按钮 |

### SplitButtonProps API

主操作与下拉操作组合按钮的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text' \| 'link'` | `'outline'` | 按钮样式 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 按钮尺寸。 |
| `danger` | `boolean` | `false` | 危险操作颜色 |
| `loading` | `boolean` | `false` | 加载状态 |
| `fullWidth` | `boolean` | `false` | 占满宽度 |
| `startIcon` | `ReactNode` | — | 前置图标 |
| `endIcon` | `ReactNode` | — | 后置图标 |
| `items` | `readonly `[`DropdownItem`](dropdown#dropdownitem)`[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `menuLabel` | `string` | — | 菜单按钮的可访问名称 |
| `dropdownProps` | `Omit<`[`DropdownProps`](dropdown#dropdown-api)`, 'items' \| 'children' \| 'disabled'>` | — | 操作菜单属性 |
