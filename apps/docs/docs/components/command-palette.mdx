## CommandItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 必需。稳定且唯一的标识。 |
| `label` | `ReactNode` | — | 必需。展示文字或内容。 |
| `keywords` | `string` | — | 搜索匹配的额外关键词。 |
| `group` | `ReactNode` | — | 条目的分组标题。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `shortcut` | `string` | — | 展示在条目旁的快捷键提示。 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `onSelect` | `() => void \| Promise<void>` | — | 条目被选择时调用。 |

## CommandPalette API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`CommandItem`](#commanditem)`[]` | — | 必需。展示的条目。 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | `false` | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起时调用。 |
| `onSelect` | `(item: `[`CommandItem`](#commanditem)`) => void` | — | 条目被选择时调用。 |
| `shortcut` | `string \| false` | `'k'` | 使用 Ctrl/Cmd 与该按键打开面板；false 禁用快捷键。 |
| `placeholder` | `string` | — | 设置 placeholder。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 没有内容时的展示。 |
| `onSearch` | `(query: string) => void` | — | 搜索文字改变时调用。 |
| `onError` | `(error: unknown, item: `[`CommandItem`](#commanditem)`) => void` | — | 操作失败时调用；命令面板会保留并展示错误。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { CommandItem, CommandPaletteProps } from '@sudden3/leaf-ui';
```

为仅展示图标的操作提供可访问名称。交互控件支持键盘操作，并跟随 ConfigProvider 的主题和减少动画设置。
