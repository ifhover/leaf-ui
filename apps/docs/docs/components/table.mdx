## API

### Table API

配置数据源、列定义、行交互与表格展示参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | 必填 | 展示的数据数组，更新时使用新数组。 |
| `columns` | `readonly `[`TableColumn`](#tablecolumn)`<TData>[]` | 必填 | 列定义数组。 |
| `rowKey` | [`TableRowKey`](#tablerowkey)`<TData>` | 必填 | 非可选的字符串或数字标识字段，或返回字符串 / 数字标识的函数。 |
| `size` | `'sm' \| 'md'` | `'md'` | 展示尺寸。 |
| `bordered` | `boolean` | `false` | 显示外边框和单元格网格线。 |
| `striped` | `boolean` | `false` | 开启斑马条纹交替背景。 |
| `rowSelection` | [`TableRowSelection`](#tablerowselection)`<TData>` | — | 行选择配置（多选或单选）。 |
| `expandable` | [`TableExpandable`](#tableexpandable)`<TData>` | — | 展开详情行与树形子行配置。 |
| `sort` | [`TableSorterState`](#tablesorterstate)` \| readonly `[`TableSorterState`](#tablesorterstate)`[] \| null` | — | 受控排序状态。 |
| `defaultSort` | [`TableSorterState`](#tablesorterstate)` \| readonly `[`TableSorterState`](#tablesorterstate)`[] \| null` | — | 非受控初始排序状态。 |
| `onSortChange` | `(sorter: `[`TableSorterState`](#tablesorterstate)` \| null, sorters: `[`TableSorterState`](#tablesorterstate)`[]) => void` | — | 排序变化回调，返回主排序与完整排序列表。 |
| `multiSort` | `boolean` | `false` | 允许按住 Shift 点击列头叠加多列排序。 |
| `manualSorting` | `boolean` | `false` | 服务端排序模式，开启后仅维护排序状态，不在本地重排数据。 |
| `pagination` | `boolean \| `[`TablePaginationProps`](#tablepagination-api) | `true` | 分页开关或配置，参见 <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a>；设为 false 时关闭分页。 |
| `manualPagination` | `boolean` | — | 由外部控制分页，不在本地切分 data；当 pagination.total 小于 0 或大于数据长度时自动启用。 |
| `resizable` | `boolean` | `false` | 展示可调整列宽的拖拽手柄。 |
| `onColumnResize` | `(columnKey: string, width: number) => void` | — | 列宽拖拽或键盘调整回调。 |
| `virtual` | `boolean \| `[`TableVirtualOptions`](#tablevirtualoptions) | `false` | 启用行虚拟滚动。 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 最大高度，超出时表头固定、表体滚动；开启 virtual 且未指定时默认 400。 |
| `minWidth` | `CSSProperties['minWidth']` | — | 表格内容区域的最小宽度；默认适应容器与列宽。 |
| `loading` | `boolean` | `false` | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 空数据内容。 |
| `error` | `ReactNode` | — | 请求失败提示；null、undefined 或 false 不展示。 |
| `onRetry` | `() => void` | — | 请求重试回调。 |
| `getRowLabel` | `(record: TData, index: number) => string` | — | 行操作的可访问名称；默认使用解析后的行 key。 |
| `onRow` | `(record: TData, index: number) => `[`TableRowProps`](#tablerow-api) | — | 自定义数据行原生属性、事件与选中样式。 |
| `tableRef` | `Ref<HTMLTableElement>` | — | 原生表格 DOM ref。 |

`aria-label` / `aria-labelledby` 应用于内部原生表格，其余原生属性传递给外层容器。

- <a id="tablekey"></a><a id="tablerowkey"></a>`TableRowKey<TData>`：非可选的字符串 / 数字字段名，或 `(record: TData, index: number) => TableKey` 函数（`TableKey = string | number`）；必须解析为稳定且唯一的标识，避免使用数组索引。
- <a id="tablesortorder"></a><a id="tablesorterstate"></a>`TableSorterState`：`{ columnKey: string; order: 'asc' | 'desc' }`；`TableSortOrder` 为 `'asc' | 'desc' | null`。
- <a id="tablerow-api"></a>`TableRowProps`（`onRow` 返回值）：支持原生 `tr` 属性与事件，额外支持 `selected?: boolean` 设置选中行样式。
- <a id="tablecell-api"></a><a id="tableheadercell-api"></a>`TableCellProps` / `TableHeaderCellProps`（`onCell` / `onHeaderCell` 返回值）：支持原生 `td` / `th` 属性、事件与 `colSpan` / `rowSpan`（为 `0` 时省略单元格），额外支持 `align`（`'start' | 'center' | 'end'`）。
- <a id="tablepresentation-api"></a>`TablePresentationProps`：可在 [ConfigProvider](config-provider#configprovider-api) 的 `components.Table` 中全局配置展示默认值（如 `size`、`bordered`、`striped`、`pagination` 等）。

### TableColumn

定义列标题、取值路径、渲染、排序、固定、省略与宽度分配。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 列唯一标识；省略时依次回退到 dataIndex 与列索引。 |
| `dataIndex` | `keyof TData \| readonly (string \| number)[]` | — | 读取单元格值的字段名或嵌套路径数组。 |
| `title` | `ReactNode` | 必填 | 表头展示内容。 |
| `label` | `string` | — | 纯文字列名；表头为自定义节点时供排序与列宽调整无障碍标签使用。 |
| `render` | `(value: unknown, record: TData, index: number) => ReactNode` | — | 自定义单元格渲染函数。 |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | 表头与单元格对齐方式。 |
| `width` | `number` | — | 固定列宽（像素）。 |
| `minWidth` | `number` | `20` | 最小列宽（像素）。 |
| `maxWidth` | `number` | — | 最大列宽（像素）。 |
| `flex` | `number` | — | 分配剩余宽度的正数权重，受 minWidth / maxWidth 约束；固定列和手动调整宽度的列忽略此项。 |
| `fixed` | `'left' \| 'right' \| 'start' \| 'end'` | — | 将列固定在起点或终点。 |
| `ellipsis` | `boolean` | `false` | 开启单行省略截断，自动切换为固定列宽布局。 |
| `sorter` | `boolean \| ((a: TData, b: TData) => number)` | — | 启用排序；true 使用默认比较，也可传入自定义比较函数。 |
| `sortDirections` | `readonly ('asc' \| 'desc')[]` | `['asc', 'desc']` | 排序顺序循环。 |
| `resizable` | `boolean` | `true` | 表格开启 resizable 时控制该列是否允许调整宽度。 |
| `className` | `string` | — | 数据单元格类名。 |
| `headerClassName` | `string` | — | 表头单元格类名。 |
| `onCell` | `(record: TData, index: number) => `[`TableCellProps`](#tablecell-api) | — | 自定义数据单元格属性、样式或合并；colSpan / rowSpan 为 0 时省略单元格。 |
| `onHeaderCell` | `(column: `[`TableColumn`](#tablecolumn)`<TData>) => `[`TableHeaderCellProps`](#tableheadercell-api) | — | 自定义表头单元格属性与事件。 |

### TablePagination API

支持直接透传 <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a> 的其他属性（如 `current`、`defaultCurrent`、`pageSize`、`defaultPageSize`、`showTotal` 等）。与独立分页器的差异如下：

- 本地分页时 `total` 可省略（默认取顶层数据长度）；服务端分页传入实际总条数，未知总数时传入 `-1`。
- 默认每页 `10` 条并开启 `showSizeChanger`；`size` 跟随表格尺寸（`md` 或 `sm`）。
- 总数未知（`total < 0`）时仅显示上一页、当前页码与下一页按钮，可通过 `hasNextPage` 控制下一页是否可用。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `total` | `number` | — | 数据总条数；本地分页可省略，未知总数传 -1。 |
| `onChange` | `(page: number, pageSize: number) => void` | — | 页码或每页条数变化回调。 |
| `hasNextPage` | `boolean` | — | 未知总数时控制下一页是否可用。 |
