### 固定列与列宽调整

用 TanStack 的 `columnPinning` 固定列，列定义的 `size`、`minSize` 和 `maxSize` 限定宽度。拖动表头边缘，或聚焦边缘后用方向键调整；`maxHeight` 让表体在内部滚动。

当两侧固定列的总宽度超过可用滚动视口时，固定列临时跟随横向滚动，避免互相遮挡；空间足够后自动恢复固定，不修改 `columnPinning` 状态。

表格始终自动渲染内容区域和分页器；只需补充工具栏时使用 `toolbar`。列固定和列宽调整仍由 TanStack 状态与 `resizable` 控制。

### 服务端排序与分页

组件不请求数据。应用控制排序与分页状态，配置 `manualSorting`、`manualPagination` 和 `rowCount`，再传回当前页数据；排序变化时重置页码，清理过期请求。TanStack 回调可能传入新值或更新函数，可直接交给 React 的 setter。

此例用定时器模拟“先排序、再分页”和请求失败，不访问服务器。接入真实接口时，将排序条件映射为请求参数，并传入 `AbortSignal`。只控制排序状态而仍需本地排序时，不设置 `manualSorting`。

## API

### DataTable API

<a id="datatableinstance-api"></a>
<a id="datatabledata-api"></a>

列定义和状态沿用 TanStack 原生 API，相关说明见 [列定义](https://tanstack.com/table/v8/docs/guide/column-defs) 与 [受控状态](https://tanstack.com/table/v8/docs/framework/react/guide/table-state)。表格始终自动渲染工具栏、内容区域和分页器；搜索、列显隐和列顺序由业务通过 TanStack 状态与自定义控件管理。

组件参数统一使用 `DataTableProps<TData>`。通常传入 `data`、`columns` 和 `rowKey`；需要在业务中访问表格实例时，先用 `useDataTable` 或原生 `useReactTable` 创建实例，再传入 `table`。两种传参方式不能混用。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | 未传 table 时必填 | 展示的数据，更新时使用新数组。 |
| `columns` | `readonly ColumnDef<TData>[]` | 未传 table 时必填 | TanStack 的原生列定义。 |
| `rowKey` | [`DataTableRowKey`](#datatablerowkey)`<TData>` | 未传 table 时必填 | 非可选的字符串或数字标识字段，或返回字符串 / 数字标识的函数。 |
| `options` | `Omit<TableOptions<TData>, 'data' \| 'columns' \| 'getCoreRowModel' \| 'getRowId'>` | — | 定制 TanStack 的状态、回调和服务端配置。 |
| `localPagination` | `boolean` | — | 是否让 TanStack 在本地切分当前页数据；关闭时保留分页状态和分页器，但直接展示传入的行。 |
| `table` | `TanStackTable<TData>` | — | 由 useDataTable 或 useReactTable 创建的实例；与 data、columns、rowKey、options 和 localPagination 互斥。 |
| `toolbar` | `ReactNode` | — | 自动布局中的工具栏内容。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `variant` | `'layered' \| 'simple'` | `'layered'` | layered 使用分层卡片；simple 使用直角内容面表头，无外框、阴影和列分隔线。 |
| `columnDividers` | `boolean` | — | 增加表体和表尾的列分隔线；layered 表头保留短分隔线。simple 模式忽略此项。 |
| `striped` | `boolean` | `true` | 两种外观均默认从第二行开始展示交替行背景，并隐藏行间分割线；关闭时显示行间细线。 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 表格视口最大高度，表头始终固定，表体在内部滚动；虚拟模式未指定时使用 400。 |
| `minWidth` | `CSSProperties['minWidth']` | — | 表格最小宽度；默认根据可见列宽计算。 |
| `loading` | `boolean` | `false` | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 空数据内容。 |
| `error` | `ReactNode` | — | 请求失败提示；null、undefined 或 false 不展示。 |
| `onRetry` | `() => void` | — | 请求重试。 |
| `selection` | `false \| 'single' \| 'multiple'` | `false` | 不选择、单选或多选。 |
| `resizable` | `boolean` | `false` | 展示可调整列的宽度手柄。 |
| `virtual` | `boolean \| `[`DataTableVirtualOptions`](#datatablevirtualoptions) | `false` | 启用行虚拟化。 |
| `pagination` | `boolean \| `[`DataTablePaginationProps`](#datatablepagination-api) | `true` | 分页器开关或展示参数，参见 <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a>；直接传入数据时，false 同时关闭本地切页。 |
| `tableRef` | `Ref<HTMLTableElement>` | — | 原生表格 DOM ref。 |
| `getRowLabel` | `(row: Row<TData>) => string` | — | 行操作的可访问名称；默认使用稳定 row.id。 |
| `renderExpandedRow` | `(row: Row<TData>) => ReactNode` | — | 渲染叶子行详情，同时配置 getRowCanExpand。 |
| `getRowProps` | `(row: Row<TData>) => `[`DataTableRowProps`](#datatablerow-api) | — | 自定义行属性与事件。 |
| `getCellProps` | `(cell: Cell<TData, unknown>) => `[`DataTableCellProps`](#datatablecell-api) | — | 自定义单元格属性、样式或合并；colSpan / rowSpan 为 0 时省略该单元格。 |

`aria-label` / `aria-labelledby` 应用于原生表格，其他原生 div 属性用于外层。

<a id="datatablerowkey"></a>

`DataTableRowKey<TData>` 只允许非可选的字符串 / 数字字段，或 `(row: TData, index: number) => string | number` 函数。布尔、对象、数组及可选字段不能直接作为标识；缺少天然标识时，应由业务生成稳定且唯一的值，不使用排序或分页后的下标。

<a id="datatablerow-api"></a>

`getRowProps` 返回的 `DataTableRowProps` 支持原生 `tr` 属性与事件，额外的 `selected?: boolean` 设置行的选中样式。

<a id="datatablecell-api"></a>

`getCellProps` 返回的 `DataTableCellProps` 支持原生 `td` 属性、事件和 `colSpan` / `rowSpan`；额外的 `align` 为 `'start' | 'center' | 'end'`，默认 `'start'`。跨度为 0 时省略该单元格。

<a id="datatablepresentation-api"></a>

[ConfigProvider](config-provider#configprovider-api) 的 `components.DataTable` 使用主表中与行类型无关的展示参数，如 `size`、`variant`、`pagination`；不支持 `tableRef`。可从 `@ifhover/leaf-ui` 导入 `DataTablePresentationProps` 组装配置；只配置默认参数不需要安装 TanStack Table，使用 DataTable 时仍需要安装。

### useDataTable

<a id="usedatatableoptions"></a>

`UseDataTableOptions<TData>` 复用 [DataTable API](#datatable-api) 的 `data`、`columns`、`rowKey`、`localPagination` 和 `options`，其中前三项必填，其余可选。`localPagination` 控制本地切页，分页器的展示参数仍在 DataTable 上配置。

`useDataTable<TData>(config: UseDataTableOptions<TData>): TanStackTable<TData>`

Hook 创建并返回一个稳定的原生实例，不读取 DataTable 的区域展示默认参数，也不请求数据。筛选、分页和展开使用本地行模型；排序模型已配置，但默认关闭排序，需要 `options.enableSorting: true` 显式开启。`options` 可覆盖相应模型及服务端设置，`manualSorting: true` 让业务接管数据顺序，但不会自动开启排序按钮。返回的实例可以直接传给 DataTable，或由业务使用 TanStack API 读写。行详情需要在 `options.getRowCanExpand` 中显式启用。

### useDataTableSelection

`useDataTableSelection(options?): UseDataTableSelectionResult`

用业务行 key 管理 TanStack 的行选择，避免应用再维护一份 `RowSelectionState`：

```tsx
const selection = useDataTableSelection({
  mode: 'multiple',
  selectedRowKeys: selectedKeys,
  onSelectedRowKeysChange: setSelectedKeys,
});

const table = useDataTable({
  data,
  columns,
  rowKey: 'id',
  options: selection.selectionOptions,
});
```

`selection.selectionOptions` 可直接传给 DataTable 或 `useDataTable` 的 `options`，也可展开到原生 `useReactTable` 的配置中。业务 key 支持字符串或数字，返回值统一为去重后的字符串；单选保留最近请求的一个 key，多选保留全部已选 key。`clearSelection()` 发出清空请求并触发回调，受控模式需由业务更新 `selectedRowKeys`。行 id 必须与 `rowKey` / `getRowId` 的结果一致。

#### 参数 (UseDataTableSelectionOptions)

<a id="usedatatableselectionoptions"></a>

配置业务行标识的受控或非受控选择状态。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mode` | `'single' \| 'multiple'` | `multiple` | 单选只保留最近请求的一个 key；多选保留全部已选 key。 |
| `selectedRowKeys` | `readonly DataTableRowSelectionKey[]` | — | 受控的已选业务行 key，数组顺序决定单选模式保留哪一项。 |
| `defaultSelectedRowKeys` | `readonly DataTableRowSelectionKey[]` | `[]` | 非受控模式的初始已选业务行 key。 |
| `onSelectedRowKeysChange` | `(selectedRowKeys: string[]) => void` | — | 选择变化时返回规范化、去重后的字符串 key。 |

#### 返回值 (UseDataTableSelectionResult)

<a id="usedatatableselectionresult"></a>

返回业务行标识、原生选择状态及清除操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `selectedRowKeys` | `string[]` | 必填 | 当前已选业务行 key；受控时来自 selectedRowKeys，非受控时来自内部状态。 |
| `rowSelection` | `RowSelectionState` | 必填 | 由业务 key 派生的 TanStack 原生 rowSelection 映射。 |
| `onRowSelectionChange` | `OnChangeFn<RowSelectionState>` | 必填 | 可直接传给 useDataTable 或原生 useReactTable。 |
| `selectionOptions` | [`DataTableSelectionOptions`](#datatableselectionoptions) | 必填 | 可直接展开到 useDataTable options 的完整选择配置。 |
| `clearSelection` | `() => void` | 必填 | 清空受控或非受控选择，并触发变更回调。 |

<a id="datatableselectionoptions"></a>

### DataTableColumnMeta

<a id="datatablecolumndef"></a>

在 TanStack 列定义的 `meta` 中使用以下属性；函数式 header 建议同时设置 `label`。`DataTableColumnDef<TData, TValue>` 为原生 `ColumnDef` 的 `meta` 补充 `DataTableColumnMeta` 类型约束，提供补全和拼写检查，不修改 TanStack 全局类型；原生列定义仍然兼容。

```tsx
import type { DataTableColumnDef } from '@ifhover/leaf-ui/table';

type Member = { id: string; name: string };

const columns = [
  { accessorKey: 'name', header: '姓名', meta: { align: 'start', label: '姓名' } },
] satisfies DataTableColumnDef<Member>[];
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | — | 排序和列宽调整使用的纯文字列名。 |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | 表头和单元格对齐。 |
| `cellClassName` | `string` | — | 单元格类名。 |
| `headerClassName` | `string` | — | 表头类名。 |

| 属性 | 类型 | 默认值 | 说明 |

### DataTablePagination API

通用展示参数见 <a href="pagination.html#pagination-api" target="_blank" rel="noopener noreferrer">Pagination API</a>（新标签页打开）。此处只说明 DataTable 的差异。

- `total`、`current`、`pageSize` 和 `onChange` 由表格实例管理，不接受 `defaultCurrent` 或 `defaultPageSize`；初始分页通过实例的 `initialState.pagination` 配置。
- `showSizeChanger` 默认开启，`size` 默认跟随 DataTable。
- 未知总数（`pageCount: -1`）时只显示上一页和下一页；额外的 `hasNextPage?: boolean` 控制下一页是否可用，未传时使用实例的判断。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `hasNextPage` | `boolean` | — | 未知总数时控制下一页是否可用。 |
