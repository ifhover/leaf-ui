浏览和操作结构化数据。

从 `@ifhover/leaf-ui/table` 子路径导入，样式自动加载。使用前安装可选依赖：

```bash

```

### 固定列与列宽调整

用 TanStack 的 `columnPinning` 固定列，列定义的 `size`、`minSize` 和 `maxSize` 限定宽度。拖动表头边缘，或聚焦边缘后用方向键调整；`maxHeight` 让表体在内部滚动。

### 服务端排序与分页

组件不请求数据。应用控制排序与分页状态，配置 `manualSorting`、`manualPagination` 和 `rowCount`，再传回当前页数据；排序变化时重置页码，清理过期请求。TanStack 回调可能传入新值或更新函数，可直接交给 React 的 setter。

## API

### DataTable API

列定义和状态沿用 TanStack 原生 API，相关说明见 [列定义](https://tanstack.com/table/v8/docs/guide/column-defs) 与 [受控状态](https://tanstack.com/table/v8/docs/framework/react/guide/table-state)。`DataTable.Toolbar`、`Content` 和 `Footer` 支持原生 `div` 属性。

以下参数由两种模式共享。`DataTableProps<TData>` 是 `DataTableInstanceProps<TData> | DataTableDataProps<TData>`；封装并透传完整参数时使用该联合类型，仅封装实例模式时使用 `DataTableInstanceProps<TData>`。两个模式的专属参数分别见 [实例模式](#datatableinstance-api) 和 [快捷模式](#datatabledata-api)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `layout` | `'auto' \| 'custom'` | — | 显式选择内置布局或完全自定义组合。省略时保留旧行为：传入 children 会替换自动布局；`children={false}` 才继续使用自动布局。 |
| `children` | `ReactNode` | — | layout="custom" 时的完整组合；省略 layout 时传入 children 会替换自动布局并触发开发提示。只是被工具栏或内容使用的嵌套数据不应放在这里。 |
| `toolbar` | `ReactNode` | — | 自动布局中的工具栏内容；仍由 DataTable 渲染 Content 和分页器。显式自定义布局请直接组合对应的公共部件。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `variant` | `'layered' \| 'simple'` | `'layered'` | layered 使用分层卡片；simple 使用整块圆角表头，无外框、阴影、斑马纹和列分隔线。 |
| `columnDividers` | `boolean` | — | 增加表体和表尾的列分隔线；layered 表头保留短分隔线。simple 模式忽略此项。 |
| `bordered` | `boolean` | `false` | 已弃用，请改用 columnDividers；columnDividers 显式传入时优先。 |
| `striped` | `boolean` | `true` | 从第二行开始展示交替行背景，并隐藏行间分割线；关闭时显示行间细线。simple 模式忽略此项，始终使用细行分隔线。 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 表格视口最大高度，表头始终固定，表体在内部滚动；虚拟模式未指定时使用 400。 |
| `minWidth` | `CSSProperties['minWidth']` | — | 表格最小宽度；默认根据可见列宽计算。 |
| `loading` | `boolean` | `false` | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 空数据内容。 |
| `error` | `ReactNode` | — | 请求失败提示；null、undefined 或 false 不展示。 |
| `onRetry` | `() => void` | — | 请求重试。 |
| `selection` | `false \| 'single' \| 'multiple'` | `false` | 不选择、单选或多选。 |
| `selectAllMode` | `'page' \| 'all'` | `'page'` | 全选当前页，或实例内已加载的可选择行。 |
| `resizable` | `boolean` | `false` | 展示可调整列的宽度手柄。 |
| `columnReordering` | `boolean` | `false` | 展示单层表头的拖拽手柄。 |
| `virtual` | `boolean \| `[`DataTableVirtualOptions`](#datatablevirtualoptions) | `false` | 启用行虚拟化。 |
| `pagination` | `boolean \| `[`DataTablePaginationProps`](#datatablepagination-api) | `true` | 默认布局的分页器开关或展示参数；快捷模式设为 false 时同时关闭本地数据截断。 |
| `tableRef` | `Ref<HTMLTableElement>` | — | 原生表格 DOM ref。 |
| `getRowLabel` | `(row: Row<TData>) => string` | — | 行操作的可访问名称；默认使用稳定 row.id。 |
| `renderExpandedRow` | `(row: Row<TData>) => ReactNode` | — | 渲染叶子行详情，同时配置 getRowCanExpand。 |
| `getRowProps` | `(row: Row<TData>) => `[`DataTableRowProps`](#datatablerow-api) | — | 自定义行属性与事件。 |
| `getCellProps` | `(cell: Cell<TData, unknown>) => `[`DataTableCellProps`](#datatablecell-api) | — | 自定义单元格属性、样式或合并；colSpan / rowSpan 为 0 时省略该单元格。 |
| `onRowReorder` | `(info: `[`DataTableRowReorderInfo`](#datatablerowreorderinfo)`<TData>) => void` | — | 展示行拖拽手柄，并返回重排后的当前页行；应用负责更新数据。 |
| `localPagination` | `boolean` | — | 是否让 TanStack 在本地切分当前页数据；关闭时保留分页状态和分页器，但直接展示传入的行。 |

`aria-label` / `aria-labelledby` 应用于原生表格，其他原生 div 属性用于外层。

### DataTableInstance API

实例模式的专属参数，其余参数见 [DataTable API](#datatable-api)。实例可由 `useDataTable` 或原生 `useReactTable` 创建。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `table` | `TanStackTable<TData>` | 必填 | 实例模式唯一的数据与状态来源；不再传入 data、columns、rowKey 或 options。 |

### DataTableData API

此表展示快捷模式的额外属性；其余展示、选择、展开和滚动参数与 [DataTable API](#datatable-api) 相同，不接受 `table`。公开类型为 `DataTableDataProps<TData>`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | 必填 | 展示的数据，更新时使用新数组。 |
| `columns` | `readonly ColumnDef<TData>[]` | 必填 | TanStack 的原生列定义。 |
| `rowKey` | [`DataTableRowKey`](#datatablerowkey)`<TData>` | 必填 | 非可选的字符串或数字标识字段，或返回字符串 / 数字标识的函数。 |
| `options` | `Omit<TableOptions<TData>, 'data' \| 'columns' \| 'getCoreRowModel' \| 'getRowId'>` | — | 定制 TanStack 的状态、回调和服务端配置。 |

### useDataTable

`useDataTable<TData>(config: UseDataTableOptions<TData>): TanStackTable<TData>`

Hook 创建并返回一个稳定的原生实例，不读取 DataTable 的区域展示默认参数，也不请求数据。筛选、分页和展开使用本地行模型；排序模型已配置，但默认关闭排序，需要 `options.enableSorting: true` 显式开启。`options` 可覆盖相应模型及服务端设置，`manualSorting: true` 让业务接管数据顺序，但不会自动开启排序按钮。返回的实例可以直接传给 DataTable，或由业务使用 TanStack API 读写。行详情需要在 `options.getRowCanExpand` 中显式启用。

### UseDataTableOptions

Hook 的配置参数；`pagination` 只控制本地截断，分页器的外观由 DataTable 配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | 必填 | 展示的数据，更新时使用新数组。 |
| `columns` | `readonly ColumnDef<TData>[]` | 必填 | TanStack 的原生列定义。 |
| `rowKey` | [`DataTableRowKey`](#datatablerowkey)`<TData>` | 必填 | 每行稳定且唯一的字符串或数字标识。 |
| `localPagination` | `boolean` | — | 是否让 TanStack 在本地切分当前页数据；关闭时保留分页状态和分页器，但直接展示传入的行。 |
| `pagination` | `boolean` | `true` | 已弃用，请改用 localPagination。不传 localPagination 时作为兼容别名；false 会关闭本地数据切分。 |
| `options` | `Omit<TableOptions<TData>, 'data' \| 'columns' \| 'getCoreRowModel' \| 'getRowId'>` | — | 定制 TanStack 的状态、回调、行模型和服务端配置。 |

### useDataTableSelection

`useDataTableSelection(options?): UseDataTableSelectionResult`

用业务行 key 管理 TanStack 的行选择，避免应用再维护一份 `RowSelectionState`：

```tsx
const selection = useDataTableSelection({
  mode: 'multiple',
  selectedRowKeys: selectedKeys,
  onSelectedRowKeysChange: setSelectedKeys,
});

const table = useDataTable({
  data,
  columns,
  rowKey: 'id',
  options: selection.selectionOptions,
});
```

`selection.selectionOptions` 可直接展开到 `useDataTable` 的 `options`，或传给原生 `useReactTable`。`selectedRowKeys` 为非受控、受控单选的最近 key 与多选的全部 key；`clearSelection()` 会同步清空选择并触发回调。行 id 必须与 `rowKey` / `getRowId` 的结果一致。

### UseDataTableSelectionOptions

配置业务行标识的受控或非受控选择状态。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `mode` | `'single' \| 'multiple'` | `multiple` | 单选只保留最近请求的一个 key；多选保留全部已选 key。 |
| `selectedRowKeys` | `readonly DataTableRowSelectionKey[]` | — | 受控的已选业务行 key，数组顺序决定单选模式保留哪一项。 |
| `defaultSelectedRowKeys` | `readonly DataTableRowSelectionKey[]` | `[]` | 非受控模式的初始已选业务行 key。 |
| `onSelectedRowKeysChange` | `(selectedRowKeys: string[]) => void` | — | 选择变化时返回规范化、去重后的字符串 key。 |

### UseDataTableSelectionResult

返回业务行标识、原生选择状态及清除操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `selectedRowKeys` | `string[]` | 必填 | 当前已选业务行 key；受控时来自 selectedRowKeys，非受控时来自内部状态。 |
| `rowSelection` | `RowSelectionState` | 必填 | 由业务 key 派生的 TanStack 原生 rowSelection 映射。 |
| `onRowSelectionChange` | `OnChangeFn<RowSelectionState>` | 必填 | 可直接传给 useDataTable 或原生 useReactTable。 |
| `selectionOptions` | [`DataTableSelectionOptions`](#datatableselectionoptions) | 必填 | 可直接展开到 useDataTable options 的完整选择配置。 |
| `clearSelection` | `() => void` | 必填 | 清空受控或非受控选择，并触发变更回调。 |

### DataTableSelectionOptions

将业务选择状态接入表格实例的 `options`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `state` | `{ rowSelection: RowSelectionState }` | 必填 | 传给 useDataTable options 的受控 rowSelection 状态。 |
| `onRowSelectionChange` | `OnChangeFn<RowSelectionState>` | 必填 | TanStack 原生选择变更回调，内部会规范化业务 key。 |
| `enableMultiRowSelection` | `boolean` | 必填 | 由 mode 决定；单选为 false，多选为 true。 |

### DataTableRowKey

`DataTableRowKey<TData>` 只允许非可选的字符串 / 数字字段，或返回字符串 / 数字的函数。布尔、对象、数组及可选字段不能直接作为标识；缺少天然标识时，应由业务生成稳定且唯一的值，不使用排序或分页后的下标。

```ts
export type DataTableRowKey<TData> =
  | {
      [Key in keyof TData]-?: TData[Key] extends string | number ? Key : never;
    }[keyof TData]
  | ((row: TData, index: number) => string | number);
```

### DataTableColumnMeta

可以在 TanStack 列定义的 `meta` 中使用以下属性。函数式 header 建议同时设置 label。使用可选的 `DataTableColumnDef<TData, TValue>` 为这些属性获得补全和拼写检查，它只为原生 `ColumnDef` 补充元数据约束，不修改 TanStack 全局类型；原生列定义仍然兼容。

```tsx
import type { DataTableColumnDef, DataTableColumnMeta } from '@ifhover/leaf-ui/table';
import type { ColumnDef } from '@tanstack/react-table';

type Member = { id: string; name: string };

const columns = [
  { accessorKey: 'name', header: '姓名', meta: { align: 'start', label: '姓名' } },
] satisfies DataTableColumnDef<Member>[];

const nativeColumn: ColumnDef<Member> = {
  accessorKey: 'name',
  meta: { align: 'start' } satisfies DataTableColumnMeta,
};
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | — | 列管理与行操作使用的纯文字列名。 |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | 表头和单元格对齐。 |
| `cellClassName` | `string` | — | 单元格类名。 |
| `headerClassName` | `string` | — | 表头类名。 |

| `size` | `'sm' \| 'md' \| 'lg'` | — | 展示尺寸。 |
| `variant` | `'layered' \| 'simple'` | — | layered 使用分层卡片；simple 使用整块圆角表头，无外框、阴影、斑马纹和列分隔线。 |
| `columnDividers` | `boolean` | — | 增加表体和表尾的列分隔线；layered 表头保留短分隔线。simple 模式忽略此项。 |
| `bordered` | `boolean` | — | 已弃用，请改用 columnDividers；columnDividers 显式传入时优先。 |
| `striped` | `boolean` | — | 从第二行开始展示交替行背景，并隐藏行间分割线；关闭时显示行间细线。simple 模式忽略此项，始终使用细行分隔线。 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 表格视口最大高度，表头始终固定，表体在内部滚动；虚拟模式未指定时使用 400。 |
| `minWidth` | `CSSProperties['minWidth']` | — | 表格的最小宽度；超出容器时在表格内横向滚动。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 没有内容时的展示。 |
| `error` | `ReactNode` | — | 请求失败时显示的内容，替代数据行。 |
| `onRetry` | `() => void` | — | 点击错误状态中的重试操作时调用。 |
| `selection` | `false \| 'single' \| 'multiple'` | — | 行选择模式；false 关闭，single 单选，multiple 多选。 |
| `selectAllMode` | `'page' \| 'all'` | — | 表头全选作用于当前页或已加载的全部筛选结果，不包含未加载的服务端数据。 |
| `resizable` | `boolean` | — | 允许拖动和使用方向键调整大小。 |
| `columnReordering` | `boolean` | — | 启用列拖拽；仅支持单层表头且不跨固定列分区。 |
| `virtual` | `boolean \| `[`DataTableVirtualOptions`](#datatablevirtualoptions) | — | 启用行虚拟化，默认关闭。 |
| `pagination` | `boolean \| `[`DataTablePaginationProps`](#datatablepagination-api) | — | 显示或配置分页器；快捷数据模式下 false 同时关闭本地切页。 |
| `tableRef` | `Ref<HTMLTableElement>` | — | 获取内部原生 table 元素，用于测量或聚焦。 |

### DataTablePagination API

沿用 Pagination 的展示参数，`total`、`current`、`pageSize` 和 `onChange` 由实例管理；`showSizeChanger` 默认开启。未知总数模式只提供上一页和下一页。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `showSizeChanger` | `boolean` | `true` | 展示每页条数选择器；DataTable 默认开启，可显式传入 false 关闭。 |
| `pageSizeOptions` | `readonly number[]` | — | 可选择的每页条数。 |
| `showQuickJumper` | `boolean` | `false` | 回车或离开分页区域时跳转。 |
| `showTotal` | `boolean \| ((total: number, range: readonly [number, number]) => ReactNode)` | `false` | true 展示默认统计，也可传入函数定制总数及当前范围。 |
| `simple` | `boolean` | `false` | 使用简洁分页器。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `hideOnSinglePage` | `boolean` | `false` | 只有一页时隐藏分页器。 |
| `size` | `'sm' \| 'md' \| 'lg'` | DataTable size | 默认跟随 DataTable 的尺寸。 |
| `variant` | `'outline' \| 'ghost'` | `'outline'` | 分页按钮样式：描边 / 无边框。 |
| `hasNextPage` | `boolean` | — | 未知总数时控制下一页是否可用。 |

### DataTableContent API

`DataTable.Content` 支持原生 `div` 属性，包括 `className`、`style` 和事件。表格的布局、选择、展开与加载参数在 [DataTable](#datatable-api) 上配置，表格 DOM ref 使用 `tableRef`。公开类型为 `DataTableContentProps`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `className` | `string` | — | 内容区域的自定义类名。 |
| `style` | `CSSProperties` | — | 内容区域的内联样式。 |
