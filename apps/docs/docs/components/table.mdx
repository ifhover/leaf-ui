# DataTable 表格

浏览、筛选和管理结构化数据。

## 安装与导入

DataTable 传入数据与列即可使用排序和分页；复杂场景传入自己的 TanStack Table 实例，获得筛选、选择、展开和列管理的统一界面。使用前安装依赖：

```bash
npm install @tanstack/react-table@^8.21.3
```

```tsx
import { DataTable } from '@ifhover/leaf-ui/table';
import type { DataTableProps, DataTableColumnMeta } from '@ifhover/leaf-ui/table';
```

表格子路径自动加载所需样式。DataTable 及其数据类型从 `@ifhover/leaf-ui/table` 导入，DataTable 不从组件库根入口导出。

`data + columns + rowKey` 模式内部创建一个 TanStack 实例，复用与高级模式相同的界面。`rowKey` 必须是非可选的字符串或数字字段，或返回字符串 / 数字的函数；标识必须稳定且唯一。默认启用本地排序、筛选、分页和展开；使用 `options` 定制初始状态、受控回调或服务端配置。`localPagination={false}` 保留分页状态和分页器，但不再本地截断数据；`pagination={false}` 仍作为旧写法同时关闭分页器和本地截断。动态切换不会重新挂载实例或清空选择。

两种模式互斥：提供 `table` 后不要再传 `data`、`columns`、`rowKey` 或 `options`。需要访问实例时使用 `useDataTable`；完全自行配置行模型时使用原生 `useReactTable`。

仅把业务需要的状态及对应回调放入 `options`，其他状态继续由 TanStack 管理。此例使用 `useDataTableSelection` 将业务行 key 映射为 TanStack 的 `rowSelection`，不需要同时维护排序、筛选和分页。需要受控选择时传入 `selectedRowKeys` 与 `onSelectedRowKeysChange`；不传这两个参数即使用内部状态。受控回调使用 TanStack 原生的值或 updater 函数契约。

`toolbar` 在默认内容上方插入工具栏；`pagination={{ ... }}` 配置分页器的展示参数，例如 `pageSizeOptions`、`showTotal` 和 `hasNextPage`。分页状态仍放在 `options.state.pagination` / `options.initialState.pagination`，不会建立第二套状态。

## 外框、列分隔线与斑马纹

DataTable 默认始终展示基础圆角的外框和向下偏移的静止阴影，外框使用与 Card 相同的减淡分隔线颜色；表头保持与表格相同的表面，底部保留 1px 分割线。`striped` 默认开启，`columnDividers` 只增加列分隔线，不再控制外框；旧 `bordered` 仍兼容但已弃用。表头文字加粗并略淡于正文，排序图标紧跟文字。斑马纹从第一行开始使用淡色背景，开启时不显示行间分割线，设置 `striped={false}` 后显示行间细线。普通行与条纹行悬停时使用相同的不透明主色混合背景；选中行使用主题浅色背景，并优先于悬停样式。

## 排序、筛选、选择与分页

`useDataTable` 返回普通 TanStack 实例，复用快捷模式的行模型、稳定主键和 RTL 列宽方向。可直接读取已选行、重置筛选或编写批量操作，而不必手动配置全部行模型和受控状态：

<ComponentExample title="管理团队成员" preview={<TableData />} fileName="data.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/table/data.tsx"
```

</ComponentExample>

`table` 是唯一的数据状态来源。Leaf UI 不重新排序或分页，也不在 TanStack 状态之外另建筛选和展开仓库；`useDataTableSelection` 只是业务 key 与 `rowSelection` 之间的受控映射。使用 `useDataTable` 时，常用本地行模型已配置；完全使用原生 `useReactTable` 时，按需要配置：

| 能力 | TanStack 配置 |
| --- | --- |
| 基础数据 | `getCoreRowModel()` |
| 本地排序 | `getSortedRowModel()` |
| 本地搜索与筛选 | `getFilteredRowModel()` |
| 本地分页 | `getPaginationRowModel()` |
| 树形或分组展开 | `getExpandedRowModel()`，树形数据同时配置 `getSubRows` |
| 行详情 | `getRowCanExpand`，以及 DataTable 的 `renderExpandedRow` |
| 分组与合计 | `getGroupedRowModel()`、列的 `aggregationFn` 与 `aggregatedCell` |

使用稳定的 `getRowId`，不要用排序或分页后的数组下标。默认全选只影响当前页可选择的行；`selectAllMode="all"` 作用于实例已加载并参与筛选的数据，**不代表全选服务端尚未加载的记录**。跨页选择由 TanStack 的 `rowSelection` 保存；服务端场景通过这些 key 处理业务，不要只依赖当前页的 `getSelectedRowModel()`。

`DataTable.Search` 默认更新全局搜索，指定 `columnId` 后只筛选该列。`DataTable.ColumnVisibility` 保留 `enableHiding: false` 的列。Shift 点击表头可多列排序；`aria-sort` 标记第一排序列。

## 固定表头、固定列与列宽

<ComponentExample title="固定列与列宽" preview={<TableColumns />} fileName="data.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/table/data.tsx"
```

</ComponentExample>

通过 `columnPinning` 控制固定列，`columnOrder` 控制列顺序，列的 `size`、`minSize` 和 `maxSize` 控制宽度。`left` / `right` 在 Leaf UI 中对应逻辑起始 / 结束侧，跟随 RTL 方向。RTL 场景同时给 TanStack 配置 `columnResizeDirection: 'rtl'`。固定列阴影只在被遮挡的内容确实位于该方向时显示，滚动到对应逻辑边界后自动隐藏；`getCellProps` 返回的 `style` 不能覆盖内部固定定位。

表格默认填满所在容器，列所需宽度超过容器时才在内部横向滚动。表头默认固定；设置 `maxHeight` 后，超出的行在表体内滚动。悬浮滚动条使用 [Scrollbar](./scrollbar)，纵向条从表头下方开始；未溢出或到达滚动边界时，滚轮继续滚动页面。

列宽手柄可拖动，也可聚焦后用左右方向键调整；Shift 增大步长，Home / End 跳到边界，双击恢复初始宽度。建议给可调整列设置合理的最大宽度。`ConfigProvider` 的 `density` 和 `theme.components.Table` 控制整个区域的密度、圆角、内边距、字号、颜色、背景和阴影。


行首和表头的手柄支持鼠标、触摸和键盘。聚焦后按空格开始，方向键移动，空格确认，Escape 取消。`onRowReorder` 返回当前页重排后的行与稳定标识，应用负责更新业务数组或提交服务端；列拖拽直接更新 TanStack 的 `columnOrder`。

行拖拽仅用于未排序、未筛选、未分组、未展开的平面非虚拟表格，其他模式不展示行手柄，避免视觉顺序和业务顺序冲突。列拖拽仅支持单层表头且不跨越固定列分区；多层表头仍可通过 `columnOrder` 明确控制。拖拽不会修改行选择或编辑器状态。

`virtual` 是显式的行虚拟化，默认不开启。为滚动区域设置 `maxHeight`，并按实际布局设置估算行高；动态高度会被重新测量，焦点所在的行不会因滚动而立即卸载。SSR 首屏输出估算窗口，客户端接管后测量实际高度。

这不是电子表格式 DataGrid：不提供方向键逐单元格导航、列虚拟化或自动移动端卡片化。普通表格维持原生语义和横向滚动；需要浏览全部数据的屏幕阅读器用户可关闭虚拟化，改用分页。

## 服务端数据

<ComponentExample title="远程分页与重试" preview={<TableServer />} fileName="advanced.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/table/advanced.tsx"
```

</ComponentExample>

远程分页使用 `manualPagination: true` 与 `rowCount`。远程排序 / 筛选分别使用 `manualSorting` / `manualFiltering`；把 TanStack 的受控状态用于请求参数，并取消过期请求。没有总数时可配置 `pageCount: -1`，分页器只展示上一页与下一页，通过 `<DataTable.Pagination hasNextPage={hasMore} />` 控制能否继续翻页。

刷新时保留已有行，展示 loading 遮罩并禁止重复交互。首次加载、空数据、请求失败使用独立状态行。自动布局展示内容，并在分页能力存在时展示分页器；`toolbar` 只补充工具栏。自定义组合请显式设置 `layout="custom"` 并排列 Toolbar、Content 和 Footer。为兼容旧代码，省略 `layout` 时仍允许 `children` 替换自动布局，但会触发开发提示；`layout="auto"` 会忽略 children 并渲染自动布局。

在快捷模式中，`pagination={false}` 同时隐藏默认分页器并关闭本地截断；传入 `table` 时，它只隐藏默认分页器，不修改外部实例。使用 `useDataTable` 时，用 `localPagination` 控制是否本地切页，用 DataTable 的 `pagination` 控制分页器显示。`localPagination={false}` 会强制绕过本地切页；`localPagination` 为 `true` 时仍以 `options.manualPagination` 为准。服务端分页使用 `options.manualPagination: true`。旧 Hook 参数 `pagination` 仅作为兼容别名保留。

表格缺少 `getFilteredRowModel()` / `manualFiltering`、`getPaginationRowModel()` / `manualPagination` 等对应能力时，会隐藏或禁用相关交互，并在开发环境给出提示。`DataTable.Search` 使用不存在的 `columnId` 或不可筛选列时同样禁用。

`DataTable.Search` 默认启用清除操作和 DataTable 尺寸；`DataTable.Pagination` 默认启用每页条数选择器。传入 `false` 可显式关闭。

未知总数模式保留原生 `id`、`style`、事件、`dir` 和可访问名称，只提供上一页 / 下一页；`showSizeChanger`、`showQuickJumper`、`showTotal`、`simple` 和 `hideOnSinglePage` 在此模式不生效。

## DataTable API

以下参数由两种模式共享。`DataTableProps<TData>` 是 `DataTableInstanceProps<TData> | DataTableDataProps<TData>`；封装并透传完整参数时使用该联合类型，仅封装实例模式时使用 `DataTableInstanceProps<TData>`。两个模式的专属参数分别见 [实例模式](#datatableinstance-api) 和 [快捷模式](#datatabledata-api)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `layout` | `'auto' \| 'custom'` | — | 显式选择内置布局或完全自定义组合。省略时保留旧行为：传入 children 会替换自动布局；children={false} 才继续使用自动布局。 |
| `children` | `ReactNode` | — | layout="custom" 时的完整组合；省略 layout 时传入 children 会替换自动布局并触发开发提示。只是被工具栏或内容使用的嵌套数据不应放在这里。 |
| `toolbar` | `ReactNode` | — | 自动布局中的工具栏内容；仍由 DataTable 渲染 Content 和分页器。显式自定义布局请直接组合对应的公共部件。 |
| `caption` | `ReactNode` | — | 表格说明。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `columnDividers` | `boolean` | — | 仅增加列分隔线；外框、圆角和向下静止阴影始终启用。 |
| `bordered` | `boolean` | `false` | 已弃用，请改用 columnDividers；columnDividers 显式传入时优先。 |
| `striped` | `boolean` | `true` | 展示交替行背景并隐藏行间分割线；关闭时显示行间细线。 |
| `stickyHeader` | `boolean` | `true` | 表头保持在滚动区域顶部。 |
| `maxHeight` | `CSSProperties['maxHeight']` | — | 滚动区域最大高度；虚拟模式未指定时使用 400。 |
| `minWidth` | `CSSProperties['minWidth']` | — | 表格最小宽度；默认根据可见列宽计算。 |
| `loading` | `boolean` | `false` | 展示加载状态。 |
| `emptyContent` | `ReactNode` | — | 空数据内容。 |
| `error` | `ReactNode` | — | 请求失败提示；null、undefined 或 false 不展示。 |
| `onRetry` | `() => void` | — | 请求重试。 |
| `selection` | `false \| 'single' \| 'multiple'` | `false` | 不选择、单选或多选。 |
| `selectAllMode` | `'page' \| 'all'` | `'page'` | 全选当前页，或实例内已加载的可选择行。 |
| `resizable` | `boolean` | `false` | 展示可调整列的宽度手柄。 |
| `columnReordering` | `boolean` | `false` | 展示单层表头的拖拽手柄。 |
| `virtual` | `boolean \| `[`DataTableVirtualOptions`](#datatablevirtualoptions) | `false` | 启用行虚拟化。 |
| `pagination` | `boolean \| `[`DataTablePaginationProps`](#datatablepagination-api) | `true` | 默认布局的分页器开关或展示参数；快捷模式设为 false 时同时关闭本地数据截断。 |
| `tableRef` | `Ref<HTMLTableElement>` | — | 原生表格 DOM ref。 |
| `getRowLabel` | `(row: Row<TData>) => string` | — | 行操作的可访问名称；默认使用稳定 row.id。 |
| `renderExpandedRow` | `(row: Row<TData>) => ReactNode` | — | 渲染叶子行详情，同时配置 getRowCanExpand。 |
| `getRowProps` | `(row: Row<TData>) => `[`DataTableRowProps`](#datatablerow-api) | — | 自定义行属性与事件。 |
| `getCellProps` | `(cell: Cell<TData, unknown>) => `[`DataTableCellProps`](#datatablecell-api) | — | 自定义单元格属性、样式或合并；colSpan / rowSpan 为 0 时省略该单元格。 |
| `onRowReorder` | `(info: `[`DataTableRowReorderInfo`](#datatablerowreorderinfo)`<TData>) => void` | — | 展示行拖拽手柄，并返回重排后的当前页行；应用负责更新数据。 |
| `localPagination` | `boolean` | — | 是否让 TanStack 在本地切分当前页数据；关闭时保留分页状态和分页器，但直接展示传入的行。 |

`aria-label` / `aria-labelledby` 应用于原生表格，其他原生 div 属性用于外层。

## DataTablePagination API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `showSizeChanger` | `boolean` | `true` | 展示每页条数选择器；DataTable 默认开启，可显式传入 false 关闭。 |

## DataTableColumnMeta

可以在 TanStack 列定义的 `meta` 中使用以下属性。函数式 header 建议同时设置 label。使用可选的 `DataTableColumnDef<TData, TValue>` 为这些属性获得补全和拼写检查，它只为原生 `ColumnDef` 补充元数据约束，不修改 TanStack 全局类型；原生列定义仍然兼容。

```tsx
import type { DataTableColumnDef, DataTableColumnMeta } from '@ifhover/leaf-ui/table';
import type { ColumnDef } from '@tanstack/react-table';

type Member = { id: string; name: string };

const columns = [
  { accessorKey: 'name', header: '姓名', meta: { align: 'start', label: '姓名' } },
] satisfies DataTableColumnDef<Member>[];

const nativeColumn: ColumnDef<Member> = {
  accessorKey: 'name',
  meta: { align: 'start' } satisfies DataTableColumnMeta,
};
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | — | 列管理与行操作使用的纯文字列名。 |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | 表头和单元格对齐。 |
| `cellClassName` | `string` | — | 单元格类名。 |
| `headerClassName` | `string` | — | 表头类名。 |

## DataTableRowKey

`DataTableRowKey<TData>` 只允许非可选的字符串 / 数字字段，或返回字符串 / 数字的函数。布尔、对象、数组及可选字段不能直接作为标识；缺少天然标识时，应由业务生成稳定且唯一的值，不使用排序或分页后的下标。

## useDataTable

`useDataTable<TData>(config: UseDataTableOptions<TData>): TanStackTable<TData>`

Hook 创建并返回一个稳定的原生实例，不读取 DataTable 的区域展示默认参数，也不请求数据。排序、筛选、分页和展开使用本地行模型，`options` 可覆盖相应模型及服务端设置。返回的实例可以直接传给 DataTable，或由业务使用 TanStack API 读写。行详情需要在 `options.getRowCanExpand` 中显式启用。

## useDataTableSelection

`useDataTableSelection(options?): UseDataTableSelectionResult`

用业务行 key 管理 TanStack 的行选择，避免应用再维护一份 `RowSelectionState`：

```tsx
const selection = useDataTableSelection({
  mode: 'multiple',
  selectedRowKeys: selectedKeys,
  onSelectedRowKeysChange: setSelectedKeys,
});

const table = useDataTable({
  data,
  columns,
  rowKey: 'id',
  options: selection.selectionOptions,
});
```

`selection.selectionOptions` 可直接展开到 `useDataTable` 的 `options`，或传给原生 `useReactTable`。`selectedRowKeys` 为非受控、受控单选的最近 key 与多选的全部 key；`clearSelection()` 会同步清空选择并触发回调。行 id 必须与 `rowKey` / `getRowId` 的结果一致。

## UseDataTableOptions

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `data` | `readonly TData[]` | — | 必需。展示的数据，更新时使用新数组。 |
| `columns` | `readonly ColumnDef<TData>[]` | — | 必需。TanStack 的原生列定义。 |
| `rowKey` | [`DataTableRowKey`](#datatablerowkey)`<TData>` | — | 必需。每行稳定且唯一的字符串或数字标识。 |
| `localPagination` | `boolean` | — | 是否让 TanStack 在本地切分当前页数据；关闭时保留分页状态和分页器，但直接展示传入的行。 |
| `pagination` | `boolean` | `true` | 已弃用，请改用 localPagination。不传 localPagination 时作为兼容别名；false 会关闭本地数据切分。 |
| `options` | `Omit<TableOptions<TData>, 'data' \| 'columns' \| 'getCoreRowModel' \| 'getRowId'>` | — | 定制 TanStack 的状态、回调、行模型和服务端配置。 |


Hook 的配置参数；`pagination` 只控制本地截断，分页器的外观由 DataTable 配置。
