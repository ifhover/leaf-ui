## 示例

### 颜色格式

使用 `showText` 显示颜色文字，`defaultFormat` 设置初始格式。切换格式不改变当前值，下一次调色按新格式输出。

<ComponentExample exampleId="formats" preview={<ColorPickerFormats />} fileName="formats.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/color-picker/formats.tsx"
```

</ComponentExample>

### 透明度

默认支持透明度，此时 HEX 可能包含 8 位。设置 `disableAlpha` 隐藏透明度控制并输出不透明颜色。


</ComponentExample>

### 控件状态

`disabled` 禁用交互，`readOnly` 锁定颜色值，`status` 显示校验外观但不执行校验。

<ComponentExample exampleId="states" preview={<ColorPickerStates />} fileName="states.tsx" width={360}>

### 渐变色

设置 `mode="gradient"` 编辑角度与色标，颜色值使用 `linear-gradient(...)` 字符串。

<ComponentExample exampleId="gradient" preview={<ColorPickerGradient />} fileName="gradient.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/color-picker/gradient.tsx"
```

</ComponentExample>

需要处理结构化色标时，使用 `gradientString` 将 [`ColorGradient`](#colorgradient) 转为字符串，`parseGradient` 将支持的线性渐变解析为结构化数据；无法解析时返回 `null`。

### 受控值与清除

<a id="进阶用法"></a>

通过 `value` 和 `onChange` 管理颜色，`allowClear` 允许清除并返回空字符串。拖动时 `onChange` 实时触发；只需处理最终值时，使用 `onChangeComplete`。

<ComponentExample exampleId="controlled" preview={<ColorPickerControlled />} fileName="controlled.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/color-picker/controlled.tsx"
```

</ComponentExample>

颜色文字按 Enter 或移走焦点提交，无效输入会提示错误。使用 `name` 参与原生表单提交；非受控字段支持表单重置，受控字段需同步重置应用状态。

## API

### ColorPicker API

颜色值、输出格式、预设颜色与面板交互的配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: ReactNode) => ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `value` | `string` | — | 受控颜色值；支持 HEX、RGB、HSL、CSS 命名颜色，渐变模式使用 linear-gradient 字符串。 |
| `defaultValue` | `string` | `'#1e964f'` | 非受控模式的初始颜色值；表单重置时恢复此值。 |
| `onChange` | `(color: string) => void` | — | 调色过程中实时触发；清除时返回空字符串。 |
| `onChangeComplete` | `(color: string) => void` | — | 一次调色操作结束时触发；清除时返回空字符串。 |
| `format` | `'hex' \| 'rgb' \| 'hsl'` | `'hex'` | 颜色文字格式；渐变模式应用于每个色标。 |
| `defaultFormat` | `'hex' \| 'rgb' \| 'hsl'` | `'hex'` | 初始颜色文字格式。 |
| `onFormatChange` | `(format: 'hex' \| 'rgb' \| 'hsl') => void` | — | 颜色文字格式变化时调用。 |
| `disableAlpha` | `boolean` | `false` | 隐藏透明度并输出不透明颜色 |
| `showText` | `boolean \| ((color: string) => ReactNode)` | `false` | 展示颜色文字或自定义文字 |
| `allowClear` | `boolean` | `false` | 允许清除颜色 |
| `presets` | `readonly `[`ColorPreset`](#colorpreset)`[]` | 内置颜色 | 预设的颜色分组。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 触发控件尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验反馈 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `readOnly` | `boolean` | — | 锁定业务值，禁止输入、选择、清除和删除。 |
| `popupWidth` | `number \| string` | `280` | 浮层宽度 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化 |
| `gradient` | `boolean` | `false` | 启用渐变颜色选择。 |
| `mode` | `'solid' \| 'gradient'` | — | 选择展示或编辑模式。 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | — | 面板初始展开状态。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |

### ColorPreset

预设颜色分组的标题与颜色值。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | 必填 | 分组标题 |
| `colors` | `readonly string[]` | 必填 | 该组的颜色值 |

### ColorGradient

描述渐变方向及色标的颜色值。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `angle` | `number` | 必填 | 渐变角度，单位为度。 |
| `stops` | `readonly `[`ColorGradientStop`](#colorgradientstop)`[]` | 必填 | 渐变中的色标。 |

### ColorGradientStop

渐变中单个颜色及其位置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定且唯一的标识。 |
| `color` | `string` | 必填 | 颜色或语义色。 |
| `offset` | `number` | 必填 | 偏移量；色标为 0–100 的百分比。 |
