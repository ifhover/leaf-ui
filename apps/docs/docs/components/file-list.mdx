# FileList 文件列表

展示文件信息，提供预览、下载与移除操作。文件数据由应用管理；实际上传使用 [Upload](./upload.mdx)。

{/* leaf:section basic */}

## 基础用法

通过 `items` 提供文件信息，并为每项设置稳定的 `uid`。文件大小以字节为单位，省略时尝试读取 `originFile.size`，两者均缺少时不显示大小；不会请求远程文件元信息。

## API

### FileListProps API

#### 文件数据与操作

名称依次取 `name`、`originFile.name`、URL 中的文件名，均不可用时显示默认名称。类型图标与媒体识别使用 MIME 或扩展名，缩略图加载失败时回退为类型图标；这些推断不会回写文件数据。

媒体播放取决于浏览器支持的编码。跨域下载可能在新标签打开，可用 `onDownload` 接入下载服务。通过 `renderActions` 添加操作时，为自定义控件提供可访问名称，并处理相应的禁用状态。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`FileItem`](#fileitem-api)`[]` | 必填 | 展示的文件 |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | 文件列表的展示形式。 |
| `previewable` | `boolean` | `true` | 为有 URL 的图片、视频和音频显示预览操作 |
| `downloadable` | `boolean` | `true` | 为有 URL 的文件显示下载操作 |
| `removable` | `boolean` | `false` | 配合 `onRemove` 显示移除操作 |
| `onPreview` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | 替换有可用 URL 的图片、视频和音频预览操作；其他文件或无 URL 时不显示预览按钮。 |
| `onDownload` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | 有可用 URL 时替换内置下载操作；无 URL 不显示下载按钮。 |
| `onRemove` | `(file: `[`FileItem`](#fileitem-api)`) => void \| boolean \| Promise<void> \| Promise<boolean>` | — | 等待移除回调，期间阻止重复点击；应用须更新 items。布尔返回值不控制列表，Promise 拒绝显示行内错误。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `renderActions` | `(file: `[`FileItem`](#fileitem-api)`, actions: ReactNode) => ReactNode` | — | 自定义行操作；应用负责自定义操作的名称与禁用处理。 |
| `emptyContent` | `ReactNode` | 暂无文件 | 空列表内容 |

### FileItem API

文件列表条目中的文件、状态与展示元信息。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | — | 稳定标识，建议提供 |
| `name` | `string` | — | 显示文件名；省略时依次取 originFile.name、URL 文件名和 File；data URL 不用于推导名称。 |
| `url` | `string` | — | 文件地址 |
| `size` | `number` | — | 文件大小，单位字节；缺省时使用 originFile.size，两者都缺省时隐藏。 |
| `type` | `string` | — | 可选 MIME 类型；展示分类还会参考 originFile.type 和扩展名，不回填此字段。 |
| `originFile` | `globalThis.File` | — | 浏览器选择的原始文件 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 上传状态，可不提供 |
| `percent` | `number` | — | 上传进度 0–100 |
| `error` | `string` | — | 失败说明 |
