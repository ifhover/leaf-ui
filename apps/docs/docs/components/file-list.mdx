# FileList 文件列表

展示文件信息、上传状态，并提供预览、下载和移除操作。

## 文件信息

按文件类型展示图标，文件大小可按需提供。图片支持预览，其他文件可直接下载。

<ComponentExample title="文件信息" preview={<FileListBasic />} fileName="basic.tsx" width="100%">

```tsx lineNumbers file="../../src/examples/file-list/basic.tsx"
```

</ComponentExample>

## 使用说明

文件大小可不提供，不会自动请求文件元信息。图标根据 MIME 或后缀识别，缩略图加载失败时回退为类型图标。图片、视频、音频支持预览，其他文件只提供下载。媒体能否播放取决于浏览器支持的编码。跨域下载可能在新标签打开，可通过 `onDownload` 接入下载服务。上传交互请使用 [Upload](./upload.mdx)。

## FileListProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`FileItem`](#fileitem-api)`[]` | 必填 | 展示的文件 |
| `downloadable` | `boolean` | `true` | 为有 URL 的文件显示下载操作 |
| `previewable` | `boolean` | `true` | 为有 URL 的图片、视频和音频显示预览操作 |
| `removable` | `boolean` | `false` | 配合 `onRemove` 显示移除操作 |
| `onPreview` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | 接管媒体预览；未提供时使用内置预览 |
| `onDownload` | `(file: `[`FileItem`](#fileitem-api)`) => void` | — | 接管下载；未提供时使用文件 URL |
| `onRemove` | `(file: `[`FileItem`](#fileitem-api)`) => void \| boolean \| Promise<void> \| Promise<boolean>` | — | 请求移除，由调用方更新 `items`。等待异步操作；拒绝时在该文件行显示错误。返回 `false` 可拒绝移除 |
| `renderActions` | `(file: `[`FileItem`](#fileitem-api)`, actions: ReactNode) => ReactNode` | — | 定制操作区 |
| `emptyContent` | `ReactNode` | 暂无文件 | 空列表内容 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `listType` | `'text' \| 'picture' \| 'picture-card'` | `'text'` | 文件列表的展示形式。 |

## FileItem API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | — | 稳定标识，建议提供 |
| `url` | `string` | — | 文件地址 |
| `name` | `string` | — | 文件名称，默认取 URL 的文件名 |
| `size` | `number` | — | 字节数，可不提供；未提供时不显示大小 |
| `type` | `string` | — | MIME 类型，未提供时根据扩展名识别 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 上传状态，可不提供 |
| `percent` | `number` | — | 上传进度 0–100 |
| `error` | `string` | — | 失败说明 |
| `originFile` | `globalThis.File` | — | 浏览器选择的原始文件 |
