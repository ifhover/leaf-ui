## 使用说明

名称可从 URL 获取，大小可不提供，不会自动请求文件元信息。图标根据 MIME 或后缀识别。图片、视频、音频显示预览，其他文件只提供下载。媒体能否播放取决于浏览器支持的编码。跨域下载可能在新标签打开，可通过 onDownload 接入下载服务。

import type { FileItem, FileListProps } from '@sudden3/leaf-ui';

## FileListProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | [`readonly FileItem[]`](#fileitem-api) | 必填 | 展示的文件 |
| `downloadable / previewable` | `boolean` | `true` | 显示下载 / 媒体预览操作 |
| `removable / disabled` | `boolean` | `false` | 显示移除操作 / 禁用操作 |
| `onPreview / onDownload` | [`(file: FileItem) => void`](#fileitem-api) | — | 自定义预览或下载；预览仍仅对媒体显示 |
| `onRemove` | [`(file: FileItem) => void \| boolean \| Promise<void> \| Promise<boolean>`](#fileitem-api) | — | 请求移除，由调用方更新 items |
| `renderActions` | [`(file: FileItem, actions: ReactNode) => ReactNode`](#fileitem-api) | — | 定制操作区 |
| `emptyContent` | `ReactNode` | — | 空列表内容 |

## FileItem API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `uid` | `string` | — | 稳定标识，建议提供 |
| `url` | `string` | — | 文件地址 |
| `name` | `string` | — | 文件名称，默认取 URL 的文件名 |
| `size` | `number` | — | 字节数，可不提供；未提供时不显示大小 |
| `type` | `string` | — | MIME 类型，未提供时根据扩展名识别 |
| `status` | `'ready' \| 'uploading' \| 'done' \| 'error' \| 'cancelled'` | — | 上传状态，可不提供 |
| `percent` | `number` | — | 上传进度 0–100 |
| `error` | `string` | — | 失败说明 |
| `originFile` | `File` | — | 浏览器选择的原始文件 |
