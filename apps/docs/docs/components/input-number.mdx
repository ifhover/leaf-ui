## InputNumber API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number \| null \| string \| null` | `null` | 受控值 / 初始值，空值为 null |
| `defaultValue` | `number \| null \| string \| null` | `null` | 受控值 / 初始值，空值为 null |
| `onChange` | `((value: number \| null) => void) \| ((value: string \| null) => void)` | — | 有效数字变化或清空时触发 |
| `min` | `number \| string` | 无限制 | 可输入数字的范围 |
| `max` | `number \| string` | 无限制 | 可输入数字的范围 |
| `step` | `number \| string` | `1` | 增减步长 |
| `precision` | `number` | — | 小数精度，范围 0–15 |
| `controls` | `boolean` | `true` | 展示增减按钮 |
| `keyboard` | `boolean` | `true` | 支持上下方向键增减 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 控件尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `prefix` | `ReactNode` | — | 前后装饰内容 |
| `suffix` | `ReactNode` | — | 前后装饰内容 |
| `stringMode` | `false \| true` | — | 使用字符串处理高精度数值、步长和边界。 |
| `formatter` | `( value: number \| string \| null, info: { userTyping: boolean; input: string }, ) => string` | — | 格式化显示文字，不改变表单的原始值。 |
| `parser` | `(text: string) => number \| string` | — | 把显示文字还原为数值。 |
| `grouping` | `boolean` | — | 启用本地化数字分组。 |
| `locale` | `string` | — | 语言或数字格式的区域标识。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |

## 使用说明

输入中的负号或小数点会暂时保留。失焦或回车时校正范围和精度；增减操作避免常见的小数累加误差。设置 name 可通过 FormData 提交，required、form、autoComplete 等属性传给输入元素，并支持表单 reset。className 与 style 作用于外层容器。
