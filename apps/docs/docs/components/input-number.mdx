# InputNumber 数字输入框

输入数量、金额等数字内容。

{/* leaf:section basic */}

## 基础用法

通过 `min`、`max` 限制范围。`onChange` 返回数值，清空时返回 `null`。输入中的负号或小数点会暂时保留，失焦或按 Enter 时校正范围与精度。

### 格式化显示

<a id="进阶用法"></a>

使用 `grouping` 显示本地化数字分组。自定义格式时，`formatter` 负责显示，`parser` 将输入文字还原为数值；格式化不改变原生表单提交的原始值。

<ComponentExample exampleId="formatting" preview={<InputNumberFormatting />} fileName="formatting.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/input-number/formatting.tsx"
```

</ComponentExample>

### 高精度数值

超出 JavaScript Number 安全精度时，使用 `stringMode`。该模式下 `value`、`defaultValue`、`step`、`min` 和 `max` 使用字符串，`onChange` 返回字符串或 `null`；不要先转成 Number。

## API

### InputNumber API

#### 表单接入

设置 `name` 可通过 FormData 提交原始数值。非受控字段支持表单重置，受控字段需同步重置应用状态。`required`、`form` 等原生属性传给输入元素；表单接入见 [Form](/components/form)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `number \| null \| string` | — | 受控数值；stringMode 时使用字符串，空值为 null。 |
| `defaultValue` | `number \| null \| string` | `null` | 非受控初始值；stringMode 时使用字符串，表单重置时恢复。 |
| `onChange` | `((value: number \| null) => void) \| ((value: string \| null) => void)` | — | 有效数字变化或清空时触发 |
| `min` | `number \| string` | 无限制 | 可输入数字的范围 |
| `max` | `number \| string` | 无限制 | 可输入数字的范围 |
| `step` | `number \| string` | `1` | 增减步长 |
| `precision` | `number` | — | 小数精度，范围 0–15 |
| `controls` | `boolean` | `true` | 展示增减按钮 |
| `keyboard` | `boolean` | `true` | 支持上下方向键增减 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 控件尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `prefix` | `ReactNode` | — | 前后装饰内容 |
| `suffix` | `ReactNode` | — | 前后装饰内容 |
| `stringMode` | `false \| true` | — | 使用字符串处理高精度数值、步长和边界。 |
| `formatter` | `( value: number \| string \| null, info: { userTyping: boolean; input: string }, ) => string` | — | 格式化显示文字，不改变表单的原始值。 |
| `parser` | `(text: string) => number \| string` | — | 把显示文字还原为数值。 |
| `grouping` | `boolean` | — | 启用本地化数字分组。 |
| `locale` | `string` | — | 语言或数字格式的区域标识。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |
