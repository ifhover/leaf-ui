## Alert API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | 必填 | 必需。提示内容 |
| `description` | `ReactNode` | — | 补充说明 |
| `type` | `'success' \| 'info' \| 'warning' \| 'danger'` | `'info'` | 提示类型；`error` 为兼容别名 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `showIcon` | `boolean` | `true` | 展示语义图标 |
| `closable` | `boolean` | `false` | 允许关闭当前提示 |
| `onClose` | `() => void` | — | 关闭后触发 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { AlertProps, FeedbackType, FeedbackTypeInput } from '@ifhover/leaf-ui';
```

## 使用说明

成功、普通信息、警告和危险使用不同语义颜色。业务文字由应用提供；关闭按钮名称沿用 ConfigProvider 语言。`FeedbackType` 使用 `danger`；`FeedbackTypeInput` 仍接受已弃用的 `error` 并归一化为 `danger`。

## 外观与丰富内容

提示默认使用中性背景，`type` 决定图标颜色和提示语义。`icon` 可以替换默认图标，`showIcon={false}` 隐藏图标。
