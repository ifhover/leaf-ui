## API

### Result API

配置结果状态、标题、说明和后续操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `status` | `'empty' \| 'success' \| 'info' \| 'warning' \| 'danger' \| 'error'` | `'empty'` | 结果状态；`error` 为兼容别名 |
| `title` | `ReactNode` | — | 结果标题；未设置时按状态和当前语言显示，null 隐藏。 |
| `description` | `ReactNode` | — | 补充说明；未设置或为 null 时不显示。 |
| `icon` | `ReactNode` | 状态图标 | 自定义图标；null 隐藏 |
| `extra` | `ReactNode` | — | 底部按钮或链接 |
| `size` | `'sm' \| 'md'` | `'md'` | 内容间距和图标大小 |
| `children` | `ReactNode` | — | 补充结果详情。 |

### Empty API

兼容组件，新增用法请使用 `Result`。`EmptyProps` 同时支持原生 `div` 属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `image` | `ReactNode` | 空数据图标 | 自定义图标；`null` 隐藏。 |
| `description` | `ReactNode` | 语言默认标题 | 空数据说明；`null` 隐藏。 |
| `size` | `'sm' \| 'md'` | `'md'` | 内容间距和图标大小。 |
| `children` | `ReactNode` | — | 底部操作内容。 |
