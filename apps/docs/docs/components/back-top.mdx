## API

### BackTopProps API

未提供 `target` 或返回 `null` 时使用窗口。系统要求减少动态效果，或 [ConfigProvider](/components/config-provider) 关闭动效时，无论 `behavior` 如何配置，均使用 `auto` 滚动。

可传入原生 `onClick`；在回调中调用 `event.preventDefault()` 可阻止内置的回顶操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `target` | `() => HTMLElement \| Window \| null` | — | 返回滚动容器；省略或返回 null 时使用 window。 |
| `visibilityHeight` | `number` | `400` | 滚动距离大于或等于此像素值时显示。 |
| `behavior` | `ScrollBehavior` | `'smooth'` | 回顶滚动方式；关闭动效或偏好减少动态效果时使用 auto。 |
