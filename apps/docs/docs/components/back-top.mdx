## 使用说明

默认监听窗口滚动；target 可返回指定滚动容器。超过 visibilityHeight 后显示按钮，点击后返回顶部；尊重系统减少动画的偏好。

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { BackTopProps } from '@sudden3/leaf-ui';
```

## BackTopProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `target` | `() => HTMLElement \| Window \| null` | — | 滚动目标或链接打开方式 |
| `visibilityHeight` | `number` | `400` | 超过此滚动距离后显示 |
| `behavior` | `ScrollBehavior` | `'smooth'` | 返回顶部的滚动方式 |
