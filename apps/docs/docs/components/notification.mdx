# Notification 通知提醒

在页面角落展示详细反馈或后续操作。短暂的操作反馈使用 [Message](/components/message)。

{/* leaf:section basic */}

## 基础用法

在应用入口放置 [ConfigProvider](/components/config-provider)，再在子组件中调用 `useNotification()`。已有该配置时无需重复添加。

```tsx
import { ConfigProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <ConfigProvider><App /></ConfigProvider>;
}
```

## API

### NotificationProps API

直接渲染时，由应用响应 `onClose` 并设置 `open=false`；`afterClose` 在离场动画结束后触发。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必填 | 受控展示状态 |
| `title` | `ReactNode` | 必填 | 标题内容 |
| `description` | `ReactNode` | — | 补充说明 |
| `type` | `FeedbackType \| 'error'` | `'info'` | 通知的状态样式；`error` 为兼容别名。 |
| `actions` | `ReactNode` | — | 通知内的后续操作；应用负责执行业务并按当前 key 关闭通知。 |
| `duration` | `number` | `4.5` | 自动关闭的秒数；0 或负数不自动关闭。悬停或焦点进入时暂停，离开后继续剩余时间。 |
| `placement` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | 显示位置 |
| `closable` | `boolean` | `true` | 显示关闭操作 |
| `onClose` | `() => void` | — | 关闭请求时调用；声明式 Notification 须由应用将 open 设为 false。 |
| `afterClose` | `() => void` | — | 关闭动画结束、内容卸载后调用，不代替 onClose 更新受控值。 |
| `icon` | `ReactNode` | — | 自定义图标 |

### NotificationApi API

`useNotification()` 直接返回此 API。嵌套的 `ConfigProvider` 共享队列，每条通知使用调用组件所在区域的主题和语言。调用组件卸载后，已有通知继续保留；入口 provider 卸载后，通知和计时器一起清理。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `(options: `[`NotificationOptions`](#notificationoptions-api)`) => string` | 必填 | 打开或按 key 替换通知，返回该通知的 key。 |
| `success` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | 必填 | 显示成功通知 |
| `info` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | 必填 | 显示信息通知 |
| `warning` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | 必填 | 显示警告通知 |
| `danger` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | 必填 | 显示危险通知；`error` 保留为兼容方法 |
| `error` | `(options: Omit<`[`NotificationOptions`](#notificationoptions-api)`, 'type'>) => string` | 必填 | 请求失败时显示的内容，替代数据行。 |
| `close` | `(key?: string) => void` | 必填 | 关闭指定 key；不传 key 会关闭同一 Provider 内的全部通知，不限于当前调用组件。 |

### NotificationOptions API

鼠标停留或焦点位于通知内部时暂停计时，离开后按剩余时长继续。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | 必填 | 标题内容 |
| `description` | `ReactNode` | — | 补充说明 |
| `type` | `FeedbackType \| 'error'` | `'info'` | 通知的状态样式；`error` 为兼容别名。 |
| `actions` | `ReactNode` | — | 通知内的后续操作；应用负责执行业务并按当前 key 关闭通知。 |
| `duration` | `number` | `4.5` | 自动关闭的秒数；0 或负数不自动关闭。悬停或焦点进入时暂停，离开后继续剩余时间。 |
| `placement` | `'top-right' \| 'top-left' \| 'bottom-right' \| 'bottom-left'` | `'top-right'` | 显示位置 |
| `closable` | `boolean` | `true` | 显示关闭操作 |
| `key` | `string` | 自动生成 | 同一 Provider 内的唯一标识；重复 open 会替换该条通知并重启关闭计时，不追加新通知。 |
| `onClose` | `() => void` | — | 关闭请求时调用；声明式 Notification 须由应用将 open 设为 false。 |
| `icon` | `ReactNode` | — | 自定义图标 |

### NotificationProviderProps API

单独使用通知时，可用 `NotificationProvider` 代替 `ConfigProvider`；显式添加它也可建立独立队列。`maxCount` 统计所有位置的通知，超出时关闭最早的通知。请在 provider 挂载时设置，之后修改不会重设队列。

```tsx
import { NotificationProvider } from '@ifhover/leaf-ui';

export function Root() {
  return <NotificationProvider maxCount={3}><App /></NotificationProvider>;
}
```

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 共享此独立通知队列的内容；ConfigProvider 已提供队列，嵌套 ConfigProvider 复用上层队列。 |
| `maxCount` | `number` | `5` | 此队列的最大同时显示数量；挂载时设置，超过时关闭最早的通知。 |
