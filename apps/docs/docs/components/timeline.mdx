# Timeline 时间线

按顺序展示事件与进展。

{/* leaf:section basic */}

## 基础用法

`children` 是事件内容，`label` 用于时间等补充信息。组件按 `items` 的顺序展示，不会根据标签自动排序；`reverse` 可反转事件顺序。

## 示例

### 交替排布

`mode="alternate"` 将事件交替放在两侧。窄容器内仍保持交替排布；内容较长时优先使用默认的单侧布局。所有事件靠右排列时使用 `mode="right"`。

### 待办事件

`pending` 在列表末尾追加等待内容，不会启动请求或自动完成。此例由应用添加完成事件，并把 `pending` 设为 `null` 来移除等待项；使用 `reverse` 时，等待项仍位于末尾。

## API

### TimelineProps API

配置时间线条目、排列方式和待办内容。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`TimelineItem`](#timelineitem-api)`[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `mode` | `'left' \| 'right' \| 'alternate'` | `'left'` | 时间线的排布方式：左侧、右侧或交替。 |
| `pending` | `ReactNode` | — | 末尾待办内容；传 null 或 undefined 不显示，false 和空字符串仍保留节点。 |
| `reverse` | `boolean` | `false` | 反转 items 顺序；pending 仍追加在末尾。 |

### TimelineItem API

描述单个事件的内容、标记与颜色。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一且稳定的标识 |
| `children` | `ReactNode` | 必填 | 事件主体内容。 |
| `label` | `ReactNode` | — | 次要说明，通常为时间。 |
| `color` | `'primary' \| FeedbackType \| 'error' \| (string & {})` | — | 颜色；`error` 为兼容别名 |
| `dot` | `ReactNode` | — | 装饰性自定义节点；重要状态须在正文中用文字说明。 |
