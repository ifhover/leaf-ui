# useImagePreview 图片预览

在事件处理中打开单张图片或图片组。页面内的图片使用原生 `img`，无需搭配图片触发组件。

{/* leaf:section basic */}

## 基础用法

在 [ConfigProvider](./config-provider) 内调用 `useImagePreview()`。未使用 ConfigProvider 时，在调用组件外包裹 `ImagePreviewProvider`。`preview` 接受图片地址、图片对象或它们组成的数组。

示例图片保存在文档站的 `public/media/`，`withBase` 仅用于适配文档站部署路径；接入项目时替换为自己的图片地址即可。

## 示例

### 图片组与下载

通过从 0 开始的 `index` 指定初始图片。`downloadable` 开启下载操作，单张图片可用 `download={false}` 隐藏下载。跨域下载需要地址允许 CORS。


点击画布两侧或底部的箭头、左右方向键或缩略图切图，首尾循环；也可拖动缩略图条切换。拖动图片可平移，滚轮或上下方向键可缩放；触屏支持双指捏合与旋转，初始尺寸下左右滑动切图。双击图片或点击“1:1”在原始尺寸与初始尺寸之间切换；“重置图片”同时恢复缩放、位置、旋转和翻转。

工具栏还提供左右旋转和水平 / 垂直翻转，不提供幻灯片播放或浏览器全屏。按 Escape、点击右上角按钮或背景关闭预览，关闭后焦点返回打开预览的元素。

`thumbnails: false` 隐藏缩略图，但保留上一张 / 下一张按钮。

大图组建议提供 `thumbnailSrc`，避免缩略图也下载原图。`width` / `height` 可用于载入前的尺寸提示；实际显示以原图加载后的自然尺寸为准。

`preview` 返回可重复调用的关闭函数。同一 Provider 再次打开预览会替换当前图片组；主动关闭、替换或调用组件卸载时都会触发这一组的 `onClose`。`onIndexChange` 返回从 0 开始的当前索引，服务自行管理切换状态，无需应用回写索引。

## API

### ImagePreviewApi API

`useImagePreview` 返回的预览调用接口。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `preview` | `( images: string \| `[`ImagePreviewItem`](#imagepreviewitem-api)` \| readonly (string \| `[`ImagePreviewItem`](#imagepreviewitem-api)`)[], options?: `[`ImagePreviewOptions`](#imagepreviewoptions)`, ) => () => void` | 必填 | 预览单张或一组图片，可指定初始索引与预览选项；返回幂等关闭函数。 |

### ImagePreviewOptions

调用命令式图片预览时的展示与关闭配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `index` | `number` | — | 初始图片索引，从 0 开始。 |
| `onIndexChange` | `(index: number) => void` | — | 当前图片切换时调用。 |
| `thumbnails` | `boolean` | — | 显示图片组的缩略图导航，默认 true。 |
| `downloadable` | `boolean` | — | 显示下载操作，默认 false。 |
| `onClose` | `() => void` | — | 预览结束时调用，包括用户关闭、返回的关闭函数、同 Provider 替换和调用方卸载。 |

### ImagePreviewItem API

下载需要外层预览启用 `downloadable`；单张图片可用 `download={false}` 隐藏下载操作。跨域下载地址需要允许 CORS，下载失败时可通过预览中的原图链接另行保存。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | 必填 | 图片地址 |
| `thumbnailSrc` | `string` | — | 缩略图地址，默认使用 src |
| `alt` | `string` | `''` | 图片文字说明 |
| `width` | `number` | — | 可选的原图像素宽度，用于载入前的尺寸提示；实际以加载后的自然尺寸为准。 |
| `height` | `number` | — | 可选的原图像素高度，用于载入前的尺寸提示；实际以加载后的自然尺寸为准。 |
| `download` | `string \| boolean` | — | 外层 downloadable 开启时，false 禁用本项下载，字符串替换下载地址，其余使用 src。跨域下载需要 CORS。 |
| `downloadName` | `string` | — | 自定义下载后的文件名 |

### ImagePreviewProvider API

为命令式图片预览提供上下文的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 可调用 useImagePreview 的内容；ConfigProvider 已自动提供此服务。 |
