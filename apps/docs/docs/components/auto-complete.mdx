# AutoComplete 自动完成

在允许自由填写的同时提供输入建议。

{/* leaf:section basic */}

## 基础用法

建议默认进行不区分大小写的包含匹配，仍允许自由填写。`onChange` 响应输入和选择，`onSelect` 只响应选择建议。带 `disabled` 的建议不可选中。

<ComponentExample exampleId="basic" preview={<AutoCompleteBasic />} width={360} fileName="basic.tsx">

```tsx lineNumbers file="../../src/examples/auto-complete/basic.tsx"
```

</ComponentExample>

聚焦或输入时展开建议。方向键高亮可用项，Enter 选择，Escape 收起，Tab 继续访问后续控件；输入法合成期间的 Enter 不会选中建议。

## 示例

### 动态建议

`onSearch` 接收输入文本，清除时收到空字符串，选择建议时不触发。建议由应用生成或从服务端获取时，设置 `filterOption={false}` 可直接展示结果，不再进行本地过滤。

### 分组建议

通过分组标题和对应的 `options` 组织建议。富文本名称使用 `searchLabel` 提供搜索文字；选择后写入输入框的是 `value`，不是 `label`。

### 禁用与只读

`disabled` 禁用整个控件；`readOnly` 允许聚焦与复制，但不允许编辑、选择或清除。

<ComponentExample exampleId="states" preview={<AutoCompleteStates />} width={360} fileName="states.tsx">

```tsx lineNumbers file="../../src/examples/auto-complete/states.tsx"
```

</ComponentExample>

支持 `name`、`required`、`form` 等原生输入属性。非受控值随原生表单重置，受控值由应用重置。字段名称和建议内容需要应用自行翻译。

## API

### AutoComplete API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly (`[`AutoCompleteOption`](#autocompleteoption)` \| `[`AutoCompleteOptionGroup`](#autocompleteoptiongroup)`)[]` | 必填 | 该分组内的建议。 |
| `value` | `string` | — | 受控文本；省略时使用内部非受控值。 |
| `defaultValue` | `string` | `''` | 非受控模式的初始文本；支持表单重置。 |
| `onChange` | `(value: string) => void` | — | 输入、清除或选择建议后返回完整文本。 |
| `onSelect` | `(value: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => void` | — | 仅选择建议时触发，返回写入的 value 与完整选项。 |
| `onSearch` | `(query: string) => void` | — | 用户输入时返回查询文字；清除时返回空字符串，选择建议不触发。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 输入框尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `allowClear` | `boolean` | — | 展示清除操作。 |
| `filterOption` | `false \| ((query: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => boolean)` | 包含匹配 | `false` 关闭本地过滤；函数可定制过滤 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `errorContent` | `ReactNode` | — | 展示加载错误和重试内容。 |
| `notFoundContent` | `ReactNode` | — | 没有匹配选项时的内容。 |
| `optionRender` | `(option: `[`AutoCompleteOption`](#autocompleteoption)`) => ReactNode` | — | 自定义选项内容。 |
| `open` | `boolean` | — | 受控的展开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控模式的初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起时调用。 |
| `virtual` | `boolean` | 过滤后超过 100 项时启用 | 仅渲染可见建议；默认在过滤后建议超过 100 项时启用。 |
| `listHeight` | `number` | `248` | 建议面板的最大可视高度。 |
| `optionHeight` | `number` | 由主题和密度计算 | 虚拟列表的预估行高；默认由主题和密度计算，实际行会被测量。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `popupPlacement` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupPlacement']` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupStyle']` | — | 浮层的自定义样式。 |
| `popupRender` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupRender']` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | [`PopupOptions`](../api/popup-options#popupoptions)`['getPopupContainer']` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |

`placeholder`、`name`、`required`、`form`、`maxLength`、`aria-*` 等属性传递给输入框；`className` 和 `style` 作用于外层容器。

#### AutoCompleteOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 唯一建议值；选择后写入输入框。 |
| `label` | `ReactNode` | — | 建议的显示文字；默认也用于本地过滤。 |
| `searchLabel` | `string` | — | 搜索纯文本；省略时使用字符串 label，其他内容使用 value。 |
| `disabled` | `boolean` | `false` | 禁用该建议。 |

#### AutoCompleteOptionGroup

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | 必填 | 建议分组的标题。 |
| `options` | `readonly `[`AutoCompleteOption`](#autocompleteoption)`[]` | 必填 | 该分组内的建议。 |
