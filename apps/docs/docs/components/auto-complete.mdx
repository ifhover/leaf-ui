# AutoComplete 自动完成

在输入文本时提供建议，帮助快速完成填写。

## 基础输入

通过 `options` 设置建议，默认按显示文本进行不区分大小写的包含匹配。`onChange` 响应输入和选择，`onSelect` 仅响应选择建议。选项上的 `disabled` 只禁用该条建议（示例中的 `Archived Garden`）；写在 AutoComplete 上的 `disabled` 则禁用整个输入控件。

## 动态建议

`onSearch` 接收用户输入。建议由你生成或从服务端获取时，可设置 `filterOption={false}` 直接展示传入结果。

异步搜索时，在应用中处理请求防抖和响应顺序，避免旧查询覆盖新结果。输入过程中允许保留自由文本。

## 富文本分组与加载状态

浮层默认与控件等宽（`popupWidth="trigger"`）。设置 `popupWidth="auto"` 仅按内容定宽，也可以比控件窄；`popupWidth={300}` 固定为 300px，也支持 CSS 长度。`popupMaxWidth` 默认未设置，下面的示例按内容定宽并显式设置最大宽度。浮层仍会在视口边缘避让。

## AutoComplete API
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly (`[`AutoCompleteOption`](#autocompleteoption)` \| `[`AutoCompleteOptionGroup`](#autocompleteoptiongroup)`)[]` | 必填 | 建议列表 |
| `value` | `string` | `''` | 受控文本；省略时使用内部非受控值。 |
| `defaultValue` | `string` | `''` | 非受控模式的初始文本；支持表单重置。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 输入框尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `filterOption` | `false \| ((query: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => boolean)` | 包含匹配 | `false` 关闭本地过滤；函数可定制过滤 |
| `onChange` | `(value: string) => void` | — | 输入或选择后的文本 |
| `onSelect` | `(value: string, option: `[`AutoCompleteOption`](#autocompleteoption)`) => void` | — | 选择建议时触发 |
| `onSearch` | `(query: string) => void` | — | 用户输入时触发，选择建议时不触发 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | — | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 面板展开或收起时调用。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `notFoundContent` | `ReactNode` | — | 没有匹配选项时的内容。 |
| `errorContent` | `ReactNode` | — | 展示加载错误和重试内容。 |
| `optionRender` | `(option: `[`AutoCompleteOption`](#autocompleteoption)`) => ReactNode` | — | 自定义选项内容。 |
| `allowClear` | `boolean` | — | 展示清除操作。 |
| `virtual` | `boolean` | — | 启用虚拟滚动；大量选项默认启用。 |
| `listHeight` | `number` | `248` | 可视列表高度。 |
| `optionHeight` | `number` | `32` | 跟随区域控件高度和密度的预估行高；实际行会被测量。 |
| `popupWidth` | `number \| string` | `'trigger'` | 浮层宽度；trigger 与触发控件等宽，auto 按内容定宽（可比控件窄），数字为固定像素值，也支持 CSS 长度。 |
| `popupMaxWidth` | `number \| string` | — | 可选的浮层最大宽度；未设置时不额外限制，仍受可视区域限制。 |
| `popupPlacement` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupPlacement']` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupStyle']` | — | 浮层的自定义样式。 |
| `popupRender` | [`PopupOptions`](../api/popup-options#popupoptions)`['popupRender']` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | [`PopupOptions`](../api/popup-options#popupoptions)`['getPopupContainer']` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `readOnly` | `boolean` | `false` | 锁定业务值，禁止输入、选择、清除和删除。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |

label 默认为 value；选中后输入框中的文本始终是 value。`placeholder`、`name`、`required`、`form`、`maxLength`、`aria-*` 等原生文本框属性直接透传，`className` / `style` 作用于外层容器。

## 类型

[`AutoCompleteProps`](#autocomplete-api) 用于定义组件属性。单独组装建议列表时，可以使用 [`AutoCompleteOption`](#autocompleteoption)：

```ts
import type { AutoCompleteProps, AutoCompleteOption, ControlSize, ControlStatus } from '@ifhover/leaf-ui';

const options: AutoCompleteOption[] = [
  { value: 'leaf@example.com' },
  { value: 'hello@example.com', label: '联系团队' },
];
```

### AutoCompleteOption
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 唯一建议值；选择后写入输入框。 |
| `label` | `ReactNode` | — | 建议的显示文字；默认也用于本地过滤。 |
| `searchLabel` | `string` | — | 复杂 label 的搜索纯文本；省略时使用可读文字或 value。 |
| `disabled` | `boolean` | `false` | 禁用该建议。 |

## 键盘与表单

输入框聚焦或输入时展开建议。↑ / ↓ 高亮可用选项，Enter 选择，Escape 收起，Tab 继续访问后续控件。中文输入法合成期间的 Enter 不会选择建议。没有匹配项时可以继续填写。

输入框可以直接参与 FormData、原生必填校验和表单 reset。建议面板默认跟随输入框宽度并继承局部主题；为输入框提供 label 或 aria-label。
## AutoCompleteOptionGroup
| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | 必填 | 建议分组的标题。 |
| `options` | `readonly `[`AutoCompleteOption`](#autocompleteoption)`[]` | 必填 | 该分组内的建议。 |
