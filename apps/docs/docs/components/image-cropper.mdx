## 使用说明

图片保持固定，拖动选框移动，拖动边缘或角点调整尺寸，支持触摸与键盘。画布默认正方形。未指定 aspect 时矩形可自由调整，圆形固定为 1:1。export() 返回 Blob。远程图片须允许 CORS；圆形 PNG 保留透明边角，JPEG 使用白底。

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { CropArea, ImageCropperHandle, ImageCropperProps, ImageCropResult } from '@sudden3/leaf-ui';
```

## CropArea API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `number` | 必填 | 横坐标 |
| `y` | `number` | 必填 | 纵坐标 |
| `width` | `number` | 必填 | 宽度，数字按像素计算 |
| `height` | `number` | 必填 | 高度，数字按像素计算 |

## ImageCropperHandle API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `export` | [`() => Promise<ImageCropResult>`](#imagecropresult-api) | 必填 | 导出为 Blob |
| `reset` | `() => void` | 必填 | 重置状态或重试 |

## ImageCropperProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | 必填 | 图片地址 |
| `aspect` | `number` | — | 固定裁剪比例，未提供时自由调整 |
| `shape` | `'rect' \| 'round'` | `'rect'` | 裁剪形状 |
| `minWidth / minHeight` | `number` | `24` | 选框最小宽高，按显示像素计算 |
| `disabled` | `boolean` | `false` | 禁止移动和调整选框 |
| `showActions` | `boolean` | `true` | 显示重置与裁剪按钮 |
| `showGrid` | `boolean` | `true` | 裁剪辅助线 |
| `crossOrigin` | `'anonymous' \| 'use-credentials'` | `'anonymous'` | 图片跨域模式，导出需要服务器允许 CORS |
| `type` | `'image/png' \| 'image/jpeg' \| 'image/webp'` | `'image/png'` | 导出图片格式 |
| `quality` | `number` | `0.92` | 导出质量，0–1 |
| `onChange` | [`(area: CropArea) => void`](#croparea-api) | — | 裁剪区域变化，坐标按原图像素计算 |
| `onExport` | [`(result: ImageCropResult) => void`](#imagecropresult-api) | — | 导出成功 |
| `onError` | `(error: Error) => void` | — | 异常回调 |
| `extra` | `ReactNode` | — | 补充内容或操作 |

## ImageCropResult API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `blob` | `Blob` | 必填 | 导出的 Blob |
| `width` | `number` | 必填 | 宽度，数字按像素计算 |
| `height` | `number` | 必填 | 高度，数字按像素计算 |
