# InputOTP 验证码输入

输入和粘贴验证码。

{/* leaf:section basic */}

## 基础用法

默认输入 6 位数字，支持整串粘贴与 one-time-code 自动填充，不符合当前模式的字符会被过滤。`onComplete` 仅表示字符已填满，验证码有效性仍须由服务端验证。


</ComponentExample>

设置 `name` 可将验证码加入 FormData。非受控表单重置恢复 `defaultValue`；受控值由应用重置。

## API

### InputOTPProps API

验证码长度、输入字符、受控值与完成事件的配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `length` | `number` | `6` | 验证码长度，取整后限制在 1–32。 |
| `value` | `string` | — | 受控的验证码文本。 |
| `defaultValue` | `string` | `''` | 非受控初始文本，表单重置时恢复。 |
| `onChange` | `(value: string) => void` | — | 用户编辑后返回经过字符过滤与长度限制的文本。 |
| `onComplete` | `(value: string) => void` | — | 用户输入达到指定长度时触发；服务端仍须验证验证码。 |
| `mode` | `'numeric' \| 'alphanumeric'` | `'numeric'` | 允许输入数字或字母数字。 |
| `mask` | `boolean \| string` | `false` | 隐藏可见格子的字符；true 使用圆点，字符串使用指定字符，不改变输入值或表单提交值。 |
| `separator` | `(index: number) => ReactNode` | — | 在零起始索引对应的字符后插入分隔内容；最后一个字符后不调用。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 输入格尺寸。 |
| `status` | `'error' \| 'warning'` | — | 显示状态 |
