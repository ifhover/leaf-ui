## API

### Tag API

配置标签的内容、外观和关闭操作。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 标签内容 |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| string` | `'primary'` | 语义颜色或自定义颜色；`default` 和 `error` 为兼容别名 |
| `variant` | `'soft' \| 'outline'` | `'soft'` | 浅底或中性背景描边形态 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸 |
| `dot` | `boolean` | `true` | 无自定义图标时显示内置状态圆点 |
| `icon` | `ReactNode` | — | 替换内置圆点的自定义图标 |
| `closable` | `boolean` | `false` | 展示关闭按钮 |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | 关闭时触发 |

### CheckableTagProps API

配置可选择标签的选中状态与变更事件。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | 受控勾选状态 |
| `defaultChecked` | `boolean` | `false` | 初始勾选状态 |
| `onChange` | `(checked: boolean) => void` | — | 值变化回调 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸。 |

### TagGroupProps API

管理标签选项组的选择值与显示方式。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | [`readonly TagOption[]`](#tagoption-api) | 必填 | 可用选项 |
| `value` | `readonly string[]` | — | 受控值 |
| `defaultValue` | `readonly string[]` | `[]` | 初始值；非受控表单 reset 时恢复 |
| `onChange` | `(values: string[]) => void` | — | 值变化回调 |
| `disabled` | `boolean` | — | 禁止交互 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸。 |
| `name` | `string` | — | 表单字段名称 |
| `form` | `string` | — | 关联表单 ID |
| `required` | `boolean` | — | 表单必填验证 |

### TagOption API

传入标签组的单个选项。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 受控值 |
| `label` | `ReactNode` | 必填 | 显示内容 |
| `disabled` | `boolean` | — | 禁止交互 |
