## API

### Tag API

配置标签的内容、外观和关闭操作。

| 属性       | 类型                                                                         | 默认值      | 说明                                                          |
| ---------- | ---------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------- |
| `children` | `ReactNode`                                                                  | —           | 子内容。                                                      |
| `color`    | `'default' \| 'success' \| 'warning' \| 'danger' \| 'info' \| (string & {})` | `'default'` | 默认灰色；也可使用四种语义预设或自定义颜色                    |
| `variant`  | `'soft' \| 'solid'`                                                          | `'soft'`    | `soft` 使用浅色背景和颜色文字，`solid` 使用颜色背景和白色文字 |
| `size`     | `'sm' \| 'md' \| 'lg'`                                                       | `'md'`      | 标签尺寸                                                      |
| `icon`     | `ReactNode`                                                                  | —           | 显示自定义图标                                                |
| `closable` | `boolean`                                                                    | `false`     | 展示关闭按钮                                                  |
| `onClose`  | `(event: MouseEvent<HTMLButtonElement>) => void`                             | —           | 关闭时触发                                                    |

### CheckableTagProps API

配置可选择标签的选中状态与变更事件。

| 属性             | 类型                         | 默认值  | 说明         |
| ---------------- | ---------------------------- | ------- | ------------ |
| `checked`        | `boolean`                    | —       | 受控勾选状态 |
| `defaultChecked` | `boolean`                    | `false` | 初始勾选状态 |
| `onChange`       | `(checked: boolean) => void` | —       | 值变化回调   |
| `size`           | `'sm' \| 'md' \| 'lg'`       | `'md'`  | 标签尺寸。   |

### TagGroupProps API

管理标签选项组的选择值与显示方式。

| 属性           | 类型                                         | 默认值 | 说明                                 |
| -------------- | -------------------------------------------- | ------ | ------------------------------------ |
| `options`      | `readonly `[`TagOption`](#tagoption-api)`[]` | 必填   | 可用选项                             |
| `value`        | `readonly string[]`                          | —      | 受控值                               |
| `defaultValue` | `readonly string[]`                          | `[]`   | 初始值；非受控表单 reset 时恢复      |
| `onChange`     | `(values: string[]) => void`                 | —      | 值变化回调                           |
| `disabled`     | `boolean`                                    | —      | 禁用交互。                           |
| `size`         | `'sm' \| 'md' \| 'lg'`                       | `'md'` | 标签尺寸。                           |
| `name`         | `string`                                     | —      | 表单字段名称                         |
| `form`         | `string`                                     | —      | 关联表单 ID                          |
| `required`     | `boolean`                                    | —      | 要求整体值非空，复合控件只校验一次。 |

### TagOption API

传入标签组的单个选项。

| 属性       | 类型        | 默认值 | 说明       |
| ---------- | ----------- | ------ | ---------- |
| `value`    | `string`    | 必填   | 受控值     |
| `label`    | `ReactNode` | 必填   | 显示内容   |
| `disabled` | `boolean`   | —      | 禁用交互。 |
