## Tag API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 标签内容 |
| `color` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' \| string` | `'primary'` | 语义颜色或自定义颜色；`default` 和 `error` 为兼容别名 |
| `variant` | `'soft' \| 'solid'` | `'soft'` | 浅底或实色形态，均为无边框且使用小圆角 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸 |
| `icon` | `ReactNode` | — | 前置圆点或自定义图标 |
| `closable` | `boolean` | `false` | 展示关闭按钮 |
| `onClose` | `(event: MouseEvent<HTMLButtonElement>) => void` | — | 关闭时触发 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { TagProps, CheckableTagProps, TagGroupProps, TagOption } from '@ifhover/leaf-ui';
```

## 使用说明

标签使用无边框的小圆角，仅提供浅底与实色形态。圆角默认取区域主题的小圆角（默认 6px），也可通过 `ConfigProvider` 的 `theme.components.Tag.borderRadius` 单独设置。标签字重固定为 500，不再提供字重参数。未指定颜色时使用主题色；`default` 映射到主题色，`error` 归一化为 `danger`。浅底形态的文字跟随标签自身颜色，警告色使用派生的可读警告文字色；实色形态使用白色文字，警告色使用 `--leaf-color-on-warning` 对比色。`CheckableTag` 和 `TagGroup` 的未选项使用浅底主题色，已选项使用实色主题色。

调用 event.preventDefault() 可阻止默认移除。在动态列表中，也可以通过 onClose 更新应用状态并移除对应项。

## CheckableTagProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | 受控勾选状态 |
| `defaultChecked` | `boolean` | `false` | 初始勾选状态 |
| `onChange` | `(checked: boolean) => void` | — | 值变化回调 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸。 |

## TagGroupProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | [`readonly TagOption[]`](#tagoption-api) | 必填 | 可用选项 |
| `value` | `readonly string[]` | — | 受控值 |
| `defaultValue` | `readonly string[]` | `[]` | 初始值；非受控表单 reset 时恢复 |
| `onChange` | `(values: string[]) => void` | — | 值变化回调 |
| `disabled` | `boolean` | — | 禁止交互 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 标签尺寸。 |
| `name` | `string` | — | 表单字段名称 |
| `form` | `string` | — | 关联表单 ID |
| `required` | `boolean` | — | 表单必填验证 |
