## RadioGroup API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly `[`RadioOption`](#radiooption)`[]` | 必填 | 必需。选项列表 |
| `value` | `string` | — | 受控值 / 非受控初始值 |
| `defaultValue` | `string` | — | 受控值 / 非受控初始值 |
| `name` | `string` | 自动生成 | 同组的字段名；提交表单时建议指定 |
| `label` | `ReactNode` | — | 分组名称 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 同组控件尺寸 |
| `variant` | `'plain' \| 'card' \| 'list'` | `'plain'` | 普通排列、卡片网格或带分隔线的成组列表。 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 排列方向 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 `event.target.value` 读取所选值 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `ref` | `Ref<HTMLFieldSetElement>` | — | 分组引用 |

## Radio API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 单选框尺寸 |
| `variant` | `'plain' \| 'card'` | `'plain'` | 普通选项或整块可点击的卡片选项。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `checked` | `boolean` | — | 受控选中状态 / 非受控初始状态 |
| `defaultChecked` | `boolean` | — | 受控选中状态 / 非受控初始状态 |
| `value` | `string \| number \| readonly string[]` | — | 受控值。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 值发生变化时调用。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `children` | `ReactNode` | — | 子内容；嵌套数据类型表示子节点。 |
| `ref` | `Ref<HTMLInputElement>` | — | 单选框引用 |

支持其他 radio 属性。`className` 和 `style` 作用于标签容器。

RadioGroup 的 label、aria-label 或 aria-labelledby 应至少提供一种分组名称。选项 label 与 value 建议保持稳定；value 使用不重复的字符串。

## 类型

[`RadioProps`](#radio-api) 和 [`RadioGroupProps`](#radiogroup-api) 用于定义组件属性。单独组装选项列表时，可以使用 [`RadioOption`](#radiooption)：

```ts
import type { RadioProps, RadioGroupProps, RadioOption, ControlSize } from '@ifhover/leaf-ui';

const options: RadioOption[] = [
  { label: '浅色', value: 'light' },
  { label: '深色', value: 'dark' },
];
```

### RadioOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | 必填 | 选项文字 |
| `value` | `string` | 必填 | 选项值，同组内应唯一 |
| `disabled` | `boolean` | `false` | 禁用该选项 |

## 外观与丰富内容

Radio 和 RadioGroup 支持图标、补充说明与状态标签。RadioGroup 的 variant="card" 自动排列卡片，variant="list" 使用成组列表。description 与 extra 作为辅助描述，extra 不应包含按钮或链接。单选组保留方向键切换、禁用选项跳过与原生表单提交。

## RadioOption

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | — | 必需。展示文字或内容。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `value` | `string` | — | 必需。受控值。 |
| `disabled` | `boolean` | — | 禁用交互。 |
