#### 表单提交与重置

通过 `name` 提交选中项的 `value`，未选中或禁用的选项不提交。单独组合 `Radio` 时，同组使用相同的 `name` 和互不重复的值。

非受控选项组在表单重置时恢复 `defaultValue`；受控组需要同步重置应用状态。

## API

### Radio API

配置单个单选框的选中状态、提交值和禁用状态。

单个 `Radio` 支持原生 radio 属性。`className` 和 `style` 作用于标签容器。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 单选框尺寸 |
| `variant` | `'plain' \| 'card'` | `'plain'` | 普通选项或整块可点击的卡片选项。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `checked` | `boolean` | — | 受控的选中状态。 |
| `defaultChecked` | `boolean` | — | 非受控模式的初始选中状态。 |
| `value` | `string \| number \| readonly string[]` | — | 该单选框在表单中提交的值，不是选中状态；选中状态使用 checked。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 event.target.value 读取所选值。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `required` | `boolean` | `false` | 要求同名的单选框中至少选中一项。 |
| `children` | `ReactNode` | — | 可点击的选项标签。 |
| `ref` | `Ref<HTMLInputElement>` | — | 单选框引用 |

### RadioGroup API

管理一组选项的单选值和选项布局。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly `[`RadioOption`](#radiooption)`[]` | 必填 | 选项列表 |
| `value` | `string` | — | 受控的选中项 value；省略时使用内部非受控值。 |
| `defaultValue` | `string` | — | 非受控模式的初始选中值；支持表单重置。 |
| `name` | `string` | 自动生成 | 同组的字段名；提交表单时建议指定 |
| `label` | `ReactNode` | — | 分组名称 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 同组控件尺寸 |
| `variant` | `'plain' \| 'card' \| 'list'` | `'plain'` | 普通排列、卡片网格或带分隔线的成组列表。 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 排列方向 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 `event.target.value` 读取所选值 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `ref` | `Ref<HTMLFieldSetElement>` | — | 分组引用 |

### RadioOption

传入选项组的单个选项，包含提交值与显示内容。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `ReactNode` | 必填 | 选项的显示内容。 |
| `description` | `ReactNode` | — | 选项下方的补充说明。 |
| `icon` | `ReactNode` | — | 选项前的图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `value` | `string` | 必填 | 选项值；同一组内应唯一。 |
| `disabled` | `boolean` | `false` | 禁用该选项。 |
