## RadioGroup API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| options | readonly RadioOption[] | 必填 | 每项包含 label、value 和可选 disabled |
| value / defaultValue | string | — | 受控值 / 初始值 |
| onChange | `ChangeEventHandler<HTMLInputElement>` | — | 从 event.target.value 读取所选值 |
| name | string | 自动生成 | 同组的原生 name；提交表单时建议显式指定 |
| label | string | — | 分组名称，显示为 legend |
| direction | `'horizontal' \| 'vertical'` | horizontal | 布局方向 |
| size | `'sm' \| 'md' \| 'lg'` | md | 同组控件尺寸 |
| disabled / required | boolean | false | 禁用整组 / 要求选择一项 |
| ref | `Ref<HTMLFieldSetElement>` | — | fieldset 节点 |

## Radio API

单独使用 Radio 时，相同 name 的选项构成一组。支持 checked、defaultChecked、onChange、disabled、size、children 以及其余原生 radio 属性。ref 指向 HTMLInputElement；className 和 style 作用于标签容器。

RadioGroup 的 label、aria-label 或 aria-labelledby 应至少提供一种分组名称。选项 label 与 value 建议保持稳定；value 使用不重复的字符串。
