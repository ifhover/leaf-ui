# AvatarGroup 头像组

成组展示成员头像，支持文字头像与人数折叠。使用 `Avatar` 定义每个成员。

{/* leaf:section basic */}

## 基础用法

将成员头像放入 `AvatarGroup`，通过每个 `Avatar` 的 `alt` 提供成员名称。

<ComponentExample exampleId="basic" preview={<AvatarBasic />} fileName="basic.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/avatar/basic.tsx"
```

</ComponentExample>

组内文字头像的颜色用于区分成员，不表示状态。

## API

### AvatarGroup API

成组展示成员头像及折叠人数的参数。

#### AvatarGroupProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `maxCount` | `number` | `Infinity` | 最多展示的头像数，超出部分折叠为 +N。 |
| `size` | [`AvatarProps`](#avatar-api)`['size']` | — | 头像尺寸预设；数字为像素值。 |
| `shape` | [`AvatarProps`](#avatar-api)`['shape']` | — | 裁剪形状 |
| `maxContent` | `(hiddenCount: number) => ReactNode` | — | 自定义溢出人数 |

### Avatar API

组内单个成员头像的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | — | 头像图片地址。 |
| `srcSet` | `string` | — | 响应式图片候选。 |
| `imageProps` | `Omit<ImgHTMLAttributes<HTMLImageElement>, 'src' \| 'srcSet' \| 'alt' \| 'onError'>` | — | 图片原生属性，如 loading、sizes、crossOrigin、objectFit 样式 |
| `alt` | `string` | 文字或语言默认值 | 可访问名称 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | 预设尺寸或像素值 |
| `shape` | `'circle' \| 'square'` | `'circle'` | 形状 |
| `icon` | `ReactNode` | — | 没有图片时显示的图标。 |
| `onError` | `() => void` | — | 图片加载失败回调 |
| `children` | `ReactNode` | — | 没有图片时显示的文字或内容。 |
