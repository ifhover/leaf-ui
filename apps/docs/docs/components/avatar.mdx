## Avatar API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | — | 头像图片地址 |
| `alt` | `string` | — | 无障碍名称 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | 预设尺寸或像素大小 |
| `shape` | `'circle' \| 'square'` | `'circle'` | 头像形状 |
| `icon` | `ReactNode` | — | 没有图片和内容时使用的图标 |
| `children` | `ReactNode` | — | 文字或自定义内容，图片失败时也会显示 |
| `onError` | `() => void` | — | 图片加载失败时触发 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { AvatarProps } from '@sudden3/leaf-ui';
```

## 使用说明

使用 alt 为头像提供名称。图片加载失败时显示 children 或 icon，更换 src 后会尝试加载新图片。
