## Avatar API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src / srcSet` | `string` | — | 图片地址 / 响应式图片候选 |
| `alt` | `string` | 文字或语言默认值 | 可访问名称 |
| `imageProps` | `Omit<ImgHTMLAttributes<HTMLImageElement>, 'src' \| 'srcSet' \| 'alt' \| 'onError'>` | — | 图片原生属性，如 loading、sizes、crossOrigin、objectFit 样式 |
| `onError` | `() => void` | — | 图片加载失败回调 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | `'md'` | 预设尺寸或像素值 |
| `shape` | `'circle' \| 'square'` | `'circle'` | 形状 |
| `icon / children` | `ReactNode` | — | 没有图片时的图标 / 文字内容 |


## 类型

可导入以下类型定义属性、组装数据或处理回调。

```ts
import type { AvatarProps } from '@sudden3/leaf-ui';
```

## 使用说明

图片加载失败时自动显示 `children`、`icon` 或默认头像，图片地址变化后会重试。`alt` 为头像提供可访问名称；图片自身避免重复朗读。`imageProps.style` 可调整裁切方式。

## 扩展类型

```ts
import type { AvatarGroupProps } from '@sudden3/leaf-ui';
```

## AvatarGroupProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `maxCount` | `number` | `Infinity` | 最多勾选或展示数量 |
| `size` | `'sm' \| 'md' \| 'lg' \| number` | — | 尺寸或间距预设 |
| `shape` | `'circle' \| 'square'` | — | 裁剪形状 |
| `maxContent` | `(hiddenCount: number) => ReactNode` | — | 自定义溢出人数 |
