## Typography API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `compact` | `boolean` | — | 减少正文段落间距。 |

## Text API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tone` | `'default' \| 'muted' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 文字的语义色。 |
| `strong` | `boolean` | — | 加粗文字。 |
| `italic` | `boolean` | — | 斜体文字。 |
| `underline` | `boolean` | — | 显示下划线。 |
| `code` | `boolean` | — | 以行内代码展示。 |
| `mark` | `boolean` | — | 突出标记文字。 |
| `ellipsis` | `boolean \| { rows?: number; expandable?: boolean }` | — | 单行或多行省略，可提供展开操作。 |
| `copyable` | `boolean \| { text?: string; onCopy?: (text: string) => void; onError?: (error: unknown) => void }` | — | 提供复制操作，可指定复制内容和回调。 |
| `editable` | `{ onChange: (text: string) => void; text?: string }` | — | 提供编辑操作；onChange 后由调用者更新文字。 |

## Paragraph API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tone` | `'default' \| 'muted' \| 'primary' \| 'success' \| 'warning' \| 'danger'` | `'default'` | 文字的语义色。 |
| `strong` | `boolean` | — | 加粗文字。 |
| `italic` | `boolean` | — | 斜体文字。 |
| `underline` | `boolean` | — | 显示下划线。 |
| `code` | `boolean` | — | 以行内代码展示。 |
| `mark` | `boolean` | — | 突出标记文字。 |
| `ellipsis` | `boolean \| { rows?: number; expandable?: boolean }` | — | 单行或多行省略，可提供展开操作。 |
| `copyable` | `boolean \| { text?: string; onCopy?: (text: string) => void; onError?: (error: unknown) => void }` | — | 提供复制操作，可指定复制内容和回调。 |
| `editable` | `{ onChange: (text: string) => void; text?: string }` | — | 提供编辑操作；onChange 后由调用者更新文字。 |

## Title API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `level` | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `2` | 标题层级，输出对应的 h1–h6。 |

## Link API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `disabled` | `boolean` | — | 禁用交互。 |
| `underline` | `boolean` | `true` | 显示下划线。 |
| `external` | `boolean` | — | 在新标签页打开并设置安全的 rel。 |
| `icon` | `ReactNode` | — | 图标内容。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { TypographyProps, TextProps, ParagraphProps, TitleProps, LinkProps } from '@sudden3/leaf-ui';
```

为仅展示图标的操作提供可访问名称。交互控件支持键盘操作，并跟随 ConfigProvider 的主题和减少动画设置。
