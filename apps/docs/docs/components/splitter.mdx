## SplitterPanel

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 必需。稳定且唯一的标识。 |
| `children` | `ReactNode` | — | 必需。面板内容。 |
| `min` | `number` | — | 面板最小百分比。 |
| `max` | `number` | — | 面板最大百分比。 |
| `collapsible` | `boolean` | — | 允许折叠和恢复面板。 |
| `resizable` | `boolean` | — | 允许拖动和使用方向键调整大小。 |

## Splitter API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `panels` | `readonly `[`SplitterPanel`](#splitterpanel)`[]` | — | 必需。工作区面板。 |
| `sizes` | `readonly number[]` | — | 受控的面板比例，总和会归一化为 100。 |
| `defaultSizes` | `readonly number[]` | — | 初始的面板比例。 |
| `onResize` | `(sizes: number[]) => void` | — | 大小改变时调用。 |
| `onResizeEnd` | `(sizes: number[]) => void` | — | 调整结束时调用。 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 左右或上下排列面板。 |

## 类型与交互

组装可复用配置时，可导入对应的属性和数据类型。

```ts
import type { SplitterPanel, SplitterProps } from '@ifhover/leaf-ui';
```

分隔条使用 role="separator" 并暴露 aria-valuenow；支持方向键调整，并跟随 ConfigProvider 的主题和减少动画设置。
