# Drawer 抽屉

从页面边缘展开内容，查看详情或完成操作。

{/* leaf:section basic */}

## 基础用法

通过 `onClose` 响应关闭请求并更新 `open`。没有 `title` 时，使用 `aria-label` 提供名称。

### 调整尺寸

<a id="进阶用法"></a>

### 嵌套推移

在子抽屉上设置 `push`，打开时推移最近的父弹层；`true` 对应 40px，也可直接传入距离。Escape 仅关闭最上层抽屉，关闭后焦点回到对应触发按钮。父抽屉关闭时同时重置子抽屉的 `open`，避免下次打开时子层仍展开。

## API

### Drawer API

抽屉的受控打开状态、展开方向、内容区域与关闭行为配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `open` | `boolean` | 必填 | 受控的打开状态，应用负责更新。 |
| `title` | `ReactNode` | — | 抽屉标题。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `onClose` | `() => void` | — | 请求关闭，由应用更新 open |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'right'` | 展开方向 |
| `width` | `number \| string` | `380` | 左右抽屉宽度 |
| `height` | `number \| string` | `300` | 上下抽屉高度 |
| `footer` | `ReactNode` | — | 底部内容 |
| `extra` | `ReactNode` | — | 标题旁的操作内容 |
| `variant` | `'plain' \| 'card'` | `'card'` | 内容外观；card 将正文分为独立的内容面。 |
| `icon` | `ReactNode` | — | 标题左侧的装饰图标。 |
| `divided` | `boolean` | `false` | 用浅分隔线划分标题、内容和底部操作区。 |
| `closable` | `boolean` | `true` | 显示关闭按钮。 |
| `maskClosable` | `boolean` | `true` | 点击遮罩时请求关闭。 |
| `keyboard` | `boolean` | `true` | 允许按 Escape 请求关闭。 |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定打开后的初始焦点。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点；也可指定目标或设为 false。 |
| `resizable` | `boolean` | `false` | 允许拖动和使用方向键调整大小。 |
| `minSize` | `number` | `240` | 最小尺寸，单位为像素。 |
| `maxSize` | `number` | `900` | 最大尺寸，单位为像素。 |
| `onResize` | `(size: number) => void` | — | 用户拖动或键盘调整时返回新尺寸；width 或 height 改变会重置手动尺寸。 |
| `push` | `boolean \| number` | `false` | 推动最近的父弹层；true 使用 40px，数字指定距离。 |
| `afterClose` | `() => void` | — | 关闭过渡结束后触发 |
| `destroyOnClose` | `boolean` | `false` | 关闭后卸载内容；preserve 优先，forceRender 会保持挂载。 |
| `preserve` | `boolean` | — | 指定是否保留内容，优先于 destroyOnClose；不重置组件外的受控状态。 |
| `forceRender` | `boolean` | `false` | 打开前也挂载内容，关闭时保持隐藏。 |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | 指定 Portal 挂载目标，也可返回 ShadowRoot。 |
