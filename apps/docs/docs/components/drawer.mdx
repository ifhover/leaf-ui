## Drawer API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `initialFocus` | `RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 指定打开后的初始焦点。 |
| `returnFocus` | `boolean \| RefObject<HTMLElement \| null> \| (() => HTMLElement \| null)` | — | 关闭后返回原焦点；也可指定目标或设为 false。 |
| `open` | `boolean` | 必填 | 必需。是否展开 |
| `title` | `ReactNode` | — | 标题 |
| `footer` | `ReactNode` | — | 底部内容 |
| `extra` | `ReactNode` | — | 标题旁的操作内容 |
| `placement` | `'left' \| 'right' \| 'top' \| 'bottom'` | `'right'` | 展开方向 |
| `width` | `number \| string` | `380` | 左右抽屉宽度 |
| `height` | `number \| string` | `300` | 上下抽屉高度 |
| `closable` | `boolean` | `true` | 关闭按钮 / 点击遮罩 / Escape 关闭 |
| `maskClosable` | `boolean` | `true` | 关闭按钮 / 点击遮罩 / Escape 关闭 |
| `keyboard` | `boolean` | `true` | 关闭按钮 / 点击遮罩 / Escape 关闭 |
| `onClose` | `() => void` | — | 请求关闭，由应用更新 open |
| `afterClose` | `() => void` | — | 关闭过渡结束后触发 |
| `forceRender` | `boolean` | — | 打开前也挂载内容，关闭时保持隐藏。 |
| `destroyOnClose` | `boolean` | — | 关闭过渡完成后卸载内容；默认保留。 |
| `preserve` | `boolean` | — | 显式控制关闭后是否保留内容，优先于 destroyOnClose。 |
| `container` | `Element \| DocumentFragment \| (() => Element \| DocumentFragment)` | — | 自定义挂载或滚动容器。 |
| `push` | `boolean \| number` | — | 打开嵌套抽屉时推动父弹层，可指定距离。 |
| `resizable` | `boolean` | — | 允许拖动和使用方向键调整大小。 |
| `minSize` | `number` | — | 最小尺寸，单位为像素。 |
| `maxSize` | `number` | — | 最大尺寸，单位为像素。 |
| `onResize` | `(size: number) => void` | — | 大小改变时调用。 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { DrawerProps } from '@sudden3/leaf-ui';
```

## 使用说明

通过 footer 放置取消、提交等操作；表单提交按钮可使用 form 属性关联抽屉内的表单。标题为空时请使用 aria-label 提供名称。支持嵌套弹窗和抽屉，关闭后焦点会回到打开位置。
