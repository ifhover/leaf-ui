# ConfigProvider 配置

为应用或局部区域设置语言、主题和组件默认参数。嵌套使用时，未指定的配置继承上层。

## 示例

### 切换语言

#### 多语言

`locale` 切换日期面板、空状态等内置文本。业务标题、字段标签和选项内容由应用自行翻译。

#### 内置语言

| 语言 | `locale` |
| --- | --- |
| 简体中文 | `zh-CN` |
| 繁體中文 | `zh-TW` |
| English | `en-US` |
| 日本語 | `ja-JP` |
| 한국어 | `ko-KR` |

默认语言为简体中文，与文档站的语言无关。这五种资源已内置；其他语言需要[提供翻译资源](#补充自己的语言)。

更新 `locale` 后，打开日期面板或空选项下拉框，查看内置文本。应用提供的字段标签保持不变。

<ComponentExample exampleId="locale" preview={<ConfigProviderLocale />} fileName="locale.tsx" width={480}>

```tsx lineNumbers file="../../src/examples/config-provider/locale.tsx"
```

</ComponentExample>

嵌套区域未指定语言时继承上层。`direction` 设置文字和交互方向，`weekStartsOn` 设置一周的起始日；浮层也会继承。

### 补充自己的语言

通过 `translations` 按语言代码提供资源。示例只补充三个法语词条，其他词条回退英文；字段名称仍由应用提供。

<ComponentExample exampleId="translations" preview={<ConfigProviderTranslations />} fileName="translations.tsx" width={480}>

```tsx lineNumbers file="../../src/examples/config-provider/translations.tsx"
```

</ComponentExample>

`locale={['fr-FR', 'en-US']}` 按顺序查找每个词条，最后由内置英文兜底。第一项控制日期与数字的区域格式。字符串等价于单项语言链，空数组无效；不会自动添加 `fr-CA → fr` 等区域回退。

嵌套资源按语言和词条合并。未传 `locale` 时继承语言链，显式传入则替换整条链；组件文案参数与 `components` 默认值优先。需要完整资源时可下载<a href={withBase('/locales/en-US.json')} download>英文 JSON 模板</a>。类型、JSON Schema 与校验方式见[翻译资源](/api/translations)。

### 继承与覆盖

优先级为 **实例参数 > 内层配置 > 外层配置 > 组件内置值**。

<ComponentExample exampleId="inheritance" preview={<ConfigProviderInheritance />} fileName="inheritance.tsx" width={480}>

```tsx lineNumbers file="../../src/examples/config-provider/inheritance.tsx"
```

</ComponentExample>

默认值按组件和参数合并。只有 `undefined` 会回退；`false`、`0` 和空字符串等值会保留。对象、数组、类名和回调整体替换，不继续合并。

### 清除继承

将组件配置设为 `null`，在当前区域恢复它的内置默认值。空对象和 `undefined` 继续继承；其他组件与主题不受影响。

<ComponentExample exampleId="reset" preview={<ConfigProviderReset />} fileName="reset.tsx" width={480}>

```tsx lineNumbers file="../../src/examples/config-provider/reset.tsx"
```

</ComponentExample>

使用 `LeafComponentDefaults` 检查可复用配置。键名与公开组件名一致；DataTable 仅使用 `DataTable` 键，别名使用规范名称，例如 `FAB` 对应 `FloatButton`。完整参数见[组件默认值参考](/api/component-defaults#leafcomponentdefaults)。

每个实例的数据、受控状态和事件仍传给组件。更新配置时传入新对象；内部控件通过所属组件配置，例如 `Modal.confirmButtonProps`，不会跟随全局 `Button` 默认值。

## API

### ConfigProvider API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `locale` | `LeafLocale \| readonly LeafLocale[]` | `'zh-CN'` | 当前语言与逐词条回退顺序；未指定则继承 |
| `translations` | `Readonly<Record<string, `[`LeafTranslation`](../api/translations#leaftranslation)`>>` | — | 按语言代码提供 JSON 翻译，嵌套时按词条合并 |
| `theme` | [`LeafTheme`](#leaftheme) | — | 区域主题；未设置的字段继承上层 |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | 继承控件、表单、菜单、列表与浮层的密度；显式尺寸优先于预设。 |
| `components` | [`LeafComponentDefaults`](../api/component-defaults#leafcomponentdefaults) | — | 当前区域的组件默认参数，嵌套时按组件和参数继承。 |
| `direction` | `'ltr' \| 'rtl'` | — | 文字和交互方向。 |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | 一周起始日，0 表示周日、1 表示周一。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `maskBlur` | `boolean` | `false` | 启用 Modal、Drawer 及基于 Modal 的确认框、命令面板等遮罩模糊；关闭可减少渲染开销，嵌套时继承。 |

其余原生 div 属性、`className` 和 `style` 作用于区域容器。

### LeafTheme

常用主题配置。未设置的字段继承外层区域。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#1e964f'` | 主题基色，浅深外观共用；交互色自动派生。 |
| `appearance` | `'light' \| 'dark'` | `'light'` | 浅色或深色；嵌套时继承显式配置 |
| `borderRadius` | `number \| string` | `8` | 基础圆角；数字为 px，小 / 中 / 大圆角按 0.5 / 1.5 / 2 倍生成 |
| `controlHeight` | `number \| string` | `34` | 基础控件高度；小 / 大尺寸分别减 / 加 6px |
| `fontSize` | `number \| string` | `14` | 基础字号；小字号减 1px，大字号加 2px |
| `fontFamily` | `string` | 系统无衬线字体 | 字体族 |
| `motion` | `boolean` | `true` | 启用当前区域的交互动效；系统减少动态效果优先，浮层继承此设置。 |
| `spacing` | `number` | — | 基础间距，其他间距按比例派生。 |
| `lineHeight` | `number \| string` | `20` | 正文行高。数字默认为 px；大于 0 且不超过 4 的数字保留旧倍率语义，字符串按 CSS 长度处理。 |
| `headingWeight` | `400 \| 500 \| 700` | `700` | Card 与 Typography 标题字重，默认 700；其他组件标签使用 `tokens.fontWeight`，默认 500。 |
| `elevation` | `'none' \| 'soft' \| 'medium'` | — | 整体阴影强度。 |
| `breakpoints` | `Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | — | useBreakpoint 使用的响应式断点。 |
| `tokens` | [`LeafThemeTokens`](../api/theme-tokens#leafthemetokens) | — | 可选的高级覆盖，不必配置全部字段 |
| `components` | `Record<string, `[`LeafComponentTokens`](../api/theme-tokens#leafcomponenttokens)`>` | — | 按组件名称覆盖局部样式。 |
