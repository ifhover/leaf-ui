# ConfigProvider 配置

为整个应用或局部区域统一设置主题、语言和组件默认参数。

放在应用入口时作用于整个应用；嵌套使用时只调整当前区域。

| 想调整什么               | 使用的配置               |
| ------------------------ | ------------------------ |
| 内置文本与自定义语言     | `locale`、`translations` |
| 主题色、外观、尺寸与间距 | `theme`、`density`       |
| 统一组件参数             | `components`             |

## 多语言

`locale` 切换日期面板、空状态、清除按钮等内置文本。业务标题、字段标签和选项内容由应用自行翻译。

### 内置语言

以下语言已内置，无需额外导入语言包。未配置 `locale` 时，默认使用简体中文。

| 语言     | `locale` |
| -------- | -------- |
| 简体中文 | `zh-CN`  |
| 繁體中文 | `zh-TW`  |
| English  | `en-US`  |
| 日本語   | `ja-JP`  |
| 한국어   | `ko-KR`  |

其他语言需要[提供翻译资源](#补充自己的语言)。仅传入其他语言代码不会自动翻译内置文本；未找到的词条最终回退到英文。

### 切换语言

更新 `locale` 即可切换语言。在下拉框中选择语言，再打开日期或空选项控件，可比较五种语言的内置提示。

### 补充自己的语言

复制<a href={withBase('/locales/en-US.json')} download>完整英文 JSON</a>作为模板，翻译后导入并传给 `translations`。键是语言代码，JSON 只包含按组件分组的文本，不需要重复写语言代码。可以只提供部分词条。

👽 下面用[火星文](https://zh.wikipedia.org/wiki/火星文)演示自定义资源，作为一个小彩蛋。它是一种混用谐音字、形近字和符号的网络写法。

未翻译的词条回退英文。字段名称、确认框正文等业务内容仍由应用提供。

火星文使用私用语言标记 `zh-CN-x-mars`，日期和数字仍按简体中文的区域格式显示。它仅用于演示，不属于内置语言。

<ComponentExample title="自定义火星文" preview={<ConfigProviderTranslations />} fileName="translations.tsx" width={360}>

```tsx lineNumbers file="../../src/examples/config-provider/translations.tsx"

```

</ComponentExample>

示例把翻译对象直接写在组件文件中，也可以从 JSON 文件导入后传给 `translations`。

`locale={['zh-CN-x-mars', 'en-US']}` 按顺序查找每个缺失词条，最后由内置英文兜底。第一项始终控制当前语言、日期与数字的区域格式；字符串等价于单项数组，空数组无效。不会自动添加 `zh-CN-x-mars → zh-CN` 或 `fr-CA → fr` 等回退。

嵌套时 `translations` 按语言和词条合并；未传 `locale` 则继承，显式传入则替换整条语言链。组件实例与 `components` 设置的文案优先。完整规则、类型、JSON Schema 和词条检查见[翻译资源](/api/translations)。

## 组件默认值

**常用参数设一次，省去每个组件重复传参。** 用 `components` 统一按钮样式、输入提示、弹窗关闭方式，后续调整也只改一处。

放在应用入口作用于全站，放在局部只影响当前区域；个别组件仍可用自身参数覆盖。

<DocsCollapse title="配置键、合并规则与使用建议">

使用 `LeafComponentDefaults` 获得类型提示，可配参数见[完整参考](/api/component-defaults#leafcomponentdefaults)。

- 键名与组件名一致，如 `Input`、`Modal`。组合组件 `DataTable.Search` 写作 `DataTableSearch`，`DataTable.Root` 写作 `DataTable`；别名 `FAB`、`ResizablePanels` 使用 `FloatButton`、`Splitter`。
- 只有 `undefined` 会回退到默认值；`false`、`0`、空字符串和类型允许的 `null` 均保留。对象、数组、类名和回调整体替换。
- 组件配置为 `null` 时清除继承，空对象和 `undefined` 继续继承；其他组件与主题不受影响。
- 每个实例的数据和事件仍写在组件上，如 `Select.options`、`Modal.open`、`onChange`。
- 更新配置时传入新对象，不要直接修改原对象。
- 内部按钮通过所属组件的参数调整，例如 `Modal.confirmButtonProps`；不会跟随全局 `Button` 配置。

</DocsCollapse>

## API

### ConfigProvider API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `locale` | `LeafLocale \| readonly LeafLocale[]` | `'zh-CN'` | 当前语言与逐词条回退顺序；未指定则继承 |
| `translations` | `Readonly<Record<string, `[`LeafTranslation`](../api/translations#leaftranslation)`>>` | — | 按语言代码提供 JSON 翻译，嵌套时按词条合并 |
| `theme` | [`LeafTheme`](#leaftheme) | — | 区域主题；未设置的字段继承上层 |
| `direction` | `'ltr' \| 'rtl'` | — | 文字和交互方向。 |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | 一周起始日，0 表示周日、1 表示周一。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `maskBlur` | `boolean` | `true` | 启用 Modal、Drawer 及基于 Modal 的确认框、命令面板等遮罩模糊；关闭可减少渲染开销，嵌套时继承。 |
| `density` | `'comfortable' \| 'compact'` | `'comfortable'` | 继承控件、表单、菜单、列表与浮层的密度；显式尺寸优先于预设。 |
| `components` | [`LeafComponentDefaults`](../api/component-defaults#leafcomponentdefaults) | — | 当前区域的组件默认参数，嵌套时按组件和参数继承。 |

其余原生 div 属性、`className` 和 `style` 作用于区域容器。`maskBlur={false}` 关闭背景模糊，仍保留半透明遮罩；此设置独立于 `theme.motion`。

### LeafTheme

常用主题配置。未设置的字段继承外层区域。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#1e964f'` | 主题色，悬停和按下等状态自动生成；深色默认采用较浅的绿色 |
| `borderRadius` | `number \| string` | `10` | 基础圆角；数字为 px，小 / 中 / 大圆角按 0.6 / 1.2 / 1.6 倍生成 |
| `controlHeight` | `number \| string` | `34` | 基础控件高度；小 / 大尺寸分别减 / 加 6px |
| `fontSize` | `number \| string` | `14` | 基础字号；小字号减 1px，大字号加 2px |
| `fontFamily` | `string` | 系统无衬线字体 | 字体族 |
| `appearance` | `'light' \| 'dark'` | `'light'` | 浅色或深色；嵌套时继承显式配置 |
| `motion` | `boolean` | `true` | 启用当前区域的交互动效；系统减少动态效果优先，浮层继承此设置。 |
| `tokens` | [`LeafThemeTokens`](../api/theme-tokens#leafthemetokens) | — | 可选的高级覆盖，不必配置全部字段 |
| `spacing` | `number` | — | 基础间距，其他间距按比例派生。 |
| `lineHeight` | `number \| string` | `20` | 正文行高。数字默认为 px；大于 0 且不超过 4 的数字保留旧倍率语义，字符串按 CSS 长度处理。 |
| `headingWeight` | `number` | — | Typography 文档标题的字重；组件标题使用 `tokens.fontWeight`。 |
| `elevation` | `'none' \| 'soft' \| 'medium'` | — | 整体阴影强度。 |
| `breakpoints` | `Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | — | useBreakpoint 使用的响应式断点。 |
| `components` | `Record<string, `[`LeafComponentTokens`](../api/theme-tokens#leafcomponenttokens)`>` | — | 按组件名称覆盖局部样式。 |

### 类型与完整参考

组装可复用配置时，可按需导入类型：

```ts
import type { ConfigProviderProps, LeafComponentDefaults, LeafTheme } from '@ifhover/leaf-ui';
```

- [LeafComponentDefaults](/api/component-defaults#leafcomponentdefaults)：组件名称与可配置的默认参数。
- [LeafThemeTokens](/api/theme-tokens#leafthemetokens)：高级主题覆盖。
