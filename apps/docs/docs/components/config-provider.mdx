## ConfigProvider API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `locale` | `LeafLocale` | `'zh-CN'` | 内置文本语言，嵌套时继承 |
| `theme` | [`LeafTheme`](#leaftheme) | — | 区域主题；未设置的字段继承上层 |
| `messages` | `Partial<`[`LeafMessages`](#leafmessages)`>` | — | 覆盖内置组件的语言文本。 |
| `textMessages` | `Record<string, string>` | — | 以英文原文为 key，覆盖扩展组件的文本。 |
| `direction` | `'ltr' \| 'rtl'` | — | 文字和交互方向。 |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | — | 一周起始日，0 表示周日、1 表示周一。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |

其余原生 div 属性、className 和 style 作用于区域容器。主题设置通过 theme 传入。

## LeafTheme

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `primaryColor` | `string` | `'#20834a'` | 主题色，悬停和按下等状态自动生成；深色默认采用较浅的绿色 |
| `borderRadius` | `number \| string` | `10` | 基础圆角；数字为 px，小 / 大圆角按 0.6 / 1.6 倍生成 |
| `controlHeight` | `number \| string` | `34` | 基础控件高度；小 / 大尺寸分别减 / 加 6px |
| `fontSize` | `number \| string` | `14` | 基础字号；小 / 大字号分别减 / 加 2px |
| `fontFamily` | `string` | 系统无衬线字体 | 字体族 |
| `appearance` | `'light' \| 'dark'` | `'light'` | 浅色或深色；嵌套时继承显式配置 |
| `motion` | `boolean` | `true` | 是否启用过渡与加载图标旋转；尊重系统减少动态效果设置 |
| `tokens` | [`LeafThemeTokens`](#leafthemetokens) | — | 可选的高级覆盖，不必配置全部字段 |
| `spacing` | `number` | — | 基础间距，其他间距按比例派生。 |
| `lineHeight` | `number` | — | 正文行高。 |
| `headingWeight` | `number` | — | 标题字重。 |
| `elevation` | `'none' \| 'soft' \| 'medium'` | — | 整体阴影强度。 |
| `breakpoints` | `Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | — | useBreakpoint 使用的响应式断点。 |
| `components` | `Record<string, `[`LeafComponentTokens`](../guide/theming#leafcomponenttokens)`>` | — | 按组件名称覆盖局部样式。 |

以上默认值适用于未配置的应用。嵌套区域继承上层显式设置；长度也支持 CSS 单位。小控件高度和字号的自动结果不会小于 1px。

## 类型

组装可复用的主题或属性时，可导入这些类型：

```ts
import type { ConfigProviderProps, LeafTheme, LeafThemeTokens, LeafLocale } from '@sudden3/leaf-ui';

const theme: LeafTheme = { primaryColor: '#7654c6', borderRadius: 8 };
const advanced: LeafThemeTokens = { controlHeightLg: 44 };
```

`LeafLocale` 直接表示 `'zh-CN' | 'en-US'`。ConfigProviderProps 对应上方 [ConfigProvider API](#configprovider-api)。

## 使用说明

嵌套区域按字段合并 tokens；手动指定的派生尺寸会继续继承。浮层、Modal、确认框和消息沿用调用区域的配置。ConfigProvider 自动托管确认框、消息、通知和顶部加载条，子组件调用相应 hook 即可，详见 [Confirm](/components/confirm) 和 [Message](/components/message)。

语言覆盖内置提示、日期、时间、清除按钮和反馈组件；业务内容、label 和 options 由应用翻译。

使用 ConfigProvider 调整主题，CSS 变量供业务组件读取和复用。入门示例见[定制主题](/guide/theming)，服务端接入见 [SSR 使用](/guide/ssr)。
