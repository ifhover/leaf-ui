# DatePicker 日期选择器

选择日期、时间或日期时间。日期模式使用本地 `Date`，`picker="time"` 使用时间字符串；选择区间请使用 [DateRangePicker](/components/date-range-picker)。

{/* leaf:section basic */}

## 基础用法

通过 `defaultValue` 设置初始日期，选择日期后自动收起。空值使用 `null`。

### 显示格式与表单提交

<a id="进阶用法"></a>

`format` 改变显示和 `onChange` 的字符串参数，不改变 FormData 的规范值。下面显示 `DD/MM/YYYY`，提交 `YYYY-MM-DD`；清除后提交空字符串，非受控字段重置后恢复 `defaultValue`。

<ComponentExample exampleId="format" preview={<Format />} fileName="format.tsx">

```tsx lineNumbers file="../../src/examples/date-picker/format.tsx"
```

</ComponentExample>

各模式的规范值为 `date: YYYY-MM-DD`、`year: YYYY`、`quarter: YYYY-QN`、`month: YYYY-MM`、`week: YYYY-Www`，日期时间为 `YYYY-MM-DD HH:mm[:ss]`。日期使用本地时间，业务时区转换由应用处理，避免把 UTC 日期字符串当成本地日历值。

字符串格式支持 `YYYY`、`MM`、`DD`、`HH`、`mm`、`ss`、`Q`，用方括号转义文字，例如 `YYYY-[Q]Q`。函数格式化若不能由默认解析识别，应同时提供 `parse`，失败时返回 `null`。更多表单配置见 [Form](/components/form)。

### 快捷日期

通过 `presets` 提供常用日期。快捷值可以是 `Date` 或同步返回 `Date` 的函数，不接收 Promise；点击有效快捷项会立即提交并收起，不等待“确定”。今天按钮可通过 `showToday` / `todayText` 配置，自定义底部内容使用 `renderExtraFooter`，其中的业务操作由应用处理。

#### 输入与确认

可直接输入或粘贴完整值，点击或用左右键选择日期分段。`Enter` 提交有效输入，`Escape` 放弃当前编辑；无效或未完成输入在焦点离开整个选择器时恢复已提交值。`Alt + ↓` 可将焦点移入面板。

日期和纯时间模式默认不要求确认，有效改动可在离开时提交。设置 `needConfirm` 后，未确认的编辑在离开时放弃；清除和快捷日期仍会直接提交。

## API

### DatePicker API

主表包含不同 `picker` 模式的参数：`format`、`parse`、`presets`、`minDate` / `maxDate` 和日历展示配置用于日期模式；`minTime` / `maxTime` 用于纯时间模式。`disabledTime` 在日期时间模式额外接收当前 `Date`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `picker` | `'date' \| 'datetime' \| 'year' \| 'quarter' \| 'month' \| 'week' \| 'time'` | `'date'` | 选择日期、时间、日期时间、周、月、季度或年。 |
| `value` | `Date \| null \| string` | — | 受控值：日期 / 日期时间为 Date，纯时间为 HH:mm[:ss] 字符串；空值为 null。 |
| `defaultValue` | `Date \| null \| string` | `null` | 非受控初始值，类型由 picker 决定，表单重置时恢复。 |
| `onChange` | `((value: Date \| null, dateString: string) => void) \| ((value: string \| null) => void)` | — | 提交时调用；日期模式返回 Date 和字符串，纯时间只返回 HH:mm[:ss] 或 null。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 选择器尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `inputReadOnly` | `boolean` | — | 只禁止手动输入，仍可在面板中选择。 |
| `allowClear` | `boolean` | `true` | 展示清除按钮 |
| `minDate` | `Date` | — | 最早可选日期；datetime 模式按完整时间戳比较，含边界。 |
| `maxDate` | `Date` | — | 最晚可选日期；datetime 模式按完整时间戳比较，含边界。 |
| `disabledDate` | `(date: Date) => boolean` | — | 限制可选择日期 |
| `minTime` | `string` | — | 最早可选时间（含边界），格式为 HH:mm 或 HH:mm:ss。 |
| `maxTime` | `string` | — | 最晚可选时间（含边界），格式为 HH:mm 或 HH:mm:ss。 |
| `disabledTime` | `((parts: `[`TimeParts`](#timeparts)`, date: Date) => boolean) \| ((parts: `[`TimeParts`](#timeparts)`) => boolean)` | — | 按业务规则禁用时间，输入和面板选择使用同一规则。 |
| `needConfirm` | `boolean` | `picker === "datetime"` | 要求点击确定或按 Enter 提交；开启后失焦放弃草稿。 |
| `showSeconds` | `boolean` | `false` | 显示并编辑秒，关闭时秒为 0。 |
| `use12Hours` | `boolean` | `false` | 使用 12 小时制与上午 / 下午。 |
| `minuteStep` | `number` | `1` | 分钟段步进与分钟列间隔，保留已有的非步长值。 |
| `secondStep` | `number` | `1` | 秒段步进与秒列间隔，保留已有的非步长值。 |
| `format` | `string \| ((date: Date) => string)` | — | 显示格式；日期支持 YYYY、MM、DD、HH、mm、ss、Q。 |
| `parse` | `(text: string) => Date \| null` | — | 自定义文本解析，失败时返回 null。 |
| `presets` | `readonly `[`DatePreset`](#datepreset)`[]` | — | 快捷选项；value 可以动态计算。 |
| `showToday` | `boolean` | `true` | 展示今天快捷按钮 |
| `todayText` | `ReactNode` | 语言默认值 | 自定义今天按钮文字 |
| `renderExtraFooter` | `ReactNode` | — | 额外底部内容，可放快捷操作 |
| `panelValue` | `Date` | — | 受控的日历显示日期。 |
| `onPanelChange` | `(date: Date) => void` | — | 日历显示的周期改变时调用。 |
| `cellRender` | `(date: Date) => ReactNode` | — | 自定义日历单元格内容。 |
| `open` | `boolean` | — | 控制面板是否展开。 |
| `defaultOpen` | `boolean` | — | 面板初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 日历展开或收起 |
| `panelVariant` | `'plain' \| 'card'` | `'plain'` | 面板外观；card 在柔和画布上以内嵌内容卡呈现。 |
| `name` | `string` | — | 原生 FormData 中的字段名。 |
| `form` | `string` | — | 关联的原生表单 ID。 |
| `required` | `boolean` | `false` | 要求整体值非空，复合控件只校验一次。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `ref` | `Ref<HTMLInputElement>` | — | 输入框引用 |

其余原生 input 属性和 `aria-*` 传给输入框，`className` / `style` 作用于外层。共享浮层配置见 [PopupOptions](/api/popup-options)。

### SingleDatePicker API

日期模式的值与回调类型；通用参数见主表。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `Date \| null` | — | 受控值。 |
| `defaultValue` | `Date \| null` | `null` | 初始值；非受控模式支持表单重置。 |
| `onChange` | `(value: Date \| null, dateString: string) => void` | — | 提交选择时返回日期和格式化字符串；清空返回 null 和空字符串。 |

### DatePreset

`presets` 使用的快捷项类型。`T` 在单值中为 `Date`，在区间中为日期元组；函数应同步、无副作用，并允许多次求值。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定且唯一的标识。 |
| `label` | `ReactNode` | 必填 | 展示文字或内容。 |
| `value` | `T \| (() => T)` | 必填 | 快捷项的值或同步取值函数；函数应无副作用，允许多次求值。 |
