# Masonry 瀑布流

排列高度不一的卡片与图片。

内容按列从上到下阅读，不按横行排列。需要逐行阅读或让键盘焦点顺序对应横行时，使用 [Grid](./grid)。

## API

### MasonryProps API

配置瀑布流的列数与条目间距。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `columns` | `number \| Partial<Record<'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl', number>>` | `{ xs: 1, sm: 2, lg: 3 }` | 列数或视口断点配置；未指定的断点继承更小断点。 |
| `gap` | `number \| string` | `16` | 列间距与条目纵向间距；数字为 px，也支持 CSS 长度。 |
