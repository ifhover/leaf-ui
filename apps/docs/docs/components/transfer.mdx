# Transfer 穿梭框

在两个列表之间选择和移动项目。

{/* leaf:section basic */}

## 基础用法

<a id="基本用法"></a>

勾选项目后，使用中间的按钮移动到另一栏。内置搜索按名称和描述筛选，“全选”只影响当前筛选结果中的可用项目。已勾选但被搜索隐藏的项目仍会一起移动。

## 示例

### 受控值与勾选

`value` 表示右侧已有的项目，`selectedKeys` 表示两栏中待移动的勾选项；勾选本身不会移动项目。分别通过 `onChange` 和 `onSelectionChange` 同步状态，移动成功后组件会取消这些项目的勾选。

### 单向移入

`oneWay` 只保留移向右侧的操作，不隐藏右侧列表、搜索或勾选功能。

## API

### TransferProps API

配置左右列表的数据、目标值与转移事件。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`TransferItem`](#transferitem-api)`[]` | 必填 | 数据项目，保持 key 唯一且稳定 |
| `value` | `readonly string[]` | — | 受控的右栏项目 key；不是待移动的勾选项。 |
| `defaultValue` | `readonly string[]` | `[]` | 非受控模式的初始右栏 key，表单重置时恢复；不重置搜索或临时勾选。 |
| `onChange` | `(keys: string[], info: `[`TransferChangeInfo`](#transferchangeinfo-api)`) => void` | — | 移动后返回右栏 key，info 包含 direction 与 movedKeys。 |
| `selectedKeys` | `readonly string[]` | — | 受控的待移动勾选 key，可包含两栏项目；勾选本身不会移动项目。 |
| `onSelectionChange` | `(keys: string[]) => void` | — | 勾选变化或移动后移除已移动的勾选项时，返回当前勾选 key。 |
| `titles` | `readonly [ReactNode, ReactNode]` | — | 左、右标题 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `searchable` | `boolean` | `true` | 显示搜索框 |
| `filterOption` | `(query: string, item: `[`TransferItem`](#transferitem-api)`) => boolean` | — | 自定义搜索规则 |
| `oneWay` | `boolean` | `false` | 隐藏移回左栏的按钮，右栏仍可搜索和勾选。 |
| `renderItem` | `(item: `[`TransferItem`](#transferitem-api)`) => ReactNode` | — | 自定义项目内容 |
| `virtual` | `boolean` | `false` | 仅渲染可见项目 |
| `height` | `number` | `180` | 每栏可滚动列表区域的高度，不包含标题和搜索框。 |
| `name` | `string` | — | 原生 FormData 的字段名；非空值提交 JSON 数组，空值提交空字符串。 |
| `form` | `string` | — | 关联表单 ID |
| `required` | `boolean` | — | 要求整体值非空，复合控件只校验一次。 |

### TransferItem API

穿梭框中可转移的单个数据项。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一且稳定的标识 |
| `label` | `ReactNode` | 必填 | 显示内容 |
| `description` | `string` | — | 补充说明 |
| `disabled` | `boolean` | — | 禁用交互。 |
| `searchLabel` | `string` | — | 搜索使用的纯文字 |

### TransferChangeInfo API

描述一次转移的方向和受影响的数据项。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `direction` | `'left' \| 'right'` | 必填 | 移动方向：'left' 移到左栏，'right' 移到右栏。 |
| `movedKeys` | `string[]` | 必填 | 本次移动标识 |
