## 示例

### 数值格式

<ComponentExample exampleId="formatting" preview={<StatisticFormatting />} fileName="formatting.tsx" width="fit-content">

数字按当前区域设置格式化，字符串直接显示。通过 `formatter` 自定义展示时，由调用者处理格式。

### 数值动画

数字默认从 0 开始，后续变化从当前显示值继续。使用 `initialValue` 调整首次起点，`duration` 调整时长；设置 `animation={false}` 或 `duration={0}` 可立即更新。

<ComponentExample exampleId="animation" preview={<StatisticAnimation />} fileName="animation.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/statistic/animation.tsx"
```

</ComponentExample>

仅有限的 `number` 值参与动画；动画期间，`formatter` 会收到中间值。加载状态结束后才开始动画，并遵循减少动态效果偏好。

### 倒计时

`value` 是截止时间的 `Date` 或毫秒时间戳，不是剩余时长。示例每次计时 10 秒，并在 `onFinish` 中更新完成反馈；组件不会自动播报每次数值变化。

<ComponentExample exampleId="countdown" preview={<StatisticCountdown />} fileName="countdown.tsx" width="fit-content">

```tsx lineNumbers file="../../src/examples/statistic/countdown.tsx"
```

</ComponentExample>

服务端渲染时，可传入同一份 `initialRemaining`，使服务端与客户端首屏一致；挂载后按实际截止时间更新。

## API

### Statistic API

配置指标名称、数值格式和变化动画。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 标题内容。 |
| `value` | `number \| string` | 必填 | 要展示的数值或文字。 |
| `precision` | `number` | — | 小数位数。 |
| `grouping` | `boolean` | `true` | 启用本地化数字分组。 |
| `prefix` | `ReactNode` | — | 前置内容。 |
| `suffix` | `ReactNode` | — | 后置内容。 |
| `formatter` | `(value: number \| string) => ReactNode` | — | 自定义指标数值的展示。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `animation` | `boolean` | `true` | 启用数值变化动画。 |
| `initialValue` | `number` | `0` | 首次动画的起始值，后续变化从当前显示值开始。 |
| `duration` | `number` | `1000` | 默认动效速度下的动画时长（毫秒），随区域动效时长缩放；0 表示立即更新。 |

### Countdown API

配置倒计时的目标时间与结束反馈。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | — | 标题内容。 |
| `prefix` | `ReactNode` | — | 前置内容。 |
| `suffix` | `ReactNode` | — | 后置内容。 |
| `loading` | `boolean` | — | 展示加载状态。 |
| `value` | `number \| Date` | 必填 | 截止时间的 Date 或毫秒时间戳。 |
| `format` | `string` | `'HH:mm:ss'` | DD、HH、mm、ss、SSS 格式，其中 HH 可展示累计小时。 |
| `onFinish` | `() => void` | — | 当前截止时间到达时调用一次；完成提示由应用提供。 |
| `onChange` | `(remaining: number) => void` | — | 更新时返回剩余毫秒数，完成后返回 0。 |
| `initialRemaining` | `number` | — | SSR 首屏使用的剩余毫秒数，客户端挂载后按截止时间更新。 |
