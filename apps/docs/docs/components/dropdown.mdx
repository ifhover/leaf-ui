## API

### Dropdown API

触发器应是支持 ref 与事件的单个按钮。Escape 关闭菜单并返回触发按钮。共享浮层参数见 [PopupOptions](/api/popup-options)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | 必填 | 菜单项列表 |
| `children` | `ReactElement< ButtonHTMLAttributes<HTMLButtonElement> & { ref?: Ref<HTMLButtonElement> } >` | 必填 | 单个按钮，支持 Leaf Button 或 button |
| `trigger` | `'click' \| 'hover' \| 'contextMenu' \| readonly ('click' \| 'hover' \| 'contextMenu')[]` | `'click'` | 触发方式；下拉菜单支持点击、悬停和右键。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 展示尺寸。 |
| `open` | `boolean` | — | 受控的展开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控模式的初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变更 |
| `onSelect` | `(key: string) => void` | — | 激活叶菜单项时返回 key，包括单选和复选项；展开子菜单不触发。 |
| `placement` | `'top-start' \| 'top-end' \| 'bottom-start' \| 'bottom-end'` | `'bottom-start'` | 菜单位置；popupPlacement 优先。 |
| `popupWidth` | `number \| string` | `—` | 浮层宽度；未设置时最小 160px，并根据内容增宽。 |
| `popupMaxWidth` | `number \| string` | `420` | 浮层最大宽度，仍受视口限制。 |
| `itemRender` | `(item: `[`DropdownItem`](#dropdownitem)`) => ReactNode` | — | 自定义菜单项的标签内容，不替换整行。 |
| `mouseEnterDelay` | `number` | `100` | 悬停触发后等待多少毫秒再打开。 |
| `mouseLeaveDelay` | `number` | `150` | 鼠标离开后等待多少毫秒再关闭。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |

### DropdownItem

下拉菜单中的操作、分组或子菜单数据。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 唯一标识 |
| `label` | `ReactNode` | — | 菜单项文字或分组标题。 |
| `icon` | `ReactNode` | — | 菜单项文字前的图标。 |
| `extra` | `ReactNode` | — | 条目右侧的附加内容；适合放快捷键、状态标签等非交互信息。 |
| `type` | `'item' \| 'divider' \| 'group' \| 'checkbox' \| 'radio'` | `'item'` | 普通项、分隔线、分组、复选项或单选项。 |
| `children` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | — | 菜单项列表。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `danger` | `boolean` | `false` | 危险操作的颜色，不会禁用菜单项。 |
| `checked` | `boolean` | — | 受控的勾选状态；省略时由菜单内部保存。 |
| `group` | `string` | — | 单选项所属的互斥组标识。 |
| `closeOnSelect` | `boolean` | — | 选择后是否关闭；默认普通项关闭，单选和复选项保持打开。 |
| `onCheckedChange` | `(checked: boolean) => void` | — | 点击勾选项时返回下一勾选状态。 |
| `href` | `string` | — | 链接目标。 |
| `target` | `string` | — | 链接的 target 属性，例如 _blank；省略时在当前标签页打开。 |
| `onClick` | `(event: MouseEvent<HTMLElement>) => void` | — | 点击此项时触发 |
