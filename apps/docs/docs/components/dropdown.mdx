## Dropdown API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
| `items` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | 必填 | 必需。菜单项列表 |
| `children` | `ReactElement< ButtonHTMLAttributes<HTMLButtonElement> & { ref?: Ref<HTMLButtonElement> } >` | 必填 | 必需。单个按钮，支持 Leaf Button 或 button |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `open` | `boolean` | `false` | 受控 / 初始展开状态 |
| `defaultOpen` | `boolean` | `false` | 受控 / 初始展开状态 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变更 |
| `onSelect` | `(key: string) => void` | — | 选择可用菜单项 |
| `placement` | `'top-start' \| 'top-end' \| 'bottom-start' \| 'bottom-end'` | `'bottom-start'` | 弹出方向 |
| `popupWidth` | `number \| string` | `—` | 浮层宽度 / 最大宽度 |
| `popupMaxWidth` | `number \| string` | `420` | 浮层宽度 / 最大宽度 |
| `trigger` | `'click' \| 'hover' \| 'contextMenu' \| readonly ('click' \| 'hover' \| 'contextMenu')[]` | `'click'` | 触发方式；下拉菜单支持点击、悬停和右键。 |
| `mouseEnterDelay` | `number` | `100` | 设置 mouseEnterDelay。 |
| `mouseLeaveDelay` | `number` | `150` | 设置 mouseLeaveDelay。 |
| `itemRender` | `(item: `[`DropdownItem`](#dropdownitem)`) => ReactNode` | — | 自定义条目内容。 |

## DropdownItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | 必填 | 必需。唯一标识 |
| `label` | `ReactNode` | — | 文字与图标 |
| `icon` | `ReactNode` | — | 文字与图标 |
| `type` | `'item' \| 'divider' \| 'group' \| 'checkbox' \| 'radio'` | `'item'` | 菜单项或分割线 |
| `children` | `readonly `[`DropdownItem`](#dropdownitem)`[]` | — | 子内容；嵌套数据类型表示子节点。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `danger` | `boolean` | `false` | 禁用 / 危险操作 |
| `checked` | `boolean` | — | 设置 checked。 |
| `group` | `string` | — | 条目的分组标题。 |
| `closeOnSelect` | `boolean` | — | 设置 closeOnSelect。 |
| `onCheckedChange` | `(checked: boolean) => void` | — | 设置 onCheckedChange。 |
| `href` | `string` | — | 链接目标。 |
| `target` | `string` | — | 目标的选择器或返回元素的函数；省略时居中。 |
| `onClick` | `(event: MouseEvent<HTMLElement>) => void` | — | 点击此项时触发 |

## 类型

定义组件属性或组装变量时可导入相关类型。

```ts
import type { DropdownProps, DropdownItem } from '@sudden3/leaf-ui';
```

## 使用说明

按钮按 ↓ / ↑ 打开菜单，菜单中使用方向键、Home、End 或文字首字符定位；Enter 选择，Escape 关闭并恢复按钮焦点。disabled 菜单项与分割线会被跳过。
