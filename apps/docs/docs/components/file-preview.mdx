## 使用说明

支持图片、PDF、音视频、文本。Office 文档提供下载或 renderUnsupported；需要在线阅读时可转换成 PDF。HTML 按文本显示。远程文件需要允许跨域读取。

### 自托管 PDF worker

构建应用时将包内 worker 复制到静态地址，并传给 workerSrc，确保阅读器和 worker 的版本一致。默认 worker 使用指定版本的 unpkg CDN。

```js
import { createRequire } from 'node:module';
import { copyFile, mkdir } from 'node:fs/promises';
const require = createRequire(import.meta.url);
await mkdir('public', { recursive: true });
await copyFile(require.resolve('@sudden3/leaf-ui/pdf.worker.mjs'), 'public/pdf.worker.mjs');
```

```tsx
<FilePreview file={{ url: '/report.pdf' }} workerSrc="/pdf.worker.mjs" />
```

## 类型

组装数据、定义回调和使用 ref 时，可以导入这些类型。

```ts
import type { FilePreviewProps, FilePreviewSource } from '@sudden3/leaf-ui';
```

## FilePreviewProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `file` | [`FilePreviewSource \| File`](#filepreviewsource-api) | 必填 | 文件或地址与名称 |
| `height` | `number \| string` | `460` | 高度，数字按像素计算 |
| `downloadable` | `boolean` | `true` | 显示下载操作 |
| `workerSrc` | `string` | — | 匹配版本的 PDF worker 地址 |
| `maxTextBytes` | `number` | `1048576` | 最多读取的文本字节数 |
| `onError` | `(error: Error) => void` | — | 异常回调 |
| `renderUnsupported` | [`(source: FilePreviewSource) => ReactNode`](#filepreviewsource-api) | — | 自定义不支持的类型展示 |

## FilePreviewSource API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `url` | `string` | 必填 | 文件地址 |
| `name` | `string` | — | 文件名称 |
| `contentType` | `string` | `''` | MIME 类型 |
