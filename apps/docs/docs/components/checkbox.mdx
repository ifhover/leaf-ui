## 全选与半选

indeterminate 表示部分选中，用于汇总子选项。它只影响显示与辅助技术识别；全选和提交值由 checked 决定。

## API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| checked / defaultChecked | boolean | — | 受控选中 / 非受控初始选中 |
| indeterminate | boolean | false | 半选状态，写入原生 input.indeterminate |
| onChange | `ChangeEventHandler<HTMLInputElement>` | — | 读取 event.target.checked |
| disabled | boolean | false | 禁用选项 |
| size | `'sm' \| 'md' \| 'lg'` | md | 容器的最小高度为 28 / 34 / 40px |
| children | ReactNode | — | 可点击的选项标签 |
| ref | `Ref<HTMLInputElement>` | — | 原生 checkbox 节点 |

name、value、required、form 等原生属性可直接使用。只有已勾选且未禁用的复选框参与原生表单提交。没有文字标签时必须提供 aria-label。className 与 style 作用于标签容器。
