# Checkbox 复选框

选择一个或多个选项，或确认某项设置。

{/* leaf:section basic */}

## 基础用法

通过文字内容提供选项名称，用户可独立切换选中状态。

#### 表单提交与重置

设置 `name` 后，只有已勾选且未禁用的选项参与提交。选项组按同一个字段名提交多个值，可用 `FormData.getAll(name)` 读取。

非受控字段在表单重置时恢复 `defaultChecked` 或 `defaultValue`；受控字段需要同步重置应用状态。

## API

### Checkbox API

支持 `name`、`value`、`required`、`form` 等原生 checkbox 属性。没有文字标签时提供 `aria-label`；`className` 和 `style` 作用于标签容器。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 复选框尺寸 |
| `variant` | `'plain' \| 'card'` | `'plain'` | 普通选项或整块可点击的卡片选项。 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `indeterminate` | `boolean` | `false` | 半选状态 |
| `checked` | `boolean` | — | 受控的勾选状态。 |
| `defaultChecked` | `boolean` | — | 非受控模式的初始勾选状态。 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 event.target.checked 读取选中状态。 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `children` | `ReactNode` | — | 可点击的选项标签。 |
| `ref` | `Ref<HTMLInputElement>` | — | 复选框引用 |

### CheckboxGroupProps API

统一管理一组选项和值的参数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | `readonly (`[`CheckboxOption`](#checkboxoption-api)` \| string)[]` | 必填 | 可用选项 |
| `value` | `readonly string[]` | — | 受控值 |
| `defaultValue` | `readonly string[]` | `[]` | 初始值；非受控表单 reset 时恢复 |
| `onChange` | `(values: string[]) => void` | — | 值变化回调 |
| `legend` | `ReactNode` | — | 字段组名称 |
| `size` | `'sm' \| 'md' \| 'lg'` | — | 复选框尺寸。 |
| `variant` | `'plain' \| 'card' \| 'list'` | `'plain'` | 普通排列、卡片网格或带分隔线的成组列表。 |
| `required` | `boolean` | — | 要求整体值非空，复合控件只校验一次。 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 选项的排列方向。 |

### CheckboxOption API

通过复选框组 `options` 提供的选项数据。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 选项值；同一组内应唯一。 |
| `label` | `ReactNode` | 必填 | 显示内容 |
| `description` | `ReactNode` | — | 补充说明。 |
| `icon` | `ReactNode` | — | 图标内容。 |
| `extra` | `ReactNode` | — | 补充状态文字或标签；不要放置交互控件。 |
| `disabled` | `boolean` | — | 禁用交互。 |
