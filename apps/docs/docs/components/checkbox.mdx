## Checkbox API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `checked` / `defaultChecked` | `boolean` | — | 受控选中状态 / 非受控初始状态 |
| `indeterminate` | `boolean` | `false` | 半选状态 |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | — | 从 `event.target.checked` 读取选中状态 |
| `disabled` | `boolean` | `false` | 禁用选项 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 复选框尺寸 |
| `children` | `ReactNode` | — | 可点击的选项标签 |
| `ref` | `Ref<HTMLInputElement>` | — | 复选框引用 |

name、value、required、form 等原生属性可直接使用。只有已勾选且未禁用的复选框参与原生表单提交。没有文字标签时必须提供 aria-label。className 与 style 作用于标签容器。

## 类型

可导入 [`CheckboxProps`](#checkbox-api) 定义组件属性，或使用尺寸类型：

```ts
import type { CheckboxProps, ControlSize } from '@sudden3/leaf-ui';
```

## 扩展类型

```ts
import type { CheckboxGroupProps, CheckboxOption } from '@sudden3/leaf-ui';
```

## CheckboxGroupProps API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `options` | [`readonly (CheckboxOption \| string)[]`](#checkboxoption-api) | 必填 | 可用选项 |
| `value` | `readonly string[]` | — | 受控值 |
| `defaultValue` | `readonly string[]` | `[]` | 初始值；非受控表单 reset 时恢复 |
| `onChange` | `(values: string[]) => void` | — | 值变化回调 |
| `legend` | `ReactNode` | — | 字段组名称 |
| `size` | `'sm' \| 'md' \| 'lg'` | — | 尺寸或间距预设 |
| `minCount` | `number` | `0` | 最少勾选数量 |
| `maxCount` | `number` | `Infinity` | 最多勾选或展示数量 |
| `required` | `boolean` | — | 表单必填验证 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 排列方向或移动方向 |

## CheckboxOption API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | 必填 | 受控值 |
| `label` | `ReactNode` | 必填 | 显示内容 |
| `disabled` | `boolean` | — | 禁止交互 |
