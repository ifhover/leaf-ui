## Breadcrumb API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`BreadcrumbItem`](#breadcrumbitem)`[]` | 必填 | 必需。路径列表 |
| `separator` | `ReactNode` | ChevronRight | 分隔内容 |
| `maxItems` | `number` | — | 路径折叠前最多展示的项数。 |
| `itemsBeforeCollapse` | `number` | `1` | 折叠后保留的起始项数。 |
| `itemsAfterCollapse` | `number` | `1` | 折叠后保留的末尾项数。 |
| `itemRender` | `(item: `[`BreadcrumbItem`](#breadcrumbitem)`, index: number) => ReactNode` | — | 自定义条目内容。 |
| `aria-label` | `string` | 语言默认值 | 导航名称 |

## BreadcrumbItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定标识 |
| `title` | `ReactNode` | 必填 | 必需。页面名称 |
| `icon` | `ReactNode` | — | 前置图标 |
| `menu` | `readonly `[`DropdownItem`](../components/dropdown#dropdownitem)`[]` | — | 该路径项的下拉菜单。 |
| `href` | `string` | — | 链接目标。 |
| `target` | `string` | — | 目标的选择器或返回元素的函数；省略时居中。 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { BreadcrumbProps, BreadcrumbItem } from '@sudden3/leaf-ui';
```

## 使用说明

最后一项标记为当前页面。BreadcrumbItem 继承原生链接属性，可通过 title 传入路由框架的 Link；没有 href 时不会生成多余的链接。
