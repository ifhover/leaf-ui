展示当前页面在导航层级中的位置。

## 基础用法

最后一项表示当前页面，可以省略 `href`。如果 `title` 已经是路由框架的 Link，也不要再传 `href`，避免嵌套链接。

## API

### Breadcrumb API

路径层级、分隔内容与中间路径折叠的配置。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | `readonly `[`BreadcrumbItem`](#breadcrumbitem)`[]` | 必填 | 路径列表 |
| `separator` | `ReactNode` | ChevronRight | 分隔内容 |
| `maxItems` | `number` | `Infinity` | 超过此项数时折叠中间路径；最小阈值为 3，默认不折叠。 |
| `itemsBeforeCollapse` | `number` | `1` | 折叠后保留的起始项数。 |
| `itemsAfterCollapse` | `number` | `1` | 折叠后保留的末尾项数。 |
| `itemRender` | `(item: `[`BreadcrumbItem`](#breadcrumbitem)`, index: number) => ReactNode` | — | 自定义条目内容。 |
| `aria-label` | `string` | 语言默认值 | 导航名称 |

### BreadcrumbItem

通过 `items` 定义的路径层级。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定标识 |
| `title` | `ReactNode` | 必填 | 页面名称 |
| `icon` | `ReactNode` | — | 前置图标 |
| `menu` | `readonly `[`DropdownItem`](dropdown#dropdownitem)`[]` | — | 该路径项的下拉菜单。 |
| `href` | `string` | — | 链接目标。 |
| `target` | `string` | — | 链接的打开目标，遵循原生 a 元素的 target。 |
