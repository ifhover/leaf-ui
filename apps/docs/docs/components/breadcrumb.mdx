# Breadcrumb 面包屑

展示当前页面在导航层级中的位置。

## Breadcrumb API

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `items` | [`readonly BreadcrumbItem[]`](#breadcrumbitem) | 必填 | 路径列表 |
| `separator` | `ReactNode` | ChevronRight | 分隔内容 |
| `aria-label` | `string` | 语言默认值 | 导航名称 |

## BreadcrumbItem

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `key` | `string` | — | 稳定标识 |
| `title` | `ReactNode` | 必填 | 页面名称 |
| `icon` | `ReactNode` | — | 前置图标 |
| `href` | `string` | — | 跳转地址；省略时显示文本 |
| `target` | `string` | — | 链接打开方式 |
| `onClick` | `MouseEventHandler<HTMLAnchorElement>` | — | 链接点击事件 |

## 类型

定义组件属性或组装列表时可导入相关类型。

```ts
import type { BreadcrumbProps, BreadcrumbItem } from '@sudden3/leaf-ui';
```

## 使用说明

最后一项标记为当前页面。BreadcrumbItem 继承原生链接属性，可通过 title 传入路由框架的 Link；没有 href 时不会生成多余的链接。
