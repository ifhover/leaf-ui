## API

### Textarea API

配置多行文本、字数限制和输入状态。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 文本域尺寸 |
| `status` | `'error' \| 'warning'` | — | 校验状态 |
| `rows` | `number` | `3` | 初始可见行数 |
| `resize` | `'none' \| 'vertical' \| 'both'` | `'vertical'` | 允许的手动缩放方向 |
| `value` / `defaultValue` | `string \| number \| readonly string[]` | — | 受控值 / 非受控初始值 |
| `onChange` | `ChangeEventHandler<HTMLTextAreaElement>` | — | 从 `event.target.value` 读取内容 |
| `disabled` / `readOnly` | `boolean` | `false` | 禁用 / 只读 |
| `ref` | `Ref<HTMLTextAreaElement>` | — | 文本域引用 |
| `autoSize` | [`boolean \| TextareaAutoSize`](#textareaautosize-api) | `false` | 根据内容调整高度，可限制行数 |
| `showCount` | `boolean \| ((value: string, maxLength?: number) => ReactNode)` | `false` | 显示字数，可自定义渲染 |

### TextareaAutoSize API

限制自动调整高度时使用的最小和最大行数。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `minRows` | `number` | — | 最少行数 |
| `maxRows` | `number` | — | 最多行数 |
