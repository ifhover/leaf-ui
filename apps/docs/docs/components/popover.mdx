## API

### Popover API

配置浮层内容、触发方式和受控展开状态。

触发元素需透传 ref 与事件。没有 `title` 时，通过 `aria-label` 为浮层提供名称。Tab 可以离开浮层，不会将焦点限制在其中。共享浮层参数见 [PopupOptions](/api/popup-options)。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | `ReactNode` | `—` | 浮层标题。 |
| `content` | `ReactNode` | 必填 | 浮层内容；交互内容使用点击模式。 |
| `children` | `ReactElement< HTMLAttributes<HTMLElement> & { ref?: Ref<HTMLElement>; disabled?: boolean } >` | 必填 | 触发元素，需要支持 ref 与事件 |
| `trigger` | `'click' \| 'hover'` | `'click'` | 触发方式 |
| `placement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | `'top'` | 浮层方向 |
| `disabled` | `boolean` | `false` | 禁用交互。 |
| `open` | `boolean` | — | 受控的展开状态。 |
| `defaultOpen` | `boolean` | `false` | 非受控模式的初始展开状态。 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化 |
| `autoFocus` | `boolean` | `true` | 点击模式打开后聚焦首个可聚焦元素，没有时聚焦面板；悬停模式不移动焦点。 |
| `aria-label` | `string` | — | 没有可见标题时，提供浮层的可访问名称。 |
| `width` | `number \| string` | `'max-content'` | 浮层宽度；数字为像素。 |
| `maxWidth` | `number \| string` | `320` | 浮层最大宽度；数字为像素。 |
| `enterDelay` | `number` | `100` | 悬停后等待多少毫秒再打开。 |
| `leaveDelay` | `number` | `100` | 指针离开后等待多少毫秒再关闭。 |
| `className` | `string` | — | 浮层面板的 CSS 类名。 |
| `style` | `CSSProperties` | — | 浮层面板的内联样式。 |
| `popupPlacement` | `'top' \| 'top-start' \| 'top-end' \| 'bottom' \| 'bottom-start' \| 'bottom-end' \| 'left' \| 'left-start' \| 'left-end' \| 'right' \| 'right-start' \| 'right-end'` | — | 浮层相对触发控件的位置。 |
| `popupClassName` | `string` | — | 浮层的自定义类名。 |
| `popupStyle` | `CSSProperties` | — | 浮层的自定义样式。 |
| `popupRender` | `(content: React.ReactNode) => React.ReactNode` | — | 包装或补充面板内容，保留传入的内容以维持交互。 |
| `getPopupContainer` | `() => Element \| DocumentFragment` | — | 返回浮层的挂载容器，也可返回 ShadowRoot。 |
