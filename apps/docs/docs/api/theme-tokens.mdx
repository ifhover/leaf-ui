# 主题变量

日常定制优先设置 ConfigProvider 的 `theme.primaryColor`、`theme.borderRadius` 和 `theme.controlHeight`，其他样式会自动派生，见[定制主题](/guide/theming)。

默认浅色基础色统一来自 `colors.ts`：主题与成功为 `#1e964f`，危险为 `#dd3f2e`，警告为 `#d38b11`，信息为 `#1677ff`。组件样式和静态色板都消费同一组 `--leaf-color-*` 变量，不要在组件内重复声明语义色。

## 类型导入

```tsx
import type { LeafThemeTokens } from '@ifhover/leaf-ui';

const tokens = {
  controlHeightSm: 28,
  borderRadiusLg: 14,
} satisfies LeafThemeTokens;
```

将该对象传给 `<ConfigProvider theme={{ tokens }}>`。

## LeafComponentTokens

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `borderRadius` | `string \| number` | — | 圆角；数字表示像素。 |
| `borderWidth` | `string \| number` | — | 此组件的边框宽度；数字为 px。 |
| `controlHeight` | `string \| number` | — | 控件高度；数字表示像素。 |
| `padding` | `string \| number` | — | 内容内边距。 |
| `gap` | `string \| number` | — | 子项之间的间距。 |
| `fontSize` | `string \| number` | — | 字号；数字表示像素。 |
| `color` | `string` | — | 颜色或语义色。 |
| `background` | `string` | — | 组件表面背景。 |
| `borderColor` | `string` | — | 外层边框与分区分隔线颜色。 |
| `headerBackground` | `string` | — | 标题区域背景。 |
| `footerBackground` | `string` | — | 底部操作区域背景。 |
| `shadow` | `string` | — | CSS box-shadow 的值。 |
| `hover` | [`LeafComponentStateTokens`](#leafcomponentstatetokens) | — | 悬停状态覆盖；嵌套区域逐字段合并。 |
| `active` | [`LeafComponentStateTokens`](#leafcomponentstatetokens) | — | 按下状态覆盖；嵌套区域逐字段合并。 |
| `focus` | [`LeafComponentStateTokens`](#leafcomponentstatetokens) | — | 键盘聚焦状态覆盖；保留可见焦点轮廓。 |
| `disabled` | [`LeafComponentStateTokens`](#leafcomponentstatetokens) | — | 禁用状态覆盖；不改变禁用行为。 |

日期、时间、范围选择器复用 `DatePicker` 的输入外壳状态；包括 `picker="time"`：输入聚焦样式通过 `DatePicker.focus` 配置，面板外观通过 `DatePicker` 配置。`InputOTP` 不支持完整的四种状态覆盖。状态用于表中指定的控件区域，不会递归修改组件内部的所有子节点。

## LeafComponentStateTokens

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | `string` | — | 当前状态的文字颜色。 |
| `background` | `string` | — | 当前状态的背景。 |
| `borderColor` | `string` | — | 当前状态的边框颜色。 |
| `shadow` | `string` | — | 当前状态的 CSS box-shadow。 |
