# 组件默认参数

通过 ConfigProvider 的 `components` 设置区域内的组件默认参数。常用示例、命名规则和继承方式见[组件默认值](/components/config-provider#组件默认值)。

## 类型导入

```tsx
import type { LeafComponentDefaults } from '@ifhover/leaf-ui';

const components = {
  Button: { variant: 'outline' },
  Confirm: { confirmText: '继续', cancelText: '返回' },
} satisfies LeafComponentDefaults;
```

将该对象传给 `<ConfigProvider components={components}>`。实例参数和服务的单次调用参数仍优先于区域默认值。
