## 全局配置

| 参考 | 用途 |
| --- | --- |
| [LeafComponentDefaults](./component-defaults#leafcomponentdefaults) | 可配置的组件名称和默认参数范围。 |
| [LeafThemeTokens](./theme-tokens#leafthemetokens) | 单独覆盖主题自动生成的样式。 |
| [PopupOptions](./popup-options#popupoptions) | 选择器与浮层共用的挂载容器、位置和内容定制参数。 |
| [翻译资源](./translations) | 补充自定义语言、设置回退顺序并检查 JSON。 |

各组件自身的参数、默认值和示例仍在对应组件文档中查询。
