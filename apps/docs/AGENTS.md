# 文档站 AI 协作约定

本文件适用于 `apps/docs/`。修改文档、示例、主题或构建脚本前，必须阅读并遵守：

- [开发、版本与文档同步流程](../../DEVELOPMENT-WORKFLOW.md)：开发分支、正式版本、独立预览与清理。
- [示例编写规则](EXAMPLE-WRITING.md)：主站示例范围、布局、源码复用与验收。
- [文档站维护说明](MAINTENANCE.md)：运行、主题、导航、中英文、快照与 AI 文档。

主站面向组件使用者。示例应简短、可运行，并直接体现 Leaf UI 的默认外观；复杂业务页面留给独立 example 站点。维护说明放在本目录的源码 Markdown 中，不放入会发布并进入搜索的 `docs/`。

保留已有未提交工作。组件与使用文档变更在开发分支完成，合并与发布遵循仓库流程；报告实际执行的验证，未发布的工作不能称为已上线。
