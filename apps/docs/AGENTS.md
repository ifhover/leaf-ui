# 文档站 AI 协作约定

本文件适用于 `apps/docs/`，继承 [仓库协作约定](../../AGENTS.md)。修改文档、示例、主题或构建脚本前，必须阅读并遵守：

- [开发、版本与文档同步流程](../../DEVELOPMENT-WORKFLOW.md)：开发分支、正式版本、独立预览与清理。
- [使用文档编写规范](DOCUMENT-WRITING.md)：内容取舍、[组件页固定结构](DOCUMENT-WRITING.md#组件页固定结构)、稳定身份、API 顺序与完整内容保留。
- [示例编写规则](EXAMPLE-WRITING.md)：主站示例范围、布局、源码复用与验收。
- [文档站维护说明](MAINTENANCE.md)：运行、主题、导航、中英文、快照与 AI 文档。
- [质量验收：当前规则](../../packages/react/QUALITY.md#当前验收规则)：按影响选择检查并报告实际结果。

涉及组件外观、主题或颜色示例时，同时遵守 [设计风格](../../DESIGN-STYLE.md)、[设计标准](../../DESIGN-STANDARDS.md) 和 [颜色系统规范](../../COLOR-SYSTEM.md)，不得用站点专属 CSS 修补组件默认外观。首页、介绍页和站点描述按 [设计风格：定位](../../DESIGN-STYLE.md#定位) 的口径撰写，不宣传自由定制或展现个性。

主站面向组件使用者。示例应简短、可运行，并直接体现 Leaf UI 的默认外观；复杂业务页面留给独立 example 站点。维护说明放在本目录的源码 Markdown 中，不放入会发布并进入搜索的 `docs/`。

分支、版本、发布、预览清理和已有工作保护统一遵循根规范，不在本文件复制操作步骤。未发布的工作不能称为已上线。
